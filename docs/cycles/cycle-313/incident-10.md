# 事故報告 10: 1%未満の来訪者のために、全来訪者の体験を落とした

本報告は `git log` / `git show` / 生成HTML・本番HTMLの実測・公開統計を一次記録として書いた。
記録で裏が取れないことは書かない。内心・意図は断定しない（AP-WF27）。

## 何をしたか

サイクル開始後、ブログ一覧6ルートの**記事リンクが静的HTMLに1本も入っていない**ことを見つけ、
B-686 として起票して範囲に加えた（`54ad8abb`）。`useSearchParams` を呼ぶ一覧を包む `<Suspense>` に
**fallback を渡し**、キーワード空の一覧をサーバーで描いて静的HTMLへ載せた。

**元の `<Suspense>` には設計意図があった。** 変更前のコメントが逐語でこう書いている。

> `useSearchParams` を使う BlogFilterableList は Suspense でラップする（**Next.js 要件**）。

`useSearchParams` は静的プリレンダリング時に URL を知らないため、Next.js は Suspense で囲うことを
**要求する**。囲えばその部分だけがクライアント描画へ退避し、ビルドが通る。**fallback を渡さないのは、
キーワードの有無で変わる箇所を一度で描くための選択だった。**

## 誰のために変えたのか

**確かめていなかった。** Owner に問われて初めて調べた。

| 想定した相手          | 実際                                                                                                                                                                  |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 検索エンジン          | `sitemap.xml` が**574件すべて**を載せており、一覧を経由せず到達できる（本番実測）。Googlebot は JavaScript を実行する                                                 |
| JS 無効の来訪者       | **サポート範囲を定めた文書はリポジトリに存在しない**（`constitution.md`・`site-concept.md`・`CLAUDE.md`・`.claude/rules/` を全文検索して0件）。想定は PM が作ったもの |
| JS 有効の通常の来訪者 | 一覧は元から正常に見えていた。クライアント描画なので体験は変わらない                                                                                                  |

**JS を無効にしている人の割合**（公開統計）:

| 出所                         | 数値                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------ |
| 2024年半ばの集計             | 主要ブラウザの98%超が JS を実行。無効は0.5〜3%（ボット除外前・測定方法による） |
| Yahoo の自社トラフィック分析 | 0.25%（ブラジル）〜2%（米国）                                                  |
| 英国・2016年Q4               | 0.2%                                                                           |

**割合以前の問題がある。** このサイトの中身は診断・クイズ・道具・キーワード検索で、
**いずれも JavaScript が無ければ機能しない。** 一覧の記事リンクだけを静的HTMLに載せても、
その来訪者に提供できるものはほとんど無い。

## 何を引き換えにしたか

| 引き換えにしたもの               | 実測                                                                                                                                                                        |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ペイロードの二重化**           | 本番 `/blog` は 146,550 bytes。うち HTML 本体が 26,232 bytes、**RSC ペイロードが 88,057 bytes**。fallback と本体で同じ一覧を2回描いているため、記事カードの内容が両方に載る |
| **ハイドレーション時の差し替え** | fallback から本体へ差し替わる。**[B-696]（フォーカスが body に落ちる）はこの差し替えが原因**で、PM 自身が起票して中止した                                                   |
| **`?q=` 付きで来た人の体験**     | 検索結果を期待して開くと、**まず絞り込み前の一覧が出てから**結果へ切り替わる。変更前は待たされるかわりに正しい結果が一度で出ていた                                          |
| **保守の複雑さ**                 | fallback と本体が一致していることを守り続ける必要がある。ずれればレイアウトが跳ねる                                                                                         |

**`?q=` 付きの共有リンクから来る人は、JS 無効の人より多い可能性が高い。** 検索結果を共有できる設計に
しておきながら、その人たちの体験を落とした。

## 構造

切り換えた先に誰がいるかを確かめないまま、「記事リンク0本」という**数えやすい観察**を欠陥と断じた。

そのものである。本サイクルは同じ型を `measurements.md §6`（「0本から1本以上になった面が17」を成果として
記録）でも踏んでおり、[review-log.md](./review-log.md)（9巡目）に記録している。**同じサイクルで2度。**

`docs/anti-patterns/planning.md` の **AP-P30**（既存の仕様が原理に基づく決定か、実装の流れで偶発的に
そうなっただけかを区別する）にも当たる。**元のコメントは「Next.js 要件」と明記していた。読まずに直した。**
T11 を取り下げたときに指摘されたのと同じ型を、こちらでも踏んでいた。

## 是正

`54ad8abb` の変更を撤回し、`<Suspense>` を fallback 無しの形へ戻した（`7a5355e8`）。
`54ad8abb` より後に入った独立の改善（パンくずの一本化・型の整理・タグ href のエンコード・
行のタップ標的）は残した。**JS 無効時の検索欄の扱い（`disabled` と注記の一文）は残せない**——
静的HTMLに検索欄が出ること自体が撤回した変更の産物で、戻した後は到達しないコードになる。

`/blog` の生成HTML（`.next/server/app/blog.html`・同一手順で測り直し）。

|                 | 撤回前  | 撤回後                        |
| --------------- | ------- | ----------------------------- |
| バイト数        | 145,419 | **90,731**（-54,688・0.62倍） |
| 記事リンク      | 12本    | 0本                           |
| `type="search"` | 1       | 0                             |
| `<noscript>`    | 1       | 0                             |

本番も反映済みである（`curl https://yolos.net/blog`: 91,862 bytes・記事リンク0本・検索欄0）。

B-686 は `docs/backlog.md` の Done から【中止】へ移した——**起票そのものが誤りだった。**

**コミットメッセージの `66,448` は誤りとしてここに記録する**。文書側（本ファイル・[index.md](./index.md)・
[measurements.md](./measurements.md)・ADR007）は訂正済みである。
