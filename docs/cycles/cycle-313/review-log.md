### 記事2本の前提が間違っていた

この巡と並行して、記事の構図そのものに誤りが見つかった。2本とも「機械が黙っていた」「誰も教えてくれない」という構図で書かれていたが、**Prettier も js-yaml も Next.js も仕様どおりに動いている**。仕様どおりに動いているものに警告を求めるのは筋が通らない。

「この frontmatter は妥当か」「出力に記事が載っているか」を実際に問うた相手は、自分で書いた検証スクリプトと自分で置いたテストだけで、前者は `tags` を一度も見ていなかった。**黙っていたのではなく、見当違いの質問をしていた。** 2本とも芯をここへ移す。

なお、Prettier が壊れた frontmatter を触らないという観察自体は正しい。壊れたブロックの中に `*   md-item`、外に `*   body-item` を置いて `prettier --write` を掛けると、外は `- body-item` に整形され中は触られない（PM が実測）。区切り記号で frontmatter と認識したうえで、YAML として読めなかったので中身を置いている——「frontmatter と認識されていないだけ」ではない。ただしこれは Prettier の落ち度ではなく、**自分の側に形の検査が要る理由**として書く。

## 9巡目 道具・ゲーム面の実機確認（ゴールの納品面）

8巡目の指摘を受けて、本サイクルのゴールの半分——`related_tool_slugs` の復元が届く面——を初めて実機で見た。**判定は「出してはいけない」。**

### 数が増えた面に、役に立つものは載っていなかった

| 見たもの                         | 実測   |
| -------------------------------- | ------ |
| 欄が出る面                       | 40     |
| **載るのが告知・開発記だけの面** | **18** |
| 混ざっている面                   | 18     |
| 主題の記事だけが載る面           | 4      |

新規に欄が出る17面に載る24本のリンクを全部読んだ結果、**道具の主題を扱った記事は1本も無かった**。13面は「1本だけ」の欄になり、うち12面は同じ1本（「ツールを10個から30個に拡充しました: プログラマティックSEO戦略の実践」）である。

その記事が QRコード・ハッシュ・タイムスタンプに触れているのは、30個の道具を並べた表の1行だけだった。**「関連」の実体は、リリース告知の表に載っていることである。**

そして、この告知系4記事こそ、パーサの読み違いで `related_tool_slugs` を失っていた4記事だった（52件が一致）。**本サイクルが復元した関連ツールの宣言は、その全量がサイト自身の告知へのリンクだった。**

### 幅360では、押す前に空振りだと分からない

題は `white-space: nowrap` + `text-overflow: ellipsis` で15〜24字に切られる。打ち切りが消えるのは viewport 900px 以上。`title` 属性もツールチップも無いので全文を見る手段がない。

```
関連ブログ記事
  ツールを10個から30個に拡充…   2026-02-18
  10個のオンラインツールを2…    2026-02-14
```

**このサイトの正典は逆である。** `Shinagaki` は品名を折り返し、`nowrap` を持つのは右端メタだけで、≤720px では `min-height: 44px` を入れている。同じ題が `/tools` の一覧では全部読めて、その下の「関連ブログ記事」では読めない。

### そのほか

- `/tools/regex-tester` 1280px で、関連ブログ記事の欄（661px）が正規表現テスター本体（600px）より背が高い。`getRelatedBlogPostsForTool` は上限を持たず公開日降順を返すので、記事を書くたびに伸び続ける。
- ゲーム面のタップ標的が 38px（`DESIGN.md` §10 は 44px）。
- ゲーム面CSSの冒頭コメントが「共通の `RelatedBlogPosts` と同型」と書いているが、書体・字サイズ・padding・題に使える幅のいずれも違う。**コードが自分について嘘を書いている**（ツギハギ禁止）。

### 判断

**「記事の frontmatter に書かれた値は復元するだけで、内容の判断はしない」という本サイクルの線引きを変えた。** この線引きは「復元は中立だ」という前提で引いたもので、前提が崩れた。維持すれば、役に立たないリンクを17面に増やして出荷することになる（憲法4・CLAUDE.md の判断原則）。

判定基準は1つに決めた——**その道具／ゲームを使いに来た人が、この記事を読んで用が進むか**。進まないなら宣言から外す。迷ったら外す側に倒す。欄が消える面は是正前の状態に戻るだけで、役に立たないリンクを見せるよりよい。

組版は正典（`Shinagaki`）に合わせ、道具面とゲーム面の食い違いも解消する。件数の上限と並び順が要るかは、データ整理の結果を見てから判断する。
