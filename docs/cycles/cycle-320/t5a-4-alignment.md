# cycle-320 T5a-4 の前と後の、診断の問の画面の左端の揃い

T5a-4 の完了の条件のうち「左端の揃いを測る」の記録。測り方は `frontend-design` スキルの「目で確かめる」の左端の揃いの項（§5）に従い、診断の問の画面で、h1・進み具合の帯・問の見出し（h2）の字・区切りの罫線・選択肢の字の左端の x を、前と後の版で測って比べた。

## 測った版とブラウザ

- 前: 7b29d201（T5a-4 の前）。後: 118eb876（`src/` は 5787eaa8 と同じことを `git diff --quiet` で確かめた）。
- どちらも `git archive` で書き出し、主の木の `node_modules` をハードリンクで写して本番ビルド（`npm run build`）し、`npm start` で配信した（前はポート 3121、後は 3122）。`package-lock.json` の blob はどちらも `248519ea`。前と後は同時に置かず、1つずつビルドして測り、測り終えたらサーバーのグループを止めて（グループのプロセスが 0、ポートが空いたことを確かめた）`.next` を消した。
- ブラウザ: `/opt/pw-browsers/chromium`（`chromium-1243`、Google Chrome for Testing 153.0.8010.12）。リポジトリの `playwright` ライブラリで起動した。

## 画面・本・問

- 画面: 375×550・320×550・1280×800（既定の文字サイズ、ルートの字 16px）。character-personality は 375×550 の 200%（プロファイルの既定の文字サイズを 32px にし、どの画面でもルートの字が 32px であることを確かめた）も。
- 本: character-personality（診断）と kanji-level（知識クイズ）。
- 問: 本のすべての問（character-personality 12問、kanji-level 10問）を、表示の1つ目の選択肢を押して進みながら測った。下の表は1問目（Q1）と、選択肢が2行以上に折れる問（Q2）を載せる。
  - character-personality の Q1 は、375×550・320×550・200% で選択肢がすでに2〜5行に折れる。1280×800 ではどの問の選択肢も1行で、Q2 は h2 が2行に折れる。
  - kanji-level は、どの画面のどの問でも選択肢と h2 が1行で、選択肢が2行以上に折れる問は無い。Q2 は2問目として載せる。
- `Math.random` は、ページのスクリプトより前に走る初期化のスクリプトで種を固定した乱数（mulberry32、種 320）に替え、選択肢の並びを前と後でそろえた。前と後の全 78 画面で、h2 と選択肢の字の並び（空白を除く）が一致した。
- 「押す前」は選択肢がボタンの画面、「答えたあと」は1つ目の選択肢を押した直後の画面。診断は次の問へ移るまでの 150ms のうちに測り、全画面で h2 が同じ問のまま、選択肢がすべてボタンでない字に替わっていたことを確かめた。知識クイズは「次へ」を押す前に、正誤の字も測った。
- 字の左端は、要素の矩形でなく、要素の中の最初の空白でない字の Range の矩形の左端で測った（最初の行の左端）。箱の左端は要素の矩形の左端。罫線は選択肢の `ul`（上の罫線）と各 `li`（下の罫線）の矩形の左端。値は CSS px で、ページの左端からの x。
- Web フォントは、測る前に各要素の字を `document.fonts.load` で読み込ませて待った（Zen Antique と IBM Plex Sans は `loaded`。端末に無い `local()` の代わりの書体は `error` になるが、使われない）。

## §5 の揃い

- 前と後の全 78 画面（2本 × 画面 × すべての問 × 押す前と答えたあと）で、h1 の字・帯の字・帯を包む箱・h2 の字・罫線（`ul` と各 `li`）・面の箱が同じ縦の線（27 か 179）に並び、選択肢の字と正誤の字がその線の 8px 内側（35 か 187）から始まった。外れた画面は前も後も0。
- h2 の箱は字より 8px 左（19・171）にあり、字の箱の左への張り出しが残っている。T5a-4 で h2 を `PhrasedText` で組むようにしたあとも、字だけが 8px 右にずれることは起きていない。
- 押す前のボタンの面と答えたあとの字は、箱の x も字の x も同じで、押しても字の位置は動かない。

## 前と後の違い

左端の x は、前と後の全 78 画面で測ったすべての要素について一致し、違いは無かった。

違ったのは行数だけで、T5a-4 の区切りの変更（[t5a-4-changes.md](./t5a-4-changes.md)）による折れの位置の変化である。押す前に数えて、行数が変わった選択肢の行は 375×550 で 9（減 8・増 1）、320×550 で 11（減 10・増 1）、200% で 11（減 8・増 3）で、h2 は 320×550 の character-personality の Q3 が 3 行から 2 行になった。1280×800 と kanji-level では行数も変わらなかった。答えたあとの行数は、どの画面でも押す前と同じ。
