# cycle-320 T5a-4 の前と後の左端の揃い

T5a-4 の完了の条件のうち「左端の揃いを測る」の記録。DESIGN.md §5 の左端の揃いを確かめる、`frontend-design` スキルの「目で確かめる」の左端の項に従い、T5a-4 が変えた面の要素の箱の左端と最初の字の左端の x を、前と後の版で測って比べた。

## 測る範囲

`git diff 7b29d201 118eb876 -- src` で、T5a-4 が来訪者に見える形を変えた所は次の5つである。`src` の CSS の差分は、`page.module.css` の `:root:has(.quizPage)`（`touch-action` だけ）と `CopyButton.module.css` の注釈だけである。

- `QuizPlayPageLayout` が、`QuizContainer`（開始・問・解き終えた画面）とその下のよくある質問・共有・関連・おすすめの区画を、新しい箱 `.quizPage` で包んだ。
- `QuestionCard` が、問の見出し（h2）と選択肢の面を `PhrasedText` で、サーバーで作った区切りの並びで組むようにした。
- `CopyButton` が、押したあとの面「コピー済み」「コピー失敗」を1つの文節で組むようにした（面の字と、升の大きさを取る見えない箱の両方）。
- 区切り（`<wbr>`）の位置が変わった。[t5a-4-changes.md](./t5a-4-changes.md) の 1. のとおり、前もって描く 3,378 ページのうち変わった 298 ページは、HTML の違いが `<wbr>` の位置だけである。そのうち 266 ページ（色の辞典 250・道具 15・`/storybook`）は `CopyButton` の見えない箱の区切りで、残りの 34 ページ（`/about`・`/privacy` の h2、四字熟語 4 ページと science-thinking の結果 9 ページの h1、記事 10 ページの h1 と表のセル、道具 9 ページの h1 とよくある質問。unix-timestamp と url-encode は両方に入る）は見出しやよくある質問の問いや表のセルの区切りである。3. のとおり、要求ごとに描くページで変わったのは、よくある質問の問い3つ（character-personality・traditional-color・unexpected-compatibility）と science-thinking の結果の9ページの h1 だけである。
- 共有の画像が1枚変わった。t5a-4-changes.md の 4. のとおり、前もって描く 578 枚のうち変わったのは `/tools/unix-timestamp` の1枚だけで、名前の行が「UNIXタイム / スタンプ変換」から「UNIXタイムスタンプ / 変換」になった。

`<wbr>` は折れる所を変え、それと一緒に要素の最小の幅（min-content）も変える。ブロックの幅いっぱいに組む要素（`/about` の h2、四字熟語と science-thinking の結果の h1）は、最小の幅が変わっても箱の左端も字の x も変わらない。一方、最小の幅が並びや表の幅を決める所（flex の並びの項目、表の自動の列、中身の幅に縮む箱）では、隣や右の要素の x が動きうる。変わった所のうち、記事の h1（flex の `header` の項目）、道具の h1（flex の `div` の項目）、よくある質問の問い（flex の `summary` の中の字）、`/blog/tools-expansion-10-to-30` の道具の一覧の表のセルのリンク、`CopyButton` の見えない箱がこれに当たる。そこで、`<wbr>` が変わったページは、置かれ方によらず、次のとおりすべて前と後で測った。

- 34 ページと、要求ごとに描く traditional-color・unexpected-compatibility の2ページ（character-personality はクイズのページとして測る）。
- 色の辞典の 250 ページすべて。
- `CopyButton` を使う 22 の道具のページすべて（前もって描く HTML に `CopyButton` が出る 15 ページと、入力のあとに出る 7 ページ）。

次のものは測らない。

- **`/storybook`。** `robots: { index: false, follow: false }` の、来訪者に見せないページである。そこにある `CopyButton` は、測った 23 ページと同じ部品である。
- **15本のクイズのうち、測った2本のほかの13本。** 15本はどれも `QuizPlayPageLayout` で描く（`/play/[slug]` の14本と `/play/music-personality`）。`.quizPage` は見え方を持たない `div` で、変わったのは `QuizContainer` と下の区画の祖先が1段増えたことだけである。区画どうしは箱の中でも兄弟のまま同じ順に並ぶので、兄弟で選ぶ指定（`Section.module.css` の `.section + .section`）も前と同じにかかる。2本（診断の character-personality と知識クイズの kanji-level）で、箱と、箱の中の区画とその中身の x が前と後で変わらなければ、同じ部品を同じ祖先の下に置くほかの13本の画面（診断ごとに違う結果の画面を含む）も動かない。問の見出しと選択肢の組み方も15本で同じ部品で、診断と知識クイズの両方の形を2本で測る。

## §5 の揃い

§5 の揃いを判断したのは、クイズのページ（`QuizPlayPageLayout` の画面）である。道具のページは刷新の前の作り（刷新は T5-18）、色の辞典と `<wbr>` だけが変わったページは T5a-4 が置き方を変えていないので、ここでは判断せず、T5a-4 の根拠を前と後の一致とした。

クイズのページでは、左端の線（狭い画面で 27、1280×800 で 179）に並ぶべきもの、その内側に並ぶべきものと、線に並べないものを、DESIGN.md §5 と §7 で分けて見た。

- **線に並ぶもの。** 見出し（h1・セクションの h2・小見出し）・段落・知らせ・進み具合の帯の字と、縁の見えるもの（プライマリボタン・選択肢の面と罫線・結果のボックスとパネルの左の線）の縁と、縁の見えないもの（パンくず・関連のリンク・共有と「もう一度挑戦する」などの行の先頭のボタン・問の h2・アコーディオンの三角）の最初の字か形。クイズのページの 310 の面のすべてで、これらは線に並び、縁の見えるものの中身は縁の 8px 内側（35 か 187）から始まった。縁の見えないものの字の箱は、字より 8px 左（19 か 171）にあり、字の箱の左への張り出しが残っている。T5a-4 で問の h2 を `PhrasedText` で組むようにしたあとも、区画を `.quizPage` で包んだあとも、字だけが 8px 右にずれることは起きていない。
- **ボックスとパネルの中のもの。** 外の線ではなく、ボックスの左の線と内側の余白の内側に並ぶ（38 か 198、一覧の行の字は 46 か 206）。
- **線に並べないもの。** 次のものは、§5 の左端を揃える対象でなく、置き方が DESIGN.md の別の決まりで決まるので、外れとして数えなかった。前と後で x が一致したことは、これらも含めて確かめた。
  - 横に接して並ぶ2つ目からのコントロールとパンくずの項目（共有の「LINE でシェア」以降、パンくずの「遊び」以降）。並べる間隔は押せる範囲と押せる範囲のあいだで測る（§5）ので、先頭の項目の字の箱の右に続く。
  - 1280×800 の一覧の行の種別・補助情報。`45rem` 以上の画面では行の右に置く（§7）。狭い画面では題の下に落ち、題と同じ 46 に並ぶ。
  - 進み具合の帯の枠。帯の字「1/…」が線に並び、枠はその右に続く。
  - 読みものの箇条書きの点。§5 は点の位置を決めておらず、項目の字は 24px の字下げの中から始まる。T5a-4 は箇条書きに触れていない。
- 押す前のボタンの面と答えたあとの字は、箱の x も字の x も同じで、押しても字の位置は動かない。
