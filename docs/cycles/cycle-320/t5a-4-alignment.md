### CopyButton の押したあとの面

クイズのページの「結果をコピー」「URLをコピー」は共有のボタン（`ShareButtons`）で、`CopyButton` ではない。押しても面の字は変わらず、共有の行の下に「コピーしました」が出る（上の表）。`CopyButton` は道具・色の辞典などが描くので、それを描く次の 13 のページで、表示されて押せる `CopyButton` を1ページに3つまで、4つの画面のそれぞれで押す前と押したあと（「コピー済み」）に測った。あわせて 17 個 × 4 画面 = 68。

- 測ったページ: `/tools/` の base64・business-email・dummy-text・fullwidth-converter・html-entity・kana-converter・line-break-remover・markdown-preview・password-generator・text-replace・unix-timestamp・url-encode と、`/dictionary/colors/ikkonzome`。開いたときに押せるボタンが無いページは、最初の入力欄に「テスト abc 123」を入れてから測った。
- 測らなかったページ: color-converter・cron-parser・hash-generator・json-formatter・traditional-color-palette は、開いたときも、その字を入れたあとも `CopyButton` が出なかった。csv-converter・number-base-converter・sql-formatter・yaml-formatter は、その字ではボタンが押せない（無効）ままだった。測った 68 個に、右に寄せるもの・左に寄せるもの、プライマリとそうでないものがどちらも入っている。
- 測ったもの: ボタンを置く升（`.copy`）の左端と幅と高さ、ボタンの箱の左端、面の最初の字の左端、面の行数、升を置いた行の左端と高さと、行の中のほかの要素の左端と最初の字の左端。

## §5 の揃い

- クイズのページでは、前と後の 232 の面と、共有のコピーを押したあとの 16 の面のすべてで、見出し（h1・セクションの h2・小見出し）・段落・知らせ・進み具合の帯の字と、縁の見えるもの（プライマリボタン・選択肢の面と罫線・結果のボックスとパネルの左の線）の縁と、縁の見えないもの（パンくず・関連のリンク・共有と「もう一度挑戦する」などのボタン・問の h2・アコーディオンの三角）の最初の字か形が、同じ縦の線（27 か 179）に並んだ。縁の見えるものの中身は、縁の 8px 内側（35 か 187）から始まった。外れた面は前も後も0。
- 縁の見えないものの字の箱は、字より 8px 左（19・171）にあり、字の箱の左への張り出しが残っている。T5a-4 で問の h2 を `PhrasedText` で組むようにしたあとも、新しい箱 `.quizPage` で区画を包んだあとも、字だけが 8px 右にずれることは起きていない。
- ボックスとパネルの中は、その左の線と内側の余白の内側に、中の見出し・字・一覧の行の縁がそろって並ぶ（38 か 198、一覧の行の字は 46 か 206）。
- 押す前のボタンの面と答えたあとの字は、箱の x も字の x も同じで、押しても字の位置は動かない。
- `CopyButton` は、左に寄せるものは押しても箱も字も動かず、右に寄せるものは升の右端に寄ったまま面の字の長さだけ左に伸び、升とまわりの並びは動かない。

## 前と後の違い

左端の x は、前と後で、クイズのページの 248 の面の 17,376 個の要素とアコーディオンの三角、`CopyButton` の 68 個のすべてで一致し、違いは無かった。

違ったのは行数（と、それによる縦の位置）だけで、T5a-4 の区切りの変更（[t5a-4-changes.md](./t5a-4-changes.md)）による折れの位置の変化である。

- クイズの問の画面: 押す前に数えて、行数が変わった選択肢の行は 375×550 で 9（減 8・増 1）、320×550 で 11（減 10・増 1）、200% で 11（減 8・増 3）で、h2 は 320×550 の character-personality の Q3 が 3 行から 2 行になった。1280×800 と kanji-level（200% を含む）では行数も変わらなかった。答えたあとの行数は、どの画面でも押す前と同じ。
- `CopyButton` を描くページ: 320×550 の unix-timestamp で、h1「UNIXタイムスタンプ変換」が 2 行から 3 行（「UNIX / タイムスタンプ / 変換」）になり、その下の区画が 42px 下に移った。`CopyButton` とその行の x は変わらない。
