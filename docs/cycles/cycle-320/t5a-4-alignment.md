# cycle-320 T5a-4 の前と後の、クイズのページと CopyButton の左端の揃い

T5a-4 の完了の条件のうち「左端の揃いを測る」の記録。測り方は `frontend-design` スキルの「目で確かめる」の左端の揃いの項（§5）に従い、T5a-4 が変えた面の要素の箱の左端と最初の字の左端の x を、前と後の版で測って比べた。

## 測る範囲

`git diff 7b29d201 118eb876 -- src` で、T5a-4 が来訪者に見える形を変えた所は次の3つである。

- `QuizPlayPageLayout` が、`QuizContainer`（開始・問・解き終えた画面）とその下のよくある質問・共有・関連・おすすめの区画を、新しい箱 `.quizPage` で包んだ。
- `QuestionCard` が、問の見出し（h2）と選択肢の面を `PhrasedText` で、サーバーで作った区切りの並びで組むようにした。
- `CopyButton` が、押したあとの面「コピー済み」「コピー失敗」を1つの文節で組むようにした（面の字と、升の大きさを取る見えない箱の両方）。

これらの面を測り、次のものは測らない。

- **区切り（`<wbr>`）だけが変わったページ。** [t5a-4-changes.md](./t5a-4-changes.md) の 1. のとおり、前もって描く 3,378 ページのうち変わった 298 ページは、HTML の違いが `<wbr>` の位置だけである（そのうち `CopyButton` を描く 266 ページは、上の3つ目として測る。色の辞典の 250 ページはどれも同じ `ColorDetail` が同じ表の行に `CopyButton` を置くので、1ページで測る）。3. のとおり、要求ごとに描く 206 ページでも、違いはよくある質問の問い3つと science-thinking の結果のページ9つの h1 の区切りだけである。`src` の CSS の差分は、`page.module.css` の `:root:has(.quizPage)`（`touch-action` だけ）と `CopyButton.module.css` の注釈だけで、どのページの要素の置き方も変わっていない。`<wbr>` が変えるのは行の折れる所だけで、どの行も同じ左端から始まるので、行の数と縦の位置は変わりえても、箱の左端も最初の字の x も変わりえない（行の変わり方は t5a-4-changes.md の 5. にある）。
- **15本のクイズのうち、測った2本のほかの13本。** 15本はどれも `QuizPlayPageLayout` で描く（`/play/[slug]` の14本と `/play/music-personality`）。`.quizPage` は見え方を持たない `div` で、変わったのは `QuizContainer` と下の区画の祖先が1段増えたことだけである。区画どうしは箱の中でも兄弟のまま同じ順に並ぶので、兄弟で選ぶ指定（`Section.module.css` の `.section + .section`）も前と同じにかかる。2本（診断の character-personality と知識クイズの kanji-level）で、箱と、箱の中の区画とその中身の x が前と後で変わらなければ、同じ部品を同じ祖先の下に置くほかの13本の画面（診断ごとに違う結果の画面を含む）も動かない。問の見出しと選択肢の組み方も15本で同じ部品で、診断と知識クイズの両方の形を2本で測る。

## §5 の揃い

左端の線（狭い画面で 27、1280×800 で 179）に並ぶべきもの、その内側に並ぶべきものと、線に並べないものを、DESIGN.md §5 と §7 で分けて見た。

- **線に並ぶもの。** 見出し（h1・セクションの h2・小見出し）・段落・知らせ・進み具合の帯の字と、縁の見えるもの（プライマリボタン・選択肢の面と罫線・結果のボックスとパネルの左の線）の縁と、縁の見えないもの（パンくず・関連のリンク・共有と「もう一度挑戦する」などの行の先頭のボタン・問の h2・アコーディオンの三角）の最初の字か形。クイズのページの 310 の面のすべてで、これらは線に並び、縁の見えるものの中身は縁の 8px 内側（35 か 187）から始まった。縁の見えないものの字の箱は、字より 8px 左（19 か 171）にあり、字の箱の左への張り出しが残っている。T5a-4 で問の h2 を `PhrasedText` で組むようにしたあとも、区画を `.quizPage` で包んだあとも、字だけが 8px 右にずれることは起きていない。
- **ボックスとパネルの中のもの。** 外の線ではなく、ボックスの左の線と内側の余白の内側に並ぶ（38 か 198、一覧の行の字は 46 か 206）。
- **線に並べないもの。** 次のものは、§5 の左端を揃える対象でなく、置き方が DESIGN.md の別の決まりで決まるので、外れとして数えなかった。前と後で x が一致したことは、これらも含めて確かめた。
  - 横に接して並ぶ2つ目からのコントロールとパンくずの項目（共有の「LINE でシェア」以降、パンくずの「遊び」以降）。並べる間隔は押せる範囲と押せる範囲のあいだで測る（§5）ので、先頭の項目の字の箱の右に続く。
  - 1280×800 の一覧の行の種別・補助情報。`45rem` 以上の画面では行の右に置く（§7）。狭い画面では題の下に落ち、題と同じ 46 に並ぶ。
  - 進み具合の帯の枠。帯の字「1/…」が線に並び、枠はその右に続く。
  - 右に寄せる `CopyButton` と、道具の行の中でラベルの右に続く値。ラベルや値と同じ行の右端に置く部品（`align="end"`）で、左端の線に並べるものでない。左に寄せる `CopyButton` は、字の箱が 8px 左に張り出し、字がその行のラベルと同じ x（375×550 で 51、320×550 の 200% で 63）に並ぶ。
  - 読みものの箇条書きの点。§5 は点の位置を決めておらず、項目の字は 24px の字下げの中から始まる。T5a-4 は箇条書きに触れていない。
- 押す前のボタンの面と答えたあとの字は、箱の x も字の x も同じで、押しても字の位置は動かない。

外れた面は、前も後も0だった。

## 前と後の違い

左端の x は、前と後で、クイズのページの 310 の面の要素とアコーディオンの三角、`CopyButton` の 205 個の3つの面のすべてで一致し、違いは無かった。

違ったのは行数（と、それによる縦の位置）だけで、T5a-4 の区切りの変更（[t5a-4-changes.md](./t5a-4-changes.md)）による折れの位置の変化である。

- クイズの問の画面: 押す前に数えて、行数が変わった選択肢の行は、375×550 で 9（減 8・増 1）、320×550 で 11（減 10・増 1）、375×550 の 200% で 11（減 8・増 3）、320×550 の 200% で 19（減 4・増 15）。h2 は、320×550 の character-personality の Q3 が 3 行から 2 行に、320×550 の 200% の Q3 が 4 行から 5 行になった。1280×800 と kanji-level（200% を含む）では行数も変わらなかった。答えたあとの行数は、どの画面でも押す前と同じ。
- `CopyButton` を描くページ: 320×550 の unix-timestamp で、h1「UNIXタイムスタンプ変換」が 2 行から 3 行（「UNIX / タイムスタンプ / 変換」）になり、その下の区画が 42px 下に移った。`CopyButton` とその行の x は変わらない。password-generator は、値が `crypto.getRandomValues` で毎回変わるので、320×550 の 200% で値の行数と行の高さが測るたびに違ったが、x は前と後で同じだった。
