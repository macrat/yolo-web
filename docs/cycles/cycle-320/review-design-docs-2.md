## 決めごとやふるまいが変わる指摘

### 指摘1: 守りの合否と「空振りでないことの対」に、守りを試した回の決め方が無い。A″ の着地のもとでは、多くの回で何も試さないまま合格になるか、満たせない

場所: t5a-design.md 6章 条件7 の「窓の守りの回」「D5 の2打目をずらす走査」の窓の中の合否、「空振りでないことの対」（decision-landing.md の「測りの合否」も同じ文）。

- 結果は押しのあとの状態（答え・移動・開閉・フォーカス）で数えると決めている。2打目の押し下げが押せるものの上に無ければ、受けても受けなくても押しのあとの状態は同じになる。
- 「窓の守りの回」は、1打目と同じ点に2打目を押す。A″ は、16 以上の送りがあれば、その点を第1の組・第2の組から 16px 以上離した所に着地させる。「はじめる」と結果への切り替わりでは、2打目の点の多くは押せるものの上に来ない。そうした回は、守りが無くても、範囲を誤って作っても「外れた件 0」になる。守りを実ブラウザで試せるのは、16 以上の送りが無い回（375×550 の character-personality、200% の12本など）と、点が押せるものに着いた回だけである。どれだけ試せたかを数える決まりも無い。連続の押しの守りの「タッチ（受けない側）」には「2打目の押し下げが次の問の上に落ちた回」に絞る決まりと「12本のそれぞれに1回以上要る」決まりがあるが、窓の守りの回には無い。
- D5 の窓の中の「120px のずれで受けること」も同じである。120px ずらした点が押せるものの上に無ければ、受けたかを押しのあとの状態から読めない。「80px 以下で受けない」も、押せるものの上に無ければ何も試していない。
- 「空振りでないことの対」の「同じ点を起点から 900ms のあとに押すと答えが入る・リンクが開く・ボタンが働く」は、同じ理由で、A″ が点を押せるものから離した回では満たせない（何も起きない）。対象の回を決めていないので、測りの担当は、外れた件と数えるか、数えないかを決められない。

直し方: decision-landing.md の「測りの合否」と t5a-design.md 6章 条件7 に、合否を数える回を「2打目の `pointerdown` の的が押せるもの（`reveal.ts` の集め方で `closest` したもの）の上にあった回」と決めて書く。窓の守りの回・D5 の窓の中の 80px と 120px のずれ・空振りでないことの対のそれぞれについて、試した回の数を記録する。試した回の下限（切り替わりごと、ずれの向きごとに1回以上など。満たせない組は PM に報告する）も決める。押せるものの上に無かった回は、試していない回として数だけ記録する。空振りでないことの対の「同じ点」は、試した回の点（2打目が押せるものに落ちた点）に限るか、押せるものの上の点を選び直して押す形にするかを決める。決めた数え方は、t5a-measure.md 0章の「落ちた先」の記録と、plan-t5a7.md 3 の押しごとの記録に置く件（押しごとに置く回の並び）にも反映する。

### 指摘2: D9（B-623）の「窓の中の2打目が開閉を起こした件 0」が、D5 の窓の中の 120px のずれ（受けるのが正しい押し）とぶつかる

場所: plan-t5a7.md 4 の「B-623」の箇条（「条件7 と D5 の走査のそれぞれで、『次へ』のあとの窓の中の2打目が答え・ページの移動・開閉を起こした件が 0 かを記録する」）、t5a-design.md 8章の表の D9 の行（「(ii) 6章 条件7 と D5 の走査で、窓の中の2打目が答え・移動・開閉を起こした件が 0」）。

D5 の窓の中の走査は、知識クイズの「次へ」→次の問でも、300ms に 120px ずらした2打目を押し、その押しを「受けること」を合否に入れる。120px ずらした点が次の問の選択肢か FAQ の `summary` に落ちれば、正しい作りではその押しは答えを入れるか開閉する。それは D9 の「窓の中の2打目が答え・移動・開閉を起こした件 0」では外れになる。2つの合否が同じ回に反対の答えを求めるので、B-623 を閉じる値が決まらない。

直し方: plan-t5a7.md 4 と8章の D9 の行の対象を「窓の中で、1打目の点から 100px 以下の2打目」（D5 では 80px 以下のずれと基本のずれ）に絞る。120px のずれの回は D9 に入れない、と書く。
