## 指摘

### 指摘1（重大）: 入れる語の基準が、起点の語そのものに当てると食い違い、迷わず使えない

スキルの「入れる語」は、入れないものを「そこで折れても2つの語として読めるもの（「一度|決めた」「普段|会えない」「ネット|サーフィン」）」とする。ところが起点の語の多くもこれに当たる。「今日／一日」は「今日」と「一日」、「自分／自身」は「自分」と「自身」、「古今／東西」は「古今」と「東西」の、どれも2つの語として読める。逆に「ネットサーフィン」は「今日一日」よりも1つの語（国語辞典の見出しにもなる外来の複合語）に近い。文のとおりに当てると「今日一日」は入らず「ネットサーフィン」は入らない、あるいはどちらも入る、と読む人で答えが分かれる。

挙げた3つの例も、性質の違うものが混ざっている。「一度|決めた」「普段|会えない」は文節の切れ目（「一度ね、決めた」と言える）で、「ネット|サーフィン」は1つの名詞の中の切れ目である。§4 はもともと、名詞の中の語の切れ目（「思考／バイアスと」「マルチ／エージェント」）を、6字を超える文節に限って折り所にしている。基準は、この §4 の決まりとの境を書いていない。

基準があいまいなままだと、足す人ごとに入れる・入れないが割れ、一覧は「その時に気になった折れ」の表になる。AP-I02 の歯止め（文ごとの表にしない）はあるが、語ごとの表がむやみに伸びる歯止めにはならない。

直す向き: 人が読んで同じ答えになる見分け方にする。たとえば次のように、語の型を挙げて決める。

- 1字の接頭辞・接尾辞が付いた語（「超／能力」）。切れ端の1字が語として読めない。
- 4字の決まった言い回しと四字熟語（「自分自身」「古今東西」「一日一善」「唯々諾々」）。
- 原語が1語の外来語を、辞書が2つの語に刻んだもの（下の指摘2 の「フレーム／ワーク」「ワーク／フロー」「アップ／ロード」「タイム／スタンプ」）。
- 文節の中の切れ目かどうかを「ね」を入れて言えるかで見る、などの検査を添え、「今日一日を」（「今日ね、一日をね」とは言わない）のように、6字以下の文節の中に BudouX の境目が落ちたものをどう扱うかを書く。

「ネット|サーフィン」を入れない例に残すなら、上の型のどれに当たらないかが読めるようにする。挙げ方は builder が決めてよいが、起点の5つと第1回の約50か所に当てて、同じ答えになることを確かめてから書く。

### 指摘3（中）: 「足す人」の起点になる読み方が、測り方の手順に無い。読むのが「折れた所」だけでは足りない

「足す人と足し方」は、測る人が「漢字か片仮名どうしが接する `<wbr>` の所で折れた所を読み」語を足すとする。ところがスキルの「見出しとコントロールの名前の折り方を測る」の手順は、`<wbr>` の所の折れをすべて「折り所での折れ」に数え、それを読む段を持たない。手順どおりに測る人は、この読みをしないで終わる（第1回の指摘4。t5a-design 6章 条件8 もまだ直っていない）。決まりが、それを動かす手順を持たない形になっている。

もう1つ、読むのが「折れた所」だけだと、測った画面（320・375・200%）で折れなかった語の中の `<wbr>` は残る。§4 とスキルの5は「`<wbr>` には優先の順が無く、行の終わりに来れば使われる」としており、ほかの幅（360・390・タブレット）では折れる。

直す向き: 測り方の手順に「要素の中の、漢字か片仮名どうしが接する `<wbr>` を（折れたかどうかによらず）挙げて読み、辞書の補いの基準に当たる語の中なら語を足す」段を足し、「足す人」はその段を指す形にする。t5a-design 6章 条件8 にも同じ段を入れる（第1回 指摘4 の PM の受け持ちと合わせ、書く人をはっきりさせる）。

### 指摘4（中）: 足したあとの確かめが、要求ごとに描く診断のページを外す。T5a-4 の完了の条件にも全ページの比べが無い

「足したあとは、前もって描くページの HTML を足す前と比べ」とあるが、診断と知識クイズの問の画面は要求ごとに描く（第1回で確かめた）。今回の起点の語が効くページそのものが、この比べに入らない。データから区切りを作る所はほかにもありうる。

また第1回の推奨4（直したあとに全ページの HTML を前後で比べ、変わった見出しをすべて挙げる）は、t5a-design の 6章（条件8）にも 7章の T5a-4 の行にも入っていない。スキルの一般の決まりだけでは、T5a-4 の完了で何を確かめるかが読めない。

直す向き: 確かめに、要求ごとに描くページの文（診断のデータの全問の見出しと選択肢。`splitIntoPhrases` の出力を前後で比べればよい）を加える。T5a-4 の完了の条件に、前もって描く全ページの比べと診断のデータの比べを書き、変わったものを挙げて語を割らなくなったことを確かめる、と書く。

### 指摘5（軽）: 語ごとの試験を語だけで書くと、文の中での刻み方の違いを見落とす

`Intl.Segmenter` の刻み方は前後の字で変わる。Node 22.23 で「今日一日中」は「今日|一日中」で、「今日一日」の一覧の語とはつながりが合わず、補いが効かない。「超能力者」は「超|能力|者」で、補いのあとも「超能力|者」の境目が残る。「足し方」の試験は「語ごとに」とだけあり、語だけを渡して試すと通ってしまう。

直す向き: 試験には、語を見つけた文（またはその文節）を渡して、補いのあとにその語が1つの語になることを書く、とする。つながりが合わずに効かない形（前後の字に語が取られる）がありうることと、そのときは見つけた形のほうを語に入れるのか、を1文で書く。

### 指摘6（軽）: 言い方のずれ

- 実装の技術の4は「5の語（辞書の補いの語を含む）の中でもない所」と書くが、補いの項は「`isInsideWord`（1と4で…）は `wordsOf` の語を使う」と書く。5の語は片仮名の続きを組み直した語（`wordStartsOf`）、`isInsideWord` が見るのは `wordsOf` の語で、指すものが違う。字の種類の変わり目の位置では結果が同じになるが、文としては「語の辞書の語（補いの語を含む）の中」にそろえる。
- 測り方の2の括弧の中の「辞書の補いの語の中と、片仮名の続きの中の語に組み直した頭でない所は含めないので」は、「片仮名の続きの中の」がどこに掛かるかを読み分けにくい。「辞書の補いの語の中と、片仮名の続きの中で語に組み直した頭でない所は、語の切れ目に含めない」のように切る。

### 参考（第2段のコードで見ること）

- 補いの語が字の種類をまたぐとき（漢字と片仮名を含む語）、`wordStartsOf` の片仮名の続きの処理は、続きの中に収まる語だけを見る（`word.start >= run && word.end <= end`）。つないだ語が続きの外から始まると、続きの中の語の頭がすべて消えうる。またぐ語を入れるなら試験を置く。
