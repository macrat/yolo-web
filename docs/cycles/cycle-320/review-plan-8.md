## 指摘

### 1. 刻みを粗くするときに、character-personality と cycle-319 で件の出た kanji-level の「もう一度挑戦する」が、守るものから無言で落ちた（中）

前の版の「削らないもの」には、375×550 のタッチに並んで、character-personality（閲覧の 85.8%）と、cycle-319 のキャリーオーバーの「もう一度挑戦する」の kanji-level の 375×550 と 1280×800 があった。後者は review-plan-5.md の指摘2 が「(b) が送るのは件の出た画面」「重みを本ごとに見ていない（AP-P33）」として足させたものである。今回の書き換えで、粗くしないものは「375×550 のタッチ」だけになり、2つとも理由なく消えた（AP-WF41: 改稿のついでに前版の守りを無言で消す）。

送る道を外したので「送らない」ための列挙は要らなくなったが、刻みを粗くする道には、この2つはそのまま掛かる。いまの文では、character-personality の 1280×800 や 375×800・320×550 の「もう一度挑戦する」と、件が既に出た kanji-level の 1280×800（`scrollY` 236 でパンくずと `h1` が画面の外に出た件）が、粗い刻みで測られうる。どちらも、15本の1本・6画面の1つなので、24px のまま残しても時間はほとんど増えない。

直し方の例: 粗くする項に「375×550 のタッチ、character-personality の全画面と全入力、cycle-319 で件の出た kanji-level の 375×550 と 1280×800 は、設計の刻みのまま残す」と書く。

### 2. 走査の中で印を付けて外した押しが、5-2 の「確かめ」と合否のどちらに入るかが書かれておらず、担当が止まる（中）

plan-t5a7.md 4 の「間隔」は、走査の中で境を越えた押し（診断の答え・知識クイズの答えと「次へ」）に「印を付けて数から外し、走査は続ける」とした。一方、t5a-measure.md 5-2 の「確かめ」は、離れなかった走査ごとに「1打目で答えた問の数＋X＋S＝その本の問の数」を見て、等しくない走査は「数えずに…同じ条件で走査をやり直す」「やり直しても等しくないときは…数え方を直してから全ての走査を数え直す」と定める。外した押しの2打目が次の問に答えを入れていたとき、それを X から外すと、この式は等しくならず、担当は 5-2 の文に従って走査をやり直すことになる。「走査は続ける」と食い違い、5-2 の文のとおりに進めると、担当はどちらに従うかで迷う。

また「数から外す」が条件7 の合否（第1の組に落ちた件が 0）にも掛かるのかが読めない。90ms の指定で実際が 160ms になった押しでも、2打目が `summary` やリンクに落ちたなら、来訪者に起こりうる件である。合否から外せば、件を見落としたまま T5a-8 を閉じうる。1回で終わる操作の「数えずに送り直す」回も同じで、捨てた回に第1の組の落ち先があったときの扱いが無い。

直し方の例: 「外すのは、90ms と 300ms の間隔ごとの数（見せる 150ms の内と外の比べ・B-620 の間隔ごとの数）からだけにする。5-2 の確かめの X・S と、第1の組の落ち先の記録には入れる。送り直した回・外した押しで第1の組に落ちたものは、件として 5 の判断に渡す」のように、外す先と残す先を書き分ける。

### 3. 「次のどちらかを選び」が、2つを合わせる道を閉じて読める（軽）

刻みを下限まで粗くしても合計が大きいときは、粗くしたうえで数日に分けるしかない。「どちらか」と書くと、2つは排他に読める。「次の一方か両方を選び」とするか、粗くしても足りないときは数日に分けると1文足す。

### 4. 「答えと『次へ』（5-2）…ほぼすべての画面で」が 5-2 の表と合わない所がある（軽）

5-2 では、知識クイズの答えの2打目は全画面で押せない字に落ち（1,440/1,440）、「次へ」の `summary` は 1280×800 で 0/216 である。理由の結びには影響しないが、5章の数を引く文なので、「知識クイズの答えを除き」などと限る。

### 5. 44px の下限の理由は、点ごとに着地が変わる変更後の版では必要な条件にとどまる（軽）

「それより粗くすると押せるものを1点も踏まずに通り過ぎうる」は、押したあとのページの組みが点によらず同じときの理屈である。変更後の版は「もう一度挑戦する」のあとに着地の関数（4-9）が点ごとに送りを選ぶので、避けられない点の帯は押せるものの高さより狭くなりうる。44px 以下なら踏み落としが無い、とは言えない。粗くする決定の文に、「下限は踏み落としを防ぐ必要な条件で、狭い帯を見落としうることは受け入れる」と書くか、粗くした画面は位置を半刻みずらした列で測るなどの手当てを書く。

### 6. 刻みを粗くするときの t5a-design.md の直しを誰が書くかが無い（軽）

plan-t5a7.md 6 では設計の文の直しを builder（担当の木）が書くが、3 の「t5a-design.md 6章 条件7 の文の直し方とともにこのレビューに通す」は書き手を書いていない。3 の決定の段で PM が書くのか、builder に頼むのかを書く。
