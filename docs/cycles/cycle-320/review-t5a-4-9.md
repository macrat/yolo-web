## 指摘

### 指摘1（中）: 条件8 の比べの外で、要求ごとに描く見出しの区切りが変わり、200% で悪くなった

2つの比べの外で、よくある質問の問い（アコーディオンのラベル）2つの区切りが変わっている。どちらのページも要求ごとに描くので、前もって描く HTML に入らず、問と選択肢の比べにも入らない。

| ページ                           | 前（7b29d201）                                   | 後                                             |
| -------------------------------- | ------------------------------------------------ | ---------------------------------------------- |
| `/play/traditional-color`        | もう\|一度やり直して\|違う\|色が\|出ますか？     | もう一度やり直して\|違う\|色が\|出ますか？     |
| `/play/unexpected-compatibility` | もう\|一度やり直すと\|同じ\|結果に\|なりますか？ | もう一度やり直すと\|同じ\|結果に\|なりますか？ |

変わった理由は、最初の文節の字の種類の変わり目（実装の技術の4）が語の中に置かれなくなったことである。辞書は「もう一度」を漢字を含む1つの語とする。

測った行は次のとおり。

- 320・375 の既定と 375 の 200% では、前と後で同じ。
- 320 の 200% では、前は「もう / 一度やり直して / 違う色が / 出ますか？」と語の切れ目で折れていた。後は「もう一度やり直 / して違う色が / 出ますか？」で、動詞の中（「やり直／して」「やり直／すと」）で折れる。

条件8 は「変わった見出しと名前をすべて挙げ」「4-10 に挙げた語と並びのほかで区切りが変わっていれば、読んで 4-10 に足す」と決めている。この2つは挙げられておらず、読まれてもいない。

**直し方**:

- 比べを、要求ごとに描くページで `splitIntoPhrases` を通る文の全体に広げる。`/play/<slug>` の題・よくある質問の問い・読みものの小見出し・結果のページの見出し（`/play/[slug]/result/[resultId]` の小見出し、相性の名前、character-fortune の小見出し）・`/play/daily`・`/play/nakamawake` などである。変わったものをすべて挙げる。

- 6章 条件8 の比べの範囲の文も、この範囲に合わせて直す（planner）。
