## 指摘

### 指摘1（高）: 寄る範囲を「点からの距離 10〜16px」と書いているが、面は正方形で、届くのは縦と横のそれぞれが半辺の内である

§8 の「面の大きさ」は「寄るのは点から面の半径まで」「10〜16 CSS px」、二度押しの箇条は「点から約 10px の所までしか寄らない」「点から約 16px の所に押せるものがあれば寄りうる」と書く。ソースでは、面は点を中心にした一辺 20〜32 の正方形で、要素の矩形がこの正方形と交われば候補になる（event_handler.cc の矩形の当たりの判定と `SnapTo` の `bounds.Intersects(touch_area)`）。届くかどうかは「縦の隔たりと横の隔たりの大きいほうが半辺（10〜16px）より小さいか」で決まり、斜めには点からの直線の距離で約 14px（最小の面）・約 22.6px（最大の面）まで届く。

この節は「点から押せるものまでのいちばん近い距離も記録する」と勧め、plan-t5a7.md 3 の「タッチの調整の距離」は、この距離と「調整の届く幅」を突き合わせて避けられたかを数え直すと決めている。直線の距離を 10・16 と比べると、たとえば縦にも横にも 9px 離れた選択肢（直線で約 12.7px）を、道具の押しでも寄る所なのに「最小の面では届かない」と数え誤る。判断の段の数を直接狂わせる書き方なので重い。

直し方の例: 「面は点を中心にした一辺 20〜32 dip の正方形で、要素の矩形がその中に入れば候補になる。縦と横の隔たりの大きいほうが半辺（つまみで拡大していなければ 10〜16 CSS px）より小さければ届き、斜めには直線の距離で約 14〜22.6px まで届く」とし、記録する距離も「縦と横の隔たりの大きいほう」（または縦と横の隔たりの2つ）と書く。PM は、plan-t5a7.md 3 と道具の `distanceToNearest` の定義が直線の距離になっていないかを確かめ、なっていれば合わせて直させる（このレビューの範囲の外だが、同じ誤りが判断に入る）。

### 指摘2（中）: 「選び方」の点数の説明が、ソースと向きが逆になっている

「要素の矩形の点からの近さ（いちばん近い所までの距離の2乗を、面の半径の2乗で割ったもの）と、面との重なりの割合を足した点数が、いちばん小さいもの」とある。ソースで足すのは「1 −（重なる面積 ÷ 重なりうる最大の面積）」、つまり**重ならない割合**で、重なりの割合をそのまま足して小さいほうを選ぶと、重ならないものほど選ばれることになり、逆の意味に読める。また割る数は `0.25 * (幅² + 高さ²)`、正方形の半分の対角線の2乗で、「面の半径」は正方形の面ではどこを指すかが決まらない。

直し方の例: 「点から矩形のいちばん近い所までの距離の2乗を、面の半分の対角線の2乗で割った値と、1 から『面と重なる面積 ÷ 重なりうる最大の面積』を引いた値を足し、いちばん小さいものを選ぶ。点の真下の押せるものは、ふつう両方が 0 になって選ばれる」。

### 指摘3（中）: 冒頭の第1段落を節の番号の範囲でサイクルに割り当てたため、T5a-7 の書き直しと食い違う

冒頭は「§1〜§7 は cycle-301 で、§8 は cycle-320 で得たもの」「§1〜§7 の実測の既定の条件は…」と書き換えた。一方、t5a-design.md 5章（cycle-316）は、T5a-7 がこの段落を「cycle-301 と cycle-316（T5a）で得たもの」と直し、T5a-7 の測りの知見を**該当する節に書き入れる**（§4 など）と決めており、React の知見も「新しい節」に足す。cycle-319/index.md のキャリーオーバーも「第1段落の『すべて cycle-301 で得たもの』を直す」を T5a-7 の残りに数えている。

このままだと、(i) T5a-7 が 5章の文のとおりに書けば §8 の cycle-320 が落ち、(ii) §4 などに T5a の知見が入った時点で「§1〜§7 は cycle-301」が事実と合わなくなり、(iii) T5a-7 の仕事のうち「第1段落を直す」が先に半分済んだことがどこにも書かれていない。

直し方の例: 冒頭は節の番号に頼らず「cycle-301（B-620…）と cycle-320（…）で得たもの。どのサイクルで得たかと測った条件は各節の根拠に書く。cycle-301 で得た節の実測の既定の条件は…」の形にし、後から節が増えても書き換えずに済むようにする。あわせて PM は、cycle-320 の index.md（またはキャリーオーバー）に「冒頭の第1段落は cycle-320 で §8 を足すときに直した。React の知見の節は §9 以降になる。5章の『cycle-301 と cycle-316（T5a）で得たもの』は cycle-320 を含めた形で書く」を残し、T5a-7 の担当が 5章の文をそのまま写さないようにする。

### 指摘4（中）: §8 の勧めが、このサイクルの計画の決定と食い違って読める

§8 は「端末に近い面で測るときは、`radiusX`・`radiusY` に 16 を渡した押しを並べる」と、面の大きさを変えた回を足す形だけを勧める。plan-t5a7.md 3 は、面の大きさを変えた回を足さず、距離の記録と届く幅の突き合わせで代えると決めた。knowledge は先々の測りへの一般の知見なので、両方のやり方を並べ、どちらを選ぶかの物差しを書くほうが読む人は迷わない。いまの形では、次のサイクルの担当が knowledge を読んで「計画が knowledge の勧めに反している」と取るか、計画にない回を足しうる。

直し方の例: 「端末での落ち先を見積もるには2つの形がある。(a) どの回でも、点から押せるものまでの縦と横の隔たり（指摘1）を記録し、最小の面（半辺 10px）と最大の面（半辺 16px）の届く範囲と突き合わせる。測りの量は増えない。(b) `radiusX`・`radiusY` に 16 を渡した押しを並べ、最大の面での落ち先をじかに見る。測りの量が倍になる。(a) で判断が決まるときは (a) を使い、(b) は (a) の境目の件を確かめるときに使う」。

### 指摘5（中）: §8 の実測の根拠に、測ったブラウザの版と条件が無い

同じ直しで playwright-mcp.md は「測る前に版を確かめ、測りの記録に書く」、browser-layout-and-scrolling.md の冒頭は「測ったブラウザとその版も根拠に書く」と決めた。§8 の根拠は「1280×800 の kanji-level と impossible-advice で…6px、16・24 で 9px 寄った」とだけ書き、ブラウザの版（review-t5a-7a-1.md の時点の `/opt/pw-browsers/chromium`、153.0.8010.12 か）・本番ビルドか・`hasTouch` などの文脈の条件が無い。冒頭の既定の条件は「§1〜§7 の」に限ったので、§8 には既定も掛からない。同じコミットで決めた書き方に、同じコミットの節が合っていない。

また、ソースは「Chromium の main」で確かめたと書くが、`main` は動く。測った版のタグ（`153.0.8010.12`。このレビューで `main` と同じ中身であることを確かめた）で確かめたと書けば、測りとソースの版がそろう（research-and-verification-techniques.md にタグで取る形が書いてある）。

直し方の例: 根拠に「Chrome for Testing 153.0.8010.12（`chromium-1243`）、本番ビルド、（文脈の条件）」を書き、ソースは「タグ 153.0.8010.12（`main` と同じ）の…」とする。版を確かめられないときは「版は記録に無い」と書く。

### 指摘6（低）: 「ずれ＋いちばん小さい面の調整」の箇条が、この節だけ読む人には何の数かが分からない

「指のずれを模して点をずらした押しも、ずらした点から同じ調整を受ける。その数は『ずれ＋いちばん小さい面の調整』の値である」の「その数」は、cycle-320 の device-triage.md D5 の数を指す書き方で、一般の知見として読むと何を数えた数かが無い。「点をずらした押しで測った落ち先は、ずれに、最小の面での寄せを重ねた結果である。ずれだけの効果を見たいときは、ずらした点から押せるものまでの隔たりも記録する」のように、起きることと測る人がすることで書く。

### 指摘7（低）: 見出しと二度押しの箇条の「端末」が、Android に限った話なのに広く読める

見出しの「端末より近い所までしか寄らない」と「道具の押しで…落ちなかった件も、端末では落ちうる」は、Android の Chrome についての推論で、iOS の Safari は測れないと同じ節が書く。見出しは「Android の端末より近い所までしか寄らない」、箇条は「Android の端末では落ちうる」とする。

### 指摘8（低）: browser-layout-and-scrolling.md の冒頭の「安定版の Chrome とも違う」は言い切りすぎ

作業の環境の版（いま 153）と来訪者の安定版が同じ時期もありうる。playwright-mcp.md も同じ言い方をしている。「同じとは限らない」とする。
