## 指摘

### 1. 「件が既に出た操作と画面」の並べ方が t5a-measure.md 5章の表の一部だけで、「件」の中身も書かれていない。正しく読むと「送る」という手がほとんど残らない（中）

plan-t5a7.md 3 の削らないものは、見出しを「件が既に出た操作と画面」とし、t5a-measure.md 5章（基準の版）の件として「5-2 の `summary` の画面」と「5-3 の 375×800 の最後の『次へ』」の2つだけを並べる。けれども 5章の表には、同じ種類の件がほかにもある。

- **5-1「はじめる」**: 2打目が1問目の選択肢に落ちた本が、6画面のすべてにある（375×550 4/15・320×550 8/15・375×800 4/15・1280×800 15/15・740×360 15/15・375×550 の 200% 4/15）。cycle-319 の件（「はじめる」の 375×550）を件として並べているので、選択肢に落ちて答えが入るのも「件」に数えている読み方になる。そう読むと、1280×800・740×360 などの「はじめる」も件の出た画面だが、並べた中に無い。
- **5-3 最後の答え・最後の「次へ」**: 第1の組に落ちた回が 375×550（2/150）・320×550（1/150）・740×360（1/150）にもある。375×800 だけが並んでいる。
- **5-4「もう一度挑戦する」**: 第1の組（`summary` とリンク。ページを離れる）に落ちる点が全6画面にある（例: 740×360 149/210、375×550 の 200% 157/315）。並んでいるのは cycle-319 の kanji-level の 375×550 と 1280×800 だけで、ほかの画面・ほかの本は送ってよいものとして読める。

前回の指摘1の直し方の例は「5-2 の…各画面、5-3 の 375×800 など」で、例を挙げたものだった。いまの文は、見出しどおりに読めば 5章の表の件をすべて含み、並べたとおりに読めば2つだけになり、PM が 3 の決定で読み方を決めることになる（前回と同じ迷い）。また「次のサイクルへ送るのは、件が出ていない画面と入力だけ」の「件」が、どの測り（cycle-319・t5a-measure.md 5章）の、どの落ち先（第1の組だけか、次の問の選択肢も含むか）を指すかが書かれていない。

見出しどおりに読むと、「はじめる」・知識クイズの「次へ」・最後の答え・「もう一度挑戦する」はほぼ全画面が削らないものになり、送れるのは知識クイズの答え（5-2 で 1,440/1,440 が押せない字）と、件の数え方によっては診断の答え（B-620 の類）くらいしか残らない。それ自体は来訪者にとって正しい（件の出た所を後回しにしない）が、計画は「収まらないとき」の手として「刻みを粗くする」と「送る」の2つを並べており、後者がほぼ使えないことに見積もりのあとで気づくと、3 の決定がやり直しになる。

直し方の例:

- 「件」を定義する（例: 「cycle-319 のキャリーオーバーか t5a-measure.md 5-1〜5-4 の表で、2打目が第1の組か次の問の選択肢に落ちた回が1つでもあること」）。そのうえで、並べ方を表の参照にする（「5-1〜5-4 の表で件のある操作と画面（いまの値では、知識クイズの答えを除くすべての操作で、ほとんどの画面）」）か、全部を並べる。
- 削らないものを「操作と画面」で決めるのか「操作と画面と入力」で決めるのかを書く（5-1・5-3・5-4 の表は入力を分けていない。B-623 の文も「全画面」とだけあり、マウスを送ってよいかが読めない。D9 を閉じるには条件7 の両方の入力が要る）。
- その帰結として、収まらないときの手は、主に「もう一度挑戦する」の掃きの刻みを（44px を下限に）粗くすることと、件の出ていない入力・知識クイズの答えを送ることになる、と書いておく。それでも収まらないとき（例: 刻みを下限まで粗くしても走らせられる量を超えるとき）にどうするか（このサイクルを延ばすのか、分け方を見直すのか）も1文あると、3 の決定で行き詰まらない。

### 2. 「担当を並べられる数」が、測りの担当を並行させない決まりと合わない（軽）

plan-t5a7.md 3 は、走らせられる量の出どころを「担当を並べられる数と、サイクルに残る日数」とする。一方、index.md の作業内容の冒頭と plan-t5a7.md 6 の測り直しは、測りの担当を並行させない（同じ t5a-measure.md・`measure/`・ポートを使う）。並べられる数はいつも1で、量は「残る日数のうち測りに回せる壁時計の時間（直列）」になる。どちらの意味の「並べる」かを書くか、「直列で回せる時間」と書き直す。

### 3. 走査の途中の回の送り直しの単位が書かれていない（軽）

plan-t5a7.md 4 の「間隔」は、境を越えた回を「数えずに送り直す」とし、語の選択の `detail` の送り直しも同じ形にした。「はじめる」・最後の答え・「もう一度挑戦する」の回は1回の二度押しで終わるので、その回を新しい文脈で送り直せる。けれども、診断の答え・知識クイズの答えと「次へ」は、全問を解き切る走査（t5a-measure.md 5-2）の中の押しで、2打目を送った時点で画面が進んでいるので、その押しだけを送り直すことはできない。走査の中で境を越えたときは、走査を初めからやり直すのか（それなら3度の上限は走査に掛かる）、越えた押しに印を付けて数から外し走査は続けるのかを書く。どちらにするかで、5-2 の「確かめ」（1打目で答えた数＋X＋S＝問の数）と見積もりの時間が変わるので、T5a-7a-1 の見積もりにも送り直しの分を含めさせると、3 の線が実際とずれにくい。

### 4. 測り直しの範囲の「（全本・全画面）」が、3 で送った画面と食い違って読める（軽）

plan-t5a7.md 6 の測り直しは「範囲は 5 で決めた範囲（全本・全画面）で、3 で決めた刻みと画面と入力のまま測る」とする。3 で画面を次のサイクルへ送ったとき、「全画面」は送った画面を含むようにも読める（送った画面は変更後の版で測っていないので、点ごとに比べられない）。括弧を「（その操作の、3 で測ると決めた本・画面のすべて）」のように書き直すと、2つの文が1つに読める。
