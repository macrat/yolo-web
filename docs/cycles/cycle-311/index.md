## 作業計画

### 目的

`docs/site-concept.md` と `DESIGN.md` を、**コンセプト → デザインシステム**の導出で整合した**単一 coherent 状態**にする。完了条件は B-651 の定義どおり:

1. 両文書に、後貼り・⚠注記・例外・特例・過去 cycle への参照・経緯・試行錯誤の跡が**一つも無い**（最初からそう書かれていたかのように読める）。
2. コンセプト＝**ブランドイメージ**（来訪者に持ってほしい印象）が site-concept.md の中に**一つの記述として**統合されている（別文書にしない）。
3. DESIGN.md の各規定が、コンセプトから**飛躍なく導かれている**。
4. 恒久文書としての `brand-image.md` が存在しない。

### 作業内容

**入力の切り分け（何を信じ、何を疑うか）。** 決定の材料は次のとおり扱う。

- **地（信じてよい）**: `docs/constitution.md`／サイト名 yolos.net の由来＝「YOLO×よろず」の二重の意味（不変の事実）／生の観測データ（GA4・Search Console の実測）／外部の一次資料。
- **容疑者（結論の根拠に引かない）**: 現行 `site-concept.md`・`DESIGN.md` の記述、cycle-310 の `brand-image.md`・`e1-decision.md`・`decision.md` の**結論**、現行の実デザイン（favicon・OGP・実装トークン）。これらは本サイクルが正す対象であって、正しさの根拠ではない。過去サイクルの導出は、**その根拠（実測・調査）まで遡って再確認できたものだけ**を採る。

**進め方の規律（cycle-310 の失敗の型を遮断する）。** 前サイクルは同じ失敗を2度繰り返した——末端（マーク）を先に変え、後から上流を作って正当化し、中間層（デザインシステム）を放置した。同じ轍を踏まないために、本サイクルは次を**手順として**課す。

- **導出の向きを固定する**: コンセプト＝ブランドイメージ（T4）→ デザインシステム（T8）→ 実デザイン（**本サイクルでは行わない**・B-652）。T4 が独立レビューを通過するまで `site-concept.md` も `DESIGN.md` も一文字も編集しない。
- **実デザインを制約として持ち込まない**: 「今の favicon がこうだから」「今のトークンがこうだから」を決定の理由にしない。再導出の結果として現行の値が変わることは**想定内**であり、実装との突き合わせは B-652 が受ける。
- **問いを機構にすり替えない**: T4 で答える問いは「**来訪者にどう感じてほしいか**」だけである。「認識される」「面をまたいで一貫する」「見つけやすい」「美しい」は、その印象を届けるための**手段**であって印象ではない。手段が印象の位置に現れたらその導出は却下する。これを T5 のレビュー基準として明示的にレビュアーへ渡す。
- **結論を先に決めない**: 店メタファーは keep/remove のどちらも**あらかじめ決めていない**。来訪者価値からの導出の結果として決める。
- **報告は一次ソースで裏取りしてから書く**: サブエージェントの報告も含め、事実の主張はファイル内容・コマンド出力で確認してから記録する。

**店メタファーの扱い（T4 の中心的な論点）。** 「よろず屋（店）」は**サイト名の由来ではなく PM の構築物**である（由来は YOLO×よろず）。したがって「店」は前提ではなく、**来訪者価値に照らして採否を決める対象**である。判断の材料は、店フレームが (a) 来訪者に持ってほしい印象を届けるのに有効か、(b) 来訪者に伝わらない符牒（店/屋/札/品書き/のれん/印）への依存を生んで理解を妨げないか、(c) 内部の設計語彙としてデザインの一貫を生む力があるか。keep でも remove でも、**上流（コンセプト）から末端（実デザイン）まで一つの答えで貫く**——半分だけ外して矛盾させることは、今回は許されない。

**実測の位置づけ（T3）。** 来訪者の実態は「誰に向けて印象を設計するのか」の接地に使う。とくに**来訪者がサイトをどう経験しているか**（検索から個別ページへ直接着地するのか、サイト全体を回遊するのか）は、ブランドの届き方に直結する。ただし印象の決定そのものはデータで自動的に決まらない——データは前提の接地であって、判断の代替ではない。GA4 の数字はボット混入の疑い（B-635）を前提に読む。

## T5 の打ち切り基準を立てたが、前提が反証された（記録）

4巡目を終えた時点で、わたしは「指摘の性質が**結論を覆すもの**から**記述精度のもの**へ移った」と観察し、「精度のみの指摘は打ち切ってよい」という基準を立てた。

**この前提は直後に反証された。** 基準を書いた数分後に返ってきた5巡目は、**致命4件（うち事実の誤り2件——測度のアーティファクトと検索エンジン交絡）**を出した。「精度の指摘に移行した」という観察は誤りだった。

したがって**この基準は運用しない**。実際、打ち切り判定を適用した指摘は1件もなく（残る指摘はすべて繰越）、閉じ方も基準とは無関係だった——繰越の筆頭は「案1 の却下論証の作り直し（根拠が崩れたため）」で、これは基準上「対応する」側の指摘である。**基準を適用して閉じたのではなく、基準の外で閉じた。**

**次サイクルへの申し送り**: 停止規則を、欠陥がまだ出ている最中に立てないこと。継続の可否は巡回数や「指摘の性質が変わった」という主観ではなく、**成果物からまだ欠陥が出ているか**で決める。
