## 作業計画

### 目的

`docs/site-concept.md` と `DESIGN.md` を、**コンセプト → デザインシステム**の導出で整合した**単一 coherent 状態**にする。完了条件は B-651 の定義どおり:

1. 両文書に、後貼り・⚠注記・例外・特例・過去 cycle への参照・経緯・試行錯誤の跡が**一つも無い**（最初からそう書かれていたかのように読める）。
2. コンセプト＝**ブランドイメージ**（来訪者に持ってほしい印象）が site-concept.md の中に**一つの記述として**統合されている（別文書にしない）。
3. DESIGN.md の各規定が、コンセプトから**飛躍なく導かれている**。
4. 恒久文書としての `brand-image.md` が存在しない。

### 作業内容

**入力の切り分け（何を信じ、何を疑うか）。** 決定の材料は次のとおり扱う。

- **地（信じてよい）**: `docs/constitution.md`／サイト名 yolos.net の由来＝「YOLO×よろず」の二重の意味（不変の事実）／生の観測データ（GA4・Search Console の実測）／外部の一次資料。
- **容疑者（結論の根拠に引かない）**: 現行 `site-concept.md`・`DESIGN.md` の記述、cycle-310 の `brand-image.md`・`e1-decision.md`・`decision.md` の**結論**、現行の実デザイン（favicon・OGP・実装トークン）。これらは本サイクルが正す対象であって、正しさの根拠ではない。過去サイクルの導出は、**その根拠（実測・調査）まで遡って再確認できたものだけ**を採る。

**進め方の規律（cycle-310 の失敗の型を遮断する）。** 前サイクルは同じ失敗を2度繰り返した——末端（マーク）を先に変え、後から上流を作って正当化し、中間層（デザインシステム）を放置した。同じ轍を踏まないために、本サイクルは次を**手順として**課す。

- **導出の向きを固定する**: コンセプト＝ブランドイメージ（T4）→ デザインシステム（T8）→ 実デザイン（**本サイクルでは行わない**・B-652）。T4 が独立レビューを通過するまで `site-concept.md` も `DESIGN.md` も一文字も編集しない。
- **実デザインを制約として持ち込まない**: 「今の favicon がこうだから」「今のトークンがこうだから」を決定の理由にしない。再導出の結果として現行の値が変わることは**想定内**であり、実装との突き合わせは B-652 が受ける。
- **問いを機構にすり替えない**: T4 で答える問いは「**来訪者にどう感じてほしいか**」だけである。「認識される」「面をまたいで一貫する」「見つけやすい」「美しい」は、その印象を届けるための**手段**であって印象ではない。手段が印象の位置に現れたらその導出は却下する。これを T5 のレビュー基準として明示的にレビュアーへ渡す。
- **結論を先に決めない**: 店メタファーは keep/remove のどちらも**あらかじめ決めていない**。来訪者価値からの導出の結果として決める。
- **報告は一次ソースで裏取りしてから書く**: サブエージェントの報告も含め、事実の主張はファイル内容・コマンド出力で確認してから記録する。

**店メタファーの扱い（T4 の中心的な論点）。** 「よろず屋（店）」は**サイト名の由来ではなく PM の構築物**である（由来は YOLO×よろず）。したがって「店」は前提ではなく、**来訪者価値に照らして採否を決める対象**である。判断の材料は、店フレームが (a) 来訪者に持ってほしい印象を届けるのに有効か、(b) 来訪者に伝わらない符牒（店/屋/札/品書き/のれん/印）への依存を生んで理解を妨げないか、(c) 内部の設計語彙としてデザインの一貫を生む力があるか。keep でも remove でも、**上流（コンセプト）から末端（実デザイン）まで一つの答えで貫く**——半分だけ外して矛盾させることは、今回は許されない。

**実測の位置づけ（T3）。** 来訪者の実態は「誰に向けて印象を設計するのか」の接地に使う。とくに**来訪者がサイトをどう経験しているか**（検索から個別ページへ直接着地するのか、サイト全体を回遊するのか）は、ブランドの届き方に直結する。ただし印象の決定そのものはデータで自動的に決まらない——データは前提の接地であって、判断の代替ではない。GA4 の数字はボット混入の疑い（B-635）を前提に読む。

**書き直し（T6）で決着させる論点（調査で判明した既存の不整合）。**

- **「札のシェアによる拡散」の扱い**: 現行 site-concept は「独自の記号が『共有できる記号』に育つかは**未検証の賭け**」と書くが、ADR002 はこの賭けを**破綻と認定して失効**させている（(a) 既知の事実と矛盾する前提、(b) 反証不能な設計、(c) 主指標がトートロジー近似）。実測でも share は約2件/28日（B-575）。「持ち帰れる成果物」（印象 C の中核）と「他者へ拡散する」は別の主張であり、後者を未検証の賭けとして温存しない。
- **オーナー帰属の誤り**: 「実験枠（rule 5 の実装・**オーナーは積極的な実験を奨励する**）」はオーナーの原発言が存在しない誤帰属（AP-P34・B-610 と同型）。ラベルを外す。
- **文書内部の自己矛盾**: 「『実験/試作』を identity の売り込みにしない」と禁じながら、自己定義が「AI に丸投げした実験サイト」になっている。Rule 3 が要求するのは**開示**であって売り込みではない、という線で一本化する。
- **中心原則の外部依存の留保**: 弁別子（参照型は SERP で配達され訪問を失う）は Google の SERP 挙動という外部仕様に依存する。現行本文はこの留保を落としている（元の調査には存在した）。一次資料で現況を確認済みなので、留保つきで書く。

**デザインシステムの再導出（T8）の進め方。** 棚卸しで、店前提を外して**規定として崩れるのは6箇所だけ**（表題・§1 リード・§1-2・§6 末項・冒頭注記・§11 の実測項目）で、のれん／品書き／値札／包み／札などは「語彙のみ依存」＝語を差し替えれば規定内容がそのまま残ることが判明した。規定の過半は店に非依存である。したがって T8 は次の順で行う。

- 各規定を「**§4 の印象（A 安心・B 気軽さ・C 手ごたえ・D 正直）のどれを、どう届けるか**」で導き直す。**どの印象にも接続できない規定は落とす**（残す理由が「今そうなっているから」なら、それは逆走）。
- **数値は再計算済みの値を使う**（[token-verification.md](./token-verification.md)）。現行の記載値は正しかったが出典文書が失われていたため、根拠を持てる形にする。あわせて **`--rule` のコントラストが 1.52:1 しかないのに「構造の主役」とされている問題**を品質バーで決着させる。
- **§番号の参照が src の135ファイル・500箇所以上にある**（§4=137・§2=97・§1=67 等）。構成を変えると参照が壊れるが、**参照を守るために構成を決めることはしない**（それは逆走）。再導出の結果として構成が変わった場合、参照の付け替えは実装作業なので B-652 に送る。
- 棚卸しが検出した**参照切れ5件**（内容 fuda 印の出典・「増幅器」・「温色ウォッシュ」の根拠・書体の「既知の落とし穴」の根拠・cycle-309 E1/E2 の混同）は、根拠が実在しない記述として**新文書に持ち込まない**。

**スコープ外（本サイクルでは行わない）。** 実デザインの変更（favicon・OGP 画像・コンポーネント・トークンの実装反映）は B-652。中心原則（体験型／参照型の弁別子）そのものの再検証は、本サイクルの目的（coherent 化）とは別の判断であり行わない——ただし、書き直した文書に**現況と食い違う断定を新たに書かない**ため、外部仕様に依存する記述は下記の一次資料で強度を確かめてから書く。

### 検討した他の選択肢と判断理由

- **(A) 2文書の⚠注記と矛盾箇所だけを部分修正する**: 却下。矛盾は末端の記述ではなく「コンセプトが決まっていない」ことに由来するため、部分修正では矛盾が残り、CLAUDE.md のツギハギ禁止にも反する。前サイクルが繰り返した失敗そのもの。
- **(B) DESIGN.md を先に整理し、コンセプトは後から合わせる**: 却下。デザインシステムは独立した権威を持たず、コンセプトを視覚規則へ翻訳したものにすぎない。この順序は前サイクルの逆走そのもの。
- **(C) コンセプトの決定に加えて実デザイン（favicon/OGP）まで本サイクルで直す**: 却下。B-652 として分離されており、一度に末端まで動かすと「決定が固まる前に実装を動かす」圧力が再発する。デザインシステム確定までを本サイクルの責任範囲とする。
- **(D) `docs/cycles/cycle-310/brand-image.md` を削除する**: 採らない。B-651 の完了条件「brand-image.md が存在しないこと」は、**恒久文書としてのブランドイメージ別文書を作らない**という原則（一つの決定は一つの権威ある場所に）を指す。cycle-310 ディレクトリ内のそれは**失敗の記録**であり、既に冒頭で【無効】と明示され index.md からリンクされている。記録を消すことは経緯の隠蔽にあたるため残す。恒久文書側（`docs/` 直下）には作らない。
