# T5 レビュー（1巡目）: 「印象」から「仕組み」へのすり替え検知（単一二値軸）

> レビュアーが書き込みツールを持たないため、PM が返答全文をそのまま保存した。

**判定: REJECT**

対象: `concept-decision.md`
軸: 各記述が **(A) 来訪者の心に起きること（印象・感情・判断）** か、**(B) サイト側の性質・仕組み・作り方・運営方針（手段）** か。**(B) が印象の位置にあれば REJECT。**

## 0. 判定基準（一貫して適用したテスト）

各文について「これは来訪者の頭の中で起きることか、サイトの側で起きること（作り手が守る規則）か」を問う。運用上の目印は**声の主体**である。

- 「〜と感じてほしい」の**引用の内側**＝来訪者の内語 → (A)。引用の中に「量産」「登録」など制作・運用の語が出ても、それは来訪者が受け取る知覚の内容なので (A)。
- 引用の**外側**で、サイトの振る舞い・仕様・方針を規範の声（「〜しない」「〜がない」）で述べているもの → (B)。これは印象の定義ではなく手段の指定であり、印象の位置に置けば cycle-310 と同型のすり替えになる。
