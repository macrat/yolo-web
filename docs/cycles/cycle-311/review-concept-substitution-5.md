## 4. REJECT 事由

### 【R1】§4「面が衝突したときの順序」が、面を constitution の条文と同一視している

第5版のこの節は**面の名だけで書かれていた**（実地確認）。第6版は constitution からの導出を足す過程で、**印象を site-side 指令と同一視する定義文が新たに混入した**。

- 「**C は Rule 2 の helpful/enjoyable であり**」——繋辞による定義。C（来訪者の「やってよかった」）が、"Make a website that is helpful or enjoyable" という**サイトへの指令そのもの**に置き換わっている。
