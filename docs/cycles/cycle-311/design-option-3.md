## 1. 系統の名前と一文の説明

# 一刷り（ひとすり）

**来訪者が得たものだけを、ページの中でただ一つの「刷り面」——地と反転したベタの面——として刷り出し、その周りはすべて紙と細い罫で組む系統。**

活版の版元にならう。紙があり、罫があり、インクは一色。インクが乗るのは版が当たった場所だけで、そこに来訪者の答えが刷られている。ページの他のどこにも面はない。だから来訪者は、スクロールも比較も判断もせずに、**自分が受け取ったものがどれかを一目で知る**。

この系統には、機械的に検査できる3つの規則がある。これがこの案の背骨であり、他のすべての選択はここから導かれる。

| #         | 規則                                                               | 導かれること                                                                                       |
| --------- | ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| **規則1** | **ベタの面は1ページにちょうど1つ。それは来訪者が得たものである。** | カード禁止・パネル禁止・色付き背景ブロック禁止が自動的に決まる。構造は罫と余白でしか示せなくなる。 |
| **規則2** | **朱は成果物の中にしか存在しない。**                               | 朱＝「あなたが得たもの」の色になる。ナビ・リンク・ボタン・見出しから色が消え、色の不在が地となる。 |
| **規則3** | **刷り面は最初の画面に必ず含まれ、説明より前に置かれる。**         | 結果の出し惜しみ・煽り・縦長LP構造が構造的に不可能になる（調査 §2-5）。                            |

規則1と2は「アクセントは1色に絞り副次は色の不在で」（調査 §1 回避策）を、**位置の規則**として言い直したものである。色数を減らすのではなく、色が出てよい**場所**を1箇所に限る。これにより、色は装飾ではなく「ここが成果物だ」という意味そのものになる。

## 2. 色

### 考え方

- **地は紙**。完全な白ではなく、わずかに温かい生成り。画面を紙に寄せることで、ベタの面が「刷られた」ものとして立ち上がる。
- **文字は墨**。純黒ではなく、わずかに温かい濃灰。長文でも刺さらず、罫と同じ系統に収まる。
- **インクは一色（藍墨）**。これがベタの面の色。規則1により、この色は1ページに1箇所しか現れない。
- **朱は点**。規則2により成果物の内側にしか現れない。使うのは「主値の下の一本線」「単位」「正誤の印」「診断の型名」など、**1つの刷り面につき1〜2箇所まで**。
- **リンク・ボタン・ナビに色は使わない**。リンクは墨＋下線（`text-underline-offset: 0.2em` / `text-decoration-thickness: 1px`）。主ボタンは墨のベタ**ではなく**、墨の2px枠＋紙地＋直角。押下で墨ベタに反転する。色で誘導しないことが、そのまま煽らないことになる。

### 具体値（明るい面／既定）

### ダークモード

反転を主題にした系統は、ダークモードで最も壊れやすい。地が暗いと「暗いベタの面」が成果物として立たなくなるからである。したがって**ダークモードでは刷り面の側を反転させる**。地が夜になり、**刷り面が紙になる**。規則1「地と反転した面がちょうど1つあり、それが成果物である」は、両モードで同一のまま保たれる。

| ------------------ | --------- | ------ |

- 明るい刷り面が夜に眩しくならないよう、刷り面は純白ではなく `#EDEAE2`（紙と同じ生成り）に固定し、面積を欄幅×必要最小限の高さに抑える。

## 3. 書体

### 方針

調査 §2-4 の「とりあえず Noto Sans JP」問題と、§1 の「既定 sans を無検討で本文に」の両方を、**本文で欧文フォントを配信しない**のではなく、**和文で1バイトも配信しない**という形で回避する。

- **本文の和文は OS 搭載書体を使い、Web フォントを配信しない。** 游ゴシック（Windows/Mac）・ヒラギノ（Apple）・Noto Sans CJK（Android、端末搭載）。配信ゼロ・小サイズに強く（§2-4）、そして「Noto Sans JP を読み込んだサイト」の顔にならない。
- **明朝は1書体だけ配信し、見出しと成果物にしか使わない。** ここが編集的コントラスト（§4-4）の全部である。
- **欧文は1書体だけ配信する。** 活版期のアメリカン・ゴシックの系譜を引く Libre Franklin。Inter / Roboto / Open Sans を避けるための消極的選択ではなく、系統（活版）から出た選択である。
- **数字は成果物の主役**なので、等幅数字（`tabular-nums`）を全面で有効にし、桁の増減で数値が踊らないようにする。

### 具体

```css
--font-sans:
  "Libre Franklin", "Yu Gothic Medium", "游ゴシック Medium", YuGothic,
  "Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans JP", sans-serif;
--font-mincho:
  "Shippori Mincho B1", "Yu Mincho", "游明朝", "Hiragino Mincho ProN",
  "Noto Serif JP", serif;
--font-mono: "IBM Plex Mono", ui-monospace, SFMono-Regular, Menlo, monospace;
```

| 用途                                             | 書体                               | 補足                                                                    |
| ------------------------------------------------ | ---------------------------------- | ----------------------------------------------------------------------- |
| 本文・ナビ・値札・ボタン                         | `--font-sans`                      | Windows の游ゴシックが細るため本文は `font-weight: 500`、見出しは `700` |
| ページ名・見出し2                                | `--font-mincho`                    | 見出しにだけ明朝が出ることで「編集された頁」になる                      |
| 成果物の言葉（診断の型名・辞典の見出し字・熟語） | `--font-mincho`                    | 大きく組んでも痩せない B1 ウェイト                                      |
| 成果物の数値（換算結果・カウント・件数）         | `--font-sans` 700 + `tabular-nums` | 明朝の数字は大サイズで弱いため数値は必ずサンセリフ                      |
| コード・JSON 出力・QR の元文字列                 | `--font-mono`                      | **成果物としてのコードのみ**。本文モノスペースは禁止（§1）              |

**配信は Shippori Mincho B1 の1ウェイトのみ**（常用漢字2,136＋人名用の主要字＋かな＋約物、`layout-features` 保持、WOFF2、約1.4MB）。漢字辞典の見出し2,136字は常用漢字と一致するため、サブセットの範囲が辞典の必要範囲を過不足なく覆う。`font-display: swap`、明朝が最初の画面に出るページでのみ `preload`。

### 組版（§2-3・§4-4 — この層が最大の差別化）

- 本文は**ベタ組み**。`font-feature-settings` による詰めは使わない。
- **`palt` は見出しと刷り面の中だけ**に適用する。大きい字ほど約物の空きが目立つため、詰めが必要なのは大きい字だけである。
- 和欧間は `text-spacing-trim: space-first` と自動アキに任せ、**原稿に半角スペースを入れない**（手打ちのアキは §2-1 の「整形残り」の症状そのもの）。
- 行送りは本文 1.75、見出し 1.45、刷り面の主値 1.15。
- 禁則・行末約物のぶら下げは既定に任せ、`word-break: normal` / `overflow-wrap: anywhere` は URL にのみ限定する。

## 4. レイアウトの原理

### 構造は何で示すか

**罫と余白だけ**で示す。面（背景色のブロック）は規則1により成果物に予約されているため、構造の表現には使えない。この制約が、調査 §1 が名指しする「アイコン付き同型カードのグリッド乱発」「カードの上端/左端だけの色付きボーダー」を、様式の好みではなく**空きスロットの不在**として排除する。

- 見出し2 の下に 1px 罫（全欄幅）。見出し3 に罫は付けない。
- のれん（サイト名）の下に 2px 墨罫。この2px は、のれんと刷り面の上辺にしか存在しない。
- 縦罫はデスクトップの2欄組でのみ、欄の間に 1px。

### 一覧の既定形＝品書き（罫区切りのリスト）

カードではなく**行**。1行1項目、区切りは 1px 罫。

```
────────────────────────────────
文字数カウント              道具・即時
テキストの文字数・行数・バイト数を数える
────────────────────────────────
四字熟語辞典                辞典・400語
読み・意味・出典から引ける
────────────────────────────────
```

- 左に**名前**（サンセリフ 700）、右端に**値札**（弱墨・12.5px・4字以内、例「道具・即時」「診断・5問」「辞典・400語」）。値札は「何であるか」と「どれだけかかるか」だけを言う。
- 2行目に一文の説明（弱墨・14px・1行で切る）。
- 行全体がリンク領域。ホバーで背景は変えず、**行の左端に 2px の墨の縦罫が出る**（面を作らない指示手段）。
- モバイルは全幅1列、デスクトップは2列（列間に縦罫）。項目数が7を超える一覧には見出し（かな・部首・種別）で束をつける。

### 角

**すべて 0（直角）。** 例外は設けない。刷り面も、ボタンも、入力欄も、画像も、タグも直角。調査 §1 の「8px の安全な中間を避け 0 か大きくへ意図的に振る」に従い 0 に振る。紙と版の系統では、角丸は物理的に意味を持たない。

### 余白のスケール（行送りに紐づく尺）

4の倍数ではなく**本文の行送りを単位**にする。雑多な中身を一冊にする器は、共通のベースラインリズムから生まれる（§3-1）。

`1ru = 28px`（本文16px × 行送り1.75）

| 名          | 値    | 用途                                                 |
| ----------- | ----- | ---------------------------------------------------- |
| `--sp-0.25` | 7px   | 値札と名前の間、行内の細かい間                       |
| `--sp-0.5`  | 14px  | 段落内の要素間、リスト行の上下パディング             |
| `--sp-1`    | 28px  | 段落間、刷り面の内側パディング（モバイル）           |
| `--sp-1.5`  | 42px  | 見出し2 の上、刷り面の内側パディング（デスクトップ） |
| `--sp-2`    | 56px  | 節の間、欄の間隔                                     |
| `--sp-3`    | 84px  | 大きな区切り（本文と「棚」の間）                     |
| `--sp-4`    | 112px | ページ上下端                                         |

すべての縦方向の値が 7px の倍数であるため、異質な内容が並んでも縦のリズムが揃う。

### 欄の設計（面ごとに主たる画面が違うことへの答え）

本文欄は**34字**（約 560px）を上限とする。そのうえで面ごとに既定を変える。

| 面                                    | 主たる画面          | 既定の組み                                                                                                                      |
| ------------------------------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **遊び**（診断・ゲーム20種）          | モバイル 87.5%      | 単段560px。操作は親指到達域（画面下1/3）に固定、**刷り面は画面上部**。デスクトップでも欄幅を広げず、単段のまま中央に置く        |
| **道具**（36種）                      | デスクトップ 90.0%  | デスクトップは2欄（入力 360px ／ 縦罫 ／ 刷り面 fluid、外枠 960px）。**入力と結果が同時に見える**。モバイルは入力の直下に刷り面 |
| **辞典**（漢字2,136・熟語400・色250） | モバイル 66.1%      | 単段560px。デスクトップは右に索引柱240px（部首・画数・かな）。見出し字は明朝で特大、**紙の上に直接**組む                        |
| **読み物**（記事86本）                | デスクトップ 100.0% | 左に柱200px（日付・目次・関連）／縦罫／本文560px。右は余白のまま残す。モバイルは柱を本文冒頭に畳む                              |

デスクトップでも本文欄を広げないため、記事と辞典は同じ34字で読める。**器（欄幅・行送り・罫・余白の尺）はどの面でも同一で、変わるのは欄の数と操作の位置だけ**である（§3-1・§3-4）。

### ページ内の順序（全面共通・固定）

1. のれん — サイト名（14px・字間0.08em）＋2px墨罫。ナビは4語のみ：**試す／片づける／調べる／読む**
2. ページ名（明朝）
3. **刷り面（成果物）** ← 最初の画面に必ず入る
4. 操作・入力（道具と遊びのみ）
5. 説明・使い方・読み物本文
6. **棚** — 関連する他の項目を品書きで3〜6件
7. 開示 — AI 運営と誤りうる旨。全ページ同一文言・同一位置・同一トーン

道具では刷り面が**初期状態から場所を占める**（「ここに結果が出ます」と弱墨で1行）。入力に応じて即時に埋まり、レイアウトは動かない。**結果が出てからページが伸びる作りにはしない**。

### 刷り面の仕様

- 幅は欄いっぱい、角0、影なし、上辺に 2px 墨罫、内側パディング `--sp-1`（モバイル）／`--sp-1.5`（デスクトップ）。
- 中身の順：値札（何の結果か・4字・`--press-fg-weak`）→ **主値（特大）** → 単位・読み（`--press-fg-weak`）→ 補足1〜2行 → 行為（コピー／保存／共有。紙色の文字＋下線、ボタンの箱は作らない）。
- 主値の型サイズは本文から**不連続に跳ぶ**。中間サイズを置かない：モバイル44px／デスクトップ64px（数値・単語）、文章型の結果は18px・行送り1.9の明朝。
- 複数の結果（例：単位換算の複数出力）は**1つの刷り面の中に行で並べる**。行間の区切りは紙色20%の細線。刷り面を2つに割ることはしない。
- 辞典の見出し字だけは例外的にベタ面を持たず、紙の上に明朝120pxで直接置く（字そのものが成果物であり、ベタ面が字形の観察を妨げるため）。この場合、**そのページのベタ面の枠は空いたままにし、他の要素に使わない**。規則1は「面は1つ以下、あるとすれば成果物」として保たれる。

## 5. 装飾の限度

### 許すもの

- **1px 実線罫**（水平・垂直）。2px 罫は**のれん下と刷り面上辺のみ**。
- **ベタ面**は成果物のみ、1ページに1つまで。
- **朱**は成果物の内側のみ、1つの刷り面につき1〜2箇所。
- **活字記号を値札に**（※ ¶ 〒 ／ ・ 連番）。意味を持つ記号だけ。
- **地の微細なグレイン**（CSS のみ・不透明度 0.03 以下・画像を配信しない）。紙の質感は「人が意図して設計した」ことを伝える（§3-3）。
- **モーション1種類のみ**：刷り面が埋まる瞬間の、80–120ms の opacity 0→1 ＋ 2px の上昇。ページ内の他のどの要素も動かない。`prefers-reduced-motion` で無効化。
- **機能を持つ記号**（外部リンクの矢印・開閉の三角）。線画1px、色は弱墨。

### 禁じるもの

構造的禁止（規則1・2から導かれる）:

- 影（`box-shadow` 全面禁止。色付きグロー・色付き影を含む）
- グラデーション（背景・文字・枠のすべて）
- 角丸（`border-radius` は 0 のみ）
- カード（枠や背景を持つ箱を並べた一覧）
- **カードの上端／左端だけの色付きボーダー**（§1 が「最も信頼できる AI の指紋」と呼ぶもの）
- 成果物以外のベタ面、成果物以外の朱
- 紫〜青のグラデ、shadcn 既定トークン、グラスモーフィズム

表層的禁止（§1 のアンチパターン）:

- 絵文字（見出し・ナビ・本文・値札のすべて）
- 装飾アイコン（機能を持たない絵）、AI 生成イラスト、Corporate Memphis 風、ストック写真、浮遊3D
- 中央揃えヒーロー＋H1直上のピル型バッジ、「ヒーロー→カード3枚→証言→統計」の定型順序
- 全要素一律の fade-in
- 本文モノスペース、見出し1語だけのセリフ／イタリック、all-caps ラベルの多用
- 一律16px角丸＋一律パディング

信頼の禁止（§2-5・constitution 2）:

- 結果の出し惜しみ（「続きを見るには」「あと1問で結果」）
- カウントダウン、偽の限定、通知の許可を先に求める挙動
- 成果物より前に置く広告、本文に混ぜる広告

### 5-b. 文章の限度（デザインシステムの一層）

調査 §2-1 の「信頼できない理由1位＝日本語の不自然さ 40.91%」に対し、**文章を色や余白と同じ層として規定する**。以下は検査可能な形で書く。

- **見出しにコロンを使わない。**「〇〇とは：3つのポイント」型を禁止。見出しは体言止めか、動詞で終える。
- **一文は60字以内。** 操作の指示は必ず動詞で終える（「入力します」ではなく「入力する」／ボタンは「変換する」）。
- **ヘッジを成果物の説明に使わない。**「一般的には」「〜かもしれません」を結果の説明から排除する。誤りうる点は**開示欄で一度だけ**言う。これが正直さの形であり、全文にヘッジを撒くことは正直さではない。
- **箇条書きの各項目の冒頭を太字にしない。** 太字は1段落につき1箇所まで。
- **「〜だけではなく、〜です」構文と汎用最上級**（「最高の」「究極の」「あらゆる」）を禁止。
- **原稿に半角スペースを入れない**（和欧間は組版に任せる）。
- **値札の語彙は固定辞書から引く**（4字以内・全サイト共通）。同じものを2つの言い方で呼ばない。
- **一人称・二人称を固定する。** サイトは自称しない（「当サイトでは」を使わない）。来訪者は「あなた」で統一し、成果物の値札は「あなたの結果」で固定する。
- **開示文は全ページ同一の1文＋リンク1つ。** ページごとに書き分けない。

## 6. 各選択が印象のどれをどう届けるか

**規則1（ベタの面は1ページに1つ、それは来訪者が得たもの）**
→ **手ごたえ（やってよかった）**：ページ内で唯一インクが乗った場所が自分の答えなので、探す・比べる過程なしに「手に入った」ことが視覚で確定する。

**規則2（朱は成果物の中にしか存在しない）**
→ **手ごたえ（やってよかった）**：サイト全体で最も強い色が自分の結果の中にしかないため、得たものがページの最高位に置かれていることが伝わる。

**規則3（刷り面は最初の画面・説明より前）**
→ **正直（取り繕っていない）**：結果に到達させる前に読ませるものが一つもなく、出し惜しみが構造的に不可能だと来訪者が最初の画面で確認できる。

**リンク・ボタン・ナビから色を外す（色は成果物にしかない）**
→ **正直（取り繕っていない）**：色で押させる仕掛けが存在せず、押すかどうかが言葉だけで判断できる。

**主値が本文から不連続に跳ぶ型サイズ（44/64px、中間サイズなし）**
→ **手ごたえ（やってよかった）**：答えが「大きい」のではなく「他と桁が違う」ため、受け取ったものの大きさとして体感される。

**紙の地・墨の文字・一色のインク（16.5:1 の対比、AAA 準拠）**
→ **安心（ここは大丈夫だ）**：どの環境でも文字が確実に読め、読めなさによる不安が生じない。

**影・グラデ・グロー・角丸の全面禁止**
→ **安心（ここは大丈夫だ）**：量産テンプレートの手癖が一つも現れず、雑に組まれた場所ではないと最初の一瞥で分かる。

**モーションを刷り面の1種類に限る**
→ **安心（ここは大丈夫だ）**：予期しない動きが起きないので、画面を警戒せずに使える。

**Web フォントを和文で配信しない（OS 搭載書体＋明朝1書体のみ）**
→ **気軽さ（気負わず、すぐできる）**：開いた瞬間に読める状態で出るので、待つという手続きが発生しない。

**刷り面が初期状態から場所を占め、結果でレイアウトが動かない**
→ **気軽さ（気負わず、すぐできる）**：入れたらそこに出ると分かっているので、試す前に構えなくてよい。

**操作をモバイルの親指到達域に固定し、道具は入力と結果を横並びにする**
→ **気軽さ（気負わず、すぐできる）**：どの面でも今持っている端末のまま片手で最後まで行ける。

**一覧の既定形＝品書き（罫区切りの行・値札付き）**
→ **広がり（他にも面白そうなものがある）**：1画面に入る項目数がカードの3〜4倍になり、「まだ他にもある」ことが総量として目に入る。

**値札（「道具・即時」「診断・5問」「辞典・400語」）**
→ **広がり（他にも面白そうなものがある）**：次に何が待っているかと、それがどれくらいで終わるかが先に分かるので、もう一つ試す判断がその場でできる。

**ページ末尾の「棚」（関連3〜6件の品書き）と、のれんの4語（試す／片づける／調べる／読む）**
→ **広がり（他にも面白そうなものがある）**：着地した1ページだけで帰る人にも、この場所にあと3つの種類があることが必ず一度は示される。

**器（欄幅34字・行送り1.75・7px の尺・罫）を全面で共通にする**
→ **安心（ここは大丈夫だ）**：診断から辞典へ移っても同じ場所にいると分かり、別のサイトに飛ばされた感覚が起きない。

**文章の層（コロン見出し禁止・60字・ヘッジ排除・固定語彙）**
→ **正直（取り繕っていない）**：読んで最初に不信を招くのは視覚ではなく日本語なので（§2-1）、言葉の癖を消すことが取り繕わなさの実体になる。

**開示を全ページ同一文言・同一位置に置く**
→ **正直（取り繕っていない）**：ページごとに言い方を変えないことで、開示が体裁ではなく事実として置かれていると伝わる。

**ダークモードで刷り面を紙側に反転させる（規則1を両モードで保つ）**
→ **手ごたえ（やってよかった）**：夜に開いても、得たものが唯一の反転面であるという関係が崩れない。

## 7. この案が弱い面

### 最も弱い：E（広がり——他にも面白そうなものがある）

**理由**：規則1・2により、一覧から**色・画像・面が全部なくなる**。品書きは項目数を多く見せられるが、**引きの強さは言葉だけに依存する**。人は未知のものを、色や絵の差異によって「面白そう」と判断することがある。この案はその手段を自ら封じている。カードのサムネイルが担う「見て気になる」を、値札と一文の説明だけで代替しなければならない。

さらに、密度の高い罫区切りリストは**一様に見える**危険がある。20の遊びと36の道具が同じ組みで並ぶと、違いが読む前には立ち上がらない。これは「探して迷う不安ではなく、見つける楽しさ」という要求に対し、楽しさの側が弱くなる方向の失敗である。

**この案の中での緩和**：値札の語彙（「診断・5問」「道具・即時」）と一文の説明の質に賭ける。つまり **E の成否が完全に文章の層に乗る**。これは §2-1 の「文章が信頼を左右する」と整合するが、賭けの一点集中でもある。文章が凡庸なら E は落ちる。

### 次に弱い：B（気軽さ——気負わず、すぐできる）

**理由**：明朝の見出し、直角、罫、生成りの紙、色の不在——これらは「整った」印象と同時に**改まった**印象を出す。活版の系統は本来、丁寧さと格式が同居する。「ちょっとやってみるか」より「きちんとした場所に来た」に寄る危険があり、遊びの面（モバイル87.5%、おそらく最も気軽に開かれる面）で最も影響が出る。

角丸0の徹底も、タップ対象の柔らかさを失わせる方向に働く。これは 48px 以上のタップ領域と `--sp-0.5` 以上の間隔で機能的には補えるが、**印象としての柔らかさは補えない**。

**この案の中での緩和**：遊びの面では見出しを明朝からサンセリフに落とす——という逃げは取らない（器を面ごとに変えると §3-1 の一貫性が壊れる）。代わりに、**言葉で気軽さを出す**。ページ名を「性格診断テスト」ではなく「やってみる」側の語にする、値札で所要（「5問」「30秒」）を先に見せる、開始ボタンの語を短くする。ここでも**文章の層が負担を引き受ける**。

### 弱さの構造

この案の弱点は E と B に別々にあるのではなく、**視覚から手段を削った分の負荷が、すべて文章の層に移っている**という一つの構造である。系統として筋は通っているが、**文章の質が落ちた瞬間に E と B が同時に落ちる**。それがこの案の賭けである。
