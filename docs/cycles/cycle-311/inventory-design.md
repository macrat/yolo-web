## A. cycle-310 由来で無効な記述の所在（git 差分で確定）

3. **L76（§4 識別マーク）の全面** — `4c38dc66` で書き換え、`3dd4a30d` で再書き換え。
4. **L77（§4 看板）の語** — 「店の印」→「識別マーク」、「店号と印から出所が読める」→「店号と識別マークから出所（yolos.net）が読める」（`4c38dc66`・`1488c73e`）。
