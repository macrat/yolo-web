## 8. REJECT 事由と要修正

### 8-1【REJECT 事由1】§4-C の説明文に (B) がある

「…と感じてほしい。**このサイトが存在する理由**である。」——後半の主語は「このサイト」で、述べているのは**サイト側で起きること**。位置は**説明文**であり、文書自身が「(A) のみ」と定めた枠の内側である。3巡目でも同一箇所が「要整理」と指摘されており、**縮められただけでサイト主語は残った**。内容としても「面が衝突したときの順序」と重複しており、説明文に置く必然性がない。

**危険の実質**: T8 は §4 を「印象の一覧」として引く。そこに「このサイトが存在する理由」が混ざると、C だけが**サイトの目的**として読まれ、「目的である以上◯◯すべき」というサイト側からの導出が C に接続する経路が開く（§6-5 は既に「C が**目的である以上**」と書いており、経路は使われ始めている）。

### 8-2【REJECT 事由2】§7 の「実施結果」2件が本文と一致しない

- 「面名・説明文はすべて来訪者側」→ C2 が反例。**基準を全文に当てたなら検出されるはずの (B) が残っている。**
- 「導出欄の (B) にはすべて変換文を付した」→ C の導出欄に変換文が無い。しかも2行上（7-2）が変換文の実在を「A・B・D・E」と正しく4面だけ列挙しており、**同一節の内部で自己矛盾している**。
- これは AP-WF09（達成していない網羅性を主張して結論を支える）と AP-WF23 に該当する。**自己点検は「点検済みである」という後続サイクルへの証明であり、証明が偽であることは、点検されていない §4 が「点検済み」として T8 へ渡ることを意味する。**

### 8-3【要修正1】§4-C の導出欄に変換が無い（3巡目 指摘4 の未完了）

3巡目 修正指示4 は「B・E（**および C7**）に変換の一文を置く」と C を明示的に含めていた。B と E には入り、**C だけが入っていない。**

### 8-4【要修正2】E の言い換えが4箇所あり、文書が自ら新設した禁止規則に反する

| 箇所            | 文言                                   | 問題                                   |
| --------------- | -------------------------------------- | -------------------------------------- |
| §3-8            | 「隣に、もう一つある」という**気づき** | 期待→認知への縮小                      |
| §4-E 強度       | 「**隣にもう一つ**」が届いている       | **§4 の内部で第二の言い回し**          |
| §5 検証表 5行目 | 「隣にもう一つあると**分かること**」   | 規則の導出可否をこの縮小版で判定       |
| §6-5            | 「隣に**次があると分かること**」       | 手段側の言い回しが印象側へ逆流する起点 |

いずれも主語は来訪者側なので単独では REJECT にしない。しかし規則の文言は「面名と説明文の語を他のどの節でも言い換えない」であり、**規則を新設した版が、規則の対象行為を4箇所で行っている**。

**実質的な危険**: 「試したい・調べたい・面白そう」（欲求）から「隣にもう一つあると**分かる**」（認知）への縮小は、次の一歩で「分かる**ようにする**」（サイト側の可視化＝(B)）へ渡る。§3 には既にその形が存在する。3巡目が「A→静かで読みやすい」で捕まえた経路と、出口が違うだけで同じ経路である。**§5 の検証表は T8 が全規則に対して繰り返すテンプレート**なので、ここで縮小版が使われていることは 3巡目の REJECT 事由と同じ位置の問題である。

### 8-5【要修正3】§4-E の強度が PV という運営指標で面の妥当性を語っている

E7「この面は**現に働いている**——organic PV の 19.0% を生んでいる」。3巡目 E9 を反転させただけで、**面の妥当性を運営指標で測る構造は残っている。** 「実際に次の一つへ進んだ人が現にいる」という来訪者側の言い方に変換すれば、指標は根拠として保ったまま印象の層を汚さずに済む。

### 8-6【軽微】§7 の「文書全体で確認した」は実施内容が申告に届いていない

確認されたのは「器の性質語への言い換え」だけで、規則の対象範囲（語の言い換え全般）では実行されていない。**指摘された形だけを潰し、規則本文で再点検していない**という、チェック対象の範囲を恣意的に絞る型。
