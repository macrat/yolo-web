# コンセプト＝ブランドイメージの決定（T4）

## 0. この文書が答える問い

**yolos.net は何であり、来訪者にどんな印象を持ってほしいか。**

これは二つの問いではなく一つである。喚起したい印象を持たない「正体」は来訪者にとって無価値であり、体現するものを持たない「印象」は接地しない。両者は一つの決定を作り手側と来訪者側から見たものにすぎないので、一体で決める（別文書に割ると必ずドリフトして矛盾する——それが前サイクルの失敗の構造的原因だった）。

## 1. 入力と、この文書の来歴

**地（根拠に引いてよい）**

- `docs/constitution.md`（Goal と Rule 1〜5）。
- サイト名 yolos.net の由来＝**YOLO × よろず**の二重の意味（不変の事実）。
- **来訪者の実測と本番の実見**（[visitor-reality.md](./visitor-reality.md)）。
- 外部の一次資料・調査（出典の条件つきで用いる）。
- **サイトに現に存在するもの（実カウント）**——遊び **20**（本番 `/play` のリンク数）、道具 **36**、ブログ記事 **86**（md **87** のうち `draft: true` の1本を除く）、漢字辞典 **2,136**・四字熟語 400・伝統色 250 ほか各辞典。

**容疑者（結論の根拠に引かない）**

現行 `docs/site-concept.md`・`DESIGN.md` の記述、cycle-310 の各文書の結論、現行の実デザイン（favicon・OGP・実装トークン）。

**この文書の来歴（独立レビューの指摘による開示）**

本文書は4度書き直されている。第1版は cycle-310 の【無効】文書と同一構造の面を「独立導出」と偽っていた。第2版は「サイトは店を名乗っていない」という事実主張が本番と矛盾し、回遊を上位9件から誤読し、3案比較が実質2案だった。第3版は **(i)** 在庫を数えずに「日本語まわりのあれこれ」と正体を定義して**道具の3/4とブログの9割を対象外にし**、**(ii)** 回遊を今度は過小に読み（辞典で項目を次々引く 18 セッション・146 PV を「回遊ですらない」と断じた）、**(iii)** 視覚の制約を3経路で現行デザインに一意化していた。

**繰り返している誤りの型は一つである——不都合な実態を確かめず、都合よく単純な説明で代替する。** 第2版は回遊を過大に、第3版は過小に読んだ。向きは毎回結論に合わせて反転し、型は変わらなかった。**似た結論に至ること自体は問題ではない。問題は、確かめずに書くことである。**

## 2. 来訪者の実像

詳細と数値は [visitor-reality.md](./visitor-reality.md)。決定に効く事実は次の7点である。

1. **来訪者の圧倒的多数は1ページで帰る。** organic セッションの 95.1%、engaged セッションでも **92.8%** が1ページで終わる。**複数の面を巡って初めて像を結ぶ設計は、定義上9割超に届かない。**
2. **デバイスは面によって違い、単一デバイスを既定に置けない。** 全体では organic の 80.9% がモバイルだが、それは organic の 86% が遊びへの着地だからである。区画別では**遊び 87.5%（n=1,222）・辞典 66.1%（n=115）・ブログ 0.0%（n=70）・道具 10.0%（n=10）**。
   - **ただしブログと道具の数字は検索エンジン構成に交絡している**——ブログ70のうち56、道具10のうち6が Bing 経由で、Bing はモバイル検索をほとんど運ばない。Google だけの独立標本はブログ n=14・道具 n=4 にすぎない。**この2区画の数字を単独で設計制約に昇格させてはならない。** 結論（単一デバイスを既定に置けない）は、交絡の小さい辞典（n=115・Google 主体で 62.3%）だけで成立する。
3. **測度によってサイトの姿はまったく違って見える。** 検索**クリック**の 92.9% は `/play`（うち診断1本で 88.0%）だが、検索**表示**の 82.4% は `dictionary`（62,119 表示・クリック 76・CTR 0.12%）。**デザインを実際に経験するのは着地した人だけである**一方、**表示は最大の未収穫分**である。どちらか一方の測度で決めない。
4. **回遊はセッション比では小さいが、PV 比では小さくない。ただし裾が極端に重い。** 2ページ以上のセッションはセッションの 4.9% で、**organic PV 1,924 のうち 365（19.0%・2ページ目以降だけで 15.3%）を生んでいる**。**しかしそのうち 128 PV（回遊 PV の 35%）は、11ページ以上見た4セッション（organic の 0.28%）が生んでいる**——この4件を除くと 12.3% に落ちる。区画をまたぐ横断は 0.7% と少なく、動きの中心は同じ区画の中である。
5. **サイトは現に「AIが営むよろず屋」と名乗っている。** トップと `/about` の表示テキストと meta description に実在し、テストが固定している。**ただしその2面は検索結果からクリックされていない**（SC 実測でクリック 0・表示 8／2）。ただし「誰も見ていない」ではない——検索から別の面に着地した5セッションが、サイト内リンクで `/`（4 PV）・`/about`（2 PV）に到達している。**「検索の入口としては機能していないが、回遊の先としては見られている」**が正確である。
6. **在庫は領域で括れない。** 道具 36 のうち日本語に関わるのは 7 程度（`char-count`・`kana-converter`・`keigo-reference` 等）で、残る約 29 は `base64`・`json-formatter`・`qr-code`・`unit-converter` など言語に依存しない汎用の道具である。ブログ 86 も大半が開発・AI 運用の記事である。**日本語まわりに寄っているのは辞典と遊びの一部であって、サイト全体ではない。**
7. **信頼を壊す第1因子は日本語の不自然さである**（40.91%）。ただし出典は**企業公式サイトで購買経験のある 300 名**を対象とした非査読のアンケートで、社内の出典文書自身が「参考値」と断っている。**当サイトは購買を伴わない無料の道具・辞典・診断サイトであり、この統計を当サイトの来訪者に当てはめること自体が母集団の拡張である。** 補助的な傍証として扱い、単独の根拠にしない。

## 3. 決定: このサイトは何か

**yolos.net は、AI が作って公開している、検索でたどり着いたそのページで用が足りる、小さな道具と辞典と読み物と遊びの集まりである。**

- **領域で括らない。** 現に在るのは、日本語の辞典も、言語に依存しない変換・計算の道具も、開発の記事も、診断や遊びもである（実測2-6）。**「よろず（あらゆるもの）」は名前の由来であると同時に、在庫の実態でもある。** 領域を狭めないのは方針であり（Rule 5）、同時に事実の記述でもある。
- **来訪者にとっての価値の単位は「1ページ」である。** 大多数は2ページ目を見ない（実測2-1）。だから各ページは、**それ単体で用が足り、それ単体で信頼に足る**ものでなければならない。とくに**トップページを検索の入口として当てにできない**（検索結果からのクリックは 0）。ただし回遊の先としては見られている（organic セッション内で 4 PV）。
- **ただし次の一つへ橋を架けることは、ゴールに直結する。** 回遊は organic PV の 19.0% を現に生んでいる（実測2-4）。順序を守る——**まずその1ページで用を足し、そのうえで「他にも試したいもの・調べたいものがありそうだ」と感じられるようにする**。満足の前に回遊を求めない。
- **この決定は、現に在るすべてに等しく適用される**——遊び 20・道具 36・辞典・ブログ 86 のいずれにも。特定の型や領域だけを正体に据えて残りを例外にしない。
- **「よろず（広さ）」の来訪者向けの扱いを、ここで決める。** 名前の由来（YOLO×よろず）は不変の事実であり、`/about` で**説明することは正直な開示として続けてよい**（§4-D）。しかし**「よろず屋である」という自己像は掲げない**（§5）。また**品揃えの規模そのものを売りにしない**——来訪者は品揃えを見に来たのではなく、一つの用事を持って来ている。§4-E が定めるのは「**他にも試したいもの・調べたいものがありそうだ**」という来訪者の期待であって、規模を見せて理解させることではない。
- **AI が運営する実験であること、内容が誤りうることを明示する**（Rule 3 が明示的に要求している）。これは**正直な開示**であって**売り物ではない**。
- **何が残るかは来訪者の行動が決める。** AI の見立ては作るきっかけにはなるが、残す理由にはならない。

**なお「新しく何を作るか」の選択基準（関与して得られるものを優先し、検索結果の画面で配達しきれる情報を量産しない）は、この正体とは別の層の判断であり、`site-concept.md` の判断基準が持つ。** 印象は現に在る全ページに適用され、選択基準はこれから作るものに適用される。両者を混同しない。

## 4. 決定: 来訪者に持ってほしい印象

来訪者が **1ページの体験の中で** 受け取る印象として、次の5つを定める。いずれも来訪者の心に起きることであって、サイトの仕組み・作り方ではない。**根拠は constitution から導けるものだけを書き、導けないものは「当サイトの選択」と明記する。**

### A. 安心（ここは大丈夫だ）

「雑に作られた場所でも、不安を煽って何かさせようとする場所でもない。安心して使える」と感じてほしい。

- 導出: **Rule 2**（人を害さない・悲しませない）と **Rule 4**（量より質・あらゆる面で最高品質）。**この二つが来訪者の側で結ぶ像が「安心」である。**

### B. 気軽さ（気負わず、すぐできる）

「難しいことも面倒な手続きもなく、いま、ここで、ちょっとできる」と感じてほしい。

- 導出: **実測と Goal による当サイトの選択**（constitution からは導けない）。来訪者は「このサイトを使う」と決めて来たのではなく、検索の途中で立ち寄っている（実測2-1・2-2）。**Goal が名指す測度は PV であり、そこへ効くのは「入口で引き返されないこと」という行動だが、来訪者の側でそれを起こすのは「気負わなくていい」という感じであり、印象として定めるのは後者だけである。**
- **Rule 2 の enjoyable からは導けない**（楽しさが軽さを要求するとは限らない——長い小説も難しいゲームも楽しい）。

### C. 手ごたえ（やってよかった）

「来てよかった。探していたものが手に入った、あるいは、やってみて面白かった」と感じてほしい。

- 導出: **Rule 2**（helpful **または** enjoyable——constitution は両方を等価に認めている）。**役に立つことと楽しいことのどちらでもよいという Rule 2 が、来訪者の側で結ぶ像が「やってよかった」である。**
- **関与（手を動かすこと）を印象の条件にしない。** 調べに来た人が調べたいことを見つけて帰るのも、記事を読んで得るものがあったのも、等しく「やってよかった」である。**関与を条件にすると、その人たちの満足を印象の外に置くことになる**——実際には、そうやって調べに来る人・読みに来る人のほうが多い（実測2-3・2-6）。
- **関与して得られるものを優先的に作るという方針は、印象ではなく「何を作るか」の選択基準の側にある**（§3 末尾）。

### D. 正直（取り繕っていない）

「この場所は自分に対して正直だ。隠しごとも、騙しもない」と感じてほしい。

- 導出: **Rule 3**（AI 運営と誤りうることの明示）と **Rule 1**（法令・倫理）。**Rule 3 が要求する開示と Rule 1 が禁じる欺瞞が、来訪者の側で結ぶ像が「正直」である。**
- **「格好つけない」は D に含めない。** 自分を魅力的に提示することは違法でも非倫理でもなく、Rule 3 が要求するのは開示であって自己提示の抑制ではない。器を控えめにするか否かは**視覚上の選択**であり、印象の層で先取りせず T8 の比較に委ねる。

### E. 広がり（他にも面白そうなものがある）

「ここには、まだ他にも試したいもの・調べたいものがありそうだ」と感じてほしい。探して迷う不安ではなく、見つける楽しさとして。

- 導出: **Rule 4 後半**（探索しやすく整理されていること）と **Goal**（回遊は PV そのもの）。**Rule 4 後半が求めるのは整理というサイト側の性質、Goal が求めるのは回遊という行動だが、来訪者の側でそれを起こすのは「まだ他にもありそうだ」という期待である。印象として定めるのは後者だけである。**
- **Rule 5 は根拠に引かない。** Rule 5（"Try a variety of things with creative ideas"）の主語は作り手であって、来訪者の印象を導かない。
- **強度（実測・脆弱性つき）**: **この期待は現に生まれている**——次の一つへ実際に進んだ人がいて、その動きが organic PV の 19.0% を生んでいる（実測2-4）。**ただしその 35% は4セッションが生んでおり、この根拠は少数の行動に強く依存する**（4件を除くと 12.3%）。進んだ先の中心は**同じ区画の中**であり、区画をまたぐ横断は 0.7% と少ない。**「他にも試したいもの・調べたいものがありそうだ」が湧くのは主に同じ種類の中であって、サイト全体の広さについてではない。**

### 面が衝突したときの順序

**順序づけるのは面（A〜E）であって、Rule の条文ではない。** constitution の優先順位（数字の小さい Rule が優先）は、**各面がどの Rule に由来するか**を通じて順序に反映させる。

- **D の全体と、A のうち「不安を煽って何かさせようとする場所ではない」の部分は、絶対の下限である**（Rule 1・Rule 2 前半に由来）。**ここを削って他を得る取引はしない。**
- **その内側で C（手ごたえ）を最大化する。** C は Rule 2 由来、A のうち「雑に作られた場所ではない」の部分は Rule 4 由来であり、**constitution が Rule 2 を Rule 4 の上に置いている以上、C はそちらより優先される**。粗削りでも「やってよかった」と感じられるものを出す判断は、この順序が認めている。
- **B（気軽さ）と E（広がり）は C に従属する。** B は C に到達するための条件、E は C を受け取った後に働く。C と衝突したら C を採る。**これは constitution からは導けない当サイトの選択である**（E の由来である Rule 4 後半と Goal は、C との優劣を定めていない）。

**A は由来の異なる二つの部分を含む。** 「不安を煽って何かさせようとする場所ではない」（Rule 2 由来）と「雑に作られた場所ではない」（Rule 4 由来）である。**A を一つの塊として C の上に置くと、Rule 4 を Rule 2 より優先することになる。** Rule 2 由来の部分だけが絶対の下限であり、Rule 4 由来の部分は C に劣後する。

## 5. 判定: 店（よろず屋）メタファーの扱い

「よろず屋＝店」はサイト名の由来ではなく、過去の PM が作った構築物である（由来は YOLO×よろず）。3案を比較する。

- **案1: 全面 keep** — 来訪者向けの自己像としても、設計の統一原理としても保持する。
- **案2: 全面 remove** — 自己像からも統一原理からも外す。規則そのものは、個別に印象へ接続して残す。
- **案3: 自己像から外し、設計の統一原理としてのみ保持する。**

### 評価

**判定に使う測度を先に宣言する。** 案1（**来訪者向けの自己像**）は「**来訪者に届くか・伝わるか**」で測る——自己像は来訪者に見せるものだからである。案3（**内部の統一原理**）は「**内部の導出に何が起きるか**」で測る——来訪者に不可視であり、感じ方では弁別できないからである。**対象の層に測度を合わせ、都合のよい測度を使い分けない。**

**評価対象を取り違えないこと。** 案1 が問うているのは「**AIが営むよろず屋**」という**自己像の語**である（トップ・`/about` の表示テキストと meta に実在）。**「のれん・品書き・棚」は来訪者に一度も表示されない内部の設計語彙**であり（可視なのは `aria-label` の「品書き」のみ）、案1 の評価対象ではない。「よろず屋」は国語辞典に載る一般語であって符牒ではない——**符牒だから伝わらない、という論法はこの語には使えない。**

**案1（現在の配置のまま保持）について。** 名乗っている2面は**検索結果からクリックされていない**（SC クリック 0・表示 8／2）。到達するのは回遊した来訪者だけで、**organic セッション 1,417 のうち5件（0.35%）**にすぎない。すなわちこの自己像は、掲げてはいるが**ほとんどの来訪者の目に触れていない**。

> **ただし「誰にも届いていない」とは書けない。** 第6版まではそう書いていたが、それは「organic PV = 0」という**測定のアーティファクト**に基づいていた（`page_view` の `medium` タグで絞ると2ページ目以降が構造上ゼロになる）。セッション基準では `/` に 4 PV・`/about` に 2 PV が到達している。**同じ文書の中で、回遊を語るときはセッション基準を、トップを切り捨てるときはタグ基準を使っていた**——結論に有利な測度を箇所ごとに選んでいたことになる（独立レビューが捕捉）。**案1 の却下は「届いていない」ではなく「ほとんどの来訪者の目に触れない配置である」ことを理由とする。**

**案1'（自己像を、届く場所へ移す）——実測が示唆する対案として、明示的に検討する。** ほとんど誰の目にも触れない2面ではなく、全員が着地する個別ページ側に「AIが営むよろず屋」を置けば、届かないという問題は解消する。とくに **E（他にも試したいもの・調べたいものがありそうだ）を一語で届けうる既存資産**として、この案には固有の魅力がある。しかし採らない。

- **(i) 伝わるかは未測定である。** `DESIGN.md` §11 が「店の語彙の来訪者到達性」を実測項目として立てたまま、一度も測っていない。**本文書はこれを「伝わらない」と確定できる根拠を持たない。** この未測定を認めたうえで、次の (ii)(iii) を理由に落とす。
- **(ii) 用事を持って来た人に、自己紹介を挟む摩擦になる。** 来訪者は「自分に似たキャラを知りたい」「この漢字の読みを知りたい」という一つの用事で着地している（実測2-3）。その面の目立つ位置に運営の自己像を置くことは、**B（気負わず、すぐできる）と C（探していたものが手に入った）に対して摩擦として働く**。
- **(iii) 店フレームを上流に残すことになり、案3 と同じ経路が開く。** 「よろず屋」は店の枠を持ち込む語であり、来訪者に見せる限り、そこから「店だから◯◯」という導出が再び生まれる余地を残す。

**したがって案1・案1' とも落ちる。ただし (i) のとおり「伝わらない」は実測されていない**——落とす理由は伝達の失敗ではなく、摩擦（ii）と導出経路（iii）である。

**案3 について。** 統一原理として「店」を残すと、**上位の統一原理が残る限り「店だから◯◯」という導出の経路が残る**——cycle-306〜310 が繰り返した「店だから印を押す」「店だから店主と名乗る」はそこから出た。**案3 は落ちる。**

> なお第3版は案3 の却下理由として「機能名なら再解釈されないとは言えない以上、語の言い換えは解決にならない」も挙げていたが、**これは撤回する**。案2 の実施内容も「のれん→ヘッダ」「品書き→罫で区切った一覧」という語の言い換えを含むため、同じ論法は案2 自身を切る。留保を案3 にだけ適用するのは選択的である。

**案2 について。** 懸念は「規律の根拠を失う」ことである。**検証すべきは、店に依存していた規則が §4 へ付け替えられるかである**——店に依存していない規則は、店を外しても失われないので検証の対象にならない。[inventory-design.md](./inventory-design.md) §G の悉皆分類によれば、`DESIGN.md` で**店前提を外すと崩れるのは6箇所**（表題・冒頭注記・§1 リード「一軒の店に見せる」・§1-2「店の言語で組む」・§6 末項「店の語彙を使う」・§11 の実測項目）、**語彙のみ依存が約15箇所**、**残る過半は非依存**である。

**店に依存していた6箇所を、§4 へ付け替えられるか。**

| 店に依存していた規定                                            | §4 へ付け替えられるか                                                                                                |
| --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| §1 リード「雑多な品揃えを**一軒の店に見せる**」（＝統一の原理） | **できない。** §4 は5つの印象を定めるだけで、多様な中身を一つに束ねる原理を与えない。**これは実際に失われる。**      |
| §1-2「**店の言語で組む**」（のれん・品書き・棚・値札・包み）    | **語彙は失われる。** 規則の中身（ヘッダの形・一覧の形式）は視覚形式なので §4 からは決まらない（下表の下2行と同じ）。 |

**参考: 店に依存していない規範的な規則が §4 に接続できるか**（これらは店を外しても失われないが、根拠を印象へ移せるかを見る）。**検証は §4 の文面のみを使い、言い換えずに行う**——T8 は同じ検証を全規則について繰り返すため、ここで言い換えると同じ崩れが全規則へ伝播する。

**結論。**

1. **店に依存していた規則のうち、統一の原理（「一軒の店に見せる」）は §4 では代替できない。これは案2 の実際の損失である**（§6 の3案比較が、代わりの統一原理を決めなければならない）。
2. **視覚形式は §4 からは決まらない**（一覧の形式・角丸・色）。ここも T8 の比較で決める領域である。
3. **規範的な規則の多くは、そもそも店にも §4 にも依存していない。** 出し惜しみの禁止・煽りの禁止・広告の分離は §4 に接続できるが、**品質バー（コントラスト AA・タップ標的 44px・キーボード操作・フォーカス可視）と AI slop 禁止リストの地は §4 ではなく constitution（Rule 2・Rule 4）とデザイン調査である。** これらは印象体系の外に立っている——**「§4 に接続できない規則は根拠がない」と読んではならない。**

この3点を明示したうえで、**案2 を採る**（損失1は §6 が引き受ける）。

### 決定

**案2 を採る。店を、来訪者向けの自己像からも、設計の統一原理からも外す。**

- **来訪者に店を名乗らない。** 店の signifier を、来訪者に届く層（表示テキスト・`aria-label`・メタデータ・画像内の文字）に置かない。
- **規範的な規則は §4 の印象へ根拠を付け替えて残す**（上表）。**視覚形式は T8 の3案比較で決め直す。**
- 規則は機能の名で書く（「のれん」→「サイト名と一本罫のヘッダ」等）。**個々の規則がどの印象に奉仕するかを、規則ごとに示す。**

> **付け替えの際の規則: §4 で定めた面名と説明文の語を、他のどの節でも言い換えない。** 「静かで読みやすい」「見つけやすい」「美しい」のような**器の性質**へ言い換えた瞬間、印象はサイト側の性質に化け、そこから導いた規則は印象に接地していないものになる（それが cycle-303〜310 の8サイクルが繰り返した失敗の形である）。

**失うもの（正直な計上）。**

1. **「一軒の店に見せる」という一語で全体の統一を説明する求心力**を失う。統一の根拠は各規則が個別に §4 へ接続して示さねばならず、記述コストは増える。
2. **視覚形式については、§4 は根拠を与えない。** 上表のとおり、一覧の形式も色も角丸も §4 からは導けない。**この空白は T8 の3案比較が埋める**——コンセプトが視覚を一意に決めないことを認めたうえで、比較で決める。
3. **来訪者可視の実コストが発生する**——トップのヒーロー文、`/about` のリード文、**両ページの meta / og / twitter description**、「結果は札にして持ち帰れます」等の書き換え。**meta description は検索結果に表示される文言であり、変更は SEO への影響を伴う。** これらを固定しているテストの更新も要る。実施は B-652。
4. **内部語彙の除去範囲は大きい**——`aria-label` の「品書き」は全ブログ記事（86本）を含む多数の面で描画される。コンポーネント名・ファイル名・公開 URL にも及ぶ。

**なお、cycle-306〜310 に起きた事故のうち店メタファーに帰責できるのは「印の要否・形をめぐる往復」までである。** 虚偽報告・隠蔽・自己点検の偽装は誠実性の失敗であって、店を外しても直らない。

## 6. コンセプトが視覚言語に与える制約（T8 への橋渡し）

**§4 の印象だけでは視覚言語は一意に決まらない**（§5 の表で実証したとおり、一覧の形式も色も角丸も導けない）。**印象を手段の代用にしない**——一意に決まると称した瞬間、現行を追認する経路がそこから開く。コンセプトが与えられるのは次の制約だけである。

1. **文章の質が信頼を左右する。** 地はデザイン調査（`docs/research/2026-07-11-design-antipatterns-and-direction.md`）であり、**AI 生成に見えるサイトで信頼を最初に壊すのは視覚ではなく日本語の不自然さであること、したがってデザインシステムが「文章」の層を持つ必要があること**を結論している。A（安心）を届けるうえで、言葉づかいは装飾より先に効く。（実測2-7 の統計はこの結論の傍証にすぎず、母集団が当サイトと異なるため単独の根拠にしない。）
2. **AI が量産したページに見えないこと。** A（安心）の裏返しの要求であり、装飾の問題ではなく信頼の問題である。
3. **デバイスの既定は面によって違う。単一デバイスを前提にしない。** 遊びの面はモバイルが 87.5%（n=1,222）、辞典は 66.1%（n=115・Google 主体）である。全体値 80.9% は遊びへの着地が多いことの反映であって、サイト全体の既定ではない。**面ごとに主たる画面を確かめて作り、どちらの画面でも成立させる。**
   - **ブログ・道具の数字（0.0%・10.0%）は制約に使わない**——検索エンジン構成に交絡しており（Bing 経由が大半）、Google だけの独立標本は n=14・n=4 と小さい（実測2-2）。**これらの面の主たる画面は、T8 で改めて確かめること。**
4. **主役は来訪者が得たものである。** C（手ごたえ）を届けるために、ページの中で最も強く現れるべきは来訪者の結果・答え・成果物である。（**器を「静か」にするか否かは、この要求から一意には決まらない。視覚上の選択として T8 の比較に委ねる。**）
5. **1ページで用が足り、そのうえで「他にも試したいもの・調べたいものがありそうだ」と感じられること**（C と E）。

**決めないこと（T8 の3案比較で決める）。**

- **視覚の系統（register）を本文書では決めない。** 第3版は「和の register を採る」と書いたが、それは導出ではなく選択だった——漢字や四字熟語を扱うことは、和の意匠を要求しない（モダニズムの組版で作られた辞典は実在する）。しかも第3版がその根拠にした「題材の中心が日本語の文字文化」は、在庫の実態（道具の3/4は言語非依存・ブログの大半は開発記事）と食い違っていた。**register は3案の比較で決める。**
- 色・書体・レイアウト形式・角丸・罫の使い方も同様である。

**何で決めるのか（§4 だけでは決まらないことを認めたうえで）。** 比較の基準は次の4つである。**§4 の印象だけで比較しようとすると、案が拮抗したときに文書に無い基準を持ち込むことになる**——それがドリフトの入口である。

1. **§4 の5つの印象をどう届けるか**（第一の基準）。
2. **デザイン調査の禁止リスト**（`docs/research/2026-07-11-design-antipatterns-and-direction.md`）。同調査は「『良い感じに』という指示は無力で、機械的に検査できる制約だけが AI の出力を平均から引き離す」と結論している。**制約2（AI が量産したページに見えないこと）を実際に満たすには、この禁止リストが要る。**
3. **品質バー**——コントラスト AA・タップ標的・キーボード操作・フォーカス可視・フォント読み込みでリフローしないこと。**これらの地は §4 ではなく constitution（Rule 2・Rule 4）であり、印象体系の外にある。どの案も満たさなければならない下限である。**
4. **面ごとのデバイス実態**（制約3）。

**T8 の手順。**

- **(i) 現行の実装値を見ずに、案を3つ生成する。** 生成は現行 `DESIGN.md` と `src/` を読んでいない者が行い、**3案は互いに異なる系統を含むこと**（すべてが同じ系統に収束したら、制約が一意化している徴候なので生成をやり直す）。
- **(ii) そこへ現行の視覚言語を、出所を伏せた4案目として匿名で加える。** **現行を候補から先験的に外すことはしない**——それは「来訪者価値を最大化する案を選ぶ」という決定原則に反する（現行が最良である可能性を、追認を恐れるあまり排除することになる）。匿名で混ぜれば、追認の圧力を受けずに候補としては残せる。
- **(iii) 4案を上記の4基準で比較して選ぶ。** 比較者にもどれが現行かを伏せる。
- **(iv) 選んだ案を規則に落とす。** 規則ごとに、どの基準（印象・禁止リスト・品質バー・デバイス実態）から来たかを示す。

**評価窓と撤退基準。** サイト全体の視覚言語の入れ替えは、当サイトで最大級の賭けである。`docs/site-concept.md` の判断基準は「着手前に評価窓と撤退基準を決める」ことを求めており、これも例外ではない。**出荷前に ADR として、何を・いつ・どの数値で判定するかを登録する**（実装は B-652）。**変更が来訪者にとって悪化だったと判定する手段を持たないまま出荷しない。**

**この節の地の脆弱性（開示）。** 上の制約1は、表示の 82.4% を占める辞典区画の性格に部分的に依存している。**辞典の処遇（体験化 or プルーニング）は B-564 として未決であり、その結論次第で制約1の重みは変わる。** T8 はこの依存を知ったうえで規則を確定すること。

## 7. 自己点検

- **測度は問いに一致しているか。** 判定の基準は一つ——**その文が述べているのは来訪者の頭の中で起きることか、サイト側で起きることか**。
  - **適用範囲**: 印象を**構成する**位置（面名・説明文、および**他節でのそれらの言い換え**）には、来訪者の心に起きることだけを置く。**導出欄は出典を名指す欄**であり、Rule や Goal といったサイト側の指令を引かざるを得ない——そこには必ず「**来訪者の側でそれが何になるか**」への変換を一文添える（**5面すべての導出欄がその形になっている**）。
  - **順序を書く節も、印象の位置である。** 面が衝突したときの順序は、**面（A〜E）を主語にして書き、Rule の条文を主語にしない**。「C は Rule 2 の helpful/enjoyable である」のような繋辞は、印象をサイトへの指令そのものと同一視するため置かない——Rule は「**由来**」として示すに留める。
  - **実施結果（§4 の全文を走査した）**: 面名5・説明文5・導出欄5・強度1・**順序節4項**の計20文に基準を当てた。面名と説明文に「このサイト」を主語とする文は無い。導出欄は5面すべてに変換文がある。§4-E の「強度」は実測の記述であり、印象の定義ではない（位置は留保欄）。
  - **順序節は書き直した。** 第6版では「C は Rule 2 の helpful/enjoyable であり」「A が二つの Rule の融合である」のように、**印象を Rule の条文（サイトへの指令）と同一視する定義文**を置いていた。§4 の他の全欄が守っている「Rule が来訪者の側で結ぶ像」という変換を、**この節だけが経ていなかった**——しかもそれは第6版の改稿で新たに混入したものだった（前版は面の名だけで書かれていた）。捕捉したのは独立レビューである。**指摘された箇所を直すたびに、書き換えた箇所へ同型が生まれている。**
  - **第4版では、この申告が偽だった。** C の説明文に「**このサイトが存在する理由である**」（主語＝サイト）が残り、C の導出欄だけ変換文が無かったのに、「面名・説明文はすべて来訪者側」「導出欄の (B) にはすべて変換文を付した」と書いていた。**指摘された面（B・D・E）だけを直し、指摘の対象外だった C を走査せずに「すべて」と申告した**——達成していない網羅性を主張して結論を支える型である。捕捉したのは独立レビューである。
  - **形式のテストで代用しない。** 「NG 語を含まないか」も「引用符の内側か」も、形を見ているだけで問いに答えていない。**位置ではなく主語で判定する。**
  - **言い換えの点検は、規則の全範囲で行う。** 第3版は §5 で印象 A を「静かで読みやすい」という器の性質に言い換えていた。第4版はその**器の性質語だけ**を潰して「文書全体で確認した」と書いたが、規則の文言は「面名と説明文の語を他のどの節でも言い換えない」であり、E を「隣にもう一つあると分かること」へ縮小した箇所が4つ残っていた（§3・§4-E の強度・§5 の検証表・§6-5）。**期待（試したい・面白そう）から認知（分かる）への縮小は、次の一歩で「分かるようにする」というサイト側の動作へ渡る経路である。** 4箇所とも §4-E の文面に統一した。
- **地から実際に導けるか、一つずつ確かめたか。** B は constitution から導けないので「当サイトの選択」と明記した。**D からは「格好つけない」を外した**（Rule 1/3 から導けない視覚選好であり、印象の層で T8 の探索空間を絞っていた）。E から Rule 5 を外した。**Rule 番号を付すこと自体は導出の証明にならない。**
- **測度を一方だけ選んでいないか。** 第2版は検索クリックだけを報告した。**第3版は回遊をセッション比だけで測り、Goal が名指しする測度（PV）を報告していなかった**——PV で見れば回遊は organic PV の 19.0% を生んでおり、「実測ではまだ達成されていない」は誤りだった。本版は両方を報告し、E の強度を書き直した。**同じ誤りが、指摘された箇所以外で繰り返されていた。**
- **在庫を確かめたか。** 第3版は在庫を数えずに「日本語まわり」と正体を定義し、**道具の3/4とブログの9割を対象外にしていた**。本版は実カウント（遊び20・道具36・ブログ86・漢字2,136）に基づき、領域で括らない定義に改めた。
- **視覚解を上流で先取りしていないか。** 第3版は「格好つけない」（§4-D）・「和の register」（§6）・「静かな器」（§6）の3経路で、現行デザインの族を事実上一意に指していた。本版は3つとも外し、T8 の3案生成に「互いに異なる系統を含むこと」を課した。
- **残る不確かさ。** (i) 制約1の重みは B-564（辞典の処遇）の結論に依存する。(ii) 参照型と体験型の CTR 差には順位交絡があり、弁別子は「実測で確定」とは言えない。(iii) 40.91% の統計は母集団が当サイトと異なるため、補助的な傍証にとどめた。
