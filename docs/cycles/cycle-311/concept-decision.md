# コンセプト＝ブランドイメージの決定（T4）

## 0. この文書が答える問い

**yolos.net は何であり、来訪者にどんな印象を持ってほしいか。**

これは二つの問いではなく一つである。喚起したい印象を持たない「正体」は来訪者にとって無価値であり、体現するものを持たない「印象」は接地しない。両者は一つの決定を作り手側と来訪者側から見たものにすぎないので、一体で決める（別文書に割ると必ずドリフトして矛盾する——それが前サイクルの失敗の構造的原因だった）。

## 1. 入力と、この文書の来歴

**地（根拠に引いてよい）**

- `docs/constitution.md`（Goal と Rule 1〜5）。
- サイト名 yolos.net の由来＝**YOLO × よろず**の二重の意味（不変の事実）。
- **来訪者の実測と本番の実見**（[visitor-reality.md](./visitor-reality.md)）。
- 外部の一次資料・調査（出典の条件つきで用いる）。
- **サイトに現に存在するもの**——遊び 16・道具 38・ブログ記事 87 本・漢字辞典 2,136 件ほか各辞典。何をどれだけ持っているかは事実である。

**容疑者（結論の根拠に引かない）**

現行 `docs/site-concept.md`・`DESIGN.md` の記述、cycle-310 の各文書の結論、現行の実デザイン（favicon・OGP・実装トークン）。

**この文書の来歴（独立レビューの指摘による開示）**

本文書は3度書き直されている。

- **初版**の印象4面は、cycle-310 が作り【無効】と自認した `brand-image.md` の5面から E を落として語を整えたものと、記号・順序・名称において**同一**だった。それを「constitution と実測だけから独立に決定した」と申告していたが事実に反する。
- **第2版**は印象を5面に増やし店の扱いを3案比較にしたが、(i) 「サイトは店を名乗っていない」という事実主張が**本番と矛盾**し、(ii) 回遊の実態を上位9件の表から「ほぼすべて別の種類を試す」と**誤読**し、(iii) 3案比較が**実質2案**（採用した案3 は内容において案2 だった）、(iv) §6 が現行 `DESIGN.md` §1 の**写像**でありながらその同型性を検査していなかった。
- **本版（第3版）**はこれらを訂正した。**似た結論に至ること自体は問題ではない（同じ地から導けば似る）。問題は、引き継いだものを独立導出と偽ること、都合のよい事実で不都合な事実を代替することである。**

## 2. 来訪者の実像

詳細と数値は [visitor-reality.md](./visitor-reality.md)。決定に効く事実は次の6点である。

1. **来訪者の圧倒的多数は1ページで帰る。** organic セッションの 95.1%、人間の操作を伴う engaged セッションでも **92.8%** が1ページで終わる。**複数の面を巡って初めて像を結ぶ設計は、定義上9割超に届かない。**
2. **その1ページはほぼモバイルの縦長画面である**（organic の 80.9%）。
3. **「実際に来ている人」と「検索の前に現れている面」は別物である。** 検索クリックの 88% は `/play`（そのうち大半が1本の診断）だが、**検索表示の 82.4% は `dictionary`**（62,119 表示・クリック 76）。ページ数でも、ブログ 87 本・漢字辞典 2,136 件ほかの**読む面・引く面が過半**を占める。
4. **回遊は実在するが、広さの経験としては非常に小さい。** engaged で2ページ以上を見たのは 70 セッション。悉皆分類すると、同一の品の中だけ（診断→その結果ページ）が 33、同一区画内で別の品が 27、**区画をまたいだのは 10（organic 全体の 0.7%）**。「四字熟語→別の四字熟語」は深さであって広さではない。
5. **サイトは現に「AIが営むよろず屋」と名乗っている。** トップと `/about` の表示テキストと meta description に実在し、テストが固定している。**ただしその2面には検索から誰も来ていない**（`/` の organic PV = 0・SC 表示 8／`/about` は 2）。「名乗っていない」のではなく「**名乗りが誰にも届いていない**」。
6. **信頼を壊す第1因子は日本語の不自然さである**（40.91%）。ただしこの数値の出典は**企業公式サイトを対象とした n=300 のアンケート**（2025-10・非査読）で、社内の出典文書自身が「参考値」と断っている。**この統計が指しているのは文章（コピー）の質であって、組版ではない**——出典の結論も「デザインシステムは『文章』の層を持つ必要がある」である。母集団も層も拡張せずに用いる。

## 3. 決定: このサイトは何か

**yolos.net は、AI が作って公開している、日本語まわりのあれこれを「その場で使える形」で置いてある場所である。** 試す（診断・ゲーム）、片づける（道具）、調べる（辞典）、読む（記事）——検索でたどり着いたそのページで、用が足りる。

- **来訪者にとっての価値の単位は「1ページ」である。** 大多数は2ページ目を見ない（実測2-1）。だから各ページは、**それ単体で用が足り、それ単体で信頼に足る**ものでなければならない。**サイト全体を見渡す面から何かを伝える設計は、現状まったく届かない**（トップの organic PV は 0）。
- **ただし次の一つへ橋を架けることは、ゴールに直結する。** Goal は PV の最大化であり、回遊は PV そのものである。順序を守る——**まずその1ページで用を足し、そのうえで次があると分かるようにする**。満足の前に回遊を求めない。
- **「試す面」だけがこのサイトではない。** ページ数でも検索表示でも、読む面・引く面が過半である（実測2-3）。**この決定は、遊びにも道具にも辞典にも記事にも等しく適用される。** 特定の型だけを正体に据えて残りを例外にしない。
- **扱う領域は狭めない**（Rule 5）。現に集まっているものが日本語まわりに寄っているのは**これまでの結果であって制約ではない**。ただし後述 §6 の視覚の制約は、いま現にあるものから導く（将来領域が変われば制約も見直す）。
- **ただし、広さそのものを来訪者に見せる自己像にしない。** 品揃えの規模は**サイト側の性質**であって、来訪者に持ってほしい印象ではない——来訪者は品揃えを見に来たのではなく、一つの用事を持って来ている。§4-E が定めるのは「**今やったことの隣に、もう一つある**」という来訪者の気づきであって、よろずの規模を見せて理解させることではない。
- **AI が運営する実験であること、内容が誤りうることを明示する**（Rule 3 が明示的に要求している）。これは**正直な開示**であって**売り物ではない**。
- **何が残るかは来訪者の行動が決める。** AI の見立ては作るきっかけにはなるが、残す理由にはならない。

**なお「新しく何を作るか」の選択基準（関与して得られるものを優先し、検索結果の画面で配達しきれる情報を量産しない）は、この正体とは別の層の判断であり、`site-concept.md` の判断基準が持つ。** 印象は全ページに適用され、選択基準はこれから作るものに適用される。両者を混同しない。

## 4. 決定: 来訪者に持ってほしい印象

来訪者が **1ページの体験の中で** 受け取る印象として、次の5つを定める。いずれも来訪者の心に起きることであって、サイトの仕組み・作り方ではない。**根拠は constitution から導けるものだけを書き、導けないものは「当サイトの選択」と明記する。**

### A. 安心（ここは大丈夫だ）

「雑に作られた場所でも、不安を煽って何かさせようとする場所でもない。安心して使える」と感じてほしい。

- 導出: **Rule 2**（人を害さない・悲しませない）と **Rule 4**（量より質・あらゆる面で最高品質）。この二つが来訪者の側で結ぶ像が「安心」である。

### B. 気軽さ（気負わず、すぐためせる）

「難しいことも面倒な手続きもなく、いま、ここで、ちょっとできる」と感じてほしい。

- 導出: **実測と Goal**。来訪者は「このサイトを使う」と決めて来たのではなく、検索の途中で立ち寄っている（実測2-1・2-2）。重い入口はその関心の軽さに釣り合わず、離脱は PV の損失に直結する。**Goal が求めているのは滞在という行動だが、来訪者の側でそれを起こすのは「気負わなくていい」という感じであり、印象として定めるのは後者だけである。**
- **Rule 2 の enjoyable からは導けない**（楽しさが軽さを要求するとは限らない）。これは実測に基づく当サイトの判断である。

### C. 手ごたえ（やってよかった）

「来てよかった。探していたものが手に入った、あるいは、やってみて面白かった」と感じてほしい。**このサイトが存在する理由**であり、ほかの4つはこれを受け取れる状態を作るために在る。

- 導出: **Rule 2**（helpful **または** enjoyable——constitution は両方を等価に認めている）。
- **関与（手を動かすこと）を印象の条件にしない。** 調べに来た人が調べたいことを見つけて帰るのも、記事を読んで得るものがあったのも、等しく「やってよかった」である。関与を必須にすると、**調べに来た人・読みに来た人が「やってよかった」と感じても、それはこのサイトが目指したものではないことになってしまう**——ページ数でも検索表示でも過半を占めるのは、その人たちが訪れる面である（実測2-3）。**関与して得られるものを優先的に作るという方針は、印象ではなく「何を作るか」の選択基準の側にある**（§3 末尾）。

### D. 正直（取り繕っていない）

「この場所は自分に対して正直だ。隠しごとも、格好つけも、騙しもない」と感じてほしい。

- 導出: **Rule 3**（AI 運営と誤りうることの明示）と **Rule 1**（法令・倫理）。

### E. 広がり（他にも面白そうなものがある）

「ここには、まだ他にも試したいもの・調べたいものがありそうだ」と感じてほしい。探して迷う不安ではなく、見つける楽しさとして。

- 導出: **Rule 4 後半**（探索しやすく整理されていること）と **Goal**（回遊は PV そのもの）。**Rule 4 後半が求めるのは整理というサイト側の性質、Goal が求めるのは回遊という行動だが、来訪者の側でそれを起こすのは「まだ他にもありそうだ」という期待である。印象として定めるのは後者だけである。**
- **Rule 5 は根拠に引かない。** Rule 5（"Try a variety of things with creative ideas"）の主語は作り手であって、来訪者の印象を導かない。§3 で「よろず＝広さは来訪者に見せる自己像ではない」と決めた以上、同じ Rule 5 を来訪者向け印象の根拠に二重使用することはできない。
- **強度の限定**: 現在、区画をまたぐ回遊は organic の 0.7% にすぎない（実測2-4）。**この面は「実測に支えられている」のではなく、「Goal から要請され、実測ではまだ達成されていない」ものである。** 受け取れる範囲は1ページの中に留める——「今やったことの隣に、もう一つある」と分かれば足りる。全体像を見せて理解させることではない（それは届かない）。

### 面が衝突したときの順序

**A（安心）と D（正直）は制約である**——満たさなければ他のすべてが無効になる土台であり、ここを削って他を得る取引はしない。その内側で **C（手ごたえ）を最大化する**。**B（気軽さ）は C に到達するための条件、E（広がり）は C を受け取った後に働く**。B・E が C と衝突したら C を採る。

## 5. 判定: 店（よろず屋）メタファーの扱い

「よろず屋＝店」はサイト名の由来ではなく、過去の PM が作った構築物である（由来は YOLO×よろず）。3案を比較する。

- **案1: 全面 keep** — 来訪者向けの自己像としても、設計の統一原理としても保持する。
- **案2: 全面 remove** — 自己像からも統一原理からも外す。規則そのものは、個別に印象へ接続して残す。
- **案3: 自己像から外し、設計の統一原理としてのみ保持する。**

### 評価

**判定に使う測度を先に宣言する。** 案1（**来訪者向けの自己像**）は「**来訪者に届くか・伝わるか**」で測る——自己像は来訪者に見せるものだからである。案3（**内部の統一原理**）は「**内部の導出に何が起きるか**」で測る——来訪者に不可視であり、感じ方では弁別できないからである。**対象の層に測度を合わせ、都合のよい測度を使い分けない。**

**案1 について。** サイトは現に「AIが営むよろず屋」と名乗っている（実測2-5）。したがって「届いていないから落とす」とは言えない。**落とす理由は別にある**——名乗っている2面（トップ・`/about`）には**検索から来る人が一人もいない**（organic PV 0・SC 表示 8／2）。すなわちこの自己像は、**掲げるコストを払いながら、誰にも届いていない**。一方、来訪者が実際に着地する個別ページでは、店の signifier（のれん・品書き・棚・印）は**自明に伝わらない符牒**であり、A〜E のどの印象にも寄与していない。**掲げても届かず、届く場所では伝わらない。案1 は落ちる。**

**案3 について。** 統一原理として「店」を残すことの問題は二つある。第一に、**上位の統一原理が残る限り「店だから◯◯」という導出の経路が残る**——cycle-306〜310 が繰り返した「店だから印を押す」「店だから店主と名乗る」はそこから出た。第二に、「機能名なら再解釈されない」とは言えない（区画も一覧も再解釈されうる）以上、語の言い換えは解決にならない。**案3 は落ちる。**

**案2 について。** 「規律の根拠を失う」という懸念があるが、これは誤りである。**規律の根拠は §4 の印象に付け替えられる**——「一覧を罫で区切って並べる」は、E（**他にも試したいもの・調べたいものがありそうだと感じる**）と A（**雑に作られた場所ではない、安心して使えると感じる**）から個別に導ける。店という物語を経由する必要はない。

> **付け替えの際の規則: §4 で定めた面名と説明文の語を、他のどの節でも言い換えない。** 「静かで読みやすい」「見つけやすい」「美しい」のような**器の性質**へ言い換えた瞬間、印象はサイト側の性質に化け、そこから導いた規則は印象に接地していないものになる（それが cycle-303〜310 の8サイクルが繰り返した失敗の形である）。**T8 は全規則についてこの付け替えを繰り返すため、この規則を守るかどうかが導出全体の成否を決める。**

### 決定

**案2 を採る。店を、来訪者向けの自己像からも、設計の統一原理からも外す。**

- **来訪者に店を名乗らない。** 店の signifier を、来訪者に届く層（表示テキスト・`aria-label`・メタデータ・画像内の文字）に置かない。
- **設計の規則は残すが、根拠を店から §4 の印象へ付け替える。** そして規則は機能の名で書く（「のれん」→「サイト名と一本罫のヘッダ」、「品書き」→「罫で区切った一覧」、「値札」→「メタ情報の小ラベル」、「棚」→「区画」）。**個々の規則がどの印象に奉仕するかを、規則ごとに示す**（T8 の作業はまさにそれである）。

**失うもの（正直な計上）。**

1. **「一軒の店に見せる」という一語で全体の統一を説明する求心力**を失う。今後、統一の根拠は各規則が個別に §4 へ接続して示さねばならず、記述コストは増える。
2. **来訪者可視の実コストが発生する**——トップのヒーロー文「AIが営む、よろず屋です。」、`/about` のリード文、**両ページの meta / og / twitter description**、「結果は札にして持ち帰れます」等の書き換え。**meta description は検索結果に表示される文言であり、変更は SEO への影響を伴う。** これらを固定しているテストの更新も要る。実施は B-652。
3. **内部語彙の除去範囲は大きい**——`aria-label` の「品書き」は全ブログ記事（87本）を含む多数の面で描画される。コンポーネント名・ファイル名・公開 URL（`…/result/{id}/fuda-image`）にも及ぶ。

**なお、cycle-306〜310 に起きた事故のうち店メタファーに帰責できるのは「印の要否・形をめぐる往復」までである。** 虚偽報告・隠蔽・自己点検の偽装は誠実性の失敗であって、メタファーとは無関係であり、店を外しても直らない。

## 6. コンセプトが視覚言語に与える制約（T8 への橋渡し）

**§4 の印象だけでは視覚言語は一意に決まらない**——「安心」から角丸 0px は導けないし、「気軽さ」は明朝とも丸ゴシックとも両立する。**印象を手段の代用にしない**（一意に決まると称した瞬間、現行を追認する経路がそこから開く）。この不足を認めたうえで、コンセプトが与える制約を明示する。

**開示**: 以下の制約のうち複数は、現行 `DESIGN.md` §1 の項目と同型である（「組版に投資する」「AI slop からの距離」「器は静か・成果物が主役」「並べて選べる」）。**同じ地から導けば似るのは当然だが、それを独立導出と偽らない。** 本節は現行 DESIGN の写しではなく §4 からの導出として書くが、結果として似ている事実をここに記す。

1. **日本語の文字と言葉が主役である。** 現に扱っているものの中心（漢字・四字熟語・伝統色・ことわざ）は日本語の文字文化そのものであり、それを扱う面が検索表示の 82.4% を占める（実測2-3）。題材が文字である以上、A（安心）を届ける主戦場は文字の扱いである。
   - **文章の質と組版は別の層である。** 信頼を壊す第1因子の統計（実測2-6）が指すのは**文章**であり、そこから組版への投資は導けない。**文章の自然さは §4-A の直接の要求として扱い、組版への投資は「題材が文字そのものである」ことから導く。** 二つを混ぜない。
2. **和の register を採る。** 扱っている題材の中心が日本語の文字文化である以上、それに応答する視覚の系統を採る。**これは register の決定であって、具体的な色・書体・値の決定ではない。**
3. **AI が量産したページに見えないこと。** A（安心）の裏返しの要求であり、装飾の問題ではなく信頼の問題である。
4. **モバイルの縦長画面が既定である**（実測 80.9%）。
5. **静かな器・主役は来訪者が得たもの。** C（手ごたえ）が目的である以上、器が主張してはならない。
6. **1ページで完結し、隣に次があると分かること**（C と E）。

**T8 の手順（現状追認の禁止）。** 上の制約は複数の視覚解を許す。したがって T8 は次の順で行う——**(i) 現行の実装値を見ずに、制約を満たす視覚言語の案を3つ以上生成する。(ii) 各案が §4 の印象をどう届けるかで比較する。(iii) 選んだ案を規則に落とす。** 「現行の値が制約を満たすかを検証する」という手順は取らない（それは追認であり、緩い制約の下では必ず現行が通る）。**本文書は現行の正典値を候補として名指ししない。** 結果として現行と同じ値に着地することはありうるが、それは比較の結果であって出発点ではない。

## 7. 自己点検

- **測度は問いに一致しているか。** 判定の基準は一つ——**その文が述べているのは来訪者の頭の中で起きることか、サイト側で起きることか**。
  - **適用範囲**: 印象を**構成する**位置（面名・説明文、および**他節でのそれらの言い換え**）には、来訪者の心に起きることだけを置く。一方**導出欄は出典を名指す欄**であり、constitution の Rule や Goal といったサイト側の指令を引かざるを得ない——そこには必ず「**来訪者の側でそれが何になるか**」への変換を一文添える（A の「この二つが来訪者の側で結ぶ像が『安心』である」がその形）。**変換のない出典は、印象を運営指標の言い換えに変える。**
  - **点検を §4 の中だけで終わらせない。** 第3版では §4 は守られていたのに、**§5 で印象 A を「静かで読みやすい」という器の性質に言い換えていた**（独立レビューが捕捉）。しかもそれは T8 が全規則で繰り返すテンプレートの位置だった。**印象の名が他節で言い換えられていないかを、文書全体で確認する。**
  - **形式のテストで代用しない。** 「既知の NG 語を含まないか」も「『〜と感じてほしい』の引用の内側にあるか」も、形が合っているかを見ているだけで問いに答えていない。後者は仕様を引用符で包めば通過してしまう。**位置ではなく主語で判定する。**
  - 初版はこの点検が機能せず、印象の位置に運営規則を書いたまま「サイト側の性質は入れていない」と申告した。捕捉したのは独立レビューである。
- **地から実際に導けるか、一つずつ確かめたか。** 第2版は5面すべてに Rule 番号を付したが、B・C・E は**その Rule から導けなかった**（B の「楽しむには軽さが要る」は根拠のない一般命題、C の関与要件は Rule 2 から出ない、E の Rule 5 は主語が作り手）。本版は導けないものを「当サイトの選択」「実測と Goal 由来」と明記し、Rule 5 を根拠から外した。**Rule 番号を付すこと自体が導出の証明にならない。**
- **測度を一方だけ選んでいないか。** 第2版は検索**クリック**だけを報告し、**表示回数**を報告しなかった。クリックで見れば診断が 88%、表示で見れば辞典が 82.4% で、サイトの姿はまったく違って見える。**結論に都合のよい測度だけを選んだ**結果、ページ数でも表示でも過半を占める面が正体と印象から外れていた（AP-P02）。本版は両方を報告し、C から関与要件を外した。
- **不都合な事実を確認したか。** 第2版は「サイトは店を名乗っていない」と書いたが、本番の HTML を確認せず**1ページの実見から一般化した**もので、事実に反していた。「存在しない」という単純で都合のよい主張が、確認なしに通っていた。本版は実文言を記録し、案1 の却下を「名乗りが誰にも届いていない」という正しい論拠に置き換えた。
- **導出の向きは正しいか。** §6 が現行 `DESIGN.md` §1 と同型であることを開示し、正典値の名指しを削除し、T8 に「現行値を見ずに3案生成」を課した。第2版は「現行値を温存しない」と書きながら現行値4つを名指ししており、申告と本文が矛盾していた。
- **他者の報告を鵜呑みにしていないか。** 本文書の事実主張は独立レビューの指摘を引き写したものではなく、**すべて PM 自身が再取得して確認した**——実測値は BigQuery で再クエリ（engaged 966／1ページ 896＝92.8%／区画をまたぐ回遊 10／`/` の organic PV = 0／表示の区画別で dictionary 62,119＝82.4%）、本番の実文言は `curl` で実 HTML を取得、コンテンツ数は `ls`／データファイルの実カウント（ブログ 87・漢字 2,136・遊び 16・道具 38）、テストによる「よろず屋」の固定は `src/app/__tests__/page.test.tsx:187,198` を実見。**指摘はすべて正しかったが、正しさを自分で確かめてから受け入れた。**
- **残る不確かさ。** (i) E（広がり）は Goal から要請されるが実測ではまだ達成されていない（0.7%）——増やせるかは未検証である。(ii) 参照型と体験型の CTR 差には順位交絡があり、弁別子は「実測で確定」とは言えない。(iii) 辞典（表示の 82.4%・クリック 0.12%）の処遇は本決定の範囲外であり、backlog（B-564）で判断する。
