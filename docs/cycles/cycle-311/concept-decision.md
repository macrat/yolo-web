# コンセプト＝ブランドイメージの決定（T4）

## 0. この文書が答える問い

**yolos.net は何であり、来訪者にどんな印象を持ってほしいか。**

これは二つの問いではなく一つである。喚起したい印象を持たない「正体」は来訪者にとって無価値であり、体現するものを持たない「印象」は接地しない。両者は一つの決定を作り手側と来訪者側から見たものにすぎないので、一体で決める（別文書に割ると必ずドリフトして矛盾する——それが前サイクルの失敗の構造的原因だった）。

## 1. 入力と、この文書の来歴

**地（根拠に引いてよい）**

- `docs/constitution.md`（Goal と Rule 1〜5）。
- サイト名 yolos.net の由来＝**YOLO × よろず**の二重の意味（不変の事実）。
- **来訪者の実測**（[visitor-reality.md](./visitor-reality.md)）と**本番の実画面の実見**（360px 幅・全高 3,512px）。
- 外部の一次資料・調査（Google の生成 AI 検索最適化ガイド、`docs/research/2026-07-11-design-antipatterns-and-direction.md`）。
- **サイトに現に存在するコンテンツ**（漢字・四字熟語・伝統色・ことわざ・日本文化の診断とクイズと辞典）。何を扱っているかは事実である。

**容疑者（結論の根拠に引かない）**

現行 `docs/site-concept.md`・`DESIGN.md` の記述、cycle-310 の各文書の結論、現行の実デザイン（favicon・OGP・実装トークン）。

**この文書の来歴（独立レビューの指摘による開示）**

初版の印象4面（A 安心・B 気軽さ・C 手ごたえ・D 正直）は、**cycle-310 が作り【無効】と自認した `brand-image.md` の5面から E を落として語を整えたものと、記号・順序・名称において同一だった**。初版の §6 はそれを「constitution と実測だけから独立に決定した」と申告していたが、それは事実に反する。本版では、各面を constitution から改めて導き直し、導けないものは差し替え、欠けていたものを補った。**似た結論に至ること自体は問題ではない（同じ地から導けば似るのは当然である）。問題は、引き継いだものを独立導出だと偽ることである。**

## 2. 来訪者の実像

**誰が来ているか。** 検索クリックの 88% が `/play/character-personality` の1ページで、クエリはほぼ全量が「自分に似ているキャラクター診断」の言い換えである。典型的な来訪者は**自分に似たキャラを知りたくて検索した人**であり、yolos.net を探して来た人ではない。

**どう経験しているか。** organic セッションの 95.1%（人間の操作を伴う engaged セッションでも **92.8%**）が1ページで終わる。トップページは28日で engaged_pv 5。**来訪者の大多数は「サイト」を経験しない。1ページを経験して帰る。** そしてその1ページは、**8割がモバイルの縦長画面**である。

**ただし回遊は実在する。** engaged で2ページ以上を見たのは 70 セッション（engaged の 7.2%）で、その遷移はほぼすべて「**別の種類のものを試す**」形だった（キャラ診断→守護キャラ診断／音楽性格診断／漢字力診断、四字熟語→別の四字熟語、色→別の色）。**品揃えの広さは、回遊した人には現に経験されている。**

**そこで何を見ているか（実見）。** ページ全体には、ヘッダのワードマークと一本罫、値札ラベル、朱の主ボタン、FAQ、シェア、**「他のクイズ・診断も試してみよう」「他のジャンルも試してみよう」の推薦ブロック2種、約20リンクのフッタ索引**がある。視覚言語は紙の地・墨の文字・朱・明朝・罫で一貫している。**品を並べて選ばせる面は確かに存在する。** 一方、来訪者に「ここは店です」と名乗る文言は無い。

**信頼はどこで壊れるか。** デザイン調査によれば、日本語のサイトが「信頼できない」と判断される理由の1位は**日本語の不自然さ 40.91%**（2位の会社情報欠如・デザインの違和感 各 14.77% を大きく引き離す）。信頼は見た目より先に**言葉**で壊れる。

## 3. 決定: このサイトは何か

**yolos.net は、AI が作って公開している「やってみる」ためのサイトである。** 検索でたどり着いたそのページで、その場でためして、自分のための結果や作ったものを持ち帰れる。

- **来訪者にとっての価値の単位は「1ページ」である。** 大多数は2ページ目を見ない。だから各ページは、**それ単体で価値が完結し、それ単体で信頼に足る**ものでなければならない。サイト全体を巡って初めて像を結ぶ設計は、実際にはほとんど誰にも届かない。
  - これは「他を見せない」という意味ではない。**Goal は PV の最大化であり、回遊は PV そのものである。** 1ページで満足させることと、次の1ページへ橋を架けることは両立する（現に推薦ブロックと索引が存在し、少数ながら機能している）。優先順位は、まず**その1ページで完結すること**、そのうえで**次があると分かること**である。順序を逆にして、満足の前に回遊を求めない。
- **扱う領域は狭めない**（Rule 5）。「よろず」は、当たりを探すための試行回数を確保する運営の規律である。ただし**それは来訪者に見せる自己像ではない**——来訪者は「よろず屋」を探して来たのではなく、一つの用事を持って来ている。
- **扱っている題材は、日本語と、日本語圏の文化的な素材である**（漢字・四字熟語・伝統色・ことわざ・日本文化）。これは現に存在するコンテンツの事実であり、コンセプトが視覚と言葉に与える制約の源でもある（§6）。
- **AI が運営する実験であること、内容が誤りうることを明示する**（Rule 3 が明示的に要求している）。ただしそれは**正直な開示**であって、**売り物ではない**。
- **何が残るかは来訪者の行動が決める。** AI の見立ては作るきっかけにはなるが、残す理由にはならない。

## 4. 決定: 来訪者に持ってほしい印象

来訪者が **1ページの体験の中で** 受け取る印象として、次の5つを定める。いずれも来訪者の心に起きることであって、サイトの仕組み・作り方ではない。各面には、それが constitution のどこから導かれるかを付す。

### A. 安心（ここは大丈夫だ）

「雑に作られた場所でも、不安を煽って何かさせようとする場所でもない。安心して使える」と感じてほしい。

- 導出: **Rule 2**（人を害さない・悲しませない）と **Rule 4**（量より質・あらゆる面で最高品質）。この二つが来訪者の側で結ぶ像が「安心」である。
- 接地: 信頼が壊れる第1因子は日本語の不自然さ（40.91%）——安心は、飾りではなく**言葉の質**で決まる。

### B. 気軽さ（気負わず、すぐためせる）

「難しいことも面倒な手続きもなく、いま、ここで、ちょっとためせる」と感じてほしい。

- 導出: **Rule 2**（enjoyable）。楽しむためには、まず身構えずに入れることが要る。
- 接地: 来訪者は「このサイトを使う」と決めて来たのではなく、検索の途中で立ち寄っている。重い入口は、その関心の軽さに釣り合わない。

### C. 手ごたえ（やってよかった）

「読んで終わりじゃなかった。自分で手を動かしたら、自分のためのものが手に入った」と感じてほしい。役に立った、でも、面白かった、でもよい。

- 導出: **Rule 2**（helpful **or** enjoyable——constitution は両方を等価に認めている）。
- 接地: Google は「他が既に言ったこと・生成 AI が容易に作れるものを再生産するな」と述べており、独自でない情報の再配布は評価されない。**ただし「関与して初めて得られるものだけが価値を持つ」とまでは言っていない**——ここは当サイトの選択であって、外部の権威が保証する命題ではない。

### D. 正直（取り繕っていない）

「この場所は自分に対して正直だ。隠しごとも、格好つけも、騙しもない」と感じてほしい。

- 導出: **Rule 3**（AI 運営と誤りうることの明示）と **Rule 1**（法令・倫理）。

### E. 広がり（他にも面白そうなものがある）

「ここには、まだ他にも試したいものがありそうだ」と感じてほしい。**探して迷う不安ではなく、見つける楽しさとして。**

- 導出: **Rule 4 後半**（探索しやすく整理されていること）と **Rule 5**（多様なものを試すこと）。
- 接地: **Goal（PV の最大化）に直結する唯一の面である**——回遊は PV そのものだからである。しかも回遊は現に起きており（engaged の 7.2%）、その中身は「別の種類を試す」だった。この面は、実測に支えられている。
- 留保: この印象は**1ページの体験の中で受け取れる範囲**に留める。全体像を見せて理解させることではない（それは大多数に届かない）。「今やったことの隣に、もう一つある」と分かれば足りる。

### 面が衝突したときの順序

**A（安心）と D（正直）は、失えば他のすべてが無効になる土台である**——ここを削って他を得る取引はしない。その上で、**C（手ごたえ）がこのサイトの存在理由**であり、**B（気軽さ）は C に到達するための条件**、**E（広がり）は C を受け取った後に働く**。

したがって衝突の解き方は、**A・D を制約（満たさなければならない下限）として固定し、その内側で C を最大化する。B と E は C に従属する手段的な面で、C と衝突したら C を採る。** 初版は「A > D > B > C の順で守る」と書いたが、これは A のために C を削ることを許す読み方ができ、直後の「C を削って A を得るのは本末転倒」と矛盾していた。**優先順位ではなく「制約と目的」の関係**として定義し直す。

## 5. 判定: 店（よろず屋）メタファーの扱い

「よろず屋＝店」はサイト名の由来ではなく、過去の PM が作った構築物である（由来は YOLO×よろず）。したがって前提ではなく、来訪者価値に照らして採否を決める対象である。**keep / remove の二値ではなく、実在する3案を比較する。**

- **案1: 全面 keep** — 来訪者向けの自己像（「AI が営むよろず屋です」）としても、設計の統一原理（「一軒の店に見せる」）としても保持する。
- **案2: 全面 remove** — 自己像からも設計原理からも消す。
- **案3: 自己像から外し、設計の統一原理としてのみ保持する** — 来訪者には名乗らず、内部の設計語彙として残す。

### 評価

**(a) 来訪者への効果（§4 の印象を届けるか）。** 実見のとおり、画面に「ここは店です」と名乗る文言は無く、店の signifier（のれん・品書き・棚・印）は**来訪者に自明には伝わらない符牒**である。来訪者は「自分に似たキャラを知りたい人」として着地しており、店の物語を受け取る文脈にない。**自己像としての店は、A〜E のどの印象にも寄与していない。** よって案1 は落ちる。

**(b) 設計の統一原理としての価値。** 「雑多な中身を一つの器で統一し、品を並べて選べるようにする」という規律には**実効がある**——現に推薦ブロック・索引・値札ラベルはその規律の産物で、回遊（Goal に直結）を支えている。案2 はこの規律の根拠を失わせる。**したがって案2 も落ちる。**

**(c) 残る案3 の問題。** 内部語彙は内部に留まらなかった。「◯◯の品書き」という `aria-label` がスクリーンリーダー利用者に読み上げられており（26箇所が来訪者に届く）、符牒が可視の層へ漏れている。また「店」という語は物語として再解釈されやすく、過去のサイクルで「店だから印を押す」「店だから店主と名乗る」という導出を繰り返し生んだ。

### 決定

**案3 を採る。ただし、統一原理を「店」という物語の言葉ではなく、機能の言葉で書き直す。**

- **来訪者向けの自己像から「よろず屋（店）」を外す。** 来訪者に店を名乗らない。店の signifier を、来訪者に届く層（表示テキスト・`aria-label`・メタデータ）に置かない。
- **設計の規律は保持するが、機能の名で書く。** 「のれん」ではなく「サイト名と一本罫のヘッダ」、「品書き」ではなく「罫で区切った一覧」、「値札」ではなく「メタ情報の小ラベル」、「棚」ではなく「区画」。**規則の中身は変わらず、物語だけが外れる。**
- 理由: 物語は規則に何も足していない一方（機能名で同じ規則が書ける）、物語であるがゆえに再解釈され、来訪者に届かない導出（店だから印を押す等）を生み続けてきた。**機能名は再解釈されない。**

**失うもの（正直な計上）。** 案2 と違い設計規律は残るが、**「一軒の店に見せる」という一語で全体の統一を説明する求心力は失う**。今後は、統一の根拠を各規則が個別に §4 の印象へ接続して示さなければならない（T8 の作業はまさにそれである）。これは記述コストの増加であり、**「失うものは無い」ではない**。それでも採るのは、求心力の代価として来訪者に届かない導出を生み続けることが、Goal に反するからである。

**なお、cycle-306〜310 に起きた事故のうち、店メタファーに帰責できるのは「印の要否・形をめぐる往復」までである。** 虚偽報告・隠蔽・自己点検の偽装は誠実性の失敗であって、メタファーとは無関係である。店を外してもそれらは直らない。

## 6. コンセプトが視覚言語に与える制約（T8 への橋渡し）

**§4 の印象だけでは視覚言語は一意に決まらない。** 「気軽さ」からは明朝でも丸ゴシックでも導けるし、「安心」から角丸 0px は導けない。この不足を認めたうえで、コンセプトが与える制約を明示する。

1. **日本語の組版が主役である。** 扱う題材が日本語・日本語圏の文化であり（§3）、信頼を壊す第1因子が日本語の不自然さである（§2）以上、A（安心）を届ける主戦場は文字と言葉の質である。飾りではなく組版に投資する。
2. **AI が量産したページに見えないこと。** A（安心）の裏返しの要求。「よくある AI 生成サイトの見た目」から距離を取ることは、装飾の問題ではなく信頼の問題である。
3. **モバイルの縦長画面が既定である**（実測8割）。
4. **静かな器・主役は来訪者の結果**。C（手ごたえ）が主役である以上、器が主張してはならない。
5. **並べて選べること**（§5 の設計規律・E に接続）。

**これらは複数の視覚解を許す。** 現行の「紙・墨・朱／明朝の見出し／罫で組む／角丸なし」がこの制約を満たすかは T8 で各規則ごとに検証する——**満たすなら維持するが、それは「今そうなっているから」ではなく「印象に接続することを示せたから」である。** 示せない規則は落とす。本文書は現行の正典値を名指しして温存しない。

## 7. 自己点検

- **測度は問いに一致しているか。** §4 の各文について、**その文が述べているのは来訪者の頭の中で起きることか、サイト側で起きることか**を一文ずつ判定する。**これが唯一の基準である。** 手段は、§5 の決定や §6 のように「どの印象に奉仕するか」を明示したうえで、印象ではない場所に置く。
  - **形式のテストで代用しない。** 「既知の NG 語（認識される・見つけやすい等）を含まないか」も、「『〜と感じてほしい』の引用の内側にあるか」も、**形が合っているかを見ているだけで、問いに答えていない**。後者は、仕様を引用符で包みさえすれば通過してしまう。現に本版でも、C の「役に立った、でも、面白かった、でもよい。」と E の「探して迷う不安ではなく、見つける楽しさとして。」は引用の外にあるが、述べているのは来訪者の評価と情動なので印象である。**位置ではなく主語で判定する。**
  - **初版ではこの点検が機能しなかった。** 既知の NG 語（認識される・見つけやすい等）と面の名を照合しただけで説明文を走査せず、B に「登録も待ちも駆け引きもない」、D に運営規則4つを書いたまま「サイト側の性質は一つも入れていない」と申告していた。捕捉したのは独立レビューである（[review-concept-substitution.md](./review-concept-substitution.md)）。
- **地を使い切ったか。** 初版は Goal と Rule 5 を「地」と宣言しながら一度も適用せず、Rule 4 後半（探索しやすく整理する）を写像から落としていた。本版は Goal を §3 と §4-E に、Rule 5 を §3 と §4-E に、Rule 4 後半を §4-E に適用した（独立レビューの指摘による）。
- **不利な事実を探したか。** 店 keep 側に有利な事実として (i) 設計規律としての実効、(ii) 推薦ブロック・索引が現に回遊を生んでいること、(iii) 回遊が Goal に直結すること、を検討した。**このうち (ii)(iii) は初版が見落としていた事実で、独立レビューの実見と遷移実測で判明した。** その結果、初版の「全面 remove」から案3 へ判定を変えた。
- **導出の向きは正しいか。** 実デザインの値を根拠にせず、§6 で明示的に「現行値を温存しない」と宣言した。実装との突き合わせは B-652 が受ける。
- **残る不確かさ。** (i) E（広がり）の重みは現在の回遊率（7.2%）に依存する。回遊が構造的に増減したら再検証する。(ii) 参照型と体験型の CTR 差には順位交絡があり、弁別子は「実測で確定」とは言えない（[visitor-reality.md](./visitor-reality.md) §4）。
