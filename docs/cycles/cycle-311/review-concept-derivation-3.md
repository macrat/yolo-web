## 3.【致命】§4-E の「強度の限定」は、E の定義と一致しない測度で下されており、Goal の測度（PV）を報告していない

§4-E は E を「まだ他にも試したいもの・調べたいものがありそうだ」と定義する。この印象の測度は「来訪者が次の一つへ進んだか」である。**E は区画をまたぐことを一言も要求していない。** ところが「強度の限定」は**区画をまたぐ回遊 0.7% だけ**を引いて「実測ではまだ達成されていない」と断ずる。**測度が問いに一致していない。** E の定義に対応する測度で見れば、engaged の 7.2% が次の一つへ進んでいる。

さらに重大なのは、**Goal が名指ししている測度（PV）で一度も報告していない**ことである。

|                                            | 値               |
| ------------------------------------------ | ---------------- |
| organic PV 合計                            | **1,924**        |
| 2ページ以上のセッション（70件）が生んだ PV | **365（19.0%）** |
| うち2ページ目以降だけ                      | **295（15.3%）** |

§3 も §4-E も「回遊は PV そのものであり Goal に直結する」と書く。その測度で測ると、E は「まだ達成されていない」どころか、**organic PV の約15%を現に生んでいる**。文書はセッション比だけを報告し、PV 比を一度も出していない。§7 は「測度を一方だけ選んでいないか」を自己点検項目に立てながら、**同じ誤りが回遊について無処置のまま残っている。**

## 4.【致命】§5 の案2 採用の決め手が、示された唯一の実例で成立していない

案2 が案3 を上回る根拠は「規律の根拠は §4 の印象に付け替えられる」の一点である。その立証として挙がる実例は**ただ1つ**——「一覧を罫で区切って並べる」は E と **A（静かで読みやすい）** から導ける。

1. **§4-A に「静か」も「読みやすい」も無い。** §5 は A を自分に都合よく言い換えたうえで、その言い換えから規則を導いている。**言い換えなしの A から「罫で区切って並べる」は出ない。**
2. **E から出るのは「隣にもう一つあると分かること」までで、形式は出ない。** カードのグリッドでも箇条書きでも横スクロールの帯でも E は満たされる。

すなわち**付け替えが可能であることの立証は0件**であり、立証はそのまま T8 へ先送りされている。**案2 と案3 の優劣を決める唯一の争点を、その争点に依存する後続タスクへ委ねている**（AP-P01）。少なくとも代表的な規則を2〜3本、§4 の5面のみから実際に導いてみせなければ、案2 の採用は根拠を持たない。

**加えて、案3 の第2の却下理由が案2 自身を切っている。** 「『機能名なら再解釈されない』とは言えない以上、**語の言い換えは解決にならない**」と書く一方、案2 の実施内容は「のれん→ヘッダ」「品書き→罫で区切った一覧」という**まさに語の言い換え**である。案3 を落とす有効な理由は第1点だけであり、第2点は撤回すべきである。現状では留保の選択的適用になっている。

## 5.【致命】§4-E が、§3 に存在しない決定を引用して Rule 5 を根拠から外している

§4-E は「**§3 で「よろず＝広さは来訪者に見せる自己像ではない」と決めた以上**」と書くが、**§3 にその決定は存在しない**。実在しない前決定を根拠にしている。（Rule 5 の主語が作り手であるという第1の理由は独立に成立するので結論自体は救済しうる。）

**さらに、この虚偽参照は実質的な未決事項を隠している。** `/about` は現に来訪者へ名前の由来（YOLO×よろず）を説明している。§5 は「**店**（屋）」を自己像から外すと決めたが、**「よろず（＝広さ）」を来訪者向け自己像として保つのか外すのかは、どこにも決定がない**。T6 と T8 はこの空白を推測で埋めることになる——それは §0 が自ら診断した失敗の構造そのものである。

## 6.【重大】§4-D の「格好つけ」は constitution から導けないのに「当サイトの選択」と明記されていない

§4 は「導けないものは『当サイトの選択』と明記する」と自らに課している。D は「隠しごとも、**格好つけ**も、騙しもない」と定義され、導出は Rule 3 ＋ Rule 1 のみである。

- 「隠しごとがない」← Rule 3: **成立**。
- 「騙しがない」← Rule 1: **成立**。
- 「**格好つけない**」← Rule 1／Rule 3: **不成立**。自分を魅力的に提示することは違法でも非倫理でもなく、Rule 3 が要求するのは開示であって自己提示の抑制ではない。

B が正直に自己申告したのと同じ扱いが D には適用されていない。**規律が、前巡に指摘された面にだけ適用されている。**

**これは語彙の問題ではない。** 「格好つけない」は印象の層に置かれた**視覚上の選好**であり、§6-5「**静かな器**」と合流して T8 の探索空間を事前に絞る。§6-5 の導出「C が目的である以上、器が主張してはならない」も含意ではない——主張する器（雑誌・作品集）でも手ごたえは届く。結果として、現行 DESIGN.md §1-1「器が主張すると、よろずは雑多に崩れる」が、**§4-D と §6-5 の二経路から、根拠を明示されないまま T8 の前提として復活している**。

## 7.【重大】§6-1・§6-2 は「表示」の測度だけで視覚の主戦場を決めている

§6-1 は「検索表示の 82.4%」を根拠に「主戦場は文字の扱いである」と結論する。しかし**その面のクリックは 26 日で 76 件（CTR 0.12%）**である。**デザインは着地した人だけが経験する。** 着地の 88.0% は1本の診断である。

§2-3 は「『実際に来ている人』と『検索の前に現れている面』は別物である」と正しく書いた。ところが §6 は**後者だけ**を使って視覚言語の主戦場を決めている。**両方を報告したことは、片方だけを使ってよい理由にならない。**

**あわせて地の脆弱性が開示されていない。** B-564 は「辞典の処遇判断（体験化 or プルーニング）」であり、**§6-1・§6-2 はプルーニングされうる区画に全面的に依存している。**

## 8.【重大】§6-2「和の register を採る」は選択であって導出ではない

「題材の中心が日本語の文字文化である以上、それに応答する視覚の系統を採る」は含意ではない。漢字・四字熟語の辞典をモダニズムの組版で作ることは可能であり実例も多い。**題材が和であることは視覚系統を一意に決めない。**

2巡目が「register の採否を決めよ」と要求したことは、その決定が導出できることを意味しない。求められたのは「候補を落とせる強度の制約」であって「導出であるかのように書かれた選択」ではない。

**§6 の逆走防止についての判定。** 手順 (i)(iii) と正典値名指しの削除は前回の経路を塞いだ。しかし本版は**視覚解の先取りを3つの別経路で復活させている**——(a) §4-D の「格好つけない」（印象の層にあるため T8 は疑えない）、(b) §6-2「和の register」（選択を導出と偽ったまま最強の絞り込みを行う）、(c) §6-5「静かな器」（導出が不成立）。この3つを合わせると指す族は現行の紙・墨・朱・明朝・罫にほぼ一意である。**現行値を名指ししないことは、現行値以外が通らない制約を上流に置いてよい理由にならない。逆走は防げていない。**
