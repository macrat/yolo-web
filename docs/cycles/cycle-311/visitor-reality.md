# 来訪者の実態（T3・2026-08-13 実測）

コンセプト＝ブランドイメージの決定を、想像でなく**実際に来ている人**に接地させるための実測。出典は BigQuery（GA4 raw `analytics_524708437` / Search Console）と本番サイトの実見。

> 初版には engaged セッションの定義の誤り・実見の不足・回遊の実態の誤断があり、独立レビュー（[review-concept-derivation.md](./review-concept-derivation.md)）の検算で判明した。本版はすべて再取得・再確認した値である。

## 窓と読み方の前提

- GA4: **2026-07-16 〜 2026-08-13（28日）**。Search Console: 同期間で実データがあるのは **2026-07-16 〜 08-10（26日）**（SC は数日遅延する）。
- GA4 の生 PV には**ボット・プリフェッチが混ざる**（B-635）。8/6 に 3,135 PV の単日スパイクがあり、同期間の Direct は 3,675 セッション / 3,695 PV（＝1.0 PV/セッション）で人間の行動の形をしていない。
- したがって**人間の需要としては、Search Console のクリックと GA4 の `medium='organic'` だけを読む**。以下はすべてその条件。
- **engaged セッションの定義**: セッション内の**全イベント**を走査して `session_engaged='1'` が立つもの（GA4 標準）。`page_view` イベントだけを見ると、engaged 判定（10秒以上の滞在など）が最初の page_view より後に立つため大幅に過小になる——初版はこれを誤った。

## 1. 来訪者はほとんど1ページで帰る

organic セッション **1,417** の内訳:

| 指標                                    | 件数  | 割合                 |
| --------------------------------------- | ----- | -------------------- |
| engaged セッション                      | 966   | 68.2%                |
| ユニークページ数が1で終わったセッション | 1,347 | 95.1%                |
| page_view イベントが1件だけのセッション | 1,176 | 83.0%                |
| **engaged かつ 1ページで終わった**      | 896   | **engaged の 92.8%** |
| engaged かつ 2ページ以上を見た          | 70    | engaged の 7.2%      |
| mobile                                  | 1,146 | **80.9%**            |

- 「95.1%」は**ユニークページ数**基準、「83.0%」は **page_view イベント**基準（同じページの再読込を2件と数えるか否かの差）。どちらで見ても大半が1ページで終わる。
- **人間の操作を伴う engaged セッションに限っても 92.8% が1ページ**である。
- トップページ `/` は28日で PV 50 だが、**その 50 はすべて `medium=null`（＝上記の「読まないと決めたチャネル」）であり、organic の PV は 0 である**。SC の表示回数も 8（クリック 0）。**検索から来た人間はトップページに一人も来ていない。**

## 2. 来ている人の8割はモバイル

organic セッションの **mobile 比 = 80.9%**（1,146 / 1,417）。**ただしこの集計値を「サイトはモバイルが既定」と読んではならない。着地区画で割ると反転する。**

| 着地区画     | organic セッション | モバイル比 | PV    |
| ------------ | ------------------ | ---------- | ----- |
| `play`       | 1,222              | **87.5%**  | 1,557 |
| `dictionary` | 115                | 66.1%      | 260   |
| `blog`       | 70                 | **0.0%**   | 95    |
| `tools`      | 10                 | 10.0%      | 12    |

**ブログに検索から着地した 70 セッションはモバイルがゼロ件、道具は 10 件中 1 件である。遊びを除いた 195 セッションでは、モバイルは 77 件＝39.5% の少数派になる。** すなわち 80.9% という全体値は「organic セッションの 86% が `/play` 着地であり、`/play` が 87.5% モバイルである」ことの言い換えにすぎない。

**この軸は既存文書が先に警告していた。** `DESIGN.md` §10 は「面差が大きく…ブログ・辞典・ツール・トップは desktop 優勢＝**単一デバイス想定は禁物**」と明記している（同§の「モバイル比 45.6%」という数値自体は 2026-03-28〜07-20 の窓・全チャネルでボット混入を含み、そのままでは使えない）。**数値が古いことと、警告している軸が誤っていることは別である。窓とチャネルの違いを理由に、面差という軸ごと退けたのは誤りだった。**

## 3. 流入はほぼ一点に集中している

Search Console（07-16〜08-10・26日）:

- 総クリック **1,303**。うち **`/play/character-personality` が 1,147（88.0%）**。
- 上位クエリは「あなたに最も近いアニメキャラ診断」（310クリック・CTR 21.3%）を筆頭に、**ほぼ全量が『自分に似ているキャラクター診断』の言い換え**。
- 2位以下は `/play/word-sense-personality` 36・`/play/music-personality` 10・`/play/traditional-color` 6 と桁が2つ違う。

つまり典型的な**来訪者**は「**自分に似たキャラを知りたくて検索した人**」であり、yolos.net を探して来た人ではない。

**ただし「クリック」で測るか「表示」で測るかで、サイトの姿はまったく違って見える。** 同窓の区画別（SC・search_type=WEB）:

| 区画         | 表示   | 表示シェア | クリック | CTR    |
| ------------ | ------ | ---------- | -------- | ------ |
| `dictionary` | 62,119 | **82.4%**  | 76       | 0.12%  |
| `play`       | 11,829 | 15.7%      | 1,210    | 10.23% |
| `tools`      | 1,058  | 1.4%       | 4        | 0.38%  |
| `blog`       | 364    | 0.5%       | 12       | 3.30%  |
| `colors`     | 15     | 0.0%       | 1        | 6.67%  |
| `(root)`     | 8      | 0.0%       | 0        | 0%     |
| `privacy`    | 6      | 0.0%       | 0        | 0%     |
| `about`      | 2      | 0.0%       | 0        | 0%     |

総表示 75,401。**クリックで測れば `play` が 92.9%（うち診断1本だけで 88.0%）、表示で測れば `dictionary` が 82.4%。** 前者は「実際に来ている人は誰か」、後者は「このサイトが検索者の前にどれだけ現れているか」である。**Goal（PV の最大化）に対しては後者が最大の未収穫分**であり（62,119 表示に対しクリック 76）、来訪者像をクリックだけで描くと、サイトの姿の大半が視野から落ちる。

ページ数で見ても同様である: ブログ記事 87 本・漢字辞典 2,136 件ほか各辞典に対し、遊び 16・道具 38。**「読む面・引く面」がページ数でも表示でも圧倒的多数を占める。**

## 4. 参照型と体験型の差は、順位交絡を差し引いて読む必要がある

| ページ                        | 表示   | クリック | CTR   | 平均順位 |
| ----------------------------- | ------ | -------- | ----- | -------- |
| `/play/character-personality` | 11,040 | 1,147    | 10.4% | **6.0**  |
| `/dictionary/kanji/庭`        | 1,053  | 3        | 0.3%  | 9.8      |
| `/dictionary/kanji/急`        | 1,047  | 2        | 0.2%  | 8.3      |
| `/tools/yoji-search`          | 902    | 2        | 0.2%  | 9.5      |

体験型（診断）と参照型（辞典・検索ツール）で CTR に2桁の差があるが、**平均順位も 6.0 対 8〜10 と差がある**。この順位帯の CTR 低下は一般的な傾向であり、**差の相当部分は順位で説明できる**。「面の型」の効果を主張するには順位を揃えた比較が要る。**この表は「参照型が負ける」ことの決定的な証拠にはならない**——弁別子を「実測で成立している」と断定しないこと。

## 5. 回遊は少数だが実在し、その中身は「別の種類を試す」である

engaged で2ページ以上を見た 70 セッションの遷移（organic・上位）:

| 件数 | 遷移                                                              |
| ---- | ----------------------------------------------------------------- |
| 9    | `/play/character-personality` → `/play/character-fortune`         |
| 6    | `/play/character-fortune` → `/play/character-personality`         |
| 5    | `/play` → `/play/word-sense-personality`                          |
| 5    | `/play` → `/play/japanese-culture`                                |
| 4    | `/play/character-personality` → `/play/music-personality`         |
| 3    | `/play/word-sense-personality` → `/play/yoji-level`               |
| 3    | `/play/character-personality` → `/play/kanji-level`               |
| 2    | `/dictionary/yoji/言語道断` → `/dictionary/yoji/自己中心`         |
| 2    | `/dictionary/colors/category/green` → `/dictionary/colors/柳煤竹` |

**上の表は遷移の上位だけであり、これを見て「ほぼすべてが別の種類を試している」と読むのは誤りである。** 70 セッションを悉皆で分類した（「品」＝先頭2階層・`/play/character-personality` とその `/result/...` は同一の品、「区画」＝先頭1階層）:

| 分類                                                         | セッション | PV  | 内訳                                                                                                    |
| ------------------------------------------------------------ | ---------- | --- | ------------------------------------------------------------------------------------------------------- |
| **「同一の品」の中で複数ページ**                             | 33         | 195 | うち **診断→その診断自身の結果ページ 15**（49 PV）／**辞典で別々の項目を次々に引いた 18**（**146 PV**） |
| **同一区画内で複数の品**（例: 診断→別の診断、漢字→別の漢字） | 27         | —   |                                                                                                         |
| **区画をまたいだ**（例: 診断→辞典）                          | **10**     | —   |                                                                                                         |

**この 33 を一括して扱ってはならない。区分の名前で中身を代表させると、どちらの向きにも誤る。** 実データを開くと:

- **play 側 15** のうち 12 は診断→その結果ページ（実装上 URL が分かれただけ）。ただし **3 セッションは結果ページを複数種類めぐっている**（伝統色の結果を7種類・科学思考の結果を2〜3種類）で計 15 PV——これは「別々の項目を次々に見る」動きそのものである。
- **dictionary 側 18** のうち 15 は2〜3ページの単発（例: 漢字→その部首の索引）。**「次々に引く」と呼べるのは 3 セッションだけ**（四字熟語24件・漢字19件・色15件）で、**この3件が 146 PV のうち 102 PV を占める**。

前版は 33 を「診断→結果ページ＝回遊ですらない」と一括し、その前の版は上位9件から「ほぼすべて別の種類を試す」と読んだ。**どちらも実データを開かずに、区分の名前で中身を説明していた。**

**Goal の測度（PV）で見ると、回遊の寄与は小さくない。**

| 指標                                                         | 値               |
| ------------------------------------------------------------ | ---------------- |
| organic PV 合計                                              | **1,924**        |
| 2ページ以上のセッション（70件・セッションの4.9%）が生んだ PV | **365（19.0%）** |
| うち2ページ目以降だけ                                        | **295（15.3%）** |

セッション比で見れば回遊は 4.9% にすぎないが、**PV 比で見れば 19.0% を占める**（回遊するセッションは1回あたりのページ数が多いため）。**セッション比だけで回遊の価値を評価すると、Goal に対する寄与を大きく見誤る。**

**ただしこの 19.0% は裾が極端に重い。** 深さ別に割ると、11ページ以上見た **4 セッション（organic 全体の 0.28%）だけで回遊 PV 365 のうち 128（35%）** を生んでいる。この4件を除くと回遊 PV は 237（12.3%）まで落ちる。**「回遊は PV の2割」という主張は、4人の行動に対する感度が極めて高い。**

区画をまたぐ移動に限れば 10 セッション（organic の 0.7%）で、「品揃えの広さ」を横断的に経験している人はごく少数である。一方、**同じ区画の中を深く辿る回遊は現に起きており、PV への寄与もそこが中心である。**

## 6. 実見: ページ全体には「並べて選ばせる面」が実在する

本番 `/play/character-personality` を **360px 幅・全高 3,512px** で実表示して確認した（初版は 375×812 の1画面だけを見て「並んだ品はない」と誤断した）。上から:

1. ヘッダ（`yolos.net` の明朝ワードマーク・朱のドット・一本罫）とパンくず
2. h1・説明文・**値札ラベル4つ**（診断 / 全12問 / 約2分 / 24タイプ）・朱の主ボタン「はじめる」
3. 関連リンク2件（守護キャラ診断・音楽性格診断）
4. FAQ 5問
5. シェアブロック（X・LINE・はてブ・URL コピー）
6. **「他のクイズ・診断も試してみよう」** — 罫で区切った3行（品名＋ひとこと）
7. **「他のジャンルも試してみよう」** — 3行（品名＋ひとこと＋**値札チップ**「運勢」「クイズ」「パズル」）
8. **フッタの全サイト索引** — ツール5・遊び5・ブログ5・その他4の約20リンク
9. AI 運営の明示（「このサイトは AI が運営する実験サイトです。内容には誤りがありえます」）

視覚言語としては**紙の地・墨の文字・朱のアクセント・明朝の見出し・罫による区切り・値札ラベル**で一貫している。**「品を並べて選ばせる面」は確かに存在する**（6・7・8）。

### サイトは現に「よろず屋」と名乗っている

**この診断ページ1枚には店を名乗る文言が無いが、それをサイト全体に一般化してはならない。** 本番の HTML を取得して確認した実文言（2026-08-13）:

| 面       | 届く層                            | 実文言                                                                               |
| -------- | --------------------------------- | ------------------------------------------------------------------------------------ |
| `/`      | 表示テキスト（ヒーロー）          | **「AIが営む、よろず屋です。」**                                                     |
| `/`      | `meta description` / og / twitter | **「AIが営むよろず屋、yolos.net。…読むだけでなく、その場でためして持ち帰れます。」** |
| `/`      | 表示テキスト                      | 「結果は**札**にして持ち帰れます。」                                                 |
| `/about` | 表示テキスト（リード）            | **「yolos.netは、「AIが営むよろず屋」です。」**                                      |
| `/about` | `meta description`                | **「yolos.netは「AIが営むよろず屋」です。…」**                                       |

出典は `src/app/page.tsx:38,194`・`src/app/about/page.tsx:23,82`。しかも `src/app/__tests__/page.test.tsx` と `src/app/about/__tests__/page.test.tsx` が「description に『よろず屋』が含まれること」を **assert して固定している**——これは残骸ではなく、現行の意図された仕様である。

**ただし、その2面には検索から誰も来ていない**（`/` の organic PV = 0・SC 表示 8／`/about` は SC 表示 2）。すなわち「**自己像は現に名乗られているが、名乗っている場所に来訪者がいない**」。

## 決定に効く含意

1. **来訪者の圧倒的多数（engaged でも 92.8%）は1ページで帰る。** ただし**回遊の PV への寄与は小さくない**——2ページ以上のセッションはセッション数では 4.9% だが、**organic PV の 19.0%（2ページ目以降だけで 15.3%）を生んでいる**。その中心は**同じ区画を深く辿る回遊**（辞典で項目を次々に引く等）であり、**区画をまたぐ横断的な回遊は 0.7%** と少ない。**セッション比だけで回遊を評価すると Goal への寄与を見誤る。**
2. **デバイスは面によって違う。単一デバイスを既定に置けない。** 全体では 80.9% がモバイルだが、それは organic の 86% が遊びへの着地だからである。区画別では遊び 87.5%・辞典 66.1%・**ブログ 0.0%**・道具 10.0% で、遊びを除くと 39.5% と少数派になる。
3. **「実際に来ている人」と「検索の前に現れている面」は別物である。** クリックの 92.9% は `play`（うち診断1本で 88.0%）、表示の 82.4% は `dictionary`。ページ数でも読む面・引く面が過半（ブログ86本〔md 88〕・漢字辞典2,136件・道具36・遊び20）。**サイトの姿を「キャラ診断に来る人」だけで描くと表示の8割とページの過半が落ち、逆に表示だけで描くと実際にデザインを経験している人（着地した人）を見失う。どちらか一方の測度で決めない。**
4. **サイトは現に「AIが営むよろず屋」と名乗っている**（トップ・about の表示テキストと meta description、テストで固定）。ただし**その2面には検索から誰も来ていない**（organic PV 0・SC 表示 8/2）。「名乗っていない」のではなく「名乗りが誰にも届いていない」。
5. 参照型と体験型の CTR 差には**順位交絡がある**。弁別子は「実測で確定した」とは書けない。
6. **トップページは入口として機能していない**（organic PV = 0）。サイト全体を見渡す面から来訪者に何かを伝える設計は、現状ではまったく届かない。
