# 来訪者の実態（T3・2026-08-13 実測）

コンセプト＝ブランドイメージの決定を、想像でなく**実際に来ている人**に接地させるための実測。出典は BigQuery（GA4 raw `analytics_524708437` / Search Console）と本番サイトの実見。

> 初版には engaged セッションの定義の誤り・実見の不足・回遊の実態の誤断があり、独立レビュー（[review-concept-derivation.md](./review-concept-derivation.md)）の検算で判明した。本版はすべて再取得・再確認した値である。

## 窓と読み方の前提

- GA4: **2026-07-16 〜 2026-08-13（28日）**。Search Console: 同期間で実データがあるのは **2026-07-16 〜 08-10（26日）**（SC は数日遅延する）。
- GA4 の生 PV には**ボット・プリフェッチが混ざる**（B-635）。8/6 に 3,135 PV の単日スパイクがあり、同期間の Direct は 3,675 セッション / 3,695 PV（＝1.0 PV/セッション）で人間の行動の形をしていない。
- したがって**人間の需要としては、Search Console のクリックと GA4 の `medium='organic'` だけを読む**。以下はすべてその条件。
- **engaged セッションの定義**: セッション内の**全イベント**を走査して `session_engaged='1'` が立つもの（GA4 標準）。`page_view` イベントだけを見ると、engaged 判定（10秒以上の滞在など）が最初の page_view より後に立つため大幅に過小になる——初版はこれを誤った。

## 1. 来訪者はほとんど1ページで帰る

organic セッション **1,417** の内訳:

| 指標                                    | 件数  | 割合                 |
| --------------------------------------- | ----- | -------------------- |
| engaged セッション                      | 966   | 68.2%                |
| ユニークページ数が1で終わったセッション | 1,347 | 95.1%                |
| page_view イベントが1件だけのセッション | 1,176 | 83.0%                |
| **engaged かつ 1ページで終わった**      | 896   | **engaged の 92.8%** |
| engaged かつ 2ページ以上を見た          | 70    | engaged の 7.2%      |
| mobile                                  | 1,146 | **80.9%**            |

- 「95.1%」は**ユニークページ数**基準、「83.0%」は **page_view イベント**基準（同じページの再読込を2件と数えるか否かの差）。どちらで見ても大半が1ページで終わる。
- **人間の操作を伴う engaged セッションに限っても 92.8% が1ページ**である。
- トップページ `/` は28日で PV 50・engaged_pv 5。**入口として機能していない**（入口は検索から個別ページへの直着地）。

## 2. 来ている人の8割はモバイル

organic セッションの **mobile 比 = 80.9%**（1,146 / 1,417）。

これは `DESIGN.md` §10 が実測として載せる「モバイル比はセッション 45.6%／ユーザー 47.8% でほぼ半々（やや desktop 優勢）」と**食い違う**。その記載は 2026-03-28〜07-20 の窓・**全チャネル**（＝上記のボット/自己トラフィック混入を含む）の値である。**窓とチャネルの条件が違えば結論が反転する**——書き直しでは条件を明示せずに比率だけを書かない。

## 3. 流入はほぼ一点に集中している

Search Console（07-16〜08-10・26日）:

- 総クリック **1,303**。うち **`/play/character-personality` が 1,147（88.0%）**。
- 上位クエリは「あなたに最も近いアニメキャラ診断」（310クリック・CTR 21.3%）を筆頭に、**ほぼ全量が『自分に似ているキャラクター診断』の言い換え**。
- 2位以下は `/play/word-sense-personality` 36・`/play/music-personality` 10・`/play/traditional-color` 6 と桁が2つ違う。

つまり典型的な来訪者は「**自分に似たキャラを知りたくて検索した人**」であり、yolos.net を探して来た人ではない。

## 4. 参照型と体験型の差は、順位交絡を差し引いて読む必要がある

| ページ                        | 表示   | クリック | CTR   | 平均順位 |
| ----------------------------- | ------ | -------- | ----- | -------- |
| `/play/character-personality` | 11,040 | 1,147    | 10.4% | **6.0**  |
| `/dictionary/kanji/庭`        | 1,053  | 3        | 0.3%  | 9.8      |
| `/dictionary/kanji/急`        | 1,047  | 2        | 0.2%  | 8.3      |
| `/tools/yoji-search`          | 902    | 2        | 0.2%  | 9.5      |

体験型（診断）と参照型（辞典・検索ツール）で CTR に2桁の差があるが、**平均順位も 6.0 対 8〜10 と差がある**。この順位帯の CTR 低下は一般的な傾向であり、**差の相当部分は順位で説明できる**。「面の型」の効果を主張するには順位を揃えた比較が要る。**この表は「参照型が負ける」ことの決定的な証拠にはならない**——弁別子を「実測で成立している」と断定しないこと。

## 5. 回遊は少数だが実在し、その中身は「別の種類を試す」である

engaged で2ページ以上を見た 70 セッションの遷移（organic・上位）:

| 件数 | 遷移                                                              |
| ---- | ----------------------------------------------------------------- |
| 9    | `/play/character-personality` → `/play/character-fortune`         |
| 6    | `/play/character-fortune` → `/play/character-personality`         |
| 5    | `/play` → `/play/word-sense-personality`                          |
| 5    | `/play` → `/play/japanese-culture`                                |
| 4    | `/play/character-personality` → `/play/music-personality`         |
| 3    | `/play/word-sense-personality` → `/play/yoji-level`               |
| 3    | `/play/character-personality` → `/play/kanji-level`               |
| 2    | `/dictionary/yoji/言語道断` → `/dictionary/yoji/自己中心`         |
| 2    | `/dictionary/colors/category/green` → `/dictionary/colors/柳煤竹` |

**回遊した人は、ほぼ全員が「別の種類のものを試す」形で回遊している**（キャラ診断→守護キャラ診断・音楽性格診断・漢字力診断、四字熟語→別の四字熟語、色→別の色）。すなわち**品揃えの広さは、回遊した来訪者には実際に経験されている**。母数は小さい（engaged の 7.2%）が、事実として存在する。

## 6. 実見: ページ全体には「並べて選ばせる面」が実在する

本番 `/play/character-personality` を **360px 幅・全高 3,512px** で実表示して確認した（初版は 375×812 の1画面だけを見て「並んだ品はない」と誤断した）。上から:

1. ヘッダ（`yolos.net` の明朝ワードマーク・朱のドット・一本罫）とパンくず
2. h1・説明文・**値札ラベル4つ**（診断 / 全12問 / 約2分 / 24タイプ）・朱の主ボタン「はじめる」
3. 関連リンク2件（守護キャラ診断・音楽性格診断）
4. FAQ 5問
5. シェアブロック（X・LINE・はてブ・URL コピー）
6. **「他のクイズ・診断も試してみよう」** — 罫で区切った3行（品名＋ひとこと）
7. **「他のジャンルも試してみよう」** — 3行（品名＋ひとこと＋**値札チップ**「運勢」「クイズ」「パズル」）
8. **フッタの全サイト索引** — ツール5・遊び5・ブログ5・その他4の約20リンク
9. AI 運営の明示（「このサイトは AI が運営する実験サイトです。内容には誤りがありえます」）

視覚言語としては**紙の地・墨の文字・朱のアクセント・明朝の見出し・罫による区切り・値札ラベル**で一貫している。**「品を並べて選ばせる面」は確かに存在する**（6・7・8）。一方、来訪者に対して「ここは店です」と名乗る文言は無い。

## 決定に効く含意

1. **来訪者の圧倒的多数（engaged でも 92.8%）は1ページで帰る。** 同時に、**回遊導線は実在し、少数ながら実際に機能している**（70セッション）。回遊は PV そのものであり、Goal（PV 最大化）に直結する——「1ページで完結」を設計原則に据えることと、回遊を増やすことは、両立させる必要がある。
2. **その1ページはほぼモバイルの縦長画面**である（8割）。
3. **来訪者の大多数は「キャラ診断をやりたい人」として1ページに着地する。**
4. **品揃えの広さは、回遊した人には実際に経験されている**（「別の種類を試す」形で）。
5. 参照型と体験型の CTR 差には**順位交絡がある**。弁別子は「実測で確定した」とは書けない。
