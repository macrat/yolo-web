# 来訪者の実態（T3・2026-08-13 実測）

コンセプト＝ブランドイメージの決定（T4）を、想像でなく**実際に来ている人**に接地させるための実測。出典は BigQuery（GA4 raw `analytics_524708437` / Search Console）。取得日 2026-08-13。

## 窓と読み方の前提

- 窓: **2026-07-16 〜 2026-08-13（28日）**。
- GA4 の生 PV には**ボット・プリフェッチが混ざる**（B-635）。実際、8/6 に 3135 PV の単日スパイクがあり、同期間の Direct は 3675 セッション / 3695 PV（＝1.0 PV/セッション）で人間の行動の形をしていない。
- したがって**人間の需要としては、Search Console のクリックと GA4 の `medium='organic'` / engaged セッションだけを読む**。以下の数値はすべてその条件で取得した。

## 1. 来訪者は「サイト」を経験しない——1ページを経験して帰る

| -------- | ------- | ---------- | ------------- | ----------- | ------------ |
| mobile   | 0       | 957        | 957           | 0           | 1.00         |
| mobile   | 1       | 189        | 140           | 49          | 1.59         |
| desktop  | 0       | 180        | 180           | 0           | 1.00         |

- **organic 全体 1,417 セッションのうち 1,347（95.1%）が 1ページで終わる**。2ページ以上は 70 セッション（4.9%）。
- 人間の操作を伴う engaged セッションに絞っても、**240 のうち 170（70.8%）が 1ページで終わる**。
- トップページ `/` は 28日で PV 50・engaged_pv 5。**入口として機能していない**（入口は検索から個別ページへの直着地）。

## 2. 来ている人の 8割はモバイル

- organic セッションの **mobile 比 = 80.9%**（1,146 / 1,417）。engaged セッションだけでも 189 / 240 = **78.8%**。
- これは `DESIGN.md` §10 が実測として記載している「モバイル比はセッション 45.6%／ユーザー 47.8% でほぼ半々（やや desktop 優勢）」と**食い違う**。その記載は 2026-03-28〜07-20 の窓・**全チャネル**（＝上記のボット/自己トラフィック混入を含む）の値である。窓とチャネルの条件が違えば結論が反転する例であり、書き直しでは条件を明示せずに比率だけを書かない。

## 3. 流入はほぼ一点に集中している

Search Console（28日・クリック）:

- 期間内の総クリックは **1,303**。うち **`/play/character-personality` が 1,147（88.0%）**。
- 上位クエリは「あなたに最も近いアニメキャラ診断」（310クリック・CTR 21.3%）を筆頭に、**ほぼ全量が『自分に似ているキャラクター診断』の言い換え**。
- 2位以下の流入ページは `/play/word-sense-personality` 36・`/play/music-personality` 10・`/play/traditional-color` 6 と桁が2つ違う。

## 決定（T4）に効く含意

1. **ブランドの印象は「1ページの中」で形成される**。95%（engaged でも 71%）の来訪者は 2ページ目を見ない。サイト全体を巡って初めて像を結ぶ設計（＝全体の構えを見せる仕掛け・面をまたいだ反復で覚えさせる仕掛け）は、実際にはほぼ誰にも届かない。
2. **その1ページはほぼモバイルの画面である**（8割）。
3. **来訪者の圧倒的多数は「キャラ診断をやりたい人」として1ページに来る**。「よろずの品揃え」を来訪者が体験している事実は無い（広さは運営側から見た性質であって、来訪者の経験ではない）。
4. 参照型は表示されてもクリックされない——中心原則の弁別子は現況の実測と整合する。
