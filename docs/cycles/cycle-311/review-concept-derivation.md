観点は導出の成否のみ。文章表現・体裁は扱わない。数値はすべて BigQuery で独立に再取得して検算した（作業 SQL は `tmp/rev-*.sql`）。実画面は本番 `https://yolos.net/play/character-personality` を 360px 幅で全ページ撮影して確認した。

## 0. 先に、同意できる部分を自分の言葉で再構成する

同意する箇所は「同意の根拠を再構成できること」を条件とする、という指示に従う。

**(1) 「ブランドの印象は1ページの中で形成される」は成立する。** 再構成: organic セッション 1,417 のうち、訪れた distinct path が1つだけのものが 1,347（95.06%）。これは私自身が再取得して一致を確認した。さらに、GA4 標準の engaged 定義（セッション内いずれかのイベントで `session_engaged='1'`）に絞った 966 セッションでも、distinct path 1 は 896（92.8%）。engagement_time 合計 ≥10s で絞っても 935 中 868（92.8%）。したがって「複数の面を巡って初めて像を結ぶ」構造に依存する印象設計は、**定義上、来訪者の 9 割超に到達できない**。この論拠は成立する。

**(2) 「各ページが単体で完結し単体で信頼に足ること」は (1) から導ける。** 到達する面が1つなら、その面の外に信頼の根拠を置く設計は機能しない。成立する。

**(3) 「Rule 3 の AI 明示は正直の開示であって売り物ではない」は成立する。** Rule 3 の文言は "Notify visitors that..." であり、notify は告知であって promotion ではない。「すごい実験でしょう」と関心を買う方向は Rule 3 の文言からは導けず、Rule 2（人を害さない・悲しませない）と併せれば誇示は要求されない。成立する。

**同意できるのはここまでである。** そして本文書の中心的な誤りは、まさにこの (1) から **「回遊・広さを設計の上流から外す」を導いた**ことにある。(1) が言えるのは「印象の形成を多面遍歴に依存させるな」までであって、「回遊を印象設計の前提から外す」「広さは来訪者の経験ではない」ではない。この飛躍が §3・§4・§5 の全体に波及している。以下、個別に示す。

## 1. 【致命】§5(e)「失うものは無い」は偽である——constitution Rule 4 後半が写像表から落ちている

§5(e) は店フレームが担っていた中身を4項目に写像し、「すべて店なしで直接言える」と結論する。しかし写像表に**無い**ものがある。

現行 `docs/site-concept.md` 判断基準3の末項は次を定める:

> **探索しやすく整理する**（rule 4 後半）——コンテンツを増やすことは、来訪者にとっての分類・回遊・見つけやすさの設計義務を伴う。

これは店の物語ではなく **constitution Rule 4 の後半（"well organized for easy to explore"）の直訳**である。ところが本決定は、

- §4「『広さ』を印象の面に立てない理由」で「サイト全体の構えを見せる仕掛け・面をまたいで覚えさせる仕掛け」を**上流から生み続ける害**として位置づけ、
- §3 で「来訪者にとっての正体は『1ページ』である」と宣言し、
- §5(e) で「失うものは無い」と断じる。

**Rule 4 は constitution 条文であって店の構築物ではない。** それを担っていた設計義務が新コンセプトのどこにも受け皿を持たないまま、「失わない」と書かれている。これは「不利な constitution 条文の無視」であり、レビュー依頼が名指しで確認を求めた項目に該当する。

§5(e) を成立させるには、Rule 4 後半の「分類・回遊・見つけやすさの設計義務」が新コンセプトのどこに継承されるかを明示するか、あるいは「Rule 4 後半は実測上優先度が下がる」という判断を **Rule 4 を明示的に引用したうえで**下す必要がある。どちらも行われていない。

## 2. 【致命】constitution の Goal と Rule 5 が、地として宣言されながら一度も使われていない

§1 は地として「`docs/constitution.md`（Goal と Rule 1〜5）」を挙げる。しかし §3・§4・§5 の全導出を通じて、

- **Goal（"achieve higher page views by providing the best value for visitors"）は一度も参照されない。**
- **Rule 5（"Try a variety of things with creative ideas"）は一度も参照されない。** §4 の「由来」は A→Rule 2/4、B→Rule 2、C→Rule 2、D→Rule 3/1 であり、Rule 5 はどこにも現れない。

これが問題なのは、**外された当のもの（広さ＝よろず）が、まさに Rule 5 と Goal に接地する要素だから**である。現行 site-concept は「広さは正体である」を Rule 5（多様性）と探索（試行回数で当たりを引く）に接地させていた。本決定はそれを「運営側の規律」に降格するが、降格の可否を判定すべき Rule 5 を参照していない。

Goal についても同じである。PV 最大化という Goal に対し、最も直接に効く判断——**88% のクリックが集中する1面から2面目への転換を設計の上流に置くかどうか**——を、Goal に照らさずに「印象の設計の前提には置かない」と決めている。「地として宣言し、決定的な場面で使わない」は導出の欠落である。

## 3. 【致命】§5(d)「churn はすべてこの生成器から出ている」は、cycle-310 自身の記録と矛盾する

§5(d) はこう書く:

> cycle-306 から cycle-310 までの churn（印の字・形・物語をめぐる往復と、**2度の偽完了**）は、**すべてこの生成器から出ている**。

`docs/cycles/cycle-310/` の事故報告を実際に読むと、9件の incident のうち店メタファーに関係するのは incident-1 のみで、その診断も「ブランドイメージ（＝喚起したい印象）を定義せず、問いを仕組みへすり替えた（AP-P02）」である。残る8件は次のとおりで、店メタファーとは無関係な**誠実性の失敗**である。

## 4. 【致命】§2 の「実見」が、当のページの最大の構造要素を落としている——§5(a) は現物と矛盾する

§2 は実見をこう記録する:

本番 `https://yolos.net/play/character-personality` を撮影して確認した実際の画面（360px 幅で全高 **3,512px**）には、上記に加えて次がある。

1. **「他のクイズ・診断も試してみよう」** — 罫囲みの3項目（日本の伝統色診断／四字熟語で性格診断／達成困難アドバイス診断）、各項目に品名（朱の明朝リンク）＋ひとこと。
2. **「他のジャンルも試してみよう」** — 3項目（今日のユーモア運勢／漢字力診断／漢字カナール）、各項目に**値札チップ**（運勢／クイズ／パズル）付き。
3. **フッタの全サイト索引** — ツール／遊び／ブログ／その他の4区画に約20リンク。

つまり画面には「**複数の品が罫で区切られて並び、値札が添えられ、来訪者が選ぶ**」面が2ブロック、さらに品揃えの索引が1枚、実在する。§5(a) が店の定義として挙げた「複数の品が並び、客が巡って選ぶ」は、**まさにこの画面上に実装されている**。「画面に店を知覚させるものは無かった」は現物と一致しない。

加えて §2 は同じ段落で「小さな**値札ラベル**」が写っていると書いた直後に「店を知覚させるものは画面上に一つも無い」と書いており、§5(b) が列挙する店 signifier（店/屋/のれん/品書き/棚/**値札**/札/印）と自己矛盾している。

原因はおそらく観測範囲である。§1 は実見を「375×812 で実表示」と記す。812px は実ページ高の 1/4 弱であり、上記の3要素はすべてその外側にある。**1画面だけを見て「画面上に一つも無い」と断じた**可能性が高い。実見は地として §1 に登録され、§5(a) の全体を支えているので、これは地の欠損である。

なお、この実見のやり直しは §5 の結論を必ずしも反転させない——「広さは提示されているのに 95% が使わない」なら、むしろ「広さは届いていない」を**強める**読み方もありうる（§10 参照）。だが現在の文書は、その検討をせず、都合のよい不完全な観測で断じている。§6 が「検証の非対称は無い」と自己申告している以上、これは自己点検の失敗でもある。

## 6. 【致命】§4 の優先順位が自己矛盾している——衝突解決規則が自分を否定する

> 衝突したら **A > D > B > C の順で守る**。…ただし C を削って A を得るのは本末転倒——**C を届けるために A・B・D を土台として敷く**、という関係にある。

前段は「A と C が衝突したら A を採れ」と命じ、後段は「A のために C を削るな」と命じる。**A と C が衝突する場面こそが優先順位を必要とする場面**であり、そこで規則が自分を否定している。T8 でこの規則を適用するビルダーは、A/C 衝突時に任意の結論を「規則どおり」と主張できる（＝規則が制約になっていない）。順序を決めるか、「A は C の下限制約であって順序ではない」等、衝突の型ごとに判定可能な形へ書き直すこと。

## 7. 【致命】§5 が T8 に渡す基準からは視覚言語が決まらない。にもかかわらず §5 は現行の正典値を名指ししている

§5 はこう定める:

**(7-1) A/B/C/D からは視覚言語が一意に決まらない。** 安心・気軽さ・手ごたえ・正直は、無数の視覚言語で達成できる。とくに **B（気軽さ）を素直に適用すれば、明朝の見出し・角丸 0px・墨の罫という硬質で儀式的な register とは逆向き**（丸みのある sans・柔らかい色・余白の広い軽い面）に働く。つまり §4 は T8 の入力として**不足**しており、T8 は必ず「§4 に書かれていない前提」を持ち込まざるを得ない。持ち込む先は、この文書が §1 で容疑者と宣言した**現行の実装**しかない。**これは失敗の型1（末端から上流を正当化する逆走）を、次タスクに構造として仕込んでいる。**

**(7-2) 名指しされた4つは、現行 `DESIGN.md` の正典値そのものである。** 実際に確認した: §2 の `--paper`/`--ink`（紙と墨）、§3「明朝の顔、ゴシックの手」、§1-2「のれん（店号と一本罫）」、§8「角丸: 0px 基調」。§1 が「現行の実装トークンは結論の根拠に引かない」と宣言した以上、**その値を上流の決定文書に候補として書き込むこと自体が違反**である。真に T8 で再導出するなら、ここで具体値に言及してはならない。書かれている以上、T8 のビルダーはこれを「望ましい着地点」として読む。

§5 のこの一文は削除するか、「T8 は現行値を参照せずに導出し、結果を事後に突き合わせる」という手順に置き換えること。あわせて、A/B/C/D だけで視覚言語を決められないことを認め、**視覚言語を決めるに足る内容（何を体現する面なのか＝文化的 register を含む）をコンセプト側に持たせる**必要がある。§2 の実見は「静かで、丁寧に組まれた、**和の紙面**」という受け取られ方を観測しているのに、§3・§4 はそれを採るとも捨てるとも書かず沈黙している。採るなら §4 に立て、捨てるなら「T8 は和の register を前提にしてはならない」と明記すること。現状は「観測したが判断しなかった」であり、T8 の逆走の余地そのものである。

- GA4 標準の engaged 定義（セッション内いずれかのイベントで `session_engaged='1'`）で数えると、**organic の engaged は 966 セッション（68.2%）**。engagement_time 合計 ≥10s でも 935。
- その 966 のうち distinct path 1 は **896（92.8%）**。

したがって §2 の括弧書き「（人間の操作を伴う engaged セッションでも 70.8%）」は、**分母（240 対 966）も率（70.8% 対 92.8%）も誤り**である。さらに「人間の操作を伴う」という形容は、**10 秒以上滞在してスクロールしたが1ページで帰った 726 セッション**を人間から除外する読みを生む。それは organic の過半であり、「1ページを丁寧に体験して帰る人」という、このサイトの最も典型的で最も価値ある行動そのものである。

**方向としては結論を強める**（92.8% ＞ 70.8%）ので、§3・§4 の (1) の論拠は保たれる。しかし、デザインシステム全体の唯一の根拠となる文書に 4 倍の取り違えを残してはならない。`visitor-reality.md` と本文書の両方を訂正すること。

**併記すべき区別**: 「95.1%」は distinct path 基準である。page_view イベント基準では 1,176 / 1,417 = **83.0%**。両者の差は、同一 path での再 page_view（mobile engaged 群で平均 3.06 イベント / 1.59 distinct path）に由来する。どちらの定義で「1ページ」と言っているのかを明記しないと、T8 以降で誤読される。

**窓の記述**: Search Console の実データは 2026-07-16〜**08-10**（26日分）までしか存在しない（GA4 は 08-12 まで）。「28日」は GA4 側にのみ当てはまる。

## 10. 【重大】反証は実在する——「よろずの品揃えを来訪者が体験している事実は無い」は偽である

依頼に従い、「店を残すべき」と言える根拠を私の側から探した。**実在する。**

**(10-1) 回遊は起きており、起きるときはよろずの経験そのものである。** organic セッションの page 遷移を実測した（同一 path 間の遷移を除く）:

回遊した 70 セッション（4.9%）の遷移先は、**ほぼすべて「別の種類のものを試す」**である。これは「複数の品が並び、客が巡って選ぶ」の実データそのものである。したがって `visitor-reality.md` の「『よろずの品揃え』を来訪者が体験している事実は無い」は**事実として偽**であり、§5(a) の「店フレームが来訪者に与えている印象は、**現実にゼロである**」も偽である。正しくは「稀である（4.9%）」。

**(10-2) 実測を「来訪者の性質」と読むのは因果の取り違えである（AP-P03）。** 95% が1ページで帰るという事実は、「来訪者が回遊を望まない」とも「サイトが回遊の理由を与えられていない」とも読める。実測はこの2つを区別しない。本文書は前者に確定させ、それを**印象設計の前提（＝正体は1ページ）**にまで昇格させている。これは「今ある状態を所与として計画を立てる」型そのものである。§6 の「残る不確かさ」は「回遊が実際に起きる構造へ変わったら再検証する」と書くが、その構造を作るかどうかを決めるのが**まさに本決定**であり、外生変数のように扱うのは循環である。

**(10-3) Goal に照らすと、外す判断は最大の PV レバーを上流から降ろす判断である。** クリックの 88% が1面に集中し、その面から2面目へ進むのが 1.6% 程度という状態は、PV 最大化という Goal から見れば**最大の未収穫レバー**である。「回遊は起きたら良いことだが、印象の設計の前提には置かない」と決めるなら、Goal に照らした損得を書かなければならない。§5(e) の「失うものは無い」は、この損失を計上していない。

**(10-4) 現行コンテンツの過半が §3 の正体に当てはまらない。** 実際に数えた: ブログ記事 88 本、ツール 35 本、play 16 本、辞典 4 系統（漢字・四字熟語・色・humor、エントリは多数）。§3 の正体「**やってみる**ためのサイト。…その場でためして、自分のための結果や作ったものを持ち帰れる」に、ブログ 88 本と辞典は当てはまらない。現行 site-concept はこれを「中心原則の弁別子（体験型／参照型）」で扱っていた。新コンセプトはそれに触れず、§5(e) の写像表にも含めていない。結果として **T8 はブログ面・辞典面のデザイン規定をコンセプトから導けない**。

以上のいずれも「店を残すべき」を直ちに証明するものではない。しかし **§5(e) の「失うものは無い」を反証するには十分**であり、§5 の判定は現在の論拠のままでは成立しない。

## 11. 【中】§4 C の外部一次資料の読み過ぎ

§4 C の由来はこう書く:

> Google は「他が既に言ったこと・生成 AI が容易に作れるものを再生産するな」と明言しており、**来訪者が関与して初めて得られるものだけが**、配達されて消える情報と違う価値を持つ。

原文を一次資料で再確認した（`https://developers.google.com/search/docs/fundamentals/ai-optimization-guide`）。該当文は "Don't just recycle what others on the internet have already said, or could easily be produced by a generative AI model." で、引用は正確である。しかし**同ガイドが示す処方は「独自の視点・専門性・一次体験（first-hand reviews 等）」であって、インタラクティブ性ではない**。一次体験に基づく静的な記事は、同ガイドが推奨する側に立つ。したがって「関与して初めて得られるものだけが価値を持つ」は原文から導けない。C は「このサイトが存在する理由」と位置づけられている以上、その外部接地が過大読解であることは看過できない。
