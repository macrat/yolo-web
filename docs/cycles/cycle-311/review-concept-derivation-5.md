## 1.【致命1】「`/` の organic PV = 0」は測定のアーティファクトであり、実際は 4 PV ある

organic セッションに属する page_view を数え直すと **`/` に 4 PV、`/about` に 2 PV**。該当5セッションはすべて Google 検索から着地し、サイト内リンクで移動している（ブログ→`/`→ブログ、辞典→`/`→辞典、診断→`/about` 等）。**organic セッションの「2ページ目以降の到達先」ランキングで `/` は第11位**であり、個別の遊びページの大半より上にある。

**原因**: 「organic PV」を **page_view イベントの `medium` タグで絞った**ため。GA4 は `medium` をセッション最初の page_view にしか刻まない。**この測度は2ページ目以降の PV を構造上ひとつも数えられない。** `/` は検索クリック 0 なので、この測度では**答えが定義上 0 以外になりえない**。

**なぜ致命的か。**

- **(a) 同じ文書が「organic PV」を二通りに使い分けている。** 回遊を主張する箇所（1,924 のうち 365）は**セッション基準**、トップを切り捨てる箇所（0）は**タグ基準**。**同一の語が二つの非互換な測度を指し、各箇所で結論に有利な方が選ばれている。**
- **(b) この 0 が案1 の却下を成立させている唯一の根拠である。** 「検索から誰も来ていない」「一人も来ていない」「何の寄与もしていない」はいずれも偽。正しい主張は「**検索から着地した人はいない（SC クリック 0）／回遊した 70 セッション中 5 件が到達している**」まで。量は小さい（4/1,924 PV＝0.21%）が、**文書が使ったのは「小さい」ではなく「ゼロ・一人も・何の寄与もない」という断定形であり、それが議論を閉じている。**
- **(c) §7 が「自分で再取得して確認した」と申告している。** 再取得はされたが、**測度が問いに答えているかは問われなかった。**

## 3.【致命3】案1' の却下は、§5 が同じ節で宣言した測度の使い分け禁止に違反している
