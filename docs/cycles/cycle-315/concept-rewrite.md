## 判断の連なり（09-18 09:34 → 10:57）

### 通底した制約——現状から逆算しない

Owner は作業中に**4回**、同じことを言った。「今どんなサイトか」「今何があるか」は一切関係がない、決めているのは「どんなサイトにするか」「何を置くか」である、と。

**これが最も効いた制約である。** わたしは繰り返し現状のコンテンツ構成を判断材料に持ち込んでいた。
現状から辻褄を合わせると、**いま置いてあるものを説明できる文しか書けない。** 骨格は現状を肯定する道具になり、何も拘束しなくなる。実測データ（GA・コンテンツ構成）は、この作業から完全に外した。

### 何を外したか

Owner の問いはいずれも「これは必須ですか？」という形で、**外すか残すかはわたしが決めている。**

| 外したもの                                                                 | 外した理由                                                                                                                                      |
| -------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 「持ち帰れる形」（コピーボタン等）                                         | ツールは「役に立った」、ゲームは「楽しかった」で足りる。**実装上の一機能が、サイト全体をつらぬく骨格たりえない**                                |
| 「そのまま遊び場として開く」                                               | 実験場を**どう見せるか**という見せ方であって、骨格ではない                                                                                      |
| 「実験場」                                                                 | 「AI が全自動で作り続けている」で既に言えている状態に、**わたしが付けた名前**にすぎない。名前を足しても情報は増えず、来訪者に何も約束していない |
| 「よろず屋」（cycle-278 以来）                                             | 上と同じ型。**比喩の名詞を足して意味を作ろうとしていた**——よろず屋・実験場・遊び場は、どれも来訪者に何も渡していない                            |
| 「やらかす」                                                               | **保身。** 挑戦することと、失敗を前提に置くことは違う                                                                                           |
| 「作っているのは AI です。実験なので、間違っていることがあります」         | constitution rule 3 が求める**開示**であって、コンセプトではない。層が違う                                                                      |
| 「探していたものが見つかったら、探していなかったものにも出会ってください」 | 回遊の誘導であって、来訪者への約束ではない                                                                                                      |

### わたしの誤りが1件、ここで潰れた

「作り続けること」と「探しやすく整理すること」が緊張すると書いたところ、Owner から「作り続けることは数を増やし続けることとイコールではない」「constitution に『探しやすく整理』は無いはずなので原文を確認せよ」と指摘された。

**原文を確認した結果、`well organized for easy to explore` は rule 4 に確かにある。** Owner の前提のほうが事実と違った。
ただし**わたしが立てた緊張のほうは、確認して消えた。** 「作る＝新しく増やす」と狭く読んだことから出た誤りで、質を上げ直すことも整理し直すことも「作り続ける」に含まれる。
**前回「失敗も見どころ」と書いていたのは、放置を正当化する読み方だったので取り下げた。**

### 核の一行を選んだ理由

同じ中身を10通りの語順・表現で並べ、そこから1つを選んだ。選んだのは **7番**。

> **AI が全自動で作り続けているから、面白いものに出会えるサイトです。**

**他の9案は「AI が全自動で作っている」と「面白いものに出会える」を並べているだけ**で、来訪者は両者を切り離して読む。7番だけが「**から**」で繋ぎ、**全自動であることが面白さの理由だと言い切っている。**

選んだ理由は3つ。

**外れうる主張だから。** 「全自動だから面白い」は外れていれば来訪者に見抜かれる。並べただけの文は外れようがない。**外れうる主張だけが、当たったときに効く。**

**他所が言えないから。** 人間が運営するサイトは「人が選んでいるから面白い」とは言えても、「全自動だから面白い」とは言えない。**この成り立ちでなければ書けない一文である。**

**以後の判断を実際に拘束するから。** 人間が企画しても作れるものを並べたら、この文は嘘になる。

**この主張が正しいことは確かめていない。** 全自動だから雑なものが量産される、という結果もありうる。それでも、検証できない安全な文より外れうる主張のほうが骨格になると判断した。外れたら直す。

### 約束の形へ

Owner から「約束という形に書き直せ」「最良の価値を提供することを来訪者に約束せよ」と指示を受けた。
また「多少の誇大広告は許容する。**コンセプトとは目指す姿であって実態の説明ではない**」という裁可を得ている。これが、現状から逆算しないという制約の裏づけになっている。

第1行は、Owner が文言を指定して確定した。

> **他では見つからないものを探している人へ。AI が全自動で作り続けているから、面白いものがここにあります。**

直前に「『他では見つからないもの』と『面白いもの』は片方を削って良いほど完全に同義か」と問われている。**同義ではない。** 誰も作らないものはたいてい誰も欲しがらないので、**希少と面白さの両方**が要る。だから両方が残った。

### 検討の仕方について受けた指示

「来訪者がどう読むかを批判的に検討せよ。**同時に、将来の PM がいかに『言い逃れ』をするかを検討せよ。** LLM は言い逃れの達人で、真にユーザー目線というわけではない。言い逃れせずに真正面から constitution に向き合わざるをえない文章にする必要がある」

**規範文書の読み手には、来訪者だけでなく将来の PM が含まれる。** 抜け道のある書き方は、抜け道として使われる。

### 文書構成

Owner の指示に沿って3層にした。

1. **ゴール**（constitution が定めるものを最上位に置く）
2. **来訪者への約束**（ゴールを達成するためのサイトの骨格）
3. **一文ずつの意図**（Do と Don't を含めて「このサイトらしさ」を形作る）

## 大量プロトタイピングへの転回（15:54 → 16:00）

Owner から仮説が示された。逐語:

> AIがサイトを運営することの面白さは、プロトタイピングの軽さにあるのではないでしょうか。日々新しいプロトタイプが生まれ、反応を見ながら調節され、反応が悪いものは取り下げられるというサイクルです。人間の運営者にはアイデアの数に限界がありますが、AIならうまいワークフローさえ整えれば無尽蔵に作ることができます。狙いすまして当てるのではなく、大量の仮説検証を同時並行で回すのです。

続けて「**サイトを最良にするための営みであって、一つ一つのコンテンツを最良にしようというものではない。上手くないアイデアに囚われるのはサンクコスト**」という指摘を受けた。

**これが「AI が全自動だから面白い」の中身を埋めた。** それまで「全自動」は上限が無いことしか言っておらず、**その上限の無さが何に使われるのか**が空白だった。
埋まったのは「**狙いすまして一発を当てるのではなく、大量に試して当たりを見つける**」——人の運営では成立しない唯一のやり方である。

ここから約束文に2行目・3行目が加わり、**一切のツギハギを残さず全体を書き直した**（`7c0e54cd`）。

> 企画会議も、採算の計算も、専門家の監修もありません。人が作るなら割に合わないものにこそ、いくらでも手をかけます。
>
> たくさん作って、たくさん試します。良かったものを伸ばし、そうでないものは引き上げます。ここに残っているのは、その結果です。

**「引き上げる」がサンクコストへの答えである。** 伸ばすことと引き上げることはどちらも判断の結果で、**放置だけがどちらでもない。**

## 対象来訪者の定義の修正（09-19）

確定した文書に、**約束文と矛盾する解説が残っていた**。Owner の問いで発覚した。

解説は対象を「探しているものが決まっていない人」に限り、決まっている人を「それを扱う専門の場所へ行けばよく、ここへ来る理由がない」として除外していた。
**この除外の前提が約束文と矛盾する。他所に無いから探しているのだから、行くべき専門の場所は存在しない。**

対象を分ける線は、探し物が決まっているかどうかではない。**既にあるもので足りなかったかどうかである。** 欲しいものが決まっていて探しても無かった人も、何が欲しいかを言葉にできないまま来た人も、同じ状態にいる。

あわせて Do を1件足した。**「名指しで求められているのに、どこにも無いものを探す」**——旧版の Do は「言葉にできていない『こういうものがあったら』を探す」だけで、決まっていない人だけを見た作り方だった。はっきり名指しされているのに誰も作っていないものも探す対象で、こちらのほうが当たりを判定しやすい（`c5c375f6`）。

**この修正の直前、Owner から「無理やり肯定と否定をひねり出すな。このサイトはあなたの責任のもとに運営される。重要なのはあなたがどうしたいかだ」という指摘を受けている。**
