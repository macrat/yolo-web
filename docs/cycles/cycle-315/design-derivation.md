## わたしが決めたこと

**アドバイスは、条件・枠・問い・提案であって、中身の決定ではない。** 次はすべてわたしの判断である。

| 決めたこと                                              | 理由                                                                               |
| ------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| **個性を色から取らない**                                | 器が色を持てば、その色と喧嘩しない中身しか置けなくなる。器の色は作れるものを狭める |
| 担い手を3つ（罫の格子・巨大な見出し・色を使わない操作） | 色以外で個性を作れる手段がこの3つだった                                            |
| **署名を罫の交わり方に置く**                            | 担い手だけでは編集系一般と見分けがつかない。文言を消しても残るのは罫の形           |
| 一覧の既定形を罫区切りの行にする                        | 探しに来た人には、1画面に入る項目数と走査の速さが価値                              |
| 見出しに Zen Antique                                    | 巨大な明朝は流行の中心にあり、既定 sans の海にも属さない顔が要る                   |
| 本文に BIZ UDPGothic                                    | 本文は顔ではない。読みやすさのために設計された書体で、約物が詰まる                 |
| 欧文に IBM Plex Sans                                    | 数字が既定で揃う。「計測する道具」の顔がこのサイトと噛み合う                       |
| 引き上げた面の扱いを定義する                            | コンセプトの Do にあるのに、対応する規定が1件も無かった                            |
