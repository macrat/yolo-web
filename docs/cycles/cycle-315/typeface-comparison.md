# 見出し書体の比較検討

**顔を書体に担わせる以上、比較なしに決めてはいけない。** 最初の選択（しっぽり明朝）は一行で決めており、根拠がなかった。
Google Fonts から選べる日本語書体18種を実際に読み込ませ、実寸で並べて決め直した。

## 18種の一覧から絞り込む

| 系統           | 候補                                                                                  | 判定                                                                |
| -------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| ゴシック       | BIZ UDPGothic / Zen Kaku Gothic New / M PLUS 2 / Murecho / Noto Sans JP               | **落とす。** 既定 sans と顔が変わらない                             |
| 丸ゴシック     | Kiwi Maru / RocknRoll One                                                             | **落とす。** 柔らかすぎて、実験の場の硬質さと合わない               |
| 極太の表示用   | Dela Gothic One                                                                       | **落とす。** 強烈だが、長い見出しで潰れ、小さい字がまったく読めない |
| 筆書き         | Yuji Syuku / Klee One                                                                 | **落とす。** 個性は強いが読みにくく、手書きの温度が中身と合わない   |
| 極細の明朝     | Hina Mincho                                                                           | **落とす。** ダークで横画が飛ぶ                                     |
| 明朝           | Noto Serif JP / Zen Old Mincho / Shippori Mincho / Shippori Mincho B1 / BIZ UDPMincho | 残す（次段で比較）                                                  |
| アンティーク体 | Zen Antique / Shippori Antique                                                        | 残す（次段で比較）                                                  |

## 6種を実寸で比較する

主見出し 65px・小見出し 33px・本文 17px・表外漢字（縹色・鴇色・鶸色・黝色・蘇芳・檳榔子・黄櫨染）を、ライトとダークの両方で並べた。

| 書体                | 顔の強さ                               | 小さい字とダーク                           | 表外漢字 |
| ------------------- | -------------------------------------- | ------------------------------------------ | -------- |
| **Zen Antique**     | **最も強い。** Web でほとんど見ない顔  | **崩れない。** 線幅が均一                  | 出る     |
| Shippori Antique    | 強い。ただし太く、詰まって見える       | 崩れない                                   | 出る     |
| Zen Old Mincho      | 端正だが、Noto Serif JP と見分けにくい | **ダークの 33px で横画が細り、弱く見える** | 出る     |
| Shippori Mincho B1  | 明朝として力がある                     | 保つ                                       | 出る     |
| Noto Serif JP       | **最も弱い。** 普及しすぎている        | ダークで細る                               | 出る     |
| Zen Kaku Gothic New | 弱い。既定 sans と大差ない             | 保つ                                       | 出る     |

## 選んだもの——Zen Antique

**アンティーク体は、明朝の骨格に太さの揃った線を持つ書風である。** 明治から昭和初期の看板や広告に使われたもので、**Web ではほとんど見ない。**

**条件1に効く理由。** 独自性のレビューが指摘したとおり、**巨大な明朝は2025年の日本語 Web デザインの流行の中心にある。** 明朝を選ぶことは、流行の真ん中に乗ることを意味する。
既定 sans の海にも、巨大な明朝の流行にも属さない顔が要る。**アンティーク体はそのどちらでもない。**

**条件2に効く理由。** 明朝の弱点は、細い横画が小さいサイズとダークで飛ぶことである。**実物で確認した**——Zen Old Mincho と Noto Serif JP は、ダークの 33px で目に見えて細った。
**アンティーク体は線幅が均一なので、この問題が起きない。** 明朝の顔とゴシックの視認性を同時に持つ。

**Shippori Antique を採らない理由。** 同系統だが線が太く詰まって見え、かなの表情が平板である。Zen Antique のほうが 65px でも 33px でも呼吸がある。

## 受け入れる代価

- **ウェイトが1本（400）しかない。** 見出しの太さで階層を作れない。
  このデザインは階層を大きさと罫で作っており、見出しにウェイト差を使わないので支障はない。
- **かなに癖がある。** 極端に長い見出しでは読みにくくなりうる。見出しを短く保つ理由がもう一つ増える。
