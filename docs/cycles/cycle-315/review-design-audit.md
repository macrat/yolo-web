### B2. 引用が原文と違い、その差が結論を作っている（D-7）

監査 L145 の表:

| 箇所     | 監査の記述                                                                        |
| -------- | --------------------------------------------------------------------------------- |
| 冒頭注記 | 来訪者可視の顔・コピーは平明な言葉で組み、**店の signifier が伝わると仮定しない** |

### B3. 色相を確かめずに「青系」と断じている（D-3）

監査 L110-111:

> §8-1 は「**紫〜青（indigo/violet）のアクセント**」を「理由の如何を問わず禁止」とする。
> §2 の固有色の例として挙がるのは**藍色 `#0d5661`**——青系である。

実測（sRGB→OKLab 変換で算出）:

| 色                | oklch hue  | HSL hue |
| ----------------- | ---------- | ------- |
| `#0d5661`（藍色） | **210.6°** | 187.9°  |
| 純青 `#0000ff`    | 264.1°     | 240°    |
| violet `#7f00ff`  | 293.6°     | 270°    |
| indigo `#4b0082`  | 301.7°     | 275°    |

**`#0d5661` は青緑（teal/cyan）で、純青から 53°、indigo から 91° 離れている。** §8-1 の禁止帯は「紫〜青（indigo/violet）」——AI slop の記号としての紫青グラデーションを指す帯であり、この色はそこに入らない。色名が「藍」であることと、色相が indigo 帯にあることは別である。

さらに §4 L77 が持ち込みを禁じているのは「任意色の**ベタ背景**」で、§2 L41 が許すのは「**囲まれた面（全面ベタでも無色でもない）**」である。**同じ段落が同じものを禁止し要求している、という指摘は成立しない。**

ただしこの箇所には**別の、本物の穴**がある: 伝統色辞典が扱う色には江戸紫・藤色・菫色のように **oklch hue が 280〜310° に入る色が実在する**。その面が来たとき、§2 の「主題が色である面は任意 hex を使う」と §8-1 の「理由の如何を問わず禁止」は正面衝突し、`DESIGN.md` はどちらが勝つかを書いていない。**D-3 は、証拠を取り替えれば成立する。**

## Major

### M1. 「比喩の語彙」と「比喩から出た実体規定」を分けていない（C-2・C-5）

C-2 は店の比喩を**語彙の問題**として扱い、「来訪者可視の面で店の語彙を使う根拠はもう無い」で閉じている。しかし `DESIGN.md` には、比喩が語彙ではなく**来訪者の体験を直接決める規定**になっている箇所がある。

> **品書き（一覧の既定形）**: 一覧の既定は**罫区切りのリスト**（品名・ひとこと・値札）であって、カードのグリッドではない。（L71）

これは一覧の見え方そのものを決める規定で、根拠は「品書き」という店の比喩しかない。同型に L70（のれん＝ヘッダに背景色・影を付けない）・L73（値札＝メタラベルの形式）・L74（包み＝結果カードだけが独立ビジュアルを持つ）がある。

**書き直しで最も判断を要するのはここである。** 語彙を捨てれば済む箇所と、語彙を捨てると**規定ごと根拠を失う**箇所は、扱いが違う。後者は「来訪者にとってその形がよいか」を独立に立て直す必要がある（一覧をリストにするかカードにするかは、コンセプト L14「他では見つからないものを探している人へ」＝探索のしやすさと、constitution rule 4「well organized for easy to explore」から問い直せる論点であって、比喩を外したら自動的に決まるものではない）。

**要求:** ①に「比喩を外すと根拠ごと消える実体規定」の一覧（節・行・規定内容）を足すこと。

### M2. `DESIGN.md` → `site-concept.md` の宙吊り参照を数え落としている（C-9）

`DESIGN.md` が `site-concept` を名指しで参照するのは **4箇所**（L5・L75・L103・L138）。監査が扱ったのは3箇所で、**L138 の2件が抜けている。**

確定した `docs/site-concept.md` を grep すると「明瞭」「言い回し」「賭け」「拡散」「シェア」「共有」いずれも **0件**。**存在しない条文を出典として引いている。** これは①の中でも最も機械検証しやすく、最も反論の余地がない証拠であり、落とすのは惜しい。AP-P34 が名指しする「他者の権威のラベルを、原発言を確かめずに引用する」の同型でもある（引用先が空である）。

### M3. 「矛盾」に数えられない過大が6件（D-2・D-6・D-7・D-8・D-12 と C-4後半）

依頼 (C) の観点で重点確認した結果、**`DESIGN.md` が自分で例外や条件を明記している箇所を「矛盾」と数えている**ものが以下。
