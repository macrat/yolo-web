## ツギハギ — 3件

### T-1. `--paper` の用途欄だけが、増築から取り残されている（L45 / L47 / L215 / L223 / L321）

L47 の `--ink` の用途欄は「文字と、文字と同じ色で引くもの・塗るもの——下線・反転の地・選択の塗り・箇条書きの点・フォーカスの外リング・favicon の地」と、例外を全部並べる形になっている。
`git log -S` で追うと、この欄は当初「文字・選択の塗り」だけで、`a8d8142e`（3巡目の指摘対応）で「反転の地・フォーカスの外リング」が足され、その後さらに「下線・箇条書きの点・favicon の地」が積まれている。**指摘のたびに1語ずつ足された列挙**であり、後付けと言える。

一方、対になる L45 の `--paper` の用途欄は最初から「地」の一語のまま一度も触られていない。しかし `--paper` は文書の中で、地以外に3か所で使われている。

- L215 `反転（--ink 地に --paper 文字）` — 文字色
- L223 `内も外も主罫の太さで、内は --paper、外は --ink` — 線の色
- L321 `--ink の地に --paper で y の一字を見出し書体で` — 字の色

`--ink` 側だけが「文字と同じ色で引くもの・塗るもの」まで書き切っているため、用途欄は尽くした列挙だと読める。その読みに立つと `--paper` の文字・線は用途欄に無い。逆に用途欄が例示にすぎないなら、`--ink` の長い列挙は要らない。**同じ列の中に、尽くした欄と一語の欄が混在している**のがツギハギである。

直し方（規定を変えない範囲）: `--paper` の用途欄を `--ink` と同じ粒度にそろえる（地と、地と同じ色で抜くもの——反転の文字・フォーカスの内リング・favicon の字）。

### T-2. hover の規定が表と箇条書きに二重に置かれ、理由の一文が隣り合う2項で重複している（L222 / L239 / L241）

- L222（表）: `| **hover / active** | 要素の内側に細罫の枠が現れる。外には出ない |`
- L241（箇条書き）: `- **hover は要素の内側に出る。** 罫で詰めて並んだ行で、隣に食い込まないため。一覧の行では左右に細罫が現れて枠が閉じ、上下は行の区切りがそのまま枠の辺になる。`

L241 の太字部分は L222 の表の記述と同じことを言い直しているだけで、新しい規定を持たない。
さらに、その理由の一文が直前の項とも重複している。

- L239: `罫で詰めて並んだ一覧の行では内側に出て、隣の行に食い込まない。`
- L241: `罫で詰めて並んだ行で、隣に食い込まないため。`

「罫で詰めて並んだ…隣に食い込まない」が2行違いで2回出る。
`git log -S "外には出ない"` と `-S "罫で詰めて並んだ"` はどちらも `3dd7ee56`（Blocker 対応）を指しており、**1回の修正を表と箇条書きの両方に同時に当てた跡**である。その後の `aa5a321d`（全体書き直し）でも畳まれずに残った。最初から書かれていれば、規定は表に一度だけ置き、箇条書きには表に書けないこと（一覧の行での枠の閉じ方）だけが残るはずである。

直し方: L241 から太字の言い直しと重複した理由を落とし、「一覧の行では左右に細罫が現れて枠が閉じ、上下は行の区切りがそのまま枠の辺になる。」だけを残す。

### T-3. `SKILL.md` の「定型構成」が、`DESIGN.md` に無い語として取り残されている（SKILL.md L40）

`SKILL.md` L40: `**機械で判定できないものがある。** 定型構成・図像の質感・動きの意図・文章の自然さ。`

「図像」「動き」「文章」は `DESIGN.md` の語（§5 図像・§11 モーション・§9 文章）に対応するが、**「定型構成」だけは `DESIGN.md` のどこにも無い**。`grep` で追うと、この語は `cycle-278` で書かれた旧デザイン文書の「定型構成の再現」に由来し、旧 `DESIGN.md` §12 の禁止リスト（`cycle-302/carryover.md`、`cycle-315/review-design.md` に当時の引用が残る）で使われていた語である。現行 `DESIGN.md` はその節ごと書き直されているので、**削除済みの版だけを指す語がスキル側に残っている**。

直し方: 「定型構成」を「どこにでもある構成（§1 の担い手が消えていないか）」のように `DESIGN.md` の語で言い換える。`DESIGN.md` 側は変更不要。
