# Major

## Major-1: 「面の中で一番大きい文字は結果である」が、3つの形のうち2つで偽になる

L282 は3つの形すべてに掛かる位置にある。ところが——

- **文章のもの**は本文の大きさ（1.0625rem）で組む。同じ面の主見出しは 2.08–4.08rem で、結果より大きい。
- **図像のもの**は文字を持たない。そもそも「一番大きい文字」が結果でありえない。
- **一行に収まるもの**でも「主見出しと同じ大きさ」なので、主見出しと同寸であって「一番大きい」ではない。

前版は「**結果の値は**主見出しと同じ大きさ…面の中で**これより**大きい文字を持たない」と、値の形に限った上で「これより大きい文字が無い」という**成立する**言い方をしていた。今回の書き直しで、スコープ（値に限る）と論理（最大でなく上限）の両方が落ちた。読者は文章の結果を持つ面で、主見出しを縮めるか結果を拡大するかの誤った判断に追い込まれる。

## Major-2: §5 の幅の割り当てと §8 の形別の幅が正面から衝突する

- §5 L155:「見出し・一覧の行・入力・**結果**・表は**組み幅いっぱいに伸び**」
- §8 L279:「**文章のもの**は本文の大きさで組み、**本文の幅で折り返す**」
- §8 L280:「**図像のもの**は区画の組み幅を**超えない**」

992px の面で、文章の結果の行長は 884px（§5）なのか 640px（§8）なのか決まらない。図像の結果も「いっぱいに伸びる」のか「超えなければよい」のかが割れる。L155 の「伸びる」は同じ文の中で見出し・本文の折り返し幅と並べられており、行長の指定として読む以外にない。

前版ではこの衝突が無かった。§5 の部品は「結果」で、§8 で本文の幅が与えられていたのは「文章の**生成物**」——§5 の部品リストに無い語——だったためである。今回「結果と生成物」を1つにまとめた結果、§5 の受け側を直さなかったことで衝突が生まれた。**§5 の割り当てから結果を外して §8 に委ねるか、§5 を「結果の区画は組み幅いっぱい／中の行長は §8」と書き分けるかのどちらかが要る。**

## Major-3: 3分に catch-all が無く、色・表・箇条書きの結果が漏れる

L275 は「形ごとに組み方が決まる」と宣言し、3つの形を並べる。だが——

- **色そのものが結果である面**は §2 L57 が明示している（「結果・生成物・主題が色そのものである項目がこれにあたる」）。§7 L243・§10 L301 もこの面の存在を前提にしている。色の見本は数字でも短い語でも文章でも図像でもない（§5 L164 の部品リストでも図像と色の見本は別）。**3つのどれにも当たらない。**
- 同じことが、結果として出る**表**・**箇条書き**にも起きる（どちらも §5 L164 の別の部品）。

§6 は同じ構造の読み分けに「どれでもない → 区画」という catch-all を置いている（4巡目 Major-3 の直しで細罫側にも候補の行が入った）。§8 だけが、網羅を宣言しながら取りこぼす形になっている。`docs/anti-patterns/planning.md` AP-P33 は、価値の種類を「色が中身の面・数字が中身の面・画像が中身の面」で分けて確認することを求めており、色の面はこの文書自身が持っている種別である。

なお **「図像のもの」の規定は「区画の組み幅を超えない」だけ**で、これは §5 L155 と L171 が既に言っていることの再掲であり、形ごとの「組み方」を与えていない。3分を立てるなら、この形が何を決めるのかも要る。

## Major-4: 帯のラベルが「直上」になり、§5 の「入力欄のラベル**だけ**は欄の直上」と矛盾する

- L160（今回の修正）:「何であるかのラベルを、**載せるものの直上に**行を分けて置く。」
- L167:「ラベルは…**入力欄・帯**・選択の記号・開閉のつまみが持つ。**入力欄のラベルだけは欄の直上に置く。**」

同じ「直上」が2箇所に現れ、片方が「だけ」で他方を排除している。前版の L160 は「中のものの**上**に置く」で、「直上」は入力欄に固有だった。今回「直上」を持ち込んだ側だけを直し、受け側の「だけ」を直さなかった。

読者は、帯のラベルを直上に置くのか（L160）、直上は入力欄の専有だから別の関係で置くのか（L167）を決められない。しかも §6 の読み分けは「**直上にラベルがある**」を入力欄とエラーの入力欄の判別条件に使っており、「直上」が入力欄に固有でなくなったことは §6 の判別にも効く（Minor-8 と同根）。

## Major-5: 「一行に収まるもの」が長さの軸で、「文章のもの」と重なる

4巡目 Major-2 は「値」と「文章の生成物」が別々の軸で切られていることだった。今回「形で切り直した」とあるが、**1つめだけが長さの軸のまま**である。

- 生成された一文（診断の一言・見出し文など）は**一行に収まる**。1つめか2つめかで、大きさが 4.08rem と 1.0625rem に割れる。括弧内の「数字・短い語」まで読めば2つめだと分かるが、読者が最初に当てるのは太字の見出し語である。
- 逆に、桁の多い数字は**一行に収まらない**。ところが同じ箇条の次の文が「収まらないときは区画の中で横に送る」と、収まらない場合の扱いを1つめの中で決めている。**同じ箇条の中で「収まる」が2つの意味で使われている。**
- この文書は「収まる」を他の3箇所（L184「ナビが1行に収まらない幅」・L248/L255「1画面に収まらない」）で**すべて「幅に入りきる」の意味**で使っている。読者がこの語をそう読むのは自然である。

分類の名を長さから種類へ（例: 数字と短い語／文章／図像）揃えれば、重複も二義も同時に消える。
