**この確認で1件、現行文書の誤りが分かった。** `site-concept.md` L83 は「偽装は最低評価に直行し、**明示はむしろ保護的に働く**」と書き、文末に「（一次資料確認済み）」を付けている。
**その但し書きが、実際には確認できない部分まで覆っている。** 前半（偽装＝Lowest）は一次資料にあるが、後半（明示＝保護的）は無い。
書き直しでは、**一次資料で確かめられる範囲だけを書く**——「偽装は最低評価に直行する」までを根拠として記し、「保護的に働く」は落とす。
AI 明示を維持する理由は constitution rule 3 であって、検索評価上の利得ではない。**利得を理由に据えると、利得が消えたときに rule 3 を捨てる論理になる。**

**コントラスト・字サイズ・タップ標的の下限は、コンセプトからは導けない。** これらは外部が決めている要件として `DESIGN.md` に正面から引く。
一方、**どの色を使うか・どの字サイズを本文に据えるかはコンセプトから導く**——外部規範が決めるのは下限であって、選択ではない。

**1.4.4 について一点、一次資料で確認できなかったことがある。** 「px 固定指定がブラウザのフォントサイズ設定に追随しないことが 1.4.4 の不適合に当たる」と明言した記述は、仕様本文にも Understanding 文書にも**見つからなかった**。
導けるのは、(a) 200% 拡大時にコンテンツ・機能を失わないこと、(b) F94（viewport 単位の誤用による失敗例）が挙がっていること、の2点までである。
**したがって B-632（`html`/`body` の `font-size:16px` 固定）を「WCAG 違反」として扱わない。** 扱うなら別の根拠——文字を大きくして読む来訪者に本文が追随しない、という来訪者価値の側——で立てる。
