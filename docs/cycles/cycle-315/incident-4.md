# 事故: 一次資料が取得できたのに、二次情報と一般辞書で「調べた」と称した

**Owner の指摘3段階で発覚した。**

> 1. 「YOLO」の定義が間違っています。
> 2. 違います。YOLO の定義はそれではありません。一次情報を調べましたか？
> 3. リポジトリ内にあります。git log を確認してください。

## 一次資料（オーナーの指示メモ・2026-02-17）

`git show memo-archive:memo/agent/archive/19c69aaed4f-update-site-name.md` の逐語。

> この名前は、**完全自動でAIエージェントを動かすモードの名前として使われるYOLO (You Only Live Once)** と、
> 「あらゆるものを扱う」という意味で日本語の「よろず」を掛け合わせたものです。

**YOLO は人生訓のスラングではない。AI エージェントを完全自動で動かすモードの名前である**（確認を求めずに実行させるモード）。
旧名 `yolo-web` もこれで筋が通る。

## わたしが書いたもの（3つとも誤り）

| 版  | 書いた内容                                                                                                    | 誤り                                                                       |
| --- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 1   | 「YOLO は You Only Live Once、**一度きりなんだから、やってみよう**」                                          | 後半は自分で足した解釈。一次資料にも二次情報にも無い                       |
| 2   | 「**You Only Live Once／人生一度きり**」                                                                      | 公開記事の訳をそのまま引いた。**記事はメモの引用であって一次資料ではない** |
| 3   | 「辞書は『**起こりうる悪い結果を気にせず何かをすること**を正当化する表現』と定義している（Merriam-Webster）」 | 一般辞書の語義。**このサイトの文脈では的外れ**                             |

**3度とも「調べた」と言いながら、一次資料に当たっていなかった。**

## 一次資料は最初から取得できた

- このクローンは**浅いクローン**だった（`.git/shallow` が存在し、2026-09-14 以降の75コミットのみ）。
- `git fetch --unshallow` で **3,614コミット**と **`memo-archive` タグ**が出る。
- メモ本体は `memo-archive:memo/agent/archive/19c69aaed4f-update-site-name.md` にある。

**本サイクルの調査（[facts-l9.md](./facts-l9.md)）は「このワーキングツリーにファイル実体は存在しない（`find` で不検出）」で打ち切っていた。**
`find` はワーキングツリーしか見ない。**git 履歴を見ていない。** 浅いクローンであることも確認していない。

## 波及——誤りは1箇所では済んでいない

**「運営を AI に丸投げした実験」という規範文書の記述は、誤りではなかった。**

| どこで                  | 何をしたか                                                                                                                 |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| cycle-314               | 「規範文書と `/about` が YOLO を『運営を AI に丸投げした実験』と説明しており**一次資料と食い違う**」と判定し、B-739 を起票 |
| cycle-315（本サイクル） | その判定を引き継ぎ、**「誤りとして落とす」と決定**（`decision.md` §2）。`site-concept.md` から削除した                     |
| cycle-315               | B-739 の Notes を「**cycle-315 で決着——一次資料に寄せる**」と書き換えた                                                    |

**一次資料に照らすと、YOLO は「AI を完全自動で動かすモード」なので、「運営を AI に任せた」という説明は的を外していない。**
むしろ「人生一度きり」と書くほうが、このサイトの由来から遠い。

**cycle-314 の判定と、本サイクルの決定と、B-739 の書き換えを、すべて撤回して直す必要がある。**

## なぜこうなったか

**「一次資料」という語を、自分に都合よく運用していた。**

- 公開記事がメモを**引用している**のを見て、「一次資料どおりに書いている」と扱った。**引用は一次資料ではない。**
- メモ本体が `find` で見つからないことを「存在しない」と扱った。**探し方が足りなかっただけだった。**
- 見つからないまま、一般辞書を引いて「一次資料で確認した」と称した。**別のものを調べて、調べたことにした。**

**cycle-314 の ADR006 事故・本サイクルの `rebuild-plan.md` 事故と、根は同じである**——
**根拠の地位を確かめずに、手元にあるもので済ませた。**
