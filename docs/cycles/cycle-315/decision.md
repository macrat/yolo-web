# 決定: `docs/site-concept.md` をどう作り直すか

案出しの経過は [options-t1.md](./options-t1.md)（線引き5案）・[options-t2.md](./options-t2.md)（矛盾解消6案）・
[options-v2.md](./options-v2.md)（統合5案）に残る。**4巡のレビューを受けた。** ここに決定をまとめる。

## 使わない論拠——レビューで潰されたもの

| 使わない論拠                                             | なぜ誤りか                                                                                                                         |
| -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 「内部の像を保つ案は、現状そのものである」               | 現行 L9 は可視テキストのみを射程とする弱い注意であり、案B は**届く面すべて**の機械検査できる禁止である。射程も強度も別物だった     |
| 「二層構造は境界で必ず漏れる」                           | 漏れは全件 grep で列挙できている（可視6件・SR 17種・メタ4件・URL 2件）。**列挙できるものは検査できる**                             |
| 「検証できない像を規範に置くな」                         | **循環。** その要求は現行 L9 が課したものであり、L9 ごと捨てる案がそれを対抗案にだけ適用するのは不公平だった                       |
| 「ツギハギ禁止を最もよく満たすから」                     | **案を区別しない。** ツギハギ禁止は成果物の状態を問う。どの案でも全文書き下ろせば満たせる                                          |
| 「案D は一次資料に反する」                               | **不成立。** `grounding.md` §4 は来訪者主語の「やってみる」を「使ってよい」と判定しただけで、使わないことは誤りにならない          |
| 「L9 は出典の許可条項を落として転記した」                | **事実に反する。** L9 が出典として挙げるのは `grounding.md` §0/§0.1 であって §4 ではない。落としたのではなく、そもそも引いていない |
| 「遅かれ早かれ同じ範囲に手が入るので、代価は割り引ける」 | **撤回する。** B-672 は `cycle-NNN` 参照の除去であって店語彙の受け皿ではない。範囲が重なる保証は無い                               |

## 像についての区別——成り立つが、適用を誤っていた

「像には2種類ある」（**正体の像**＝このサイトが何であるか／**様式の像**＝作るものの見た目）という区別自体は成り立つ。**しかし適用が逆だった。**
`DESIGN.md` の「のれん・品書き・棚・値札」は**様式の像**であり、「様式の像は伝わる必要がない」という自分の原理に従えば、内部に置いてよいことになる。

**正しい形はこうである。**

> **像の種類は、それを内部に置いてよいかを決めない。決めるのは「来訪者に届くか」だけである。**
> 届く経路があるものは種類を問わず伝達が要求され、届かないものは種類を問わず要求されない。

## 決め手——像が判断を決めているか

**来訪者への効果では、案A（像を降ろす）と案B（像を内部に保ち届く面で禁じる）に差がつかない。** どちらでも来訪者に届く面から店語彙は消える。

**差がつくのは、像が判断を決めているかである。** ここは論証が要る。レビューが反例を4件挙げたので、1件ずつ答える。

| 反例として挙がったもの                                               | 検討                                                                                                                                                                                   |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **需要起点の仕入れ**（追加条件2「実在する検索需要に応える」）        | 「需要から出発し、証拠で確かめてから作る」は**検索市場の観察**から出る。よろず屋でなく専門店でも、同じ規則になる。比喩は**言い方**を与えているが、規則の中身を決めていない             |
| **棚落ち**（撤退の条件）                                             | 撤退の規則（評価窓を待つ・数値基準は Search Console・外れを放置しない）は、**検索の反応が遅いという実測**と **rule 4** から出る。店の比喩を外しても1文字も変わらない                   |
| **棚と動線**（rule 4 後半「探索しやすく整理する」）                  | **constitution rule 4 が直接定めている。** 比喩を経由していない                                                                                                                        |
| **`DESIGN.md` §8 行1**（紫〜青のアクセント禁止）**の理由が循環する** | **これは正しい指摘だが、像の問題ではない。** 禁止の理由が「AI slop から遠ざかる＝差別化」に依存しており、その「差別化」の中身が空席になる。**禁止リストの根拠の問題**であり、T5 で扱う |

**したがって、反例1〜3 が示したのは「比喩が規則に言い方を与えている」ことであって、「比喩が規則を決めている」ことではない。**

**ただし、言い方を与えることには価値がある。** 「棚から下げる」は「評価窓を経て外れと判断したものを削除する」より覚えやすく、伝わりやすい。
**それを失うことは代価である**——下の比較表に計上する。

**判断を決めていない像を、規範の中心に置く根拠は無い。** これが決め手である。
「検証できないから」ではない（それは循環だった）。「**規則の中身を決めていないから**」である。

## 決定

### 1. 線引き——何を残し、何を落とすか

**判定は2段で行う。** 一本の問いでは落とすリストの多くが判定できなかった（レビュー BL-3）。

**第1問: それは実装者・書き手が従うべきことか。** 従うべきこと（規則）なら残す。

**第2問: 従うべきことでないなら、次のどれか。** いずれも落とす。

| 落とす類型                                                           | 現行の該当                                          |
| -------------------------------------------------------------------- | --------------------------------------------------- |
| **来歴**——いつ誰が何をしたかの記録                                   | L7（改訂履歴）・L9 のうち cycle-309/310 の経緯      |
| **文書自身への警告**                                                 | L3（自己否定バナー）                                |
| **他の規則の言い換え・重複**                                         | L36（L93 と重複）                                   |
| **後付けの強調**——規則を足さず、既にある規則に感情を添えるだけのもの | L19「注意書きではなく個性である」                   |
| **弁解**——過去の失敗と対比して現在を正当化するもの                   | L57 末尾・L76「（失敗済みの方向）」                 |
| **裏取りできない他者の権威ラベル**                                   | L57「オーナーは積極的な実験を奨励する」             |
| **一次資料で確認できない事実主張**                                   | L83「明示はむしろ保護的に働く（一次資料確認済み）」 |
| **権威づけの語**                                                     | L17「正典」                                         |

**L5（文書の使い方の但し書き）は残す。** 第1問で「従うべきこと」に当たる——この文書をいつ引くかを定めており、規則である。
**書き方は変える**（但し書きの体裁ではなく、文書の射程を定める節として書く）。

**`t3-derivation-map.md` の (a)(b)(c) 分類は採らない**（分類に収まらない規則が9件あるとレビューが指摘し、その指摘が正しかった）。同文書は現行規則の棚卸しとしてのみ有効である。

### 2. サイト名の由来——一次資料どおりに書く

**YOLO（You Only Live Once）× よろず（万事・あらゆるもの）。**
「YOLO ＝ 運営を AI に丸投げした実験サイト」という語釈は、オーナーの指示メモと食い違うため**誤りとして落とす**。
「不変の事実」という格付けも落とす（それを与えた一次資料が存在しない）。

### 3. 店の像——正体の像としては据えない

**「よろず屋」を `site-concept.md` の自己定義に置かない。** 理由は上記のとおり、**規則の中身を決めていないから**である。
「屋（店）」を落とし、「よろず」は残す。由来の一次資料で裏付けが取れるのは「よろず」の側であり、扱う範囲を狭めないという規則もそこから出る。

### 4. 来訪者に届く面での店語彙——機械検査できる禁止として書く

**「来訪者に届く面」を列挙で定義する。**

1. 画面に表示される文字
2. スクリーンリーダーに読まれる文字列（`aria-label`・`alt`・`title`・視覚的に隠したテキスト）
3. メタデータ（ページ題・説明・共有カード・構造化データ）
4. URL のパス
5. **画像に描かれる文字**（持ち帰り画像・共有カードの生成物）

**5 を落としていた**（レビュー MJ-4）。`src/lib/fuda-image.tsx` が生成する画像に文字が描かれ、約60ルートに乗る。**この面だけが規範の外にあった。**

**「目に見えるか」で線を引かない。** スクリーンリーダーに読まれる文字列は目に見えないが、来訪者に届いている。

**内部（コンポーネント名・変数名・コメント）は、この禁止の対象外とする。** ただし**新しく内部の店語彙を増やさない。**

**この免除がもたらす状態を、正直に書く**——規範が店の像を持たないのに、実装が店の語彙で書かれている状態が残る。
**これは違反ではないが、次に読む人を迷わせる。** 既存の整理は中止中の **B-656**（店語彙の内部識別子・コメントの整理）の射程である。

### 5. 「やってみる」——残す。主語は来訪者

由来（一度きりだから、やってみる）から直接出る。`grounding.md` §4 が来訪者主語の用法を「使ってよい」と判定している。
実際の PV 比（やってみる側 88.7%・28日）とも一致する。
**運営の営み（実験・試作）を来訪者への売りにしない**という禁止は残す——`grounding.md` §0.1(4) が主語を明示して論じた規則である。

### 6. 来訪者への一言——受け取れるものの記述にする

名乗りの文にしない。

**ブランドクエリについて、実測の言葉で書く**（レビュー MJ-7）。直近28日・90日ではゼロ件だが、Search Console の保持全期間では **26表示・2クリック**ある。
また**表示回数の約4割は匿名化されて文字列が取れない。** したがって言えるのは「**指名検索はほぼ無い**」までであり、「検索面で0点」とは言えない。
**この事実から引き出してよい結論は「名乗りを変えても失う認知がほぼ無い」ことだけである。**

### 7. AI 運営の開示——名乗りと分け、3要素を欠かさない

**AI が運営していること・これが実験であること・内容が誤りうること。** 現行サイト（`src/app/page.tsx:200`）はこの3要素を満たしているので、そこから後退させない。
維持する理由は constitution rule 3 であって、検索評価上の利得ではない。

### 8. `DESIGN.md` へ渡すもの

**4層で渡す。**

**(1) 正体から導かれるもの**

| 正体のどこから                | 制約                                                                                          |
| ----------------------------- | --------------------------------------------------------------------------------------------- |
| あらゆる題材を扱う            | 題材が変わっても作りが変わらないこと。来訪者が別のサイトに来たと感じる状態を作らない          |
| その場でためせる              | 入力と結果に最短で到達できること。待たせない・探させない・主操作を折り返しの下へ落とさない    |
| 結果を持ち帰れる              | 成果物が単体で成立すること。サイトの文脈なしで何の結果か読み取れる                            |
| AI が作り、誤りうる           | **確からしさを演出で作らないこと。** 中身の確からしさと釣り合わない作り込みで信頼を調達しない |
| **来訪者に届く言葉**（決定4） | **届く5面で、初めて来た人に通じない語を使わない。** どの語を避けるかは `DESIGN.md` が列挙する |

**(2) constitution から直接来るもの**: rule 4 から「面の数を増やす方向の設計をしない・分類と回遊を設計する」、rule 2 から「煽らない・出し惜しみしない・偽の限定を作らない」。

**(3) 外部が決める下限**: WCAG 2.2。**等級を明示して引く**（AA と AAA を混同しない）。

**(4) 観測から来るもの**: **面によってデバイスの比率が大きく違うため、単一デバイス想定をしない。**
（**具体の比率は書かない**——手元の数字は `DESIGN.md` §10 からの孫引きで、出所に「小標本・固定値として扱わない・全体では非多数派」という留保が付いている。本サイクルはデバイス比を測っていない。）

**様式（紙と墨を据えるかどうか）は、ここでは決めない。** T5 で案を並べて決める。

## 案の比較表

|                                | 案A 白紙起草・像を降ろす                                                                         | 案B 像を内部に保ち届く面で禁じる     | 案C 像を別の像へ           | 案D よろず屋を残し「やってみる」を落とす         | 案E 来歴だけ落として構造を組み直す                                                                             |
| ------------------------------ | ------------------------------------------------------------------------------------------------ | ------------------------------------ | -------------------------- | ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| **1 来訪者が受け取るもの**     | 受け取るものを直接言える                                                                         | **同じ**（届く面から店語彙は消える） | 同じ                       | 弱い——「よろず屋」だけでは何が得られるか言えない | **現行のまま**（「AI が営むよろず屋です」——意味を説明する面が `/about` 1面だけで、しかも「屋」は説明されない） |
| **2 検索結果での見え方**       | 同等                                                                                             | 同等                                 | 同等                       | 弱い                                             | **現行のまま**（指名検索はほぼ無く、名乗りが認知を作っていない）                                               |
| **3 引く者が迷わないか**       | 「店語彙は使わない」の一文                                                                       | 境界の列挙が要る（列挙すれば明確）   | 同等                       | 自己定義と中心原則が切れる                       | 来源は読めるが自己定義は現行のまま                                                                             |
| **4 規則の中身を決めているか** | 像を持たないので問題が生じない                                                                   | **決めていない像を保つ**             | 様式の像は見た目にのみ効く | 決めていない                                     | 決めていない像を保つ                                                                                           |
| **5 実装との距離**             | **最も遠い**——実装が店語彙で書かれた状態が残る（違反ではないが読む人を迷わせる。受け皿は B-656） | **最も近い**                         | 遠い                       | 近い                                             | 近い                                                                                                           |
| **6 失うもの**                 | **比喩が与えていた覚えやすさ**（「棚から下げる」等の言い回し）                                   | 失わない                             | 別の比喩に置き換わる       | 失わない                                         | 失わない                                                                                                       |

**採るのは案A である。** 決め手は**基準4**——像が規則の中身を決めていない。

**代価を2つ計上する。**

1. **比喩が与えていた覚えやすさを失う**（基準6）。規則は残るが、言い回しは平板になる。
2. **実装が店語彙で書かれた状態が残る**（基準5）。`src/` のコンポーネント名・識別子・コメントは本サイクルでは触らない。
   **受け皿は中止中の B-656 である**——ただし B-656 は内部識別子・コメントが対象で、**来訪者に届く面の可視テキスト6件・メタデータ4件・URL 2件には受け皿が無い。** T8 で起票する。
