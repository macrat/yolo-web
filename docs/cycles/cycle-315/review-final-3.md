## Major

### MJ-1. 外部下限の受け方が「達成基準のすべて」になり、一次資料と食い違う

成果物 L147-149:

> **外部が決める下限**（こちらでは動かせない）: WCAG の現行勧告（現時点で 2.2）が定める**達成基準のすべて**。
> とくに落とさないのは、非テキストコンテンツの代替（1.1.1・等級 A）、コントラスト比、文字サイズの拡大耐性、タップ標的の大きさである。
> **等級を明示して引く**（AA と AAA を混同しない）。外部が決めるのは下限であって、選択ではない。

**問題は3つある。**

**(a) 一次資料と食い違う。** WCAG 2.2 の達成基準は等級 A / AA / AAA の3層からなり、W3C 自身が Understanding Conformance で次のように書いている（本レビューで取得）。

> "It is not recommended that Level AAA conformance be required as a general policy for entire sites because it is not possible to satisfy all Level AAA success criteria for some content."

**「すべて」は AAA を含む。** 外部の当事者が「サイト全体の方針として求めることは推奨しない・一部の内容では満たすことが不可能」と明言しているものを、「**外部が決める下限**（こちらでは動かせない）」「**選択ではない**」として受けている。等級の選択は、外部が決めるのではなくこちらが決める事柄である。

**(b) 同じ段落の中で衝突している。** すべての達成基準が動かせない下限なら、より厳しい AAA が常に勝つので、「**AA と AAA を混同しない**」という指示は意味を失う。逆に等級を区別して引くのなら、下限は「すべて」ではない。**3行の中で両方を言っている。**

**(c) 次の作業の入口を壊す。** `DESIGN.md` はこの4層から導出される（L132）。この受け方のまま導出すると、本文コントラストは 4.5:1（1.4.3・AA）なのか 7:1（1.4.6・AAA）なのか、タップ標的は 24px（2.5.8・AA）なのか 44px（2.5.5・AAA）なのかが**規範から決まらない**。`index.md` の T0 は両方の値を一次資料で揃えてあるのに、選ぶ側の規則が無い。中止17件のうち B-660・B-669・B-682 の結論がここに依存する。

**どう直すか。1文で足りる。** 等級を名指しする形にする——たとえば「**WCAG の現行勧告（現時点で 2.2）の等級 AA を下限とする**（非テキストコンテンツの代替 1.1.1 は等級 A）。とくに落とさないのは……。**AAA は下限ではない。採るときは等級を明示して採る。**」。**1.1.1 を名指しで残すこと**——落とすと B-668 が元に戻る。あわせて、とくに落とさない4項目のうち等級が付いているのは 1.1.1 だけなので、残り3つにも基準番号と等級を添えると「等級を明示して引く」が文書自身で守られる。
