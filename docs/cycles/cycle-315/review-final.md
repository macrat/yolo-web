### BL-2. 決め手（「像が判断に効いていない」）が論証されておらず、反例がある——v2-B1 は「今度も公平でない」

**何が問題か。** 決定はこの表を決め手に据えている。

| 問い                         | 「よろず屋」の像は答えを出すか                                                           |
| ---------------------------- | ---------------------------------------------------------------------------------------- |
| このコンテンツを追加すべきか | **出さない。**「あらゆるものを扱う」は**よろず**から出る。**屋（店）**は何も足していない |
| このコンテンツをやめるべきか | **出さない**                                                                             |
| どう作るべきか               | **出さない**                                                                             |

**2行目と3行目には、理由が1文字も書かれていない。** 1行目の理由も「よろずで足りる」だけで、屋（店）が何も足さないことの検証ではない。

**反例を探した。4つ見つかった。**

1. **仕入れの向き（追加の判断）。** 店は「作れるもの」ではなく「売れるもの」を仕入れる。これは新 `site-concept.md` の追加条件2（実在する検索需要に応える／需要から出発する）と禁止「**作れるから作る**」そのものである。「よろず」は範囲しか言わないので、この向きは出てこない。**屋（店）の側から出ている。**
2. **棚落ち（やめる判断）。** 売れない在庫を棚から下げるのは店の基本動作で、「外れを放置しない。判定の時期を過ぎて外れと分かったものは、直すか消す」に対応する。
3. **棚と動線（rule 4 後半）。** 「増やすことは、整理する義務を伴う。分類・回遊・見つけやすさの設計なしに面を増やさない」は、店の像の中心的な働き（棚割りと客動線）そのものである。決定 §8 はこれを「constitution から直接来るもの（正体からは導けない）」に分類しているが、**店の像を持てば正体からも導ける**——つまり「像は判断に効かない」の反例になっている。
4. **決定自身が空席を作っている。** §8(1) 行1「あらゆる題材を扱う → 題材が変わっても作りが変わらないこと」の理由は「来訪者が別のサイトに来たと感じる状態を作らない」で、**制約の言い換えである**。`review-v2` M7 が確認したとおり、この制約の理由は元は「一軒分の統一」＝店の像だった。像を外した結果、理由が循環に戻っている（`review-concept` MJ-3 の1行目の指摘が未解消）。**像が担っていた仕事が空席のまま残っている**ことは、像が何も担っていなかったことの反証である。

**補強に使われた実測も、留保を落としている。** 決定は「`DESIGN.md` での効き方も、実測では『呼び名』に留まる——`facts-design.md` は §2〜§7 を**語彙のみ**と判定した。真に依存しているのは §1 と §11 の2節だけである」と書く。しかし `facts-design.md` B 節は §4（L76）と §6（L95）に **「判断に迷った箇所」** を明記し、どちらも「店の比喩を外すと指示対象が消えるため**依存**とも読める」と書いている。`review-v2` m5 が同じ要約の問題を指摘しており、**同じ文がそのまま再掲されている。**

**なぜ問題か。** `review-v2` B1 は「案B を、その案が実際に書いている条件で評価し直せ」と求めた。決め手は差し替わったが、**新しい決め手も主張のみで、有利な実測だけを引き、不利な留保を落としている**（AP-P02: 留保の選択的適用／検証の強度を結果の有利不利で変える）。棄却の型は変わっていない。

**どう直すか。** 3つのどれかを採る。

- (a) **決め手を成り立つ形に書き直す。** 成り立つ版は存在する——「像から読み取れる判断（需要起点の仕入れ・棚落ち・棚割り）は、いずれも**すでに規則として明示的に書かれている**。像は、明示された規則に何も付け加えない」。これなら反例1〜3 を潰せる。ただしこの版を採るなら、反例4（§8 行1 の理由が空席になった）に答える必要がある——一貫性を選ぶ理由を、像に頼らず書くこと。
- (b) **決め手を基準1・5 の組に移す**（来訪者への効果は同じ／実装との距離で案B が優る、という構図を正面から認めたうえで、別の実質で案A を採る）。
- (c) 案B を採る。

いずれにせよ、**`facts-design.md` の「判断に迷った箇所」2件を要約に残すこと。**

**なぜ問題か。** `review-t1` Major-6 が案4 について「一本の線ではなく、5種類のアドホックな網である」と指摘し、`review-v2` B4 が「線引きが依然として決まっていない」と Blocker にした。**3巡目で表は作られたが、表を生む規則は作られていない。** 列挙表は T3 の一回限りの作業には足りたが、線引きの規則としては成立していないため、次に誰かがこの文書に何かを足すとき、何を落とすかは再び判定できない。**これは B-670（規範の射程）を解いた当の文書が、自分の編集規則を持たないという形で同じ穴を残すことになる。**

1. これは規則か、規則がどう生まれたかの話か（→ 来歴を落とす）。

そのうえで、**L5（射程）が「残す」に判定されることを表に反映する**（現状は落とすリストに入ったまま、成果物では復活している）。

## Major

### MJ-1. 「デザインへ渡すもの」の4層は、排他でも網羅でもない

依頼された問い（決定8 の4層は互いに排他で、漏れがないか）に、1つずつ答える。

**(a) 数が合っていない。** `decision.md` §8 は「**渡すものを3つの層に分けて書く。**」と宣言してから (1)(2)(3)(4) の**4層**を並べている。文と中身が食い違っている。

**(b) 排他でない。** 「AI が作り、誤りうる」は正体であると同時に constitution rule 3 由来である（成果物 L145 が rule 3 として同じ事実を掲げている）。層(3) の「タップ標的の大きさ」と層(4) の「モバイルを前提に組む」も重なる。排他を主張するなら、重なる行をどちらに置くかの規則が要る。

**(c) 網羅でない——渡し口が2箇所に割れている。** 成果物 L114 は「どの語を避けるかの具体は `DESIGN.md` が列挙する」と `DESIGN.md` に仕事を課しているが、L118 の「**`DESIGN.md` は次を受け取る**」に続く4層にそれが入っていない。「次を受け取る」と書いた以上、これは網羅の宣言である。

**どう直すか。** (i)「3つの層」を「4つの層」に直す。(ii) 重なる行の置き場所を決める。(iii) 語彙の要求を4層のどれか（または5つ目の層）に入れ、渡し口を1箇所にする。(iv) 様式の選択が観測から来るなら、**その観測を観測層に載せる**（載せないなら、T5 は様式を何から決めるのかを決定に書く）。

### MJ-2. 「見た目の作り込みで信頼を調達しない」が広すぎ、T5 の方向と正面から衝突する

> AI が作り、誤りうる → **確からしさを演出で作らないこと。見た目の作り込みで信頼を調達しない**

`options-t5.md` は「明朝の見出し×ゴシックの本文は日本の編集デザインの正統で、AI 量産サイトから最も遠い顔を作る」として様式を選ぼうとしている。**これは見た目で信頼を作る論である。** いまの文言のままなら、T5 の最有力の論拠が、コンセプトによって禁じられる。
