# デザインの中心——第1段階: 見た目

**見た目と組み方を分けて、見た目から決める。** 混ぜると軸が交差して選べない。
ここで決めるのは**地の色・文字の色・アクセントを誰が持つか・書体の系統・面の作り方・装飾の量**。一覧の形や情報の並べ方（組み方）は次の段階で決める。

現状の実装は見ていない。

## 判定の条件

**Owner から2つの条件を受けている。この2つが最上位にある。**

| #   | 条件                                              |
| --- | ------------------------------------------------- |
| 1   | **デザインだけで yolos.net だと分かる強烈な個性** |
| 2   | **誰もが使えるユーザビリティ**                    |

そのうえで、このサイトの成り立ちから来る条件が3つ。

| #   | 条件                                                                                        |
| --- | ------------------------------------------------------------------------------------------- |
| 3   | **中身が多様で、入れ替わり続けることに耐える**——器の色が中身とぶつからない                  |
| 4   | **装飾の誘惑を構造的に塞ぐ**——中心が緩むと必ず飾りが戻る（この3サイクルで実際に起きている） |
| 5   | **「割に合わないものに手をかける」温度が出る**——安く見えない                                |

**条件1と条件3は、色では両立しない。** 器が強い色を持てば個性は出るが中身とぶつかり、器が色を捨てれば中身は守れるが個性が消える。
**だから個性を色から取らない。構造と書体から取る。** これが以下の判断の軸になる。

---

## 案A. 紙と墨と朱（現行の系統から店の像だけを外す）

| 項目               | 内容                                    |
| ------------------ | --------------------------------------- |
| 地                 | 生成りの紙色（低彩度）                  |
| 文字               | 墨                                      |
| アクセントの持ち主 | **器が持つ**（朱1色）                   |
| 書体               | 明朝の見出し × ゴシックの本文           |
| 面の作り方         | 罫（1px）。影なし・角丸 0px             |
| 装飾の量           | ゼロ（例外として成果物に識別マーク1つ） |

**強み**: 既定 sans から最も遠い顔になる。日本語として読みやすい。既に一度導出されていて、質が高い。

**弱み**: **器が朱を持つため、中身の色とぶつかる**（条件1）。そして和の含意——伝統・職人・和色——がサイトの中身と関係がない。
**この系統は、この3サイクルで実際に装飾を呼び戻している**（朱肉の印・捺印質感の禁止規定が必要になったこと自体が証拠）。条件3を満たさない。

---

## 案B. 無彩の器と、中身の色

| 項目               | 内容                                       |
| ------------------ | ------------------------------------------ |
| 地                 | 白（ダークは黒）                           |
| 文字               | 黒（ダークは白）                           |
| アクセントの持ち主 | **中身が持つ**。器は色を一切持たない       |
| 書体               | 明朝の見出し × ゴシックの本文              |
| 面の作り方         | 罫と余白だけ。影なし・角丸 0px             |
| 装飾の量           | ゼロ。**器に飾る場所が構造的に存在しない** |

**強み**: **中身が何色でも壊れない**（条件1を構造的に満たす）。器に色が無いので、装飾を足す場所がない（条件3）。
そして**多様であること自体が画面に出る**——器が無彩だから、中身の色がそのまま個性として立つ。**これは大量に作って試しているサイトでしか起きない絵である。**

**弱み**: **中身が無い場所——器だけの画面——は地味になる。** 第一印象を器が助けない。
コントラスト・文字の大きさ・余白で持たせる必要がある。

---

## 案C. 濃い地

| 項目               | 内容               |
| ------------------ | ------------------ |
| 地                 | 暗い地を既定にする |
| 文字               | 明るい文字         |
| アクセントの持ち主 | 器が持つ（1色）    |
| 書体               | ゴシック基調       |
| 面の作り方         | 濃淡の面で区切る   |
| 装飾の量           | 少ない             |

**強み**: 器だけでも印象が立つ。案Bの弱点がここには無い。

**弱み**: **中身の色が濃い地の上で沈む**（条件1）。とくに淡い色・暗い色の中身が死ぬ。
そして暗い地＋1色のアクセントは**テック系テンプレートの型に最も近い**（条件2・条件3）。

---

## 案D. 器が強い色を持つ

| 項目               | 内容                                 |
| ------------------ | ------------------------------------ |
| 地                 | 白                                   |
| アクセントの持ち主 | **器が持つ**。彩度の高い色を複数使う |
| 書体               | 太いゴシック                         |
| 面の作り方         | ベタ面で区切る                       |
| 装飾の量           | 多い                                 |

**強み**: 第一印象が強い。楽しい場所に見える。

**弱み**: **中身の色と正面からぶつかる**（条件1）。そして**装飾の量が中心に組み込まれている**——条件3を最初から満たさない。
「割に合わないものに手をかける」ではなく「賑やかにした」に見える（条件4）。

## 案E. 素のまま

| 項目               | 内容                   |
| ------------------ | ---------------------- |
| 地・文字           | ブラウザ既定に近い白黒 |
| アクセントの持ち主 | 誰も持たない           |
| 書体               | システム既定           |
| 面の作り方         | 何もしない             |
| 装飾の量           | ゼロ                   |

**強み**: 入れ替わりに完全に耐える。作るコストがゼロ。

**弱み**: **既定 sans で組まれた量産サイトそのものになる**（条件2）。そして**手をかけていないことが、そのまま見える**（条件4）。
「割に合わないものにこそ、いくらでも手をかけます」と真逆の顔になる。

---

## 案F. 太い黒罫の格子と、巨大な明朝

| 項目               | 内容                                                               |
| ------------------ | ------------------------------------------------------------------ |
| 地                 | 白（ダークは黒）                                                   |
| 文字               | 黒（ダークは白）                                                   |
| アクセントの持ち主 | **中身が持つ**。器は色を一切持たない                               |
| 書体               | **明朝の見出しを極端に大きく** × ゴシックの本文                    |
| 面の作り方         | **太い黒罫（3px）の格子。罫は画面端まで届く。** 内部の区切りは 1px |
| 操作の記号         | **反転（黒地に白抜き）と下線。色を使わない**                       |
| 装飾の量           | ゼロ                                                               |

**案Bに、個性を出すための3つを足したもの。** 太い罫・巨大な明朝・反転。**どれも色を使わない。**

**強み**:

- **色を使わずに強烈な個性が出る**（条件1）。端まで届く太い黒罫の格子と、巨大な明朝の見出しは、一目で見分けがつく。
- **色を使わないことが、そのままユーザビリティになる**（条件2）。黒と白の対比は最も高いコントラストで、**色覚に依存しない**。操作を反転と下線で示せば、色が見えなくても操作が分かる。太い罫は弱視の人にも境界が見える。
- **中身の色とぶつからない**（条件3）。器が無彩のまま。
- **飾る場所が無い**（条件4）。器に色が無く、面はすべて罫で区切られている。
- **手をかけた感じが出る**（条件5）。巨大な明朝は既定 sans では作れない顔で、罫の太さの階層は組んだ人がいることを示す。

**弱み**: 太い罫は、狭い画面で窮屈になりうる。**内側の余白と罫の太さの階層を規定として持つ必要がある。**
そして黒白の強いコントラストは、硬く冷たく見える危険がある。**余白と本文の読みやすさで温度を作る。**

---

## 選んだもの——案F「太い黒罫の格子と、巨大な明朝」

**わたしはこれをやりたい。**

**条件1と条件3が色で両立しないなら、個性を色以外から取ればいい。** ここが判断の芯である。

器が色を持たないことは変えない。**中身は入れ替わり続け、何が置かれるか事前に決まっていない。器が色を持てば、その色と喧嘩しない中身しか置けなくなる。** 器の色は、作れるものを狭める。

**そのうえで、無彩のまま個性を出す手段が3つある。**

**太い黒罫の格子。** 罫を画面端まで届かせ、面を明確に区切る。**これは色を一切使わずに、画面の骨格そのものを個性にする。** 量産サイトは影と角丸で面を作る——太い罫で組む画面は、それだけで見分けがつく。

**巨大な明朝の見出し。** 既定 sans では絶対に作れない顔で、**書体そのものが器の個性を担う。** 色を使わずに顔を作る唯一の手段である。

**反転（黒地に白抜き）だけが操作を示す。** ボタンも、現在地も、選択状態も、色ではなく反転で示す。**これが個性であると同時に、そのままアクセシビリティになる。**

**条件2が、この案では条件1と対立しない。むしろ同じものから出てくる。** 黒白の対比は最も高いコントラストで、色覚に依存せず、太い罫は境界を弱視の人にも見せる。
**普通は個性とユーザビリティが取引になるが、色を捨てたことで取引が消える。** これがこの案を選ぶ最大の理由である。

**案Aを採らない理由。** 悪くない。質は高い。**採らないのは器が朱を持つからで、それは条件3に反する。** そして和の含意はサイトの中身と関係がない。
**ただし案Fは案Aを捨てることではない。** 明朝の見出しも罫も角丸 0px も残る。**変わるのは、罫が太くなり、見出しが大きくなり、器から朱が消えることである。**

**案Bを採らない理由。** 条件1を満たさない。**わたし自身が「器だけの画面は地味になる」と弱点に書いた。** 案Fはその弱点だけを塞いだものである。

### 弱点を、見た目の側でどう塞ぐか

| 弱点                     | 塞ぎ方                                                                 |
| ------------------------ | ---------------------------------------------------------------------- |
| 狭い画面で窮屈になる     | 罫の太さに階層を持つ（外枠 3px・内部 1px）。内側の余白を最小 16px 取る |
| 硬く冷たく見える         | 本文の行間を広く取り、余白を惜しまない。**密度で詰めない**             |
| 反転が押せると分からない | 反転する面は必ず 44px 以上・カーソルと focus を明示                    |

# デザインの中心——第2段階: 組み方

見た目（案F）の上で、**画面の骨格・一覧の既定形・面の追加の仕方**を決める。

## 案K1. 罫区切りの行

一覧の既定形を、**罫で区切った1行1項目**にする。行の中に品名・ひとこと・種別が並ぶ。

**強み**: 1画面に入る項目数が最も多い。**走査が速い**——目が縦一列を降りるだけで済む。
見た目（太い罫の格子）とそのまま噛み合う。**行を1つ足すことが、面を1つ足すことと同じコストになる。**
**行全体をクリック標的にできる**ので、標的が大きく取れる（条件2）。

**弱み**: 項目ごとの違いが出しにくい。中身の色が小さくしか出せない。

## 案K2. カードの格子

項目を四角い区画として並べる。

**強み**: 項目ごとに面積があるので、**中身の色を大きく見せられる**。

**弱み**: **1画面に入る項目数が落ちる。** 大量に並んでいることが伝わらない。
そして**「アイコン付き同型カードの3枚組」は量産サイトの最も強い記号**で、条件1と正面から衝突する。

## 案K3. 1面1カラムの連続

項目を縦に大きく、読み物のように連続配置する。

**強み**: 1項目ごとの印象が強い。

**弱み**: **走査できない。** 探しに来た人が、目当てに辿り着くまでにスクロールし続けることになる（条件2）。

---

## 選んだもの——案K1「罫区切りの行」

**探しに来た人にとって、走査の速さが全てだから。**

この人は、欲しいものがあって、どこにも無かった人である。**ここに来て最初にすることは、ここに何があるかを見ることだ。** 1画面に入る項目が多いほど、その人が早く辿り着く。**カードは面積を食い、大量に並んでいることを隠す。**

そして**行を1つ足すことが面を1つ足すことと同じコストになる。** 「たくさん作って、たくさん試す」が、組み方の側で成立する。

**中身の色が小さくしか出せない**という弱点は、行の左端に**色の帯**を置くことで塞ぐ（主題が色である面に限る）。器は無彩のままで、中身の色だけが行に差す。

## 画面の骨格

**全ページが同じ格子の上に乗る。**

| 部位 | 中身                                                               |
| ---- | ------------------------------------------------------------------ |
| 上端 | サイト名（明朝）と、下に太い罫。ナビは文字だけ。現在地は反転で示す |
| 本文 | 読む面は読む幅に絞り、操作面は広い幅まで使う。左揃え基調           |
| 下端 | 太い罫の上に、AI 運営の告知と最小限のリンク                        |

**面を足すときに、新しい部品を作らない。** 行・罫・見出し・本文・入力・結果——この6つの組み合わせで組めることを、面の設計の条件にする。
**組めないものが出たときだけ部品を足し、足した部品は必ず `DESIGN.md` に書く。**

## 引き上げた跡

引き上げた面は、**一覧から消す。** そして**その URL に来た人を、行き止まりにしない**——何が置かれていたかを一行で示し、一覧へ戻す。
**跡を残さないことと、来た人を放り出すことは別である。**
