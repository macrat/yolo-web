# デザインの中心——第1段階: 見た目

**見た目と組み方を分けて、見た目から決める。** 混ぜると軸が交差して選べない。
ここで決めるのは**地の色・文字の色・アクセントを誰が持つか・書体の系統・面の作り方・装飾の量**。一覧の形や情報の並べ方（組み方）は次の段階で決める。

現状の実装は見ていない。

## 判定の条件

| #   | 条件                                                                                        |
| --- | ------------------------------------------------------------------------------------------- |
| 1   | **中身が多様で、入れ替わり続けることに耐える**——器の色が中身とぶつからない                  |
| 2   | **既定 sans で組まれた量産サイトから遠い**——品質の下限として                                |
| 3   | **装飾の誘惑を構造的に塞ぐ**——中心が緩むと必ず飾りが戻る（この3サイクルで実際に起きている） |
| 4   | **「割に合わないものに手をかける」温度が出る**——安く見えない                                |

---

## 案A. 紙と墨と朱（現行の系統から店の像だけを外す）

| 項目               | 内容                                    |
| ------------------ | --------------------------------------- |
| 地                 | 生成りの紙色（低彩度）                  |
| 文字               | 墨                                      |
| アクセントの持ち主 | **器が持つ**（朱1色）                   |
| 書体               | 明朝の見出し × ゴシックの本文           |
| 面の作り方         | 罫（1px）。影なし・角丸 0px             |
| 装飾の量           | ゼロ（例外として成果物に識別マーク1つ） |

**強み**: 既定 sans から最も遠い顔になる。日本語として読みやすい。既に一度導出されていて、質が高い。

**弱み**: **器が朱を持つため、中身の色とぶつかる**（条件1）。そして和の含意——伝統・職人・和色——がサイトの中身と関係がない。
**この系統は、この3サイクルで実際に装飾を呼び戻している**（朱肉の印・捺印質感の禁止規定が必要になったこと自体が証拠）。条件3を満たさない。

---

## 案B. 無彩の器と、中身の色

| 項目               | 内容                                       |
| ------------------ | ------------------------------------------ |
| 地                 | 白（ダークは黒）                           |
| 文字               | 黒（ダークは白）                           |
| アクセントの持ち主 | **中身が持つ**。器は色を一切持たない       |
| 書体               | 明朝の見出し × ゴシックの本文              |
| 面の作り方         | 罫と余白だけ。影なし・角丸 0px             |
| 装飾の量           | ゼロ。**器に飾る場所が構造的に存在しない** |

**強み**: **中身が何色でも壊れない**（条件1を構造的に満たす）。器に色が無いので、装飾を足す場所がない（条件3）。
そして**多様であること自体が画面に出る**——器が無彩だから、中身の色がそのまま個性として立つ。**これは大量に作って試しているサイトでしか起きない絵である。**

**弱み**: **中身が無い場所——器だけの画面——は地味になる。** 第一印象を器が助けない。
コントラスト・文字の大きさ・余白で持たせる必要がある。

---

## 案C. 濃い地

| 項目               | 内容               |
| ------------------ | ------------------ |
| 地                 | 暗い地を既定にする |
| 文字               | 明るい文字         |
| アクセントの持ち主 | 器が持つ（1色）    |
| 書体               | ゴシック基調       |
| 面の作り方         | 濃淡の面で区切る   |
| 装飾の量           | 少ない             |

**強み**: 器だけでも印象が立つ。案Bの弱点がここには無い。

**弱み**: **中身の色が濃い地の上で沈む**（条件1）。とくに淡い色・暗い色の中身が死ぬ。
そして暗い地＋1色のアクセントは**テック系テンプレートの型に最も近い**（条件2・条件3）。

---

## 案D. 器が強い色を持つ

| 項目               | 内容                                 |
| ------------------ | ------------------------------------ |
| 地                 | 白                                   |
| アクセントの持ち主 | **器が持つ**。彩度の高い色を複数使う |
| 書体               | 太いゴシック                         |
| 面の作り方         | ベタ面で区切る                       |
| 装飾の量           | 多い                                 |

**強み**: 第一印象が強い。楽しい場所に見える。

**弱み**: **中身の色と正面からぶつかる**（条件1）。そして**装飾の量が中心に組み込まれている**——条件3を最初から満たさない。
「割に合わないものに手をかける」ではなく「賑やかにした」に見える（条件4）。

## 案E. 素のまま

| 項目               | 内容                   |
| ------------------ | ---------------------- |
| 地・文字           | ブラウザ既定に近い白黒 |
| アクセントの持ち主 | 誰も持たない           |
| 書体               | システム既定           |
| 面の作り方         | 何もしない             |
| 装飾の量           | ゼロ                   |

**強み**: 入れ替わりに完全に耐える。作るコストがゼロ。

**弱み**: **既定 sans で組まれた量産サイトそのものになる**（条件2）。そして**手をかけていないことが、そのまま見える**（条件4）。
「割に合わないものにこそ、いくらでも手をかけます」と真逆の顔になる。

## 選んだもの——案B「無彩の器と、中身の色」

**わたしはこれをやりたい。**

**器が色を持たないことが、このサイトの成り立ちと噛み合う。** 中身は入れ替わり続ける。何が置かれるか事前に決まっていない。
**器が朱を持てば、朱と喧嘩しない中身しか置けなくなる。** 器の色は、作れるものを狭める。**色を持たない器だけが、何を置いても壊れない。**

そして**多様であることが、画面の上に出る。** 器が無彩なら、並んだときに見えるのは中身の色だけになる。
点数が少なければこれは成立しない。**大量に作って試し続けているサイトだけが作れる絵である。**

**装飾の誘惑も構造で塞げる。** 器にアクセント色が無いということは、飾りを置く場所が無いということである。
この3サイクルで起きたのは、器が朱を持っていたために「朱をどう使うか」の判断が繰り返し必要になり、そのたびに印・札・捺印質感へ広がったことだった。**場所を無くせば、判断そのものが要らなくなる。**

**案Aを採らない理由をはっきり書く。** 悪くない。質は高く、既に導出されている。
**採らないのは、器が朱を持つからである。** そして和の含意はサイトの中身と関係がない。

**ただし案Bは、案Aを捨てることではない。** 明朝の見出しも罫も角丸 0px も残す。**変わるのは、それを「和だから」ではなく「無彩の器で質を出すため」に選ぶことと、器から朱が消えることである。**

### この案の弱点を、見た目の側でどう塞ぐか

**器だけの画面が地味になる。** 塞ぎ方は3つ。

1. **コントラストを強く取る**——薄いグレーで曖昧にしない。黒は黒、白は白。
2. **文字を大きく、余白を大きく**——密度で誤魔化さず、一つ一つを大きく見せる。
3. **明朝の見出しを顔にする**——書体そのものが器の個性を担う。色を使わずに顔を作る唯一の手段である。
