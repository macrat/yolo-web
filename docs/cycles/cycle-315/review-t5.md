## Blocker

### B1. 様式の決め手に置いた「観測」は、使ってはならないと既に決まった数字であり、しかも主張の向きが逆である

options-t5 の核心（L22–31）は「制約が候補を絞り、**観測が1つを選んだ**」であり、その観測として `DESIGN.md` L17 の
「信頼を壊す第1因子＝日本語の不自然さ 40.91%」と L53「明朝の見出し×ゴシックの本文は日本の編集デザインの正統で、AI 量産サイトから最も遠い顔を作る」を引いている。
**この2つはいずれも「観測」ではない。**

**(1) 40.91% は出所を辿れるが、単独の根拠に使わないことが既に決定済みである。**

- 一次資料: `docs/research/2026-07-11-design-antipatterns-and-direction.md` L32（デザポケ調べ300名・2位は各14.77%）。同文書は冒頭 L8 で「**個別の統計値は参考値**」と自ら留保している。
- `docs/cycles/cycle-311/concept-decision.md` L36 の決定（逐語）: 「出典は**企業公式サイトで購買経験のある 300 名**を対象とした非査読のアンケート…**当サイトは購買を伴わない無料の道具・辞典・診断サイトであり、この統計を当サイトの来訪者に当てはめること自体が母集団の拡張である。補助的な傍証として扱い、単独の根拠にしない。**」
- options-t5 は、この数字を**様式を一意に決める唯一の決め手**として使っている。これは「単独の根拠にしない」という決定の正面からの違反であり、AP-P32（上位の未検証仮説を下位の規則の検証基準に使う）・AP-P06（過去の同種決定の経緯を調査せず矛盾する判断をする）に該当する。

**(2) 仮にこの数字を認めたとしても、それは様式を選ばない。むしろ逆を示す。**

40.91% が言っているのは「**視覚ではなく日本語が信頼を壊す**」であり、2位の「デザイン違和感」は 14.77% にすぎない。
出典文書自身の結論も「**デザインを磨いてもコピーが AI 臭ければ信頼は崩れる→デザインシステムは『文章』の層を持つ必要がある**」（研究 L32）であって、「だから明朝を使え」ではない。
**この統計は、視覚様式の選択が信頼にとって二次的であることの根拠である。** それを視覚様式（紙と墨 vs 無装飾のモダン）の決め手に転用するのは非論理である。
言い換えると、options-t5 が立てた「制約→観測→様式」の連鎖は、**観測の段で切れている。**

**(3) L53 は観測ではなく無出典の断定である。**

研究文書に「日本の編集デザインの正統」「AI 量産サイトから最も遠い顔」という記述は無い。あるのは L51「組版＝最大の差別化層…明朝×ゴシックの編集的コントラスト」という調査員要約1行のみで、同文書は出典の性格を「デザイナー/スタジオの批評記事であり査読研究ではない」と断っている。
options-t5 はこれを `DESIGN.md` から引用符付きで引き、**現行 `DESIGN.md` の記述そのものを観測の地位に格上げしている。** `DESIGN.md` は本サイクルが書き直す対象であり、冒頭で自ら「信用してはならない」と宣言している文書である（AP-P34 が名指しする「既存文書に貼られたラベルを原発言を確かめずに引用する」型）。

**求めること。** 「何が様式を選んだか」を書き直す。選択肢は3つある——(a) 40.91% を傍証の位置に戻し、様式を選ぶ別の根拠を立てる、(b) 様式は**制約から決まらない選択**であると認めたうえで、何を選ぶかを別の判断軸（後述 M3・M4）で決める、(c) 様式の決定自体を本サイクルの射程外として保留する。
**いずれにせよ「観測が選んだ」とは書けない。** 書けば `DESIGN.md` に新しい嘘を埋め込むことになり、それは本サイクルが解こうとしている状態そのものである。

### B4. 「節番号が変わる」代価の見積もりが、実際に起きることを取り違えている——参照は壊れるのではなく、静かに間違う

案1 の骨格は**11節に1〜11の番号を振る**。現行も §1〜§11 である。実測（`grep -o '§[0-9]\+' src`）では参照の分布は §4=350・§8=209・§2=209・§3=176・§10=91・§1=84・§7=69・§6=34・§5=20・§9=1。
新旧の対応はこうなる:

| 現行              | 新（案1）                     |

| §3 タイポグラフィ | §4 文字と組版                 |

`§8 禁止リスト` を引いているコメント209件は、新文書では「§8 成果物」を指す。`§2 のトークン` を引く209件は「§2 外が決める下限」を指す。

**そして、この代価は避けられる。** options-t5 は「節番号を守るために旧構成を保つ」か「番号を変えて1,245件をずらす」の二択を立てているが、**第3の選択肢が検討されていない**——
(a) 節に番号を振らず名前で引く、(b) 安定した見出しアンカーを与えて番号参照を廃止する方針を `DESIGN.md` 側で宣言する、(c) 新構成に合わせて意図的に番号を非連続にする（旧番号と衝突させない）。
いずれも `src/` を触らずに **`DESIGN.md` 側だけで**「無言で嘘になる」ことを防げる。CLAUDE.md の意思決定原則を「代価を引き受ける」根拠に使っているが、**代価を避ける手が検討されていない以上、その引用は成立しない。**

**求めること。** 節の識別子をどうするかを案として並べ、選ぶ。「番号は変わる・それでよい」で済ませない。

### B5. `.claude/skills/frontend-design/SKILL.md` が代価に計上されていない。しかもこれは代価ではなく、本サイクルで直せる取りこぼしである

`SKILL.md` は「デザインの単一情報源は `DESIGN.md`。本スキルはそのクイックリファレンス」と自称し、**`DESIGN.md` を実装へ翻訳する唯一の仕組み**である。
節番号を次のように名指ししている: 見出し「世界観（DESIGN.md §1）」「トークン（§2 が正典値）」「タイポグラフィ（§3）」「レイアウト（§4）」「結果の性質で振る（§7・判定軸）」「文章（§6・デザインの管轄）」「禁止リスト（§8）」「品質バー（§10）」。
さらに「作業の型」の第1項が **「作る前に `DESIGN.md` の該当節を読む（結果面→§4 包み/札/印+§7・一覧→§4 品書き・コピー→§6）」** という節番号のルーティング表になっている。

**節番号が変われば、この仕組みは全面的に誤誘導する。** `DESIGN.md` を読ませる前段が違う節へ送るため、B4 の「無言で嘘になる」がビルダーの入口で起きる。

**cycle-315 は `.claude/` を対象外にしていない。** `index.md` の射程限定は「`docs/` の他ファイルは変更しない」であり、`src/` 不変は完了条件7で機械検証される。**`SKILL.md` は `docs/` でも `src/` でもない。**
つまりこれは「本サイクルでは直せない代価」ではなく、**直せるのに計上されていない作業**である。

加えて `SKILL.md` は、本サイクルが落とすと決めたものをそのまま抱えている——「店構え」「よろず屋」「印」「正典値」（AP-P34 の禁止語）、および冒頭の「【移行状態の注意（cycle-278）】」という来歴ブロック（ツギハギ禁止）。
`DESIGN.md` だけを直して `SKILL.md` を放置すると、**旧コンセプトが実装への翻訳経路に残り続ける**——これは options-t5 が案2 を退けた理由（「旧コンセプトの遺産が新しい看板の下で生き続ける」）と同じ事態が、別のファイルで起きるということである。

**求めること。** `SKILL.md` の扱いを T5 の決定に明記する（本サイクルで書き直すか、T8 で起票して次サイクルに送るか）。どちらでもよいが、**決めずに黙っているのは不可**。

### B6. 現行の最大の規則ブロック（禁止リスト11項目）の導出根拠が、新コンセプトに存在しない

案1 の決め手は基準2（「制約から導出されており、導出できない部分がそれと分かるか」）である。ところが現行 §8 の禁止リスト11項目と §3 の書体規定の根拠は、現行 §1-4「**AI slop からの距離は機械的制約で保つ**」——すなわち「AI 量産サイトと違う顔を作る＝差別化」である。

**新 `site-concept.md` に「差別化」も「AI slop からの距離」も無い。** あるのは「AI の**供給力・量産力**を差別化の第一の柱にしない」（別の話）と「確からしさを演出で作らない」だけである。
「確からしさを演出で作らない」からは、グラデーション・グロー・グラスモーフィズム・偽の限定は導ける。しかし**導けないものが残る**——
「Inter/Roboto 等の欧文既定 sans を本文に指定しない」「all-caps 多用禁止」「角丸 8〜16px の全面適用禁止」「ピル形状禁止」「アイコン3枚カードのヒーロー禁止」。
これらは「平均から離れる」＝差別化の規則であって、確からしさの演出とは無関係である。

つまり案1 の §10「やらないことの一覧」は、**基準2 が最も強いと主張したその基準を、最も項目数の多い節で満たせない。**

**求めること。** 禁止リストの各項目について、(a) 制約から導けるもの、(b) 外部が決めるもの、(c) 導けないが選んだもの（＝差別化という、コンセプトに無い理由）を分けて示せるかを T5 の段階で確認する。(c) が残るなら、**その理由をコンセプトへ昇格させるか、`DESIGN.md` 固有の選択として明記するか**を T5 で決める。骨格を決める前に決まっていなければ、T6 で必ず「導出したことにする」誤魔化しが入る。

## Major

### M1. 5つの判断基準に、来訪者の観点が無い

- 基準1 = 止まっている**起票済みチケット**が判定可能になるか
- 基準2 = 導出の筋が通るか（文書の内部品質）
- 基準3 = **引く者**（実装者）が迷わないか
- 基準4 = ツギハギ禁止（文書の内部品質）
- 基準5 = **実装との距離**（参照網の維持コスト）

**5つのうち4つが文書と実装者の都合であり、来訪者は1つも主語になっていない。** 基準1 は最も来訪者に近いが、主語は「17件」という過去サイクルが起票した集合であって、来訪者が実際に受け取る画面ではない。
これは AP-P30（過去に決まった現状を所与にする）に触れる——**17件は cycle-312 の観察範囲がたまたま拾ったものであり、来訪者価値の網羅ではない。**

とくに次の観点が基準から欠けている:

1. **この規範に従って作られた画面は、来訪者にとって読みやすく・速く・迷わないか。** 「待たせない」制約を落とした（B2）ことと連動して、性能が一度も基準に現れない。
2. **白紙起草が、いま来訪者価値を守っている規則を落とさないか。** 現行 §2「色そのものが中身の面」（伝統色辞典・伝統色診断の固有色）は、AP-P33 が cycle-282/283 の実害から抽出した規則である。案1 は「現行は最後に落ちている規則が無いかの照合にのみ使う」としか書いておらず、**落としたときに壊れるのが来訪者価値であることが基準に反映されていない**（AP-P24: 過去サイクルが確立した設計判断の無意識な打ち消し）。
3. **どちらの様式が来訪者にとって良いか。** B1 が扱った「紙と墨 vs 無装飾のモダン」は、判断基準の5つのどれでも評価されていない。文書の最重要の論点が、自分の判断基準の外にある。

**求めること。** 来訪者を主語にした基準を足し、各案をその基準で評価し直す。少なくとも (1) と (2) は必須。

### M2. 4案が同じ軸に張られていない

- 案1（白紙起草）と案2（最小変更）は**起草の方針**の対立である。
- 案3（2部構成）と案4（制約＝節）は**節の割り方**の対立である。

案3 は案1 と排他ではない。その証拠に、選定は「案1 を骨格に、案3 の分離を節の中で行う」という**合成**になっている。
つまり実際に比較されたのは案1 vs 案2 の1軸だけで、決め手として挙げられた理由（基準2・旧コンセプトの遺産）も案2 にしか向いていない。**案3・案4 は「選ばれなかった案」ではなく「別の問いへの答え」である。**

これは形式要件（3案以上）を満たしていても、**選択肢の張り方としては1軸2案しかない**ことを意味する。M3・M4 の欠落と合わせると、実質的な比較はほとんど行われていない。

**求めること。** 軸を明示して案を並べ直す。最低限、(軸A) 起草方針、(軸B) 節の割り方、(軸C) 様式の扱い、(軸D) 節の識別子（B4）の4軸それぞれに案を立てる。

### M3. 有力な選択肢の欠落——「様式を選び直す（紙と墨をやめる）」案がゼロ

options-t5 は冒頭で「5つの制約を満たす様式は少なくとも2つある」と立て、**無装飾のモダンを具体的に記述した**。それだけの前置きをしておきながら、4案はすべて紙と墨を前提にしている。
案1 は「様式は『紙と墨』を**選び直したものとして**据える（現行の踏襲ではなく、判断としてやり直す）」と書くが、**やり直した結果が必ず現行と同じになる設計**であり、これは選び直しではない。

B1 で示したとおり、選び直しの唯一の根拠（40.91%）は無効である。**根拠が無効なら、選び直しの結論は現行と同じにならない可能性がある。**
とくに「AI が作り、誤りうる／確からしさを演出で作らない／**見た目の作り込みで信頼を調達しない**」という制約は、紙と墨に対する**反証の方向に働く**（→ M7）。

**求めること。** 「様式を無装飾側へ振る案」を実際に文章として1案立て、他案と同じ基準で評価する。捨てるなら、捨てた理由を書く。

### M4. 有力な選択肢の欠落——「様式の決定を保留し、判定に必要な下限だけ先に確定する」案

止まっている17件を並べると（B3 の表）、**そのほとんどは様式の選択に依存しない**——コントラスト・タップ標的・字サイズの下限、トークン化されていない直書き、絵文字ゲート、約物の統一、罫の使い分け、モーションの時間。
「明朝か sans か」「生成りの紙か白か」が決まらないと判定できない項目は、B-677（共有画像の地の色）程度である。

したがって「**外が決める下限＋制約から直接導ける規則＋機械検査できる禁止**だけで `DESIGN.md` を成立させ、様式（色相・書体の顔）の選択は根拠が立つまで明示的に未決とする」案が成立する。
この案は基準1 で案1 と同等以上、基準2 で最強（導出できないものを「未決」と書くのだから嘘が入らない）、基準4 でも同等である。
**基準2 を決め手に据えるなら、この案を検討せずに案1 を選んだ説明は付かない。**

**求めること。** この案を立てて評価する。棄却するなら「様式を未決にすると何が判定できなくなるか」を具体的に挙げて棄却する。

### M5. 基準5 の実測引用が誤っている（`facts-src.md` と照合）

options-t5 L41（逐語）:

- L161: 「うち **`DESIGN.md` を名指しして店語彙を引くコメントが 169 行 / 155 ファイル**」

### M6. 案1 §2「外が決める下限」の括りが、本サイクル自身の T0 の結論と衝突する

案1 §2 は「**外が決める下限（WCAG 2.2 から直接引く。コントラスト・文字サイズ・タップ標的）**」である。
`index.md` の T0 確認結果（一次資料・確認日 2026-09-17）と、私が W3C で再確認した内容はこうである:

| 項目         | WCAG 2.2 の実際                                                                    | 現行 `DESIGN.md`                       |
| ------------ | ---------------------------------------------------------------------------------- | -------------------------------------- |
| タップ標的   | **2.5.8 AA = 24×24 CSS px**。44×44 は **2.5.5 AAA**                                | §10 は 44px                            |
| 文字サイズ   | **1.4.4 AA は「200% 拡大に耐える」**。最小フォントサイズの下限は WCAG に存在しない | §3/§4 は 16px・12–13px などの px 値    |
| コントラスト | 1.4.3 AA 4.5:1（大きい文字 3:1）。**1.4.11 非テキスト 3:1 も AA**                  | §2/§10 は 4.5:1 のみ。非テキストは無し |

`index.md` は既に「`DESIGN.md` §10 のタップターゲット 44px は WCAG 2.2 AA（24px）より**厳しい側**。規格に合わせて緩めない」「**B-632 を『WCAG 違反』として扱わない**」と結論している。

つまり、**44px も 16px も「外が決める下限」ではなく「こちらが選んだもの」である。** 案1 §2 の括りはこの3つを外部側へ入れており、
決定の内容3「各節の中で『外が決める下限』と『こちらが選んだもの』を書き分ける」という自分の方針と、骨格の §2 が矛盾している。
さらに 1.4.11（非テキストコントラスト 3:1）が列挙から漏れており、これは B-668（下限の欠落）と同じ型の欠落を新文書で再生産する。

**求めること。** §2 の中身を T0 の確認結果の逐語に合わせる。「WCAG 2.2 が決めているのは 24px・200% 拡大・4.5:1・3:1(非テキスト)。44px と 16px はその上に**こちらが積んだ選択**である」と書ける形にする。

### M7. 制約4が紙と墨に向ける最大の反証が検討されていない

制約「AI が作り、誤りうる → **見た目の作り込みで信頼を調達しない**」に対し、紙と墨の様式は現行 §1-3 で「**人が組んだ密度**」を目的として掲げている——すなわち「人が丁寧に組んだように見せる」ことが目的である。
**これは「見た目の作り込みで信頼を調達する」の定義そのものに見える。**

options-t5 は「無装飾のモダンは制約4 を満たしながら AI が雑に作った見た目に接近する」という一方向の懸念だけを検討し、**紙と墨が制約4 に反する可能性を一度も検討していない。** AP-P02（自分の案を否定するデータを探したか／検証の強度を結果の有利・不利で変えていないか）に該当する。

この検討は必須である。結論が「反しない」（＝丁寧な組版は演出ではなく可読性の実質である）であっても構わないが、**その論証こそが `DESIGN.md` に書かれるべき導出**であり、それ無しでは T6 は書けない。

### M8. 「無装飾のモダンは AI 量産サイトの典型そのもの」に出典が無く、手元の調査はむしろ逆を示す

options-t5 L27–28 はこの断定を紙と墨の採用理由の半分にしている。しかし `docs/research/2026-07-11-...md` が名指しする AI slop の指紋は「**紫〜青グラデ／全面グラデ／グラスモーフィズム／色付きグロー／カード片側の色ボーダー／アイコン3枚カード／一律16px角丸／浮遊する3D**」であって、**白地・黒字・サンセリフ・余白ではない。**
同文書 §2-2 はむしろ「**信頼される要因は引き算**: 『シンプルで清潔感』13.47%・『フォントが読みやすく情報が整理』13.13%。華美でなく可読性と整理」と記録している。
