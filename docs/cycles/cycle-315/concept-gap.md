## 「書かないほうがよい」とされるものとの照合

## 留保

- **②ターゲットは、このプロジェクトでは意図的に外されている**——ターゲット定義の仕組みは cycle-278 のオーナー指示で廃止された（`docs/rebuild-plan.md` §4）。**一般論と食い違うが、食い違いには理由がある。**
- 日本語圏の 5W1H 定式は、調査で**書籍・公的機関・学術の一次情報が1つも見つからなかった**（提唱者・初出も特定できず）。日本語圏の通念として扱い、根拠の強さは英語圏の一次情報と同列に置かない。
- デジタル庁「ウェブサイトガイドライン案」は**「コンセプト」という語を使わず**、企画時に求めるのは主利用者の決定・利用ニーズの特定・提供範囲の企画のみ。なお「案」であり正式発効は未確認。

# 「コンセプト」の定義そのものと照らす

出典は `tmp/research-concept-definition.md`。

## 定義（一次資料で確認できたもの）

| 出典                                                           | 定義                                                                                                                                                                                                                                    |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Kotler & Keller**（Marketing Management 14e・PDF本体を確認） | 「A product idea is a possible product the company might offer to the market. **A product concept is an elaborated version of the idea expressed in consumer terms.**」「consumers don't buy product ideas; they buy product concepts」 |
| **JMR生活総合研究所**（用語集）                                | 「この商品はどのようなものか、**誰が使うのか、メリットは何か**等を"**ひとことで言い表したもの**"」。構成要素は ①誰に ②何を ③どのように                                                                                                  |
| **デジタル大辞泉**                                             | 「創造された作品や商品の**全体につらぬかれた、骨格となる発想や観点**」                                                                                                                                                                  |
| **国立国語研究所**（外来語言い換え提案）                       | 言い換え語「**基本概念**」。「事業や開発を進める際の、**基本となる考え方**」                                                                                                                                                            |
| **Merriam-Webster**                                            | "something conceived in the mind: thought, notion" / "an abstract or generic idea generalized from particular instances"                                                                                                                |

**日英のずれ**: 日本語の語義には「**全体につらぬかれた**」という一貫性・統一性が組み込まれているが、確認した英語辞典3種のどれにも「全体を貫く」に相当する語が無い。英語側の重心は**アイデア寄り**。

## 照合の結論

| 定義                                                   | 今回の文書はこれに当たるか                                                                                                                                                                                             |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Kotler「**消費者の言葉で表現された**もの」             | **部分的にのみ。** 来訪者への一言（「その場でためして、結果や作ったものを持ち帰れます」）は消費者の言葉だが、**全体の 1.5%**。残り9割は運営側の規則であり、消費者の言葉ではない                                        |
| JMR「**誰に・何を・どのように**をひとことで」          | **誰に＝無い。** 何を＝部分的（ベネフィットが消費者の言葉になっていない）。どのように＝**過剰にある**（規則として 51%）。「ひとこと」＝一文はあるが全体の 1.5%                                                         |
| 大辞泉「全体につらぬかれた、**骨格となる発想**」       | **骨格の発想はある**（「あらゆる題材で、その場でためせるものを作って置く場所」）。ただし**それが全体を貫いているとは言えない**——文書の規則の多くは観測由来・外部要件由来で、正体から導かれていないと自分で分類している |
| 国語研「事業や開発を進める際の、**基本となる考え方**」 | **基本となる考え方＋詳細な運用規則の混合物**である                                                                                                                                                                     |

## わたしの見立て

**今回作ったものは、一般的な意味での「コンセプト」を含んではいるが、それだけではない。**

- コンセプトに当たるのは「このサイトは何か」**509文字（6.7%）**。
- 残りは**判断基準・運用規則・デザインへの制約**であり、一般にはコンセプトとは別の層（Garrett の Scope/Structure/Surface、Pichler の戦略要素）に置かれるもの。
- **文書名が「サイトコンセプト」であることと、中身の9割が規則であることがずれている。**

**足りないもの**（一般に挙げられる要素のうち）:

- **②ターゲット**——0件。ただし cycle-278 のオーナー指示で仕組みごと廃止されており、**食い違いには理由がある**。
- **③提供価値／ユーザーニーズ**——「入力すると結果が出る」はあるが、**誰のどんな課題が解けるのかを書いていない。** Kotler の言う「consumer terms」になっていない。**この欠落には理由が見当たらない。**

**多すぎるもの**:

- **「デザインへ渡すもの」1,561文字（20.6%・最大の節）。** Garrett の5層では Surface 層の判断（WCAG の等級指定）を、戦略段階の文書が持っている。
- 分量そのもの。**7,576文字**は、Pichler の A4 1枚・Amazon の1ページ未満と桁が違う。
