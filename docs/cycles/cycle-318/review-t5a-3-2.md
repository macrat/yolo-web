## 指摘

### 1.（直す）範囲の端の丸めの試験が、丸めを外しても通る（第1回の指摘2の試験が効いていない）

`chooseLanding` の丸め（`Math.ceil`・`Math.floor`）を外した写しで `reveal.test.ts` を走らせると、68件すべてが通った。足した試験「範囲の端は空きが欠けない向きに丸め、整数の送りから選ぶ」（`plan: { base: 100, span: { min: 50.5, max: 300 } }`・`scrollable.max: 120.5`）は、基準 100 が範囲の中にあるので、候補が整数の 100 から 1px ずつ並び、丸めが無くても 51 に着く。試験の名前が言っていることを確かめていない。

丸めが効くのは、基準が範囲の外にあって、候補が範囲の端（端数）から始まるときである。たとえば `planGroup` で、まとまりが画面に入っているが端から 8px の内に寄っているとき（基準 0、範囲の上の端が −4.5 など）にこれが起きる。`npx tsx` で確かめた値:

```
chooseLanding({ plan: { base: 100, span: { min: 50.5, max: 80.5 } }, point: { x: 100, y: 500 },
  avoidFirst: [{ top: 560, bottom: 640, left: 0, right: 200 }], avoidNext: [], scrollable: { min: -5000, max: 5000 } })
// 丸めあり 51、丸めなし 50.5
```

- 来訪者に見える差は 1px に満たないが、第1回の指摘2で決めた「基準は整数・候補は 1px 刻み」を固める試験が無いと、のちの手直しで丸めが落ちても気づけない。第1回の指摘3と同じ「試験があるように見えて固めていない」形である。
- 直し方: 試験の値を、基準が範囲の外にあるものに替える。下の端（切り上げ）は上の例（51 を期待）、上の端（切り捨て）は、たとえば `plan: { base: 200, span: { min: 100, max: 150.5 } }`・押せるもの無しで 150 を期待（どの送りも同じ点なので基準にいちばん近い端に着き、丸めが無ければ 150.5）。直したあと、`Math.ceil` と `Math.floor` をそれぞれ外すと、その試験が落ちることを確かめる。
