### 6. D4: 範囲の式と `100svh` の読み方が決まっておらず、それを固める試験も無い（小）

「下端を、`visualViewport` の高さと `100svh` の小さいほうで決める」は、次の2通りに読める。

- (ア) `offsetTop + min(visualViewport.height, 小さいビューポートの高さ)`
- (イ) `min(offsetTop + visualViewport.height, 小さいビューポートの高さ)`

つまんで拡大したとき（`offsetTop` が大きい）、(イ) は下端を画面の上のほうに切ってしまう。reveal.md 2章の「2つの高さを比べる」という書き方は (ア) を指すが、式として書かれていない。試験の5つは、どれも `offsetTop` が 0 のときにしか差が出ないので、(イ) で書いても通ってしまう。

`100svh` をどう読むか（たとえば `height: 100vh; height: 100svh` の見えない箱の高さ）も書かれていない。「読んだ高さが 0」の落とし先は、その読み方を前提にしている。

- 直し: 式を (ア) と明記し、読み方を1文で書く。試験に「`offsetTop` が 0 でなく、`offsetTop + height` が小さいビューポートの高さを超える（拡大したとき）」を足して、6つにする。7章の T5a-3 の行も合わせる。
