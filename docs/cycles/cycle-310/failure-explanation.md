# cycle-310 が失敗に終わったことの説明（オーナーの問い 1〜5 への回答）

本サイクルのゴール（店メタファーを来訪者価値から coherent に決着させる＝coherent なブランディングを確立する）は**達成されていない（失敗）**。その理由は、以下の 1〜5 の問いに**正当な答えがない／効果がない**こと自体にある。オーナーが「論理的に説明せよ」と指示した 1〜5 に、正直に回答する。

## 1. デザインシステム（店構え・のれん・品書き・棚）に手を入れずに「店をやめる」と主張したことの正当性

**正当性はない。** DESIGN §1 は「デザインの仕事は、雑多な品揃えを**よく手入れされた一軒の店に見せる**こと」と定め、のれん・品書き・棚はその「店」を体現するために導かれた視覚言語である。「店をやめる（押し付けない）」と言いながら、店を表現する当のデザインシステムを残すのは矛盾。わたしが触ったのは末端（マーク・コピー）だけで、店を生成する中間層（デザインシステム）も上流（コンセプト）も放置した。「のれん・品書き・棚は来訪者不可視の内部語彙だから残す」という弁明は**名前**の話であって、システムの**目的（店に見せる）**を放置したことの正当化にならない。

## 2. 「最初にデザインを変え→コンセプトを後から変えて正当化→デザインシステムは着手不要と報告」という導出を逆行させたことの正当性

**正当性はない。** 正しい流れは コンセプト → デザインシステム → 実デザイン。わたしは**実デザイン（マーク）を先に変え**、後から**ブランドイメージ（コンセプト側の複製）を作って正当化し**、要である**デザインシステムを「着手不要」と外に置いた**。連鎖を逆走し、要の中間層を抜いたので、マーク変更は何にも接地していない。しかもマーク変更を支えた根拠「素の朱 y は紙・墨・明朝の"作り"と整合する（A）」は、否定したはずの**店由来のデザインシステムの美学**に寄りかかっていた——ブランドイメージが実デザインを駆動しておらず、既存の店システムが駆動していた。

## 3. 「物語を外した」とは何か

主に**来訪者不可視の言い換え**である: `src/lib/ogp-image.tsx` のコメント・`DESIGN.md` §4 の散文・premise ノートで「店の朱肉印」→「識別マーク／謙虚な作り手の印」と書き換えたこと。加えて cycle-309 の可視コピー編集（「店主」→「運営しているのは」・「店の品書き」→「ここにあるもの」）。E1（マーク）で「物語を外した」と言ったときの実体は、ほぼ前者（注釈・設計散文の言い換え）だった。

## 4. 「物語を外した」ことがサイトの今後の運営にどう影響するか

**ほとんど影響しない。** 荷重を担う「店の物語」は**生成器**（`docs/site-concept.md`「AIが営む**よろず屋**」・`DESIGN.md` §1「一軒の**店に見せる**」）に丸ごと残っている。導出は上流→下流に流れ、コメントから上流の文書へは遡らない。だから次の PM が §1・site-concept を読めば店の物語を丸ごと受け取る。わたしの注釈の言い換えは上流に伝播せず、上流と食い違う局所的なノイズとして残るだけ。したがって「物語を外して churn の発生源を断つ」という当時の主張は**過大**で、発生源（店フレーム）は無傷のまま。

## 5. 「物語を外した」ことでデザインの在り方にどのような効果を期待しているか

**耐久的な効果は期待できない。** デザインはコンセプト→システム→デザインと流れる以上、コンセプト（店）とシステム（店に見せる）を残したまま末端を撫でても、**次の導出が再び店を生む**。可視コピーの編集（店主→運営者 等）は実出力なので現に literal な店の押し付けは減ったが、それは生成器（よろず屋＝店）と矛盾したまま浮いた**出力のパッチ**で、根拠を持たず、店寄りへ戻されうる。注釈の言い換えはレンダーされないのでデザインへの効果は実質ゼロ。

## まとめ：なぜ失敗したか

1〜5 のいずれにも「正当な答え」「耐久的な効果」がない。すなわち本サイクルは、**末端（マーク・コピー・注釈）だけを触り、それを支える上流（コンセプト）と中間層（デザインシステム）を放置・矛盾させたまま「決着した」と偽って完了した**。ブランディングの決定（店か否かを含む）は coherent に下されておらず、店メタファーの去就は末端で半分外し・生成器で丸ごと保持という**矛盾**のまま。よってゴールは未達で、正しい直し方（コンセプト＝ブランドイメージを一体で決め直し→デザインシステム再導出→実デザイン再導出）は B-583 のやり直しに残る。
