# レビュー（2回目）: ナカマワケの盤のスマートフォンでの組み方（コミット 8231b9b・05e32ba）

## 判定

**要修正（改善指示）**。来訪者に見える画面は、見渡せる・押せる・読める・フォーカスが見える・崩れない、のどれも満たしている。直さなければならないのは `DESIGN.md` の食い違い1つ（指摘1）と、サイクルの記録の誤った記述1つ（指摘2）。

## 直すもの

### 1. `DESIGN.md` が、2px のリングについて、自分の中で食い違っている

§6 の二重リングの項に「左右の内側の余白が 4px のマス……だけは、挟む `--paper` を 1px、外の輪を 2px にし」と足したが、同じ文書のほかの2か所が、これと反対のことを例外なしに言っている。

- §5「線」: 「**サイトに引く線は2種類だけで、あいだの太さを持たない。**」（太い 3px・細い 1px）。表の「太い」の行の使う場所に「フォーカスの外リング」がある。2px の輪は、この決まりが持たないと言っている「あいだの太さ」そのもので、しかも表では外リングは太い線になっている。
- §6 の状態の表の「フォーカス」の行: 「内も外も太い線と同じ太さで、内は `--paper`、外は `--ink`」。

§5 の「線」は §1 の見分けの形（罫線で組む画面）を支えるサイト全体の決まりで、次にリングや線を作る担当はここを読む。食い違ったままだと、「2種類だけ」を信じて 4px のマスのリングを 3px に戻す（字に重なる不具合が戻る）か、「2px もある」と読んでほかの所にも中間の太さを持ち込むか、のどちらかが起こりうる（AP-I08）。

直し方は担当とPMに任せるが、次のどちらかで、文書全体を1つの状態にすること。

- (a) 2px の輪を採るなら、§5「線」の冒頭の決まりと表、§6 の状態の表の「フォーカス」の行を、この輪を含む形に書き直す（例外を §6 の1文にだけ置かない）。「2種類だけ」という決まりを変えることの是非も判断して、サイクルの記録に残す。
- (b) 「2種類だけ」を守るなら、4px のマスのリングを 3px と 1px の線だけで、字に触れずに出す形を探して、実装と §6 を合わせる。

どちらでも、4字が幅いっぱいの 358px・5字が1行の 412px・文字サイズ 200% の 375px で、Tab で撮って字との距離を測り直すこと。

### 2. サイクルの記録の「2.4.13 を満たす」は誤り

`docs/cycles/cycle-321/fix-nakamawake-grid.md` の「採った案」に「WCAG 2.2 の 2.4.13 の目安（2px 以上の線と 3:1 の対比）を満たす」とある。2.4.13 の求める面積は「フォーカスの無いときの部品の外周の 2px の帯の面積以上」で、W3C の解説（Understanding SC 2.4.13）は、部品の縁から内側に離して出す輪は 2px では足りず、3px 以上要るとしている。実測の寸法で数えると、375px 幅のマス（77×68）は外周の 2px の帯が 564px²、4〜6px に出る 2px の輪は 500px² で、足りない。360px 幅（74×68）でも 552px² に対して 488px²。

このサイトは §12 で 2.4.13（AAA）を約束していないので、来訪者が損をするとまでは言えない（下の「確かめたこと」のとおり、リングは等倍でもはっきり見える）。ただ、誤った根拠が記録に残ると、指摘1の判断（2px を採るか）を誤らせるので、記録を事実に合わせること。2px を採るなら、根拠は「AAA の面積には届かないが、等倍の画面で見分けられる」のように、実際に確かめたことで書く。

### `DESIGN.md` §5 の語を選ぶ盤の決まり

実装（`45rem` 未満で間隔と、四角を上に置くマスの左右の余白が 4px、ほかは 8px）と合っている。「中身は縁の内側 8px から始まる」に従わないこと、語を中央に置き幅いっぱいの行だけが 4px に届くことが書かれ、どのマスで何が起こるかが読める。経緯の言い回しは無い。§6 の二重リングの項も、指摘1の食い違いを除けば、どのマスでリングがどこに出るか（太い線の太さの地と輪、4px のマスは 1px の地と 2px の輪、hover も 1px の地）が実装と合っている。
