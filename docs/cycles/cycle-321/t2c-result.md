- **操作は新しい版だけで行った。** 本番では同じ操作をしていない（画面の作りが違い、同じスクリプトが使えないため）。操作について「本番より悪くない」と言える根拠は、「新しい版で操作ができた」ことだけである。本番で行ったのは、表示の記録と撮影、字と地の比の検査、記事の目次、先読みの数え、状態コード、`og:image` である。
- **ゲームは最後まで遊んでいない。** イロドリは5問のうち2問目に進む所まで、漢字カナールと四字キメルは1回の推測（漢字カナールは不正な入力も1回）、ナカマワケは外れの1手だけである。正解したとき・負けたとき・遊び終えたあとの画面（結果、共有のボタン、翌日の案内）は見ていない。
- **外へ出る操作は押していない。** X・LINE・はてなブックマークへの共有のボタンは、ある・見えることだけを確かめた。
- **Google アナリティクスは確かめていない。** 新しい版のビルドには計測の ID が入っておらず、計測のスクリプトが読み込まれない。
- **実物のタッチの端末では見ていない。** 375×550 は Chromium の端末の模倣（タッチあり）である。Safari と Firefox では見ていない。
- **見た URL は、種類ごとに1つずつである。** ツールは 36 本のうち文字数カウントだけ、診断の結果は1つだけ、辞典の詳細は種類ごとに1つだけである。ほかは見ていない。
- **確かめのあいだ、この環境はほかの作業で重かった**（負荷の平均が 10 前後）。待ち時間を長めに取って確かめたが、表示の速さについては何も言えない。
- `capture-result-*.json` の `theme` の欄は、スクリプトの作りのためにライトとダークの別ではなくページの配色の情報が入っている。ライトとダークの別は `shot` の欄のファイル名で分かる。
