## 直さないといけない点

### 1. 複合動詞の中で折れる（語の途中で折れる）。375 幅で 4 か所、320 幅で 4 か所

文節の分け方（BudouX）は、複合動詞を2つの文節に分ける（「思い｜描いてから」「成し｜遂げている」）。`refineAtWords` は語の中の区切りを外すが、語の辞書（`Intl.Segmenter`）が複合動詞を1語として返さないので、この区切りは外れずに `<wbr>` になる。そこが行の終わりに来ると、語の途中で折れる。

実際の画面で出た折れ（「/」が行の切れ目）:

- 375 幅
  - character-personality 第7問: 「まず頭の中で完成形を細部まで思い / 描いてから、実際に手をつける」
  - japanese-culture 第11問: 「仲間と一緒に体を動かしたり競い / 合ったりする時間」
  - yoji-personality 第8問: 「仲間と共に大きなことを成し / 遂げている」「誰も歩いたことのない道を切り / 拓いている」
- 320 幅
  - japanese-culture 第15問: 「体全体で対象に向き / 合っている感覚」
  - science-thinking 第19問: 「日常の中の小さな発見を切り / 取った写真」
  - word-sense-personality 第9問: 「「好きです。付き / 合ってください」と、 / それだけ言う」
  - yoji-personality 第8問: 「仲間と共に大きなことを成し / 遂げている」

DESIGN.md §4 は「文節の分け方が語の中に置く境（「見た／目」「切り／替え」）も折り所にしない」と決めていて、これに反する。本番は 375 幅で「成し遂げている」「切り拓いている」を1行に収めていて、ここは本番より悪い。いちばん閲覧の多い character-personality の、いちばん多い 375 幅でも1か所出る。

送っている区切りの並びでは、ほかに次の複合語にも区切りがあり、幅や文字サイズによっては同じように折れうる（15 本で 21 個）: 「振り｜返って」「立ち｜止まって」「動き｜出したくなる」「笑い｜合える」「感じ｜取りながら」「聞き｜返して」「狙い｜撃つ」「粘り｜強く」など。

直すときは、選択肢だけでなく、同じ `splitIntoPhrases` を使う見出しにも同じ規則が当たるので、文節の分け方の側で、複合動詞（動詞の連用形に動詞が続く所）を語の中として扱う形で直すのがよい。直したら、上の例をテストで確かめ、見出しの既存のテストと、選択肢の 375・320 幅の実測をやり直すこと。

### 2. impossible-advice 第5問の「クマ」が、320 幅で3行に割れ、1字だけの行ができる

- 直したあと（320 幅）: 「クマ / （食べることと寝ることが好 / き）」
- 本番（320 幅）: 「クマ（食べることと寝ることが好 / き）」

丸括弧の中では折らない規則なので「クマ」の後ろでまず折れ、括弧の一続き（15 字）が 320 幅の1行（全角 13 字ほど）に入らず、その中で字の所で割れる。本番にもある1字だけの行が残ったうえに、名前の「クマ」だけの行が増えて、本番より読みにくい。

DESIGN.md §4 は、組み方で避けられない1字だけの行・丸括弧の一続きの中の折れについて、「来訪者に渡していない文を直す」と決めている（選択肢の文は結果の名前ではないので、言い回しを変えてよい）。320 幅の1行に括弧の一続きが収まる言い回しに変えること。15 本のほかの選択肢には、375・320 幅で同じものは無かった。
