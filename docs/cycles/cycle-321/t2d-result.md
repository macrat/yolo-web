## 確かめられなかったこと

- **無くなる 19 本と `…/twitter-image` が、実際に検索から見られているか。** Search Console のデータ（BigQuery）を引こうとしたが、認証の誤り（Invalid Credentials）で引けなかった。
- **sitemap にも、ビルドが事前に作るページにも、本番の HTML のリンクにも無い URL。** 例: 診断の結果のページに問い合わせ文字列を付けた共有用の URL、`/api/` 以下。存在しない値を入れた 9 本が両方とも 404 を返すことだけ確かめた。
- **操作したあとの JavaScript のエラーとはみ出し。** 3 は、ページを開いて読み込みが落ち着いた時点（と、下まで送った時点）だけを見ている。ボタンを押す・入力する・メニューを開く、といった操作のあとは見ていない。
- **入れ物の中で切り落とされているもの。** はみ出しは `body` の幅で測ったので、`overflow: hidden` などの箱の中で切られている中身は拾えない。
- **本番の配信の仕組みに由来する差。** 新しい版は手元の `next start` で動かしたもので、本番の配信（Vercel）に載せたときの応答ヘッダーやキャッシュは見ていない。転送先の日本語の表し方と末尾のスラッシュの差は、origin/main を手元で起動したものと新しい版が同じだったので、出荷しても本番のいまの振る舞いのままになると見ているが、出荷して確かめたものではない。
- **Chromium 以外のブラウザー。**
