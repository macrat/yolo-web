## D の見立て（なぜ新しい版でだけ起きるか）

本番と同じ版は、「はじめる」を押してもスクロールしない。開始の画面の「はじめる」と同じ高さに、問の見出しか1つ目の選択肢が入れ替わりで出る。見出しが2行以上の診断では2打目が見出しに落ち（害なし）、見出しが1行の診断では1つ目の選択肢に落ちる（B と C の組）。

新しい版は、「はじめる」を押すと、進み具合の帯から最後の選択肢までのまとまりを画面に入れるように送る（`QuizContainer.tsx` の切り替わりのあとの送りと、`src/lib/reveal.ts` の `revealLanding`・`chooseLanding`）。このとき、1打目の点の真下に選択肢が来ない送りを、まとまりが画面に丸ごと入る範囲の中から探す。D は、この探し方が効かない3つの場合に起きている。記録した区画と選択肢の位置を、ソースの計算に当てて確かめた。

1. **まとまりは画面に入るが、選択肢が高くて点をよけきれない**（375×550 の character-personality・character-fortune・word-sense-personality、文字200% 下端寄せの yoji-level）。character-personality では、送ったあとの区画が画面の 78〜541px、選択肢が 187〜541px にあり、点は y=350 である。まとまりを丸ごと見せたまま動かせる幅は 70px（区画の上端を 8px まで上げる）しかなく、高さ 355px の選択肢はどこへ動かしても y=350 を覆う。よける送りが無いので、基準の送り（まとまりの下端を画面の下端の 8px 上に置く）のままになり、2打目が選択肢に落ちる。選択肢の字が長く、行が3行に折れる診断ほどこうなる。
2. **まとまりが画面より高く、送りを選べない**（文字200% の大半）。区画が 8〜958px（animal-personality）や 8〜1386px（character-personality）と画面の 550px を越える。`planGroup` は、画面より高いまとまりでは範囲を基準の送り1つだけにするので、区画の上端を画面の上端の 8px 下に置く送りに決まり、点の下に選択肢が来ても動かせない。文字200% 中央寄せで A になった組（character-fortune・japanese-culture・word-sense-personality・yoji-level）は、点（y=275）がたまたま問の見出しの上に来ただけである。
3. **点の真下からは外したが、すき間が 1px に満たず、ブラウザが近くのボタンに当て直した**（375×550 の kotowaza-level・yoji-level。C の contrarian-fortune・unexpected-compatibility・kanji-level の新しい版も同じ）。kotowaza-level では選択肢の下端が 349.6px、点が y=350 で、`elementFromPoint` は押せない所を返す。けれど touchstart を受けたのは最後の選択肢のボタンで、click の座標は (70, 344) に動いていた。Chromium がタッチのタップを近くの押せるものへ寄せる働き（タッチの当たりの補正）である。`chooseLanding` は点が矩形の真上にあるかだけを見るので、0.4px 外れていれば「よけた」と数える。`page.touchscreen.tap` の指の広さは半径 1px で、それでも 6px 寄せられた。

補足の確かめ（指の広さを付けたタップ。CDP の `Input.dispatchTouchEvent` に radiusX・radiusY を付け、375×550 の「はじめる」を各1回）:

- 半径 12px: 分け方は上の表と同じだった（A4・B2・C4・D5）。
- 半径 24px: 新しい版は 15 本ぜんぶで1問目に答えが入った（A0・B0・C6・D9）。約 12px 下によけていた animal-personality・impossible-advice・japanese-culture・science-thinking（A → D）と traditional-color・yoji-personality（B → C）も、近くの選択肢に当て直された。本番と同じ版の「はじめる」の結果は変わらなかった。
- 同じ補足で「次へ」を打つと、本番と同じ版は 300ms で、2打目が結果のおすすめのリンク（「漢字辞典で…」など）に当て直されて別のページへ移った（半径 12px で kanji-level と kotowaza-level、半径 24px で3本とも）。新しい版では起きなかった。

## 確かめられなかったこと
