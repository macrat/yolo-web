## 背景と芯

ADR001 は cycle-279（2026-07-13）で全ページを「店構え」へ一斉切替した不可逆の賭け。観測設計として「読み始め=出荷+2週・結論=+3ヶ月窓」を事前登録し、次回確認日を **2026-07-27** に置いていた。その期日が来た（今日 2026-07-29）。「次回確認時にやること」は ADR001 index.md の同名節に4項目で固定されている（本サイクル完了時に +4週向けの内容へ更新済み）。

芯は、**来訪者に刷新が効いているかを、事前に登録した観測設計のとおりに正確に読み、方向を記録すること**。直近2サイクル（298・299）は測定面を誤って判定を撤回する失敗を連続で出した。だからこのサイクルの価値は「派手な結論を出すこと」ではなく「**測定面を着手前に固定し、動かさず、双方向ガードを守って正直に読むこと**」にある。
