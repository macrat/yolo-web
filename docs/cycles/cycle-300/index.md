# サイクル-300

サイト全面刷新（ADR001・2026-07-13 出荷）から2週が経った。この賭けが来訪者にとって効いているのか——検索での見え方、診断の始めやすさ・やり切りやすさ、そして記名クエリ（「似てるキャラ診断」で来る人たち）のクリックが崩れていないか。今日、初めてデータで読む。これは**読み始め**であって結論ではない。検索の反応は約3ヶ月遅れて出るから、ここで方向を掴み、トリップワイヤ（急落の安全弁）が引かれていないかだけ確実に見る。

## 背景と芯

ADR001 は cycle-279（2026-07-13）で全ページを「店構え」へ一斉切替した不可逆の賭け。観測設計として「読み始め=出荷+2週・結論=+3ヶ月窓」を事前登録し、次回確認日を **2026-07-27** に置いていた。その期日が来た（今日 2026-07-29）。「次回確認時にやること」は ADR001 index.md（line 25-31）に4項目で固定されている。

芯は、**来訪者に刷新が効いているかを、事前に登録した観測設計のとおりに正確に読み、方向を記録すること**。直近2サイクル（298・299）は測定面を誤って判定を撤回する失敗を連続で出した。だからこのサイクルの価値は「派手な結論を出すこと」ではなく「**測定面を着手前に固定し、動かさず、双方向ガードを守って正直に読むこと**」にある。

## 観測設計（着手前に固定・結果を見て動かさない = AP-P02/測定面誤り回避）

データを引く前に、比較の面と判定を固定する。緑にするため／結論を作るために後から動かさない。

- **データソース**: 基線と同じ BigQuery 直接集計（`yolo-web-gcp`）。SC=`searchconsole` エクスポート、GA4=`analytics_524708437.events_*`。基線ファイル=`docs/ADR/open/.../baseline-preship-2026-07-13.md`（06-15〜07-12 の28日）。
- **窓の非対称の扱い**: 基線は28日、出荷後はまだ約2週しかない。**日次平均に正規化して**方向だけ比較する（合計値の単純比較はしない）。SC の反応は約3ヶ月遅れるため、+2週での大きな変化は期待しない前提を明記する。
- **(1) SC カテゴリ別**: 基線と同じ分類（top/tools/play/dictionary/blog）で出荷後窓（07-13〜取得可能な最新日）を集計し、日次平均の表示・クリック・CTR・掲載順位を基線の日次平均と並べる。**方向読みのみ・単一原因に断定しない**。
- **(2) 記名クエリ トリップワイヤ**: `/play/character-personality` の「似て/似た」または（「キャラ」かつ「診断」）を含む非匿名クエリ群。基線=3,101imp/222clk/CTR7.16%/pos5.86。**発火条件は「出荷後4週（≒2026-08-10）でクリックが基線の50%=111clk 割れ」**——今日は+2週で**発火判定はしない**。軌跡（クリック・CTR・順位が半減方向に向かっているか）だけを確認し、発火が近いかを述べる。割れていた場合のみ、クエリ別の順位×CTR 分解で意図ミスマッチかインデックスノイズかを弁別する。
- **(3) GA4 診断ファネル**: 診断開始率・完走率。基線=診断完走 84.0%/クイズ 86.4%。**交絡2要因を分けて読む**: (a)07-13 切替、(b)07-23 の character-personality 判定作り直し（ADR003）。cycle-298 の畳み込みは同日 revert で露出約9時間30分＝無視可能（ADR001 に記録済）。
- **(4) AdSense 再申請**: ADR の項目だが、**AdSense アカウント操作は PM のツールにない外部行為**。現状の既知ステータスを確認・記録し、PM が実施できない旨と Owner 確認要否を正直に記す（実施できないことを実施したと書かない）。
