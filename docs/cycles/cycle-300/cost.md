# cycle-300 の時間・消費の実測と、事後レビューを打ち切る判断

CLAUDE.md「Check anti-patterns on failure」と **AP-WF38 候補**（内部記録の完全性を追求して来訪者価値ゼロの作業を生み続けない）に従い、一次資料 [cycle-298/cost.md](../cycle-298/cost.md) と本サイクルを突き合わせた記録。※Owner が過去の二次災害（終了後の記録に時間をかけすぎ来訪者価値ゼロのまま費用を浪費した件）を指し示したのが照合のきっかけだが、**照合と打ち切りの義務の源はルールであって Owner ではない**（AP-WF24）。

## どこまでが価値を生み、どこから生んでいないか

**価値を生んだ（将来のサイクルの誤動作を防いだ／来訪者に届く欠陥を見つけた）**——A〜I巡:

- **A巡**: 「全数調査」の虚偽と、AP 集を一度も触っていない cycle-291 を違反として書いた捏造を撤回（将来サイクルが誤った棚卸しを引き継ぐのを防いだ）。
- **B巡**: ADR001 の +4週タスクから実機点検という具体行動を消していたのを復帰（「要監視」の実体がゼロになるのを防いだ）。
- **C巡**: `level_end` の計器の意味が実コードと違うと判明（完走率＝最終問到達率）。**「来訪者が結果に到達できていない」という誤った害の説明を撤回**し、実機点検を12日先送りしていたのをその場で実施。
- **D巡**: 「モバイル比率＝母集団シフトの傍証」の撤回漏れ・着地クエリ別が GA4 で実行不可能と確定（08-10 に実行不能タスクを残さない）。
- **E/F巡**: **SC 平均順位に `+1` が必要**（`sum_position` は0起点）という**全サイクル共通の測定誤り**を一次資料で確定し、repo 全体（定型レポート含む4ファイル・6行）を是正、`docs/knowledge/` へ恒久化。
- **H巡**: **実機の可視高の取り方の誤り**を突かれ、375×635 で測り直すと**4択のうち1つが fold 下・1つが途中で切れる状態が全設問で続く**と判明。**サイト最大流入面の生きた UX 欠陥**で、本セッション最大の来訪者価値。
- **I巡**: その発見を書いた backlog 行・ADR に撤回済みの「見切れは候補にならない」が残っており、**builder が読む起点で実在する摩擦を除外させる**状態だったのを是正。

**価値を生んでいない**——J・K巡:

- J巡: 完了サマリの排他的断定（「本体に残るのは cycle-299 分だけ」）と AP-I01 の追記漏れ。
- K巡: 上記の完了サマリ1行の取り残しと、**review-log に J巡の行が無いこと**（＝自己参照の機械）。

つまり **直近2巡（J・K）では、指摘の class が「来訪者に届く成果物・次サイクルの行動を決める記述の欠陥」から内部文書の表現精度と巡の帳簿へ移っていた**（「欠陥が出尽くした」の意味ではない＝下記「判断」の根拠1を参照）。cycle-298 が「9巡目以降は Blocker ゼロのまま内部文書の表現精度」と書いたのと同じ地点に来ている。

## 判断：事後レビューの継続をここで打ち切る

**AP-WF39 候補**（AP-WF38 や「綺麗に閉じたい」を口実にレビューを打ち切るな。継続可否は**巡回数でなく、まだ成果物の欠陥が出ているか**で決める）に照らして判断する。巡回数を理由にはしない。判断の根拠は次の3点:

1. **直近2巡（J・K）で、指摘の class が成果物の欠陥から内部文書の表現精度・レビュー経過ログの帳簿へ移った**（cycle-298/cost.md が「来訪者に何も届かない」と特定した class に一致）。**ただしこれは「欠陥が出尽くした」ことの証明ではない**——本サイクル自身に反証がある: **G巡は Blocker 0 で終わり、その直後の H巡が本セッション最大の来訪者価値（4択の fold 下）を出した**。静かな巡は欠陥の不在を意味しない。そこで**観点（レンズ）を変えた成果物レンズの点検を別途置いた**——`/cycle-completion` 手順5のワークフロー AP 点検で、実機レイアウト・算式・ゲートログの真正性・キャリーオーバー実在を独立再現させ、**この時点で追加の成果物欠陥は検出されなかった**（＝不在の証明ではない。実際その後の手順5再点検で AP-WF24 違反が1件見つかり、是正した）。この巡の結果は打ち切りの典拠の一つに留める。
2. **ただし K巡の M1 は例外として直す**——「本体に残るのは cycle-299 分だけ＝実測で確認」は**虚偽の検証済みラベル**で、次サイクルが B-540 のスコープを過小に見積もる。これは「実体との一致・虚偽記録の撤回」という記録の目的の内側なので、打ち切りの対象にしない（修正した）。
3. （**補助的な考慮であって主たる根拠ではない**——「閉じないと着手できない」はいつでも成立し打ち切りの正否を区別しないため、判断の重みからは外す）実機で確認した欠陥の修正 B-614 が待機しており、遅延は来訪者の不利益になる。

**自己参照の機械を断つ**: review-log への巡追記が次の指摘を生む連鎖を止めるため、**本サイクルの review-log は K巡の記載をもって閉じる**（以後、内部文書の表現精度のみを理由とした巡追記はしない）。この打ち切りは「レビューを省略する」ことではなく、**目的（実体の誤りと虚偽記録の是正・規約準拠）が達成された領域での作業停止**である。

**受け入れるリスク（正直に）**: **未検出の欠陥が残っている可能性がある**——静かな巡が欠陥の不在を意味しないことは本サイクル自身が2度実証した（G巡→H巡、手順5点検→再点検の AP-WF24）。加えて内部文書には表現の不整合が残っている可能性がある（巡数の数え方・粒度の揺れ・言い回し）。それらが将来のサイクルを誤動作させる経路は、上記1で確認した限り見つかっていない。もし残っていれば、次に開いた PM が見つけて直せばよい。**完全無欠な内部文書は目的ではない。**
