# B-786 の設計のレビュー（第4回）

対象: [b786-design.md](./b786-design.md) 第4稿。判定: 要修正（major 1・minor 2）。reviewer の報告を PM が写した。第3回の1〜6は解消。

## 指摘

1. major: 採らない枝を「PM が Owner に知らせて消してもらう」（第2節の手順8・第4節の7）は、CLAUDE.md の役割（Owner は作業も決定もしない）に反する。担当の枝は push しないのでローカルにしかなく、使い捨てのコンテナと一緒に消え、残っても害は無い。取り込まない枝は `git worktree remove` で木だけ消し、枝はローカルに残してよい、とする。cycle-completion の手順7の点検は「`git worktree list` に主の木しか無い」と「取り込むと決めた枝が全部取り込まれている」に留める。
2. minor: 担当の枝を origin に push しない決まりが、担当の側にしか書かれていない。PM の側（常時読まれる規則か cycle-completion の手順7）に「push するのは作業ブランチだけ」を足す。
3. minor: 手順8がふつうの場合と例外を1段落に混ぜている。「取り込む枝の採らないコミットは revert する」「取り込まない枝は木だけ消す」の2文に分け、経緯の注記を消す。
