## 全体の見直し

- §10 の画像の節は、名前・枠・中身・書体と段・折り方・代替テキスト・持ち帰る画像の順に、それぞれ1つの原則から各ページの形が出る書き方で、例外の形・経緯の名残は無い。
- 副題の切り方と「どの問も、画像の中に全部入る」（ゲームの結果）は食い違わない。ゲームの画像は副題を持たず、問ごとの結果は譲る対象でない。
