### 読み上げの確かめ方（t3-design.md 2-4）

2-4 の測り方（Chromium の読み上げの木と、`MutationObserver` で数えた書き換えの回数）で、375 と 1280 の両方で次のとおり再現した。

- 着いたとき: `/storybook/list/101`・`?q=一`・`/page/2` のどれでも、見えている行は `paragraph` で、`status` は空。クエリのある URL に着いたときの組み替えでも読ませない。
- 名前の欄に「いっ」を 60ms おきに打つ: 見えている行は2回替わり、`status` は打ち終えて約 0.5 秒後に「9語（全101語）」へ1回だけ替わる。450ms おきに打つと、1字ごとに落ち着くので2回替わる（98語 → 9語）。これは意図どおり。
- IME: CDP で変換中の「い」「いっ」を入れているあいだ、見えている行も `status` も替わらず、「一」を確定すると1回ずつ替わる。
- `?sort=easy` で「次へ」を Enter: 見えている行が1回替わってフォーカスを受け、`status` は0回。続けて押しても、戻るで戻っても 0回。link モードで送っても `status` は空のまま、フォーカスは件数の行、行の上端は画面の 16px。

この測り方の妥当さ: 二重の読み上げの原因（ページ送りでライブリージョンが書き換わること・打鍵ごとの書き換えが予約に積まれること）は DOM の書き換えとして起きるので、書き換えが起きないことを数えるのは、原因が無くなったことの確かめとして妥当である。一方で、実際の読み上げソフトが「空から文が入った `role="status"`」を読むか、`tabindex="-1"` の段落にフォーカスが来たときその文を読むかは、この測り方では確かめられない。どちらも読み上げソフトの通常の振る舞いで、ライブリージョンが最初から DOM にある（あとから差し込んでいない）ので、読まれない心配は小さい。この残る不確かさは、T3-11 のキーボードの確かめに NVDA か VoiceOver で聞く機会があれば、そこで聞くとよい。

## 指摘

### Minor-1 条件を変えたあとは、読み進めると件数を2度聞く

- どこ: `src/components/ListStatus/index.tsx` 52〜57行。見えている件数の行の直後に、見えない `role="status"` の段落がある。
- 何が起きるか: 一度でも条件を変えると、`status` の文はそのまま残る。読み上げの木は `paragraph: 9語（全101語）` → `status: 9語（全101語）` と、同じ文が2つ続く。ページを送ったあとは「9語（全101語）のうち51〜…」と「9語（全101語）」が続く。
- t3-design.md 2-4 は「来訪者が条件を変えるまでは空にしておきます。見えている行と同じ文を、ページを読み進める読み上げに2度読ませないため」と、同じ害を理由に挙げている。いまの形では、その理由が条件を変える前にしか効かない。
- 来訪者にどう効くか: 読み上げの来訪者が、絞り込んだあと一覧の頭から読み直すたびに、件数を2度続けて聞く。害は小さいが、設計が避けると言ったことが半分しか避けられていない。
- 直し方の方向: どちらかに決めて、2-4 の理由と揃える。(a) 読ませたあと（例えば数秒後か、欄からフォーカスが外れたとき）に `status` を空に戻す。(b) 残すことを受け入れ、2-4 の「2度読ませないため」を「着いたときの組み替えで読ませないため」だけにする。

### Minor-2 索引の区切りの見出しの大きさと罫線が DESIGN.md に無く、単字より小さい

- どこ: `src/components/LinkIndex/LinkIndex.module.css` 42〜51行（`.group + .group` の線、`.groupHeading` の `font-size: var(--text-step-1)`）。
- 何が起きるか: CSS のコメントは区切りを「セクションの中の小見出し」（§5）と呼ぶが、大きさは §4 の小見出しの表（45rem 以上で `1.49rem`、64rem 以上で `2.08rem`）に従わず、どの幅でも `1.0625rem`（17px）に固定している。そのうえで単字の索引の字が `1.49rem`（23.84px）になったので、漢字「水」の詳細では、区切りの見出し「5画」（17px）がその下に並ぶ字（24px）より小さい。どの幅でも同じ（375・1280 で実測）。また、最初の区切りに線を引かないことは t3-design.md 2-9 にしか無く、§5 の「セクションの中の小見出しは、上に細い罫線を引く」と字面で食い違う。
- 来訪者にどう効くか: 見出しの字が項目の字より小さく、「5画」「6画」の区切りが字の並びに埋もれる。117字を画数で追うとき、区切りを目で拾いにくい。
- 直し方の方向: 索引の区切りの見出しを §7「索引」に定める（大きさ——単字の索引では字より小さくしない、など——と、最初の区切りの線を見出しかラベルが兼ねること）。そのうえで `LinkIndex` をそれに合わせる。§4 の小見出しの段に従うなら、それを使う。

### Minor-3 §5 の書き足しが読みにくく、§6 のフォーカスの行と噛み合っていない

- どこ: DESIGN.md §5「コンポーネントを置けるのはコンテンツ幅の中だけ」の箇条と、§6 の表の「フォーカス」の行。
- 何が起きるか: 書き足した「ページ送りのあとにフォーカスを受ける件数の行（§7）がそれと同じに持つ字の左右 8px の箱と」は、「それ」が何を指すか（縁の見えないコントロールの押せる範囲）を読み手が戻って探さないと分からない。1文の中に例外を5つ並べる形がさらに長くなり、あとから差し込んだ跡が見える（ツギハギ）。また §6 の「フォーカス」は「押せる範囲に密着した二重リング」と言うが、件数の行は押せないので押せる範囲を持たない。実装はリングを箱の内側に出しているが、その規定は §6 に無い。前回の Minor-6 の「§6 の『フォーカス』の行が『押せる範囲』を持たない要素のリングをどう扱うかと食い違わないようにする」が残っている。
- 来訪者にどう効くか: 直接には効かない。次に件数の行のようなフォーカスを受ける押せない要素（見出しへの移動など）を作る人が、どこにリングを出すかを DESIGN.md から決められない。
- 直し方の方向: 字の左右 8px の箱に名前を付けて §5 で1回定義し（縁の見えないコントロールと件数の行が持つ）、コンテンツ幅の外へ出るものの箇条はその名前で言う。§6 の「フォーカス」は「押せる範囲（押せないものは字の箱）」のように、押せない要素の場合も言う。

### Minor-4 §7 の単字の索引の書き足しの言い方

- どこ: DESIGN.md §7「索引」の「漢字1字だけを並べる索引は、字を見出しの2段目（`1.49rem`）で組む。…押せる範囲は 44px のままなので、並びの幅は変わらない。」
- 何が起きるか: (a)「見出しの2段目」は、見出しの書体（Zen Antique）で組むとも読める。実装は本文の書体（リンクの書体）で組んでいる。§4 は「本文から 1.4 倍ずつの5段」と言うので、「§4 の段の2段目の大きさで、本文の書体で組む」のように、大きさだけを借りることをはっきり言うほうがよい。(b)「並びの幅は変わらない」は既定の文字サイズでだけ正しい。既定を 32px にすると、単字の押せる範囲は 64px になる（本文の大きさなら 50px）。規定の文に、成り立つ条件の限られた理由が入っている。
- 来訪者にどう効くか: 直接には効かない。書体を読み違えて実装すると、Zen Antique に無い字を含む索引で字形が混ざる（§3）。
- 直し方の方向: (a) を言い直し、(b) の理由を「押せる範囲は 44px の下限のままなので、既定の大きさでは並びの幅が変わらない」とするか、理由から外す。

### Minor-5 五十音順が、差の位置で比べていて、段の順（濁点 → 小書き・長音）で比べていない

- どこ: `src/lib/list-browse.ts` 147〜182行（`kanaCollationKey` の2段目は、寄せる前の形を符号位置で比べる）。
- 何が起きるか: 1段目が同じ語どうしを、最初に違う字の位置で比べる。日本語の照合（JIS X 4061・`Intl.Collator("ja")`）は、語全体で濁点の差を先に比べ、小書きや長音の差はそのあとに比べる。そのため「はあと・はあど・はーと」（`Intl.Collator` は「はーと・はあと・はあど」）、「きっが・きつか」（同「きつか・きっが」）が逆になる。いまのデータ（漢字の最初の読み 2,136・訓読み 2,411・四字熟語 400・ユーモア辞典 30）では1件も食い違わない。
- 来訪者にどう効くか: いまは効かない。長音符を持つ読み（ユーモア辞典の「こーひー」「ぱすわーど」など）が増え、1段目が同じ組ができると、辞書と違う順が出る。ファイルの頭のコメントと t3-design.md 2-6 は「日本語の照合と同じ順」を約束している。
- 直し方の方向: 比べる形を3段にする（1段目はいまの形、2段目は濁点・半濁点を残して小書きと長音だけを寄せた形、3段目は寄せる前の形）。境目の語をテストに足す。
