## 計算の正しさ

### 法律の数え方と照らした値

年齢計算ニ関スル法律は、年齢を出生の日から数え、民法 143 条を準用する。143 条2項は、期間を応当日の前日の終わりに満了させ、最後の月に応当日が無ければその月の末日の終わりに満了させる。道具は「満了の翌日から1つ上」と出すので、応当日のある月はその日、無い月は翌月の1日が区切りになる。

この規則を、道具のコードを見ずに書き起こした（`E_n` = n か月の期間が満ちる日。応当日があればその前日、無ければその月の末日。道具の区切りは `E_n + 1`）。道具の `calculateAge` と、年・月・日・通算日数・通算月数の5つを比べた。

- 1999〜2002年の毎日を生年月日にし、基準日を 0〜800 日後の毎日と、その先 1600 日後までの7日おきにとった組。
- 1900-02-28・1904-02-29・1960-01-31・1972-03-31 生まれを、126 年先まで 37 日おきにとった組。
- 合わせて 1,341,791 組で、食い違いは 0。日数の最大は 30。`TZ=Asia/Tokyo` と `TZ=America/New_York` のどちらでも同じ。

代表の値:

```

2000-02-29 → 2004-02-28  3歳11ヶ月30日   2000-02-29 → 2004-02-29  4歳0ヶ月0日
2001-01-31 → 2001-02-28  0歳0ヶ月28日    2001-01-31 → 2001-03-01  0歳1ヶ月0日
2000-01-31 → 2000-02-29  0歳0ヶ月29日    2000-01-31 → 2000-03-01  0歳1ヶ月0日
2001-01-29 → 2001-02-28  0歳0ヶ月30日    2001-01-29 → 2001-03-01  0歳1ヶ月0日
2001-01-31 → 2001-03-30  0歳1ヶ月29日    2001-01-31 → 2001-03-31  0歳2ヶ月0日
```

- 2月29日生まれは、閏年は2月29日、平年は3月1日から1つ上になる。法律上の満了は毎年「2月28日の終わり」で、どちらもその翌日である。
- 1月29〜31日・3月31日生まれが短い月をまたぐと、その月には1か月が満ちず、翌月の1日に満ちる。
- 通算日数は `基準日 − 生年月日` と、通算月数は `年×12 + 月` と、どの組でも一致した。区切りの日は月の数とともに前にしか進まず、日数は 0 から1日ずつ増えて次の区切りで 0 に戻る。

### FAQ の答え

「年齢はいつ1つ増えますか？」の答えは、上の値と合っている。法律の「前日が終わった時」と道具の「当日から」が同じことだと言い、2月29日生まれの閏年と平年を分けて書いている。巷の「2月28日に年をとる」という話を知る来訪者も、ここで食い違いを解ける。

### m1. 結果の値と FAQ が変わったのに、`updatedAt` が 2026-03-02 のまま

`src/tools/types.ts` は `updatedAt` を「Set when main content is updated.」と定め、JSON-LD の `dateModified` とサイトマップの最終更新日がこれを使う。このタスクで、2月29日生まれ・月末生まれの年齢の値が変わり、FAQ に1問が加わった。道具が来訪者に出すものが変わった更新である。同じサイクルの T4-15e（QR コード）でも、同じ理由で `updatedAt` を直させている（[review-t4-15e.md](./review-t4-15e.md) の Minor-2）。

直し方: `meta.ts` の `updatedAt` を、この直しをコミットする日時（`+09:00` の ISO 8601）にする。

### m2. `getConstellation` の3つの分かれ道のうち、1つは死んでいて、残る2つは同じ条件

`CONSTELLATIONS` の12件は、どれも `startMonth !== endMonth` である。`startMonth === endMonth` の分かれ道（`// Same month range`）には入らない。山羊座の「Wraps around year」と、ほかの「Normal range」の分かれ道は、条件の式が一字一句同じである。

- 読む者は「年をまたぐ星座には特別な扱いがある」と思って3つの分かれ道を比べ、同じだと確かめるまで読まされる。T5 が写す見本の一部でもある。
- 値は正しい（1巡目で確かめた境のまま）。

直し方: ループの中を `(month === c.startMonth && day >= c.startDay) || (month === c.endMonth && day <= c.endDay)` の1つの条件にし、英語のコメントを除く。どの星座も隣り合う2つの月にまたがるので、年をまたぐ山羊座も同じ条件で決まることを、1行のコメントで書くとよい。テストは今のまま通るはずである。

### m3. コメントと FAQ の言い回しに、読み違えの余地がある

- **`monthAnniversary` のコメント**: 1文目は「年齢と月と日は、この日の当日から1つ進む」と書く。この日に進むのは年齢か月で、日は 0 に戻る。また、1文目はこの関数の返す日を「応当日」と呼ぶが、応当日の無い月に返すのは翌月の1日で、法律の言う応当日ではない。コメントの後半は同じ日を「区切り」と呼び、`calculateAge` のコメントも「区切りの日」と呼ぶ。直し方: 1文目を「生まれた日から monthCount か月が満ちた区切りの日。年齢と月は、この日の当日から1つ進み、日はこの日を 0 として数える」のように、「区切り」にそろえる。
- **FAQ の最後の1文**: 「生まれた日にあたる日がない月は、翌月の1日から1ヶ月進みます」は、「翌月の1日から数えて1か月たつと進む」とも読める。答えの中でいちばん具体例の要る所なのに、例の日付が無い。直し方: 「1月31日生まれの人は、2月に31日がないので、3月1日に「1ヶ月」になります」のように、日付で言い切る。
