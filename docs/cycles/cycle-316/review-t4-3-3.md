## よかった点

- 登場を「操作に応えたか」で決める形になり、知っている呼び出し側が決める。既定が動かないので、T4-6 以降で渡し忘れても §11 の「一律の fade-in を持たない」に反する側には倒れない。
- 横に送る枠の付け外しがサイトの中で1つの関数になり、記事の本文と結果のボックスで、キーボードと読み上げの来訪者が同じ扱いを受ける。
- `useIsServerRendered` を、描かれ方に意味がある量の帯（水和の組みの引き継ぎ）にだけ残し、使いどころがはっきりした。
