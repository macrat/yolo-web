## Minor

### Minor-1. 5章が「『次はこれを』という見出しは無い」とするが、解き終えた画面には「次はこれを試してみよう」がある

5章の「結果のページのすべてのタイプのあと」は、`/play/*/result/*` だけを測って「T5 の行の『次はこれを』という見出しは無く、共有の次は『他のクイズ・診断も試してみよう』」と書く。結果のページについては正しいが、プレイ面の**解き終えた画面**（`QuizContainer` が描く `ResultCard`）には、`ResultNextContent` の見出し「次はこれを試してみよう」（h3）がある。解き終えた画面の並びは、結果のボックス → 「この結果を共有」 → 詳しい読みもの（character-personality ではすべてのタイプ24行を含む） → 「もう一度挑戦する」 → 「次はこれを試してみよう」 で、結果のページ（24行のあとに共有）とは共有の位置が違う（`ResultCard.tsx:496`〜`:547`、`QuizContainer.tsx:247`〜`:249`）。

T5 の行の「24行の一覧のあとの共有と『次はこれを』までの距離」は、2つの面を混ぜて書いたものと読める。解き終えた画面は PV の 81% を占めるプレイ面の上にあり、character-personality（全体の 74.87%）の来訪者が結果を最初に見る画面なので、ここで24行のあとの「次はこれを試してみよう」までの距離を測っていないのは、T5 の設計（5-c のどこに全幅の罫線を引くか・どこをセクションにするか）の材料の抜けになる（AP-P01）。いまの書き方では、設計者が「『次はこれを』は無い」と受け取り、解き終えた画面を見ないまま進みうる。

**直し方**: 5章に、解き終えた画面（375px の character-personality。結果は `blazing-poet` など結果のページと同じタイプにそろえる）の、すべてのタイプの見出しの y・その区画の下端・「もう一度挑戦する」・「次はこれを試してみよう」の見出しの y を足し、「『次はこれを』という見出しは結果のページに無く、解き終えた画面にある」と面を分けて書く。12章に、解き終えた画面を出すまでの手順（回答の選び方）を書く。T5 の行の該当の文は、PM が面を分けて書き直す（「結果のページでは24行の一覧のあとの共有と『他のクイズ・診断も試してみよう』まで、解き終えた画面では24行の一覧のあとの『次はこれを試してみよう』まで」など）。

### Minor-2. 4-1 が書く「T5 の行の見込み（843 と 682）」が、いまの T5 の行と食い違う

4-1 の「最初の結果の行」は「（T5 の行の見込みは 843 と 682）」と書くが、いまの T5 の行は「h1 を §4 の大きさにすると 844 と 731」と、棚卸しの実測を書いている。同じ棚卸しの中で、T5 の行の中身を2通りに言うことになる。ほかにも「T5 の行の『約83件』」（10-2）・「T5 の行の『辞典の検索の欄の見えるラベルが無い』」（3章）・「T5 の行の『1280px・200% で画面の外に出る』」（8章）・「T5 の行の条件『1表より増やさない』」（8章）は、書き直す前の行の言葉を指していて、いまの行には無い。

**直し方**: 4-1 の括弧は「（書き直す前の T5 の行の見込みは 843 と 682）」とするか消す。ほかの4か所も、書き直す前の行を指すと分かる言い方にそろえる（冒頭の注記に「『T5 の行の〜』は 8ecefc6 より前の行の言葉を指す」と1行足すのでもよい）。
