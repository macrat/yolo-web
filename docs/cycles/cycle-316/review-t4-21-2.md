## 指摘

### Minor-1: ADR の「次回確認時にやること」の2に、GA の率の取り直しが入っていない

取り直しは観測の項目と cycle-316 の T10 にだけ書かれている。ADR の手順2（出荷の直前にカテゴリ別の基線を取る）は Search Console だけで、次の確認でこの ADR を開いた PM が手順に沿って進めると、GA の仮の値を置き換える作業が抜けうる（T10 はサイクルの文書で、出荷が cycle-316 の外になれば読まれない）。手順2に「あわせて、観測の項目の GA の率とページの共有を同じ28日で数え直し、仮の値を置き換える」と足す。

### Minor-2: t4-design.md の T4-21 の行が「出荷の前の値として書き足す」のままで、ADR の「仮の値」と呼び方がずれている

T4-21 の行の作業欄は「出荷の前の値として書き足す」、完了の条件は「出荷の前の28日の値」。ADR ではこの値は仮の値で、出荷の前の値は T10 で取り直すと書いた。同じ値を別の名で呼んでいて、完了の条件を読んだ人が「2026-08-29〜09-25 の値が出荷の前の値」と取り違えうる。行を「仮の値として書き足し、T10 で出荷の直前28日に置き換える」に合わせる。
