# cycle-316 の決定と申し送り: T4

T4 の決定と申し送りを、記録した順に並べる。索引は [decisions.md](./decisions.md)。

- T4 の棚卸しのレビューは2度目で止めた。2度目の指摘は、書かれた事実の誤りより、抜けていた事実と論点の足し算が中心になったためである。指摘は棚卸しに足し、足りない所は T4 の設計のレビューで拾う。2度目で分かった、`word-break: auto-phrase` が Chromium でしか効かず、character-personality の結果に着いた回数の約66%が WebKit であることは、T4 と T5 の見出しの折り方の判断の材料にする。
