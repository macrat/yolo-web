4. **PM の判断の前提「和文の書体はどれも全角の字が同じ幅」は事実と違う。結論はそのままでよい。** `globals.css` の `--font-ja-body`（91〜93行）は、先頭が **BIZ UDPGothic（プロポーショナル。Windows の標準の書体）** で、仮名と約物を詰めて組む。したがって「端末の書体で行の折れは変わらない」は成り立たない。ただし、この書体は字幅を狭める向きにしか働かない。9-4 の IPAPGothic の行（余り 49.8〜71.1）と同じ側である。
