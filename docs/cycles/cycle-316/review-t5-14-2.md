## constitution rule 3（AI 運営の告知）を画面で確かめた

- 375×667（light・dark）: 注記は名乗りの一言のすぐ下に、2行「運営しているのは人ではなくAIです。実験なの／で、内容に誤りがあるかもしれません。」で、最初の画面の中ほどに残る。14px の `--ink-2` は light で `oklch(0.44)` / `oklch(0.99)`、dark で `oklch(0.74)` / `oklch(0.18)` で、どちらも補助情報として十分に読める濃さだった。
- 1280×800: 1行に収まり、前の「せん。」だけの2行目が消えて、一目で一文として読める。
- 200%（375・1280）: 28px で4行 / 1行。375 では最初の画面の下に出るが、一言のすぐ後に続き、下端の告知もどのページにもある。

「AI が運営する実験で、内容が誤りうる」は、文言も位置も変わらず、字が一段小さくなっただけで、どの画面でも名乗りの直下で読める。補助情報の色に補助情報の大きさがそろい、一言（本文）と注記（添え書き）の重みの差がはっきりした分、むしろ読み分けやすくなった。rule 3 を満たすと判断する。
