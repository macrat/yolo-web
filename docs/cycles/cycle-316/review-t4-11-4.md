## 5. 共有の部品とコード

- `savedLayoutScript`:
  - `<` を `<` にして埋め込むので、設定の文字列に `</script>` があってもスクリプトは閉じない。テストはその文字列で実行までしている。
  - 本番のビルドでも、スクリプトはサーバーの HTML に入って動いている（開き直したときの CLS が 0 であることで確かめた）。
- 水和の安全さ:
  - サーバーで描いた木では、本体の前のスクリプトが値を書く。
  - ブラウザで新しく描くとき（サイト内の移動）は、`useState` の初期化の関数が、最初の描画の前に値を書き直す。初期化の関数に副作用を置くのは React の慣例から外れる。ただし、外してから書くので、何度呼ばれても同じ結果になり、実害は無い。
  - ページを離れるときに値を外し、外された区画の高さ 0 は覚えない。
- 汎用性: `finishedStatuses`・`rememberedHeights`・`finishedValues` は、どれもゲームの名前を持たない設定で、テストもある。
- 使われなくなったコード: 見当たらない（四字キメルの `storage.ts` の不要な部分も消えている）。
- 歴史のコメント: 見当たらない。どのコメントも、いまの動きとその理由を説明している。
