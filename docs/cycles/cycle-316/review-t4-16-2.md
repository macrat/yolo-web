## 指摘

### Major-1 刻んでいるとき（開いたときの状態）に、見出しの下に空きが出る。空きを出さずに位置を保つ組み方がある

`tmp/cycle-316/t4-16-fix/light-w375-f16-ticking.png`・`dark-w375-f32-ticking.png`・`light-w320-f32-ticking.png`。見出しの升が「2026/09/26 18:40:47 時点のUNIXタイムスタンプ」の高さを取るので、刻んでいるあいだは「現在のUNIXタイムスタンプ」の下に、幅 320・375 の 16px で1行、200% で2行の空きができる。刻んでいるのはページを開いたときの状態で、375px は来訪者のいちばん多い幅の1つなので、スマートフォンで開いた来訪者のほとんどがまずこの空きを見る。見出しと数字が離れて、見出しがどの値を指すのかがつかみにくく、組みの崩れにも見える。前回の「位置を変えない」に応えて、代わりにいつも見える所に空きを置いたので、前回の指摘の反対側に振れている（AP-I06）。

**2つの状態で見出しの字の量を同じにすれば、升を取っておかなくても位置は変わらず、空きも出ない。** 例えば、刻んでいるときも止めているときも見出しで値の日時を言う（「2026/09/26 18:40:47 のUNIXタイムスタンプ」。刻んでいるあいだは日時も数字と一緒に刻み、止めると一緒に止まる。§11 の止める・reduced-motion の扱いはそのまま掛かる）。「現在の」と「時点の」を言い分けたいなら、字数が同じなので同じ幅になる（数字の幅が秒ごとに揺れないよう `font-variant-numeric: tabular-nums` を付ける）。値の日時がいつも見えることは、刻んでいるときの来訪者にも「この数字はいつか」を言い、写す前の確かめになる。どの言い方にするかは builder が決める。直したら、320・375 の 16px と 200% で、刻んでいるとき・止めたときの両方で見出しと数字のあいだに空きが無く、押しても数字とボタンの位置が変わらないことを撮って測る。

### Minor-3 320px・200% で、10桁の数字が桁の途中で折れる

`tmp/cycle-316/t4-16-fix/light-w320-f32-ticking.png`。「1790448」と「044」の2行に分かれる。`DESIGN.md` §8 は「数字を折るのは桁区切りの位置だけ」とし、数字・短い語は「収まらないときは、収まる段まで下げる。最下段でも収まらないなら折り返す」とする。前回のレビューが「必要なら桁の途中で折れる」と書いたのは、この規定を見落としていた。1行目だけを読んだ来訪者が7桁の値と取り違えうる。行の幅に合わせて字を小さくして1行に収める（例: 行に `container-type: inline-size` を付け、数字の字の大きさを `min(1.1rem, 行の幅 ÷ 10桁ぶん)` にする）ようにし、それでも収まらないときだけ折る。直したら 320px・200% で10桁が1行にあり、行の外に出ないことを撮る。

### Minor-4 コピーのボタンに「コピーしました」の幅を持たせたので、フォーカスと hover の枠が字より大きく空き、同じ道具のほかのコピーのボタンと形が違う

`tmp/cycle-316/rv416b/bar-focus-copy-375-16.png`（375px・16px。枠が「コピー」の約2倍の幅で、右半分が空）、`bar-focus-copy-320-32.png`（320px・200%。枠が2行ぶんの高さで、下半分が空）。フォーカスとタップの範囲は一致しているが（§6）、来訪者には字の無い所まで伸びたボタンに見える。同じ道具の結果の表にあるコピーのボタン（ローカル時刻・UTC・ISO 8601・秒・ミリ秒、日時からの秒・ミリ秒の7つ）は幅を取っておかないので、同じ働きのボタンが同じ面で違う形になる（§12「位置の一定」の同じ形）。

縦積みにしたので、コピーのボタンはボタンの組の最後にあり、16px ではどの幅でも「コピーしました」になっても「止める」と同じ行に収まり（320px でも収まることを測った）、ほかのものは動かない。200% の狭い幅でボタンが2行になり下の区画が1行ぶん下がるのは、押した来訪者の目が向くボタンそのものは動かない。コピーのボタンからは幅の取り置きを外し、この道具のほかのコピーのボタンと同じ組み方にする。コピーのボタンの字が変わるときの大きさの揺れを押さえたいなら、それはサイトの20余りの道具のコピーのボタンすべてに関わるので、共有の部品で別のタスクとして扱う（道具の中の部品で1つのボタンだけに当てない）。Major-1 を字の量を揃える形で直せば、見出しにも取り置きは要らなくなり、`SteadyText` と `.steady` の規則はまるごと要らなくなる。

### Minor-5 見出しが語の途中で折れる

`tmp/cycle-316/t4-16-fix/light-w375-f32-stopped.png`・`dark-w375-f32-ticking.png`。375px・200% で「UNIXタイムスタ／ンプ」と折れる。§4 は文節が1行に収まらないときその文節の中で折ることを認めるが、「UNIX」と「タイムスタンプ」の語の切れ目があるのに、語の中で折っている。「UNIX」と「タイムスタンプ」のあいだにも `<wbr>` を置けば、375px・200% では「UNIX／タイムスタンプ」と語の切れ目で折れる（320px・200% では「タイムスタンプ」も1行に入らず、語の中で折れるのは §4 どおり）。Minor-4 でコピーのボタンの重ねを残す場合は、「コピーし／ました」の折れ方も同じ扱いにする。
