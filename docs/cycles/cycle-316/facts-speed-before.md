# 変更前の表示の速さ（実測）

計測日: 2026-09-24

本書は実測値の列挙のみ。案・評価は含まない。

## 条件

- 対象: `src/` が main（`23c9349`）と同一のブランチで `npm run build` した本番用ビルドを、手元で `next start -p 3000` で起動したもの
- 計測器: Lighthouse 12（`./tmp/lh` に入れたもの）。performance カテゴリのみ。モバイルの既定（模擬の回線と CPU の減速）
- ブラウザ: Playwright 同梱の Chromium（`/opt/pw-browsers/chromium-1194`）、`--headless=new --no-sandbox`
- 各ページ5回、同じ機械で続けて測った
- LCP は `largest-contentful-paint` の numericValue、転送量は `total-byte-weight` の numericValue

## 転送量の内訳と LCP の要素

同じ25回の JSON（`./tmp/lh/before/*.json`）から、`network-requests` のうち `resourceType` が `Font` のものを数えた。**転送量とフォントの値は、5回とも同じか ±0.5% 以内だった。**

| ページ         | 総転送量 | Web フォントの転送量 | Web フォントのファイル数 | LCP の要素                                              |
| -------------- | -------: | -------------------: | -----------------------: | ------------------------------------------------------- |
| 診断のプレイ面 |   558KiB |               232KiB |                       15 | 説明文の段落（「12個の日常シチュエーションに答えて…」） |
| 診断の結果面   |   549KiB |               293KiB |                       20 | 結果の本文の段落                                        |
| ツール         |   493KiB |               270KiB |                       18 | 説明文の段落                                            |
| 辞典の詳細     | 1,435KiB |               835KiB |                       50 | 英語の意味の段落                                        |
| ブログ記事     |   575KiB |               278KiB |                       19 | 記事の見出し                                            |

5ページとも LCP の要素は文字である。

## ページが描く字の異なり数

`.next/server/app/**/*.html`（上と同じ変更前のビルドで、事前に書き出された 3,299 ページ）から `<script>` を除いて本文の文字列を取り出し、かな・漢字（U+3040–30FF・U+4E00–9FFF）の異なり数を数えた。分割配信される和文の Web フォントの転送量は、ページが描く字の異なり数で決まる。
