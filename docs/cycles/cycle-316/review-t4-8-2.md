## 指摘

### Minor-1 JavaScript が動かないと、「占っています……」のまま空のボックスと空いた場所が残り、来訪者には壊れて見える

JavaScript を切った 375px では、ボックスの中は補助情報と見出し「占っています……」だけで、その下に高さ 400px ほどの空の枠と、共有の区画の分の空白が続きます（`tmp/cycle-316/review-t4-8-2/nojs-375.png`）。見出しは占いが進んでいると言っていますが、いつまで待っても何も出ず、来訪者は「壊れている」か「待てば出る」と受け取ります。JavaScript を切っている来訪者のほか、スクリプトの読み込みに失敗した来訪者にも同じ画面が出ます。変更前も「運勢を占っています...」の1行が残り続けていましたが、今は大きな空の枠が並ぶぶん、壊れて見える度合いが強くなっています。

場所を取る仕組みはそのままで、JavaScript が動かないときだけ、占えない理由と、どうすれば見られるかを字で言います。たとえば、ボックスの中の見えない中身の前に `<noscript>` で「今日の運勢は、JavaScript を使って占います。JavaScript を有効にすると表示されます。」を置きます。`<noscript>` の中身は JavaScript が動く来訪者には描かれないので、CLS には影響しません。

### Minor-2 電柱運の今日のアクション「家の中で、安全な場所を一度だけ後ろ歩きしてみる」の言い回しがぎこちない

「家の中で」と「安全な場所を」と、場所を2度言っていて、「安全な場所を」は「を」で歩く場所を言うので「安全な場所の上を後ろ歩きする」とも読め、一読でつかみにくい文です。また「安全な」という断り書きが文の真ん中に入り、ほかの運勢のアクション（「日当たりの良い場所で3分間目を細める」など）の軽さと比べて硬く読めます。「家の中の広いところで、一度だけ後ろ歩きしてみる」のように、場所を1つにし、安全は「家の中の広いところ」で言わせます。
