  - 選択の表示は §11 の操作フィードバックの長さに収める。
  - その間の同じ設問への再入力は、受け付けないなら受け付けないことが見える状態で扱う（選んだ選択肢が選択済みに見え、ほかは押せないと分かる）。
  - 選択肢を §6 のどの種類として組むかを先に決め、DESIGN.md に無ければ先に書く。
- この設計は3案以上を比べ、単独でレビューを受けてから実装すると書く。
