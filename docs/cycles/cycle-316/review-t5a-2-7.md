## 指摘

1. **137行の「記録した時点で数えた S は 2,740 − 2,424 = 316 になる」は、算術から出ない。**
   - X = 2,424 は、解いた問の数から出した最終の X である（6,096 − 3,096 − 576）。一方、2,740 は記録した時点（1打目から約 450ms）の X と S の和である。記録した時点の S を 2,740 − 2,424 と出すには、記録した時点の X が最終の X と等しい必要がある。
   - 同じ文の後半は「記録のあとに答えが入った2打目」があることを認めている。その2打目は、最後の問への S だけでなく、途中の問への X でもありうる。途中の問の答えが記録のあとに入れば、記録した時点の X は 2,424 より少なく、記録した時点の S は 316 より多い。
   - 結論の範囲（最終の S は 316 以上 399 以下）は正しい。記録した時点の X は 2,424 以下なので、記録した時点の S は 316 以上であり、最終の S はそれ以上になるからである。誤っているのは「316 になる」という等号だけである。
   - **直し方**: 例えば「記録した時点の X は最終の X（2,424）以下なので、記録した時点の S は 2,740 − 2,424 = 316 以上である（算術）」とし、後半の「S は 316 以上で、…399 以下」につなぐ。

2. **比べる先の X と S をどう数えるかが書かれていない。0章の手順のまま数えると、変更後の版で X を取りこぼしうる。**
   - 136行は、基準の版でも変更後の版でも、走査ごとに X と S を分けて記録するとする。何から数えるかは書いていない。本文に書かれた数え方は、0章の「記録するまでの待ち」（途中の答えは1打目から約 450ms）の画面と、137行の「帯の番号が2以上進んでいたか」だけである。T5a-7 は、文だけからはこれを使う見込みが高い。
   - 変更後の版では、診断の答えは 150ms 見せてから進む（t5a-design.md 4-3）。300ms の2打目が次の問に答えを入れると、その問が進むのは1打目から約 450ms で、ちょうど記録の時点にあたる。負荷で実際の間隔が延びれば（0章の「負荷」）、記録の時点ではまだ進んでいない。帯の番号で数えると、変更後の版では X が系統的に少なく出る。基準の版（押すとすぐ進む）とは取りこぼし方が違うので、B-620 の材料の比べが誤る。指摘1 のとおり、記録した時点の数と最終の数が違いうることは、この文書自身が示している。
   - **直し方**: 136行に、X と S を、記録の時点の画面でなく、答えの記録から数えると書く。例えば、捕捉の段階の `click` の記録で2打目がどの問の選択肢に落ちたかを見て、走査を終えたあとの答えと突き合わせる。あるいは走査ごとに「問の数 − 1打目で答えた問の数」を X と S の和とし、最後の問を1打目で押さずに結果に移ったかで S を決める。どちらの版にも同じ数え方を使うと書く。
