## 指摘

### Minor-1: 結果のページの CSS に「共通 --accent に寄せる」と「本人には表示されない」が残っている

このコミットは、`src/app/play/*/result/[resultId]/page.tsx` の経緯のコメントを書き直した。しかし、隣の `page.module.css` の冒頭のコメントはそのままである（`[slug]`・animal・character-personality・contrarian・impossible・traditional-color・unexpected・yoji・character-fortune）。そこには次の2つが書いてある。

- 「クイズごとの派手色（accentColor / --type-color）を使わず共通 --accent に寄せる」。前回の Major-1 と同じ文で、いまの `DESIGN.md`（UI は無彩、`--accent` は消すトークン）と食い違う。
- 「このページは第三者向けのシェア／検索ランディング専用で、受検者本人には表示されない」。このコミットで、解き終えた画面の「あなたのタイプ」の行が本人をこのページへ連れていくようになった。いまの動きと合わない。

次にこれらのファイルを触る builder は、この文を読んで UI に色を戻すかもしれない。本人が来ない前提で、ページを組むかもしれない。どちらも来訪者に見える形で効く。

T5 には「ページやゲームの CSS・TSX に残る経緯の注記を消す」とある。しかし、これは経緯ではなく、誤った指示である。隣の `page.tsx` を直したこのタイミングで、一緒に直してほしい。

### Minor-2: Tab で行に移ったとき、「あなたのタイプ」が読み上げられない

読み上げの木では、「あなたのタイプ」はリンクの後ろの別の段落である（`paragraph: あなたのタイプ`）。読み上げで順に読み進める来訪者には届く。しかし、Tab やリンクの一覧でリンクを渡り歩く来訪者は、「花鳥風月タイプ、リンク、現在の項目」と聞くだけで、「あなたのタイプ」を聞かない。§7 の「来訪者のものであることを文字で添える」ことが、読み上げの一部の使い方では伝わらない。

直し方の方向: `ItemList` の補助情報に id を振り、`currentItemHref` の行のリンクに `aria-describedby` でつなぐ。こうすればリンクの名前は名前だけのまま（§7「読む名前は行の名前だけ」）で、説明として「あなたのタイプ」が読まれる。`OtherTypesNav.test.tsx` に、リンクの説明（`toHaveAccessibleDescription`）の検査を足す。

### Minor-3: 見出し「他のタイプ（N）」の扱いを検討した跡が無い

前回の Minor-2 は、行に字を添えることと、見出しを「全タイプ（8）」のような語にすることを「合わせて検討し、§7 に書く」ように求めていた。直したのは行の字だけで、見出しは「他のタイプ（24）」のままである。どちらにするかの判断も、t3-design.md・§7 に書かれていない。

件数の 24 には来訪者のタイプも含まれる。結果のページでは、開いているページのタイプも含まれる。そのため、「他の」と件数と「あなたのタイプ」の行が互いに合わない。字が添わったので、来訪者が迷うことは減った。それでも、1280px では「あなたのタイプ」が行の右の端に離れて出る。見出しの語が合っていれば、行の字を探さなくても一覧の中身が分かる。

見出しの語を変えるか、変えない理由を t3-design.md の 3-2 に書いてほしい。

### Minor-5: 進み具合の帯のコメントの根拠が、§2 に無い

- `ProgressBar.module.css` に「§2 の選択の塗りと同じ扱い」とある。しかし、進み具合は選択ではない。§2 の `--ink` の用途（文字と同じ色で塗るもの）に当てはめるなら、そう書けばよい。無い対応を書くと、ほかの部品が「選択の塗り」を真似る根拠になる。
- 帯の `transition: width 0.3s` は、答えを押したことへの操作フィードバックである。§11 は 150ms 以下と定めている。
- 帯は `DESIGN.md` に無い部品である（frontend-design スキル「DESIGN.md に無いコンポーネントを足したくなったら、先に DESIGN.md へ書く」）。

帯を直した今のうちに、コメントの根拠を正し、動きを 150ms 以下にしてほしい。帯を §のどこで扱うかも決めてほしい（T5a の範囲にするなら、index.md の T5a に書く）。枠の細い `--ink` の線は T5 が扱うので、ここでは求めない。
