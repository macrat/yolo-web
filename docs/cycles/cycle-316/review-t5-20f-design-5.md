### 指摘2（planner・中）: 操作の行が「この結果を共有」の続きに見え、5-c が捨てた案 C の理由に答えていない

3-7 の c は、「もう一度挑戦する」と結果ごとのリンクを、見出しを持たない操作の行として「この結果を共有」のすぐ下に置く。来訪者から見ると、次の2つの問題がある。

**(a) 共有の区画と操作の行の区切りが無い。**

「この結果を共有」は小見出し（h3）を持つ区画で、その下の X・LINE・URLをコピーは、下線の字のボタンを 8px で縦に並べたものである。「もう一度挑戦する」も同じ形の下線の字のボタンなので、見出しも線も無く 8px 下に続けると、共有の4つ目の操作に見える。

§5 では、小見出しの中身はその下の次の見出しか罫線までと読める。そのため、kotowaza-level の結果のリンク（「漢字力診断にも…」のような1文）も、「この結果を共有」の下に並ぶ1行に見える。読み上げでも、h3 のあとに見出しなしで続くので、共有の区画の続きとして聞こえる。

3-7 の表は、見出しの似た2つのセクションが続く問題（a・b）だけを比べ、c が共有と混ざることを見ていない。8-3 のスクリーンショットの確かめも、「見出しが残っていないこと」しか見ない。

**(b) t5-design.md 5-c の決定を、理由に答えずに替えている。**

5-c は、案 C「『もう一度挑戦する』と『次は』を共有のすぐ下（読みものの前）に置く」を、次の理由で捨て、B（読みもののあと）を採った。

> 自分のタイプの読みもの（結果を受け取った来訪者がいちばん読みたいもの）の前に、ほかへ進む操作が挟まり

3-7 の c は、一覧を除いた C そのものである。結果のリンクは、ほかへ進む操作である。9章の「替える過去の決定」は T5-5b の組みを替えるとだけ書き、5-c がこの位置を捨てた理由を、なぜ今は当たらないのかを書いていない（AP-P06・AP-P24）。

- 一覧が無いので、読みものが下がる量は「1画面以上」より小さい。これは c の得の側の事実である。
- 一方、読みものを読み終えてからもう一度解きたい来訪者は、読みものの上まで戻ることになる。character-personality の読みものは長い。これは損の側で、書かれていない。

逆に、得の側の事実もある。1-6 の「同じページを開き直す」175 閲覧は、解き終えた来訪者がやり直しのボタンを見つけずに読み込み直した数かもしれない。これは、ボタンを上に置く根拠になりうる。ただし、そうとは決められない。

比べていない案もある。たとえば、見出しを持たない操作の行を、読みもの（このタイプについて）の末尾か、「他のクイズ・診断も」の前に置く案である。これは 5-c の B の位置を保ち、見出しの似た2つのセクションも作らない。知識のクイズは読みものを持たないので、どの案でも共有のすぐあとになる。

直し方:

- 3-7 に、操作の行の置き場所の案を足して比べる。少なくとも、共有のすぐ下と、読みもののあとの2つである。
- 5-c の C を捨てた理由に、どう答えるかを書く。
- 共有のすぐ下を採るなら、操作の行が共有の区画の一部に見えない組みを決める。例は、細い罫線や小見出しで分けることである。§5 の「小見出しは上に細い罫線」との関係も書く。
- 8-3 の確かめに、「もう一度挑戦する」と結果のリンクが共有の操作と別のまとまりに見えることを、Q3 のスクリーンショット（animal-personality・kanji-level の intermediate・character-personality）で見ることを足す。
- 9章の替える決定に、5-c の C を捨てた理由を替えることを足す。

参考（指摘ではない）: 知識のクイズでは、「もう一度挑戦する」がいまより結果のボックスに近くなる。いまは共有のあとに、罫線と「次はこれを」の見出しを挟んでいた。T5a の着地（結果への切り替わりで2打目が第1の組に落ちないこと）の余地が減る向きである。8-2 の条件4が T5a の条件7を測り直すので、測ってから扱える。
