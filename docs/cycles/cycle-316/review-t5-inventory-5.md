## Minor

### Minor-1. 解き終えた画面の事実が、11章のまとめと 5-c の候補に入っていない

5章に解き終えた画面の表を足したが、次の2か所がそれを受けていない。

- **11章**の「診断のプレイ面（81.01%）」の行は、h1・関連の見出し・FaqSection の線・回答中の選択肢・「はじめる」だけを挙げ、解き終えた画面の距離（375px で共有から「次はこれを試してみよう」まで 3,954px、24行の区画のあと）を挙げない。一方「診断の結果（1.07%）」の行は「共有までの距離（4,419px）」を挙げている。まとめだけを読むと、長い距離の問題は PV の 1% の面にしか無いと読め、74.87% の来訪者が最初に結果を見る面の仕事が落ちる（AP-P01）。
- **5-c** は「結果のボックス・読みもの・すべてのタイプ・共有・『他のクイズ・診断も試してみよう』『他のジャンルも試してみよう』のどれをセクションにするか」と候補を並べるが、解き終えた画面にしか無い「もう一度挑戦する」と「次はこれを試してみよう」（h3。`ResultNextContent`）、およびそれに続く「よくある質問」「この診断を勧める」が無い。候補を列挙している以上、設計者はこの列挙から選ぶので、解き終えた画面の区切りが問いから漏れる。

**直し方**: 11章の「診断のプレイ面」の行に「解き終えた画面の共有から『次はこれを試してみよう』までの距離（character-personality の 375px で 3,954px）」を足す。5-c の候補に「もう一度挑戦する」「次はこれを試してみよう」（解き終えた画面）を足し、プレイ面の解き終えた画面と結果のページで共有の位置が違うことを踏まえて面ごとに決める問いと分かるようにする。
