### Minor-3: 結果のページで「他のタイプ」の見出しが、ページで最も大きな見出しになる

`OtherTypesNav` の見出しは h2 の既定（§4 のセクションの見出し）に従う。そのため、1280px では 46.72px になる。同じページのほかの見出し（「このキャラの成り立ち」16.8px、h1 の 16px）はまだ T5 の前の値なので、`/play/character-personality/result/*` と `/play/traditional-color/result/*` では「他のタイプ（24）」がページで最も目立つ字になる。部品は §4 に従っていて、ずれているのはページの側である。出荷は T5 のあとなので、来訪者には届かない。ただし、検索とシェアから最初に着く面なので、T5 の診断の面で見出しの段がそろうことを、確かめる項目として T5 に書いておいてほしい。
