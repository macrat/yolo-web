## T6-2

- ブログの `src/app/blog/[slug]/twitter-image.tsx` の削除は、担当がステージしたものが T5 の設計のコミット 106e161 に入った。T6-2 のレビューの範囲には 106e161 のこの削除を含める。
- 代替テキストは案 a（`generateImageMetadata`）を試したが、動的なルートの下ではビルドが画像を書き出さない（Next 16.3 は Route Handler の `generateStaticParams` を最後の段しか集めず、`generateImageMetadata` に `params` が渡らない。ブログの画像は0枚、最初の要求で 7.7 秒）。そのため案 c（動的なルートは画像の種類を言う文、1ページのルートは画像の字を順に読む文）にした。画像の URL は `/opengraph-image` のまま。
- `twitter-image.tsx` を消しても、Next 16 は `og:image` から `twitter:image` を同じ URL と代替テキストで出す。古い URL を指すことはない。
- ビルド 1分28秒、ブログの画像 86枚・計 5.4 MB。書体の取得先を壊すとビルドが止まる（exit 1）。配信した PNG はビルドの `.body` とバイト単位で同じ。
