## 指摘

### Major-1 詳しい読みものが続く診断で、共有の区画の下に大きな空きができる

詳しい読みものの最初の小見出しは、上に 32px の余白と線を持つ。区画の下の 24px がそれに足されたので、最後のボタンの下から最初の線まで、8px（行の間）＋知らせの行 26px＋24px＋32px ＝ 90px（ボタンの字の下からは約 100px）あく。読みもののセクションどうしのあいだ（字の下から線まで約 32〜38px）の約3倍で、375×667 では画面の高さの約15%が何もない帯になる（science-thinking・character-personality・animal-personality の 375 と 1280 で撮った）。ボックスから「この結果を共有」までは 24px なので、共有の区画が上に寄り、その下に穴が開いたように見える。2巡目は 66px（8px＋26px＋区画の下 0＋32px）で、この巡で 24px 広がった。

前回の指示の後半（「区画の下の大きな空きは、次の読みものの側の上の余白を見直して詰める」）が行われていない。区画のあいだを `.card` の gap が決めるなら、読みものの最初の小見出しは、その前に来るもの（共有の区画）とのあいだを自分の上の余白で重ねて取らない形にする（例: 小見出しの上の余白を、読みものの中で前のセクションがあるときだけのものにする）。これで区画の下は、次が読みものでもリンクでも同じ「知らせの行＋24px」になる。読みものの部品は結果のページ（`/play/[slug]/result/[id]`）でも使うので、そちらの見え方も撮って確かめる。

### Major-2 読みがタイプ名に付いて見えない（伝統色では、名前と色見本のまんなかに浮く）

タイプ名の下と読みのあいだが 16px になり、読みの下が 24px になった。字の端どうしで測ると、見出しの行の余白が加わるので、次のとおり、読みはタイプ名から、補助情報とタイプ名のあいだよりも離れ、下の要素とほぼ同じ距離にある。

| 面                                     | 補助情報→タイプ名 | タイプ名→読み | 読み→次の要素 |
| -------------------------------------- | ----------------- | ------------- | ------------- |
| traditional-color 375（次は色見本）    | 18px              | 27px          | 31px          |
| traditional-color 1280（次は色見本）   | 22px              | 30px          | 31px          |
| word-sense-personality 375（次は説明） | 17px              | 27px          | 36px          |
| word-sense-personality 1280（同）      | 20px              | 30px          | 36px          |

伝統色では「さくらいろ」が「桜色」と色見本のまんなかに浮き、どちらに属するかが近さで分からない。読みは名前の読み方なので、見出しの組の中で、補助情報とタイプ名のあいだ（§5 のいちばん小さい 8px）と同じか、それより近くに置くのがよい。2巡目の 8px はそうなっていた。

負の margin に戻すのではなく、読みを見出しの組（`ResultBox` の頭の行の中、補助情報・タイプ名と同じ所）に置き、タイプ名とのあいだを補助情報とタイプ名のあいだと同じ仕組みで決める形にする。`ResultBox` は T4-17 も触るので、どちらのタスクで持つかは PM が決めて渡す。直したあと、上の4つの面で、字の端どうしの距離が「タイプ名→読み」＜「読み→次の要素」になることを測る。

### Minor（まとめ）

1. **OGP の画像は名前と読みを別の分け方で組んでいる。** `src/app/play/[slug]/result/[resultId]/opengraph-image.tsx` は `result.title` と `result.reading?.kana` を使うので、伝統色は「藍色(あいいろ)」（半角の丸括弧）を題にし、言葉センスは題と読みを分ける。解き終えた画面・結果のページ・一覧は `resultHeadingName` にそろったので、OGP の画像を組み直す T6 に「`resultHeadingName` を使う」を渡す。この巡の差分の範囲ではない。
2. **`.reading` のコメントが、Major-2 を直すと合わなくなる。** 「下の内容とのあいだを中身どうしのあいだより 8px 広くとって、読みが…タイプ名に付いて見えるようにする」は、実際には付いて見えていないので、直すときに書き直す。
