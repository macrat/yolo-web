# T3 着手前の洗い出し（一覧）

計測日: 2026-09-25
本書は実測とコードの読み取りの列挙のみ。案・評価は含まない。

- 対象: `HEAD`（`0a42f03`）。作業ツリーに未コミットの変更は無い。
- 計測: `next build` のあと `next start` で配信したものを、Playwright（Chromium 1194）で開いた。画面は **375×667**（狭い画面）と **1280×800**（広い画面）。
- y 座標は、ページ先頭からの CSS px（スクロールしていない状態の `getBoundingClientRect().top + scrollY`）。375px では上端（`header`）の下端が y=63。
- 読み上げの名前は、Playwright の `ariaSnapshot()` と、CDP の `Accessibility.getPartialAXTree`（Chromium が計算した名前）で取った。
- 件数は、いまのデータ（`src/tools`・`src/play`・`src/blog`・`src/data`・`src/humor-dict`）から数えた値と、画面で数えた行の数。両者は一致した。
- 「1画面に収まる」は、一覧の最初の行の上端から最後の行の下端までの高さが、画面の高さ（667 / 800）以下であること。
