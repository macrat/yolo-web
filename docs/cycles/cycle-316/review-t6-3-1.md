## 画像を見て（来訪者から見て）

- **ゲーム4本の副題は、前の `ogpSubtitle` より良くなった。** 前は「毎日の漢字パズル」「毎日の色彩チャレンジ」「毎日の仲間分けパズル」で、新しい補助情報「パズル」と並べると「パズル」を2度言うだけで、何をするのかを言わなかった。いまの `shortDescription` は「毎日1つの漢字を推理するパズル」「毎日5つの色を作って色彩感覚を鍛えよう」「16個の言葉を4グループに分けるパズル」で、カードを見ただけで遊び方が分かる。ナカマワケだけ「毎日」が消えたが、中身が具体になったほうが大きい。副題の出どころが遊びの一覧のカードの説明と同じになったのも良い（画像だけの欄が無くなった）。
- **ユーモア辞典は、名前・読み・定義が §10 のとおりに分かれた。** 前は「月曜日（げつようび）」を名前として組み、定義を80字で切っていた。いまは見出し語を名前の段で大きく、読みをその下に、定義を切らずに3行で置いている。この辞典の読みどころは定義なので、カードに全文が出るのは来訪者にとって価値がある。読みと定義は §10 のとおり同じ書体・色・大きさで、あいだは 8px 広いだけ。それでも、読みは見出し語のかなで短いので、定義の1行目と見分けられる。
- **道具**: 補助情報「ツール」・名前（h1）・副題（h1 の下の説明）で、画面の頭と同じものがカードに出る。「Base64エンコード・」「デコード」の折れは中黒の後ろで、§4 のとおり。
- **privacy**: 上端のサイト名と同じ「yolos.net」を副題に繰り返すのをやめ、名前だけになった。同じ語が2度並ばなくなった。

## `?v=` とハッシュ

- b のルート（ユーモア辞典・`/play/[slug]`・music-personality）は `shareOpenGraphImage` が中身と枠の値から `?v=` を作る。30語と15本の `?v=` はどれも違う値で、中身を変えたページだけ URL が変わる。Route Handler はクエリを読まずに同じ PNG を返した。
- 規約のファイルのままの42本は、Next が付ける `?{hash}` である。Next 16.3 の `next-metadata-image-loader` は `[contenthash]`、つまり `opengraph-image.tsx` そのものの中身から hash を作る。このため、道具の `meta.ts` の名前や説明を変えても URL は変わらない。これは 3-2 の「`?{hash}` を付けるか」の表が、規約のファイルのままのルートについて受け入れていること（「そのファイルを書き換えない限り変わらない」）で、T6-3 の欠けではない。この出荷では42本ともファイルが書き換わったので、URL は前と違い、SNS は取り直す。
