## 指摘

### 1.（直す）GA の読み込みの文を1つの出どころにまとめる（逸脱 3）

`middleware.ts` の `analyticsTags()` は、`GoogleAnalytics` の読み込みの URL と、インラインの初期化の文（`dataLayer`・`gtag('js')`・`consent default`・`config` と `release`）を書き写しています。1-b が採ったのは「ほかのページと**同じ** GA の読み込み」で、ねらいは 410 の数を**ほかのページの数と同じ所で、同じ意味で**読むことです。

- 同じであることを確かめるものがない。2つのテストはそれぞれ自分の写しを文字列で確かめているだけなので、同意の既定を変える・`config` に項目を足す（`release` のような全イベントに乗る値など）といった直しを片方だけにしても、テストはすべて通り、410 だけが違う設定で送り続けます。直すたびに2か所を直すことになる形で、1-a が B（404 の書き写しを残す案）を捨てた理由と同じです。
- もうずれている: middleware は ID を `encodeURIComponent` で包み、`GoogleAnalytics` は包まない。いまの ID では結果が同じでも、2つは別々に書かれたものだという印です。
- `analyticsTags()` のコメントは「GoogleAnalytics と同じ ID と同じ設定で送り」と言い切っていますが、それを保つ仕組みがありません。

直し方: React に頼らない小さなモジュール（例 `src/lib/google-analytics.ts`。`server-only` を付けず、`RELEASE_ID` だけを import する）に、読み込みの URL を作る関数と、インラインの初期化の文を作る関数を置き、`GoogleAnalytics`（`<Script src>` と `<Script>` の中身）と `build410Html` の両方がそれを使う。ID の包み方はどちらか1つに決める。テストは、その関数の出力を1か所で確かめ、`GoogleAnalytics` と 410 の HTML にはその関数の出力がそのまま入ることを確かめる形にする（410 の側で文字列を二重に書かない）。`analyticsTags()` のコメントは、同じ関数を使うことを言う形に書き直す。middleware の束に入るのは短い文字列の関数だけで、重さは変わりません。

受け持ち: `src/components/GoogleAnalytics/`（とその試験）は 10-4 の表のどのタスクの行にもなく、並行して触るタスクもないので、T5-23 の直しとして触ってよい。ただし T5-23 の行と 10-4 は `src/middleware.ts` しか書いていないので、PM は T5-23 が `GoogleAnalytics` と新しいモジュールも触ることを cycle のドキュメント（10-4）に書き足してください。このあとに `build410Html` を触るのは T6-10（icon の `<link>`）で、順番は変わりません。

### 2.（直す・小）テストの名前が §4 と食い違う

「見出しは語の中で折らず、行頭の禁則を厳しい側で組み、auto-phrase に頼らない」とありますが、`overflow-wrap:anywhere` は、文節が1行に入らないとき（200% の 320・375 で実際に起きている）に文節の中で折るための宣言です。名前が「語の中で折らない」と言い切ると、§4 の「文節が1行に収まらないときだけ、その文節の中で折る」と逆のことを確かめているように読めます。例「見出しは文節の中では1行に収まらないときだけ折り、行頭の禁則を厳しい側で組み、auto-phrase に頼らない」のように、§4 の言い方に合わせてください。

## T10 への申し送り（PM が ADR009 に書き足す）

GA を載せた日から、`/blog/<削除したスラッグ>`（`DELETED_BLOG_SLUGS` の19件）で `page_view` が新しく出ます。題は「このコンテンツは終了しました | yolos.net」です。ADR009 の GA の読み（character-personality の保存と共有の率・ページの共有の回数）には入らず、Search Console のカテゴリ別の系列も、410 は索引に載らないので変わりません。ただし、GA でサイト全体やブログのページビューを出荷の前後で比べると、この分だけ出荷の後が増えて見えます。ADR009 の「出荷の日から計測の出方が変わるもの」に次の1項を足してください: 「削除した記事の URL（410）が `page_view` を送るようになる。ブログやサイト全体のページビューを前後で比べるときは、`page_title` がこの題のもの（または `DELETED_BLOG_SLUGS` のパス）を除く」。この数は、1-b の「置き換え先のある5件を転送にするか」の材料にも使います。
