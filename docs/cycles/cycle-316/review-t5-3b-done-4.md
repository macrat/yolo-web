| -------------------------------------------------- | ----------------------------------------------------------------- | --------------------------------------------------- |

第3回の値（0.118・0.104、2918 → 3000）は headless shell のもので、第3回の記録はそれを言っていなかった。知見の文書はそれを Chromium の振る舞いとして写しているので、次にこの組み方を使う人は、来訪者の Chrome でも layout-shift と `scroll` が出ると読む。どちらの種類で測ったかと、本体では出なかったことを書く（`MutationObserver` に届くことは種類によらない）。「一瞬の DOM を見ることを考える」という結びは、そのままでよい。

あわせて、画面の枠の記述を測りに合わせる。文書は「受け手ではコピーの前後で同じだった」と書くが、第3回の記録は「375px の上端は 1 画素だけ違う」と言っている。自分の測りでは、受け手があるとコピーのあとに枠が1枚出て、上端の 375px・1280px とも 1 画素（y=26 の1点）が違った（本体。headless shell の 1280px は 0）。受け手を止めると、コピーのあとに枠は出なかった。来訪者には見えない差だが、「同じ」とは書かず「1 画素のほかは同じ」とする。

出どころの書き方も分ける。いまは「layout-shift の記録は、字を 100ms 除いたままにする対照（見出しだけ、1280px）で 2 件出た。受け手では……（見出しだけは 20 回写しても 0 件）」から `MutationObserver` の 8 件までを1つの（review-t5-3b-done-3.md）で括っているが、対照の 2 件と 20 回の 0 件は builder の測りで、第3回の記録には無い。
