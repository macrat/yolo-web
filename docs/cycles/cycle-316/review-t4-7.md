## 指摘

### Major-1 本文の幅を変えたことで、隠れた字の無い「続きを読む」が 375px で12タイプに出る。説明の字も本文の大きさと違う

- **どこが:** 結果のページの説明は `DescriptionExpander` が組み、説明の字数（`countCharWidth` が 128 を超えるか）だけで4行に切って「続きを読む」を出す。字数の閾値は、幅 600px の枠で「1行に全角16字」として決めたもので（`[slug]/result/[resultId]/page.tsx` のコメント）、この変更で説明の幅が 375px で 321px、1280px で 640px に広がったため、4行に全文が入るのに切って「続きを読む」を出す説明が増えた
- **数:** 「続きを読む」を持つ説明は前後とも 106。そのうち隠れている字が無いものは、375px で前 1 → 後 **12**、1280px で前 29 → 後 31。375px の12は、traditional-color の ai・shu・wakakusa・yamabuki・hisui、yoji-level の master、yoji-personality の6タイプ（shoshikantetsu・tenshinranman・sessatakuma・meikyoshisui・ishindenshin・yuoumaishin）。藍色（`ai`）では、「…導く存在です。」で文が終わった直後に「続きを読む」が出て、押しても何も増えない。若草色と山吹色では、この行のために誘いのボタンが最初の画面の下端（667px）を越える
- **来訪者にとって:** 押しても何も起きないボタンは、ページが壊れていると思わせる。とくに 375px は来訪者の多い幅で、伝統色診断と四字熟語の診断の結果のページの半分以上に出る
- **説明の字:** 説明は `font-size: 1rem`・`line-height: 1.8`（16px・28.8px）で、すぐ上のキャッチコピー（この変更で本文の大きさになった。17px・31.45px）と並ぶと、続く2つの段落で字の大きさと行間が違う。§4 の本文は `1.0625rem`・`1.85` で、2-2 は結果のページの説明を「h1 のあとの段落」として置くとしている
- **直し方（builder が決める）:** 2-2 のとおり説明を h1 のあとの段落として全文を置くか、切るのを残すなら、描いた幅で本当に字が隠れるときだけ「続きを読む」を出す形にする。どちらにするかは、最初の画面に誘いのボタンが入る数（上の 93）がどう変わるかを測って決め、決めたことを設計に残す。切るのを残す場合は、§8「1つの結果を切り分けて見せる分割・段階表示を持たない」との関係も設計に書く。どちらでも、説明の字を §4 の本文の大きさと行間にそろえ、字数の閾値のコメント（「1行あたり全角16文字」）を事実に合わせる

### Minor-1 8ルートで、「全N問 / 登録不要」が次の読みものの見出しに接している

- **来訪者にとって:** 小さい灰色の字が下の見出しの添え書きに読め、誘いと読みものの境が見えない
