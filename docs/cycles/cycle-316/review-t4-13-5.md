## 指摘

### Major-1: `line-break: strict` で、4字の片仮名の語に1字だけの行が出る（320 既定を含む）

50問 × 320/375/1280 × 16〜32px（2px 刻み）で、実際の格子の組み（`<wbr>` と `phrased` も同じ）で語のマスの行を数えた（grid6.mjs）。

| 組み方                                | 1字だけの行 | 行頭の長音符・小書きの仮名 |
| ------------------------------------- | ----------- | -------------------------- |
| いまの組み（`line-break: strict`）    | 12          | 0                          |
| `line-break` を外した組み（前の組み） | 0           | 98                         |

1字だけの行が出るのは次の語である。

- 320 既定（4列・61px）: #11「ジュー／ス」、#41「リゾッ／ト」、#18「ブラッ／ク／ホール」
- 375 18px・20px: 同じ3語（20px では「ブ／ラック／ホール」）
- 320 200%（2列・129px）: 同じ3語

`strict` は小書きの仮名と長音符で行を始めないので、4字の語が3字の升に入るときの折り所が「3字＋1字」しか残らない。4巡目で `strict` を試したのは「サラリーマン」「シャープペンシル」などの3語だけで、ほかの語での影響を測っていなかった。PM の決定（t4-design.md）は「1字の行は出ず」を理由に 320 既定で4字の語が折れることを受け入れており、この前提が崩れた。ブリーフの5（1字の行も、ー・小書きの仮名で始まる行も作らない）を満たさない。`text-wrap: pretty`（1字の行58）や `balance` を外す組み（798）も試したが、どちらも悪くなる。

- **直すこと**: 50問すべての語で、1字の行と行頭の約物がどちらも0になる組みを探す。たとえば、既定の 320px で4字の語が1行に入るようにマスの中の余白や字の間を見直す、あるいは3字＋1字しか折り所が無い語だけ折り所を決めて渡す、など。どちらも0にできないときは、どちらを受け入れるかを PM が決め直して t4-design.md に書く。直したら、50問 × 3幅 × 16〜32px の表を出す（grid6.mjs と同じ測り方）。

### Minor-1: 文節でない語にも `<wbr>` が入る

`splitIntoPhrases` は、ことわざのほかに次の語も2つに分ける。「く｜つわ虫」「の｜ぞみ」「は｜たき込み」「は｜まぐり」「は｜やぶさ」「こうの｜とり」「あか｜つき」「も｜みじ」「かし｜こまり」「たい｜焼き」「ぬか｜漬け」「あん｜ぱん」（#6・9・10・16・18・25・30・32・40・41）。これらの語は `phrased` の組みになり、語の中に折り所が足される。いまの測りでは、ここから1字の行は出ていない（狭いマスでは「はま／ぐり」「はた／き込み」と折れる）。ただ、WordGrid と page.tsx の注釈は「文節を持つ語（ことわざなど）」と書いており、実際に渡している値と合わない。「は｜まぐり」の折り所は、字の大きさやマスの幅が変わると「は」だけの行を作りうる。

- **直すこと**: 文節で折る語を、どの文節も2字以上ある語に限るなど、ことわざのように本当に文節を持つ語だけにする。または、ほかの語の分け方を直す。

### Minor-2: #34 の日は、1280×800 でチェックのボタンが 4px 最初の画面から出る

ことわざの日（#34。次は 2026-10-12、その後 12-01 と 2027-01-25）では、3行に折れる語が3つあり、`dailyOrder` の並びで3つが別々の行に入ると、ボタンの下端が 804px になる（chk1280d.mjs。2026-10-12 の並びで 804、2026-08-15 の並びで 782）。字は読めて押せるが、枠の下の 4px が切れる。ほかの49問は 761px 以下。

- **直すこと**: この日にも 800px に入るよう、格子の上か下の間を詰めるか、1280 のマスで3行に折れないようにする。PM が受け入れるなら、t4-design.md に書く。

### Minor-3: page.tsx とテストに、足した跡が残る（ツギハギ）

- `src/app/play/nakamawake/page.tsx`: `wordPhrases` の組み立てが、`dateDisplayString` の注釈（「new Date(todayStr) is parsed as UTC …」）とその式のあいだに差し込まれた。注釈が、その直後の `wordPhrases` を説明しているように読める。`import { splitIntoPhrases }` も、ほかの `@/lib` の読み込みと離れた1行目に足されている。
- `src/play/games/nakamawake/_lib/__tests__/engine.test.ts`: `import { dailyOrder } from "../engine";` が、同じ `../engine` からの読み込みのすぐ下に別の行として足されている。
- **直すこと**: `wordPhrases` を注釈の前へ移し（または日付の注釈を式の直前に戻し）、読み込みを1つにまとめる。

### Minor-4: ナカマワケは、取っておいた場所の `<style>` を外したときに片付けない

回転と拡大の空白は直った（区画と中身の差は 0）。ただ、4巡目の Minor-3 の「ナカマワケにも、外したときの片付けを入れる」は入っていない。`nakamawake-saved-layout` の `<style>` は、サイト内でほかのページへ移ったあとも `<head>` に残る（回転の測りでも、解き終えた日の最後まで `true`）。漢字カナールと四字キメルは `useEffect(() => () => releaseSavedLayout(...))` で外している。いまの値はナカマワケの中でしか読まれず、見た目の害は測れなかったが、同じ部品を使う4つのゲームで片付け方が違う。

- **直すこと**: 漢字カナールと同じ片付けを入れる。入れないなら、その理由を PM が決めて書く（イロドリも同じ）。
