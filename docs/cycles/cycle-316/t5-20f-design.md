## 2. 決めること

1. 中身のあとに並ぶセクションの順を、すべての面で1つの決まりにする。そのうえで、ゲームと診断・クイズで、次に遊ぶものの一覧をどこに、どの見出しで置くか（§12 位置の一定。状態の間でもページの間でも）。

6. GA の計測が途切れないこと。

| b. 位置で決める（上にあるほうを残す）                                                                                    | 関連ゲームを残す                                                                                                                   | 入口（名前だけ）を残し、すぐ下の一覧から除く。一覧から説明を持つ行が消え、kotowaza-level では空になる | 入口を残し、下の一覧から除く                                                                    | 捨てる   |
| **c. 隣り合う2つは形で、離れた2つは位置で決める。** 隣り合うとは、あいだに見出しを持つ別のセクションを挟まないことである | 離れている（よくある質問と共有を挟む）。上の関連ゲームを残し、遊びのおすすめから除く                                               | 隣り合う。説明を持つ行を残し、入口から除く                                                            | 離れている。上の入口を残し、「他のジャンルも」が開始の画面でその行き先を除く                    | **採る** |

c を採る理由:

- 隣り合う2つは、来訪者が同じ画面で読み比べる。そこでは、行き先を選んだ理由を言うもの、説明を持つ行のほうが、選ぶ手がかりを多く渡す（§7）。
- 離れた2つは、来訪者が上のほうに先に出会う。下のほうは、送っていった先で出会うさっきの行の繰り返しである。上を残せば、いちばん近い所の道が消えない。
- 形だけで決める a は、中身のすぐあとの道（辞典の関連ゲーム、開始の画面の入口）をページの下端へ送る。位置だけで決める b は、説明を持つ行を名前だけのリンクのために消す。

**名前だけのリンク**は、§7 の行の一覧の行でない1本のリンクである。名前に短い句を添えたもの（関連ゲームの「漢字カナール - 毎日の漢字パズルで遊ぶ」、入口の「四字キメルで遊ぶ」）も含む。**説明を持つ行**は、§7 の行の一覧の行で説明を持つものである。**行き先を選んだ理由を言うリンク**は、結果ごとのおすすめのリンクである。

**除き方**: 除く行き先は、一覧が選ぶ前に候補から外す。選んでから外して補うと、関係の薄いものが入る。辞典の詳細の遊びのおすすめは、漢字カナールを外してから重なりの順に選ぶと、漢字の詳細は四字キメル・漢字力診断、四字熟語の詳細は四字熟語力診断・四字熟語で性格診断になり、補いは要らない（planner の実測）。選んでから外して `PLAY_FEATURED_ITEMS` で補うと、漢字の詳細に漢字と関係の無い逆張り運勢診断が入る（review-t5-20f-design-3.md）。

### 3-4. 診断・クイズの開始の画面の関連の入口

3-3 の c を当てはめると、関連の入口は次のとおりになる（5-2 の選び方で planner が数えた。実測）。

- すぐ下の「他のクイズ・診断も」に並ぶ行き先を入口から外す。30本のうち12本（8本の診断・クイズ）が外れる。入口の全部が外れる4本（kotowaza-level・impossible-advice・contrarian-fortune・animal-personality）は、入口を描かない。残る18本は、辞典の一覧・ゲーム・「他のクイズ・診断も」に入らない診断である。
- ページの下の「他のジャンルも」に並ぶ入口の行き先（kanji-level の漢字カナール、yoji-level と yoji-personality の四字キメル）は入口に残し、「他のジャンルも」が開始の画面でその行き先を除き、同じ分類の次に近いゲームを並べる（kanji-level は四字キメル、yoji-level は漢字カナール）。
- 入口のデータ（`relatedLinks`）は書き換えない。外すのは、同じ画面の一覧に並ぶかで決める。一覧の選び方や登録が変わっても重ならず、一覧に並ばなくなった行き先は入口にまた出る。

一覧を入口より優先する理由は、一覧の行が説明と問数を持つからである。入口の名前だけのリンクで選ぶより、同じ行き先を説明付きで選べる。

結果ごとのおすすめのリンクは、結果に合わせて書いた1文で、行き先を選んだ理由を言う。kotowaza-level では、その1文（操作の行。3-7）のすぐ下の「他のクイズ・診断も」に同じ行き先が並ぶ（隣り合う）。kanji-level と yoji-level では、そのリンクの行き先（漢字カナール・四字キメル）が、ページの下の「他のジャンルも」に並ぶ（離れている）。

### 4-1. ページの並び

### 4-2. 「今日のほかのパズル」の中身

- 見出しのすぐ下に進みの行（§4 の補助情報の大きさ・`--ink-2`）、その下に、いまのゲームを除くデイリーゲームの行の一覧（§7、ボックスを持つ）を `ALL_GAMES` の順に置く。
- **行は、名前・説明・補助情報を持つ。** 行は `toPlayListItems` と同じ作りで、名前・説明（`shortDescription`）・補助情報「毎日更新」を持つ。今日遊び終えたゲームの行は、補助情報に「今日は遊び終えた」を足す。種別（ゲーム）は全件で同じなので出さない（§7）。
- 一覧は、4本とも遊び終えた日も描く。セクションが状態によらず同じ形で出て（§12 位置の一定）、遊び終えたほかのゲームの結果を見直しにも行ける。
- 進みの行の文（3-2 の c）。数えるものはいまと同じ `lastPlayedDate`。文言は T7 がさらに見直す。

  | 今日遊び終えた本数 | 進みの行                             |
  | ------------------ | ------------------------------------ |
  | 0                  | 出さない                             |
  | 1〜3               | 今日は4本のうち{n}本を遊び終えました |

### 6-2. `DESIGN.md` §7「件数と備え」

「選んだ一覧」の項のすぐ下に、次の項を足す。

>   - **重なるときに残すほう**: 隣り合う2つ（あいだに見出しを持つ別のセクションを挟まない）は、行き先を選んだ理由を言うリンク、説明を持つ行、名前だけのリンクの順に残す。同じ画面で読み比べるので、選ぶ手がかりの多いほうを残す。離れた2つは、上のほうを残す。来訪者は上のほうに先に出会い、いちばん近い所の道が消えない。除く行き先は、一覧が選ぶ前に候補から外し、選んでから外して補わない。
>   - **送りの案内**（連載・前後の記事・一覧へ戻る道）は、順に進むか戻るための案内で、行き先が順で決まっているので除かない。選んだ一覧は、同じページの送りの案内が指す行き先を、選ぶ前の候補から外す。送りの案内どうし（連載と前後の記事）が同じ記事を指すのは、どちらも順を言うもので、この決まりに数えない。
>   - **数えないもの**: パンくずとページ送り、表の中と文の中のリンク、そのページの主操作の行き先（プライマリボタンが指す行き先で、長い読みもののあとに同じ誘いをもう一度置くものを含む）、結果のボックスの中のリンク（結果の一部として別のタイプを指すもの）、1つの並びの中の繰り返し（四字熟語の構成漢字の、同じ字の2度目）。どれも、2つの案内が行き先を読み比べさせるものでなく、除くと来訪者が道や中身を失う。

「名前だけのリンク」は、§7 の行の一覧の行でない1本のリンクで、名前に短い句を添えたもの（辞典の関連ゲームの「漢字カナール - 毎日の漢字パズルで遊ぶ」）も含む。数えないものは、1-5 で実際のページに当たったもの（主操作の繰り返し・構成漢字・同点のタイプ）と、パンくず・ページ送りである。送りの案内と選んだ一覧の重なり（ブログの関連記事と前後の記事）は数える。送りの案内を残し、選んだ一覧の側から除けば、来訪者は何も失わない（前後の記事に残る）。T5-31 はこの形でブログの関連記事を直す。

### 6-3. frontend-design スキルの「機械で確かめる」

表に次の行を足す。
