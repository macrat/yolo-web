### 3. css-modules.md の導入文に編集履歴が入っている（軽微）

「§1 は cycle-171 で確かめ cycle-316 で現行のコードに合わせて書き直したもの」の「書き直したもの」は、根拠ではなく編集の経緯であり、ツギハギ禁止（経緯はサイクル文書へ）に当たる。新ルールが求めるのは「実測か推論か」と「根拠のサイクル」なので、例えば「§1 は cycle-171 で実測し cycle-316 で現行コードに対して再確認、§2 は cycle-316 で実測」のように、確かめ方とサイクルだけを書く（§2 の「得たもの」も実測か推論かが読み取れない）。実際に何で確かめたかは cycle-316 の記録に合わせること。

### 4. README の説明が knowledge-directory.md の Do を一部落としている（軽微）

`.claude/rules/knowledge-directory.md` は「Owner から共有された技術的な知見を記録する」も Do に挙げているが、README の導入文は「作業の中で確かめた非自明な技術的事実」に限定している。Owner 共有の知見も置き場所であることが README から読めるよう一言加える（または両者の記述を揃える）。
