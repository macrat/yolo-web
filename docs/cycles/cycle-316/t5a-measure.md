- **押し方（条件6・7）**: どの回も新しいブラウザの文脈から始めた（Web フォントを読み込んでいない）。
  - **押す点**: 押すものの矩形の中心（整数に丸めた座標）。選択肢は行（`li`）の中心、「はじめる」「次へ」「もう一度挑戦する」はボタンの中心。
  - **送り**: 押すものが画面に丸ごと入っていないときだけ、来訪者の送りとして、下にはみ出していれば下端が画面の下端から 8px 上に、上にはみ出していれば上端が画面の上端から 8px に来るまで送ってから押した。T5a-7 は、来訪者の送りを CDP の `Input.dispatchMouseEvent`（`mouseWheel`・`deltaY` に送る量）で送り、送りが止まってから押す点を測る。ブラウザは `--disable-smooth-scrolling` で起こし、ホイールの送りを即時にする。`window.scrollTo` で送らないのは、変更後の版が来訪者の送りを送りを起こす入力（ホイール・指の移動・キー）で知り、字の読み込みのあとに送り直すかを決めるためで、`scrollTo` では来訪者が送ったことにならない（cycle-319 のキャリーオーバーの「T5a-6 の判断で受け入れたこと」）。
  - **2度の押し**: 同じ点を2度、CDP の `Input.dispatchTouchEvent`（`hasTouch` の文脈。touchStart と touchEnd）か `Input.dispatchMouseEvent`（1打目は `clickCount: 1`、2打目は `clickCount: 2` の mousePressed・mouseReleased）で送った。1打目を送ってから指定の間隔だけ待って2打目を送り、1打目の返事は待たない。
  - **語の選択の対**（t5a-design.md 6章 条件7）: 新しい文脈で開いて「はじめる」を `element.click()` で押し、1問目の見出しの最初の字（字の範囲の矩形の中心）を、画面に丸ごと入っていなければ来訪者の送りを挟んでから、マウスの「2度の押し」で押す。2打目を送ってから 700ms 待って、選択の字と2打目の `mousedown` の `detail` を記録する。`detail` が 2 でない回は送り直す。範囲は15本 × 90・300ms × 6画面（T5a-7 の道具の操作 `select`）。
  - **記録するまでの待ち**: 時間で待ち、描画は待たない。「はじめる」と、最後の答え・最後の「次へ」は2打目を送ってから 700ms、途中の答えと「次へ」は1打目から約 450ms（2打目を送ってから 450 − 間隔 ms）待ってから、落ちた先と画面を記録した。
  - **2打目で離れたか**（5-2）: 記録の時点に出ている画面でなく、2打目の `click` の記録で決める。サイトの中のリンクは遷移の先を読み終えてから画面を替えるので、記録の時点にはまだ古いページの問が出ていることがあるためである。2打目の `click` の要素が、今のページ（2打目の `click` の時点の `location.pathname`。サイトの中のリンクは遷移を始めるとすぐ `location` を移った先に替えるので、記録の時点の URL と比べると、離れた押しを離れていないと数え違える）と違う道（`pathname`）を指して同じタブで移る `a[href]` の中にあるか、解き終えた画面の「もう一度挑戦する」のボタンであれば、その走査はその押しで離れたとする。今のページと同じ道へのリンク（パンくずの末尾など）と `#` だけのリンクは、問や結果が出たまま残るので離れたとしない。

    - **別のタブや共有の画面を開く押し**（結果の画面の「X でシェア」「LINE でシェア」の `window.open(…, "_blank")`、`navigator.share`、`target="_blank"` のリンク）: 離れたとしない。元のページは結果のまま残り、来訪者はタブや共有の画面を閉じれば読んでいた所に戻れるからである。この押しは、落ちた先の記録にボタンやリンクとして残り、t5a-design.md 6章 条件7 の第1の組に落ちた件に入る。開いたタブの行き先は、localhost の外への要求を止める `context.route` の受け手（「ブラウザ」の箇条）で取る。遷移の要求（`isNavigationRequest()` が真）で `frame()` が投げるものが、開いたタブの最初の遷移である（フレームが作られる前の遷移の要求では、Playwright の `frame()` は投げる。同じタブで外へ移るリンクの要求では `frame().page()` が元のページを返すので、混ざらない）。その要求の URL を行き先として、その押しの落ちた先に添えて記録する。開いたタブ自身の `page.url()` からは取らない。外への要求を止めているので、開いたタブには Chromium のエラーのページが描かれ、`page.url()` は `chrome-error://chromewebdata/` になって行き先を持たないためである。開いたタブは、ブラウザの文脈の `page` の出来事で拾ってすぐ閉じる。

    - いま出ている問に答えが無い: その問の選択肢。
    - 知識クイズで、いま出ている問に答えがある: その問の「次へ」。「次へ」の2打目が次の問の選択肢に落ちて答えを入れたときも、これに当たる。
