## 指摘事項

### 1. science-thinking の h1 が、既定の文字サイズの 375px で行頭に「？」を置く（DESIGN.md §4 違反。T5-4 が作った）

`t54-breaks-after.json` とスクリーンショット `t54-after-science-thinking-375.png` のとおり、375px の既定で h1 が「理系思考タイプ／診断 — あなたは／アインシュタイン型／？チューリング型？」と組まれ、4行目の行頭が「？」になる。文節の区切り（`splitIntoPhrases`）は「アインシュタイン型？」を1つの文節として正しく返しているが、この文節（10字）が 33.28px の主見出しでは 375px のコンテンツ幅に入らず、ブラウザが文節の中の「型」と「？」のあいだで折っている。区切りの仕組みでも CSS の禁則でも防げない折れである。

§4 は「既定の文字サイズでは、見出しに…禁則の破れ（行頭の…！？…）を作らない。組み方で避けられないときは、見出しのうち来訪者に渡していない文を直す」と定める。クイズの題名は、診断のタイプ名（来訪者に渡した結果の名前）ではないので、直す側に入る。この折れは T5-4 が h1 を主見出しにしたことで生まれたもので、T5-4 の完了の前に直す必要がある。

- 直すのは `src/play/quiz/data/science-thinking.ts` の `title` で、T5-4 の受け持ちのファイル（10-4）の外にある。PM が受け持ちを決めて builder に直させる（T5-4 の追いのコミットとして扱うのが自然）。
- 題名は `<title>`・OG 画像・パンくず・結果のページのパンくず・構造化データにも出る。変える前に、このページの検索からの流入（GA・Search Console）を確かめ、検索の見出しとして弱くならない文にする。
- 新しい題名は、320・375・1280 の既定で h1 に1字だけの行・禁則の破れが0であることを測って確かめる（320 の「アインシュタイ／ン型？」のような文節の中の折れも、減らせるなら減らす）。「はじめる」が 320/375 の最初の画面に入ることも取り直す。

### 2. 共有の部品を変えたのに、使うすべてのページの前後を撮り比べていない（AP-I14）

`RelatedQuizzes` と `RecommendedContent` が自分で `Section` を描くようになり、プレイ面のほかに、結果のページ（`ResultPageShell`）・`/play/daily`・ゲーム（`GameLayout`）の見た目が変わる。builder の撮影はそれぞれ1ページ（`t54-*-other-result/daily/game.png`）だけである。実際に、結果のページでは「他のクイズ・診断も試してみよう」の上には罫線が無いのに、その下の「他のジャンルも試してみよう」の上にだけ全幅の罫線が入り、ゲームのページでは「他のジャンルも試してみよう」の見出しが上の一覧の枠から 16px まで寄り、下が大きく空くなど、使う側ごとに崩れ方が違う。

- 結果のページのすべて（`ResultPageShell` を使うものと、それぞれの `page.tsx` を持つもの）と、ゲームのページのすべてを、変更の前と後の 375px で撮り（または見出しと罫線の y を測り）、違いが上に書いた3種類だけであることを確かめて記録する。
