# サイクル-314

**このサイトには、いま信じてよい規範が無い。**

`docs/site-concept.md` と `DESIGN.md` は、どちらも冒頭にこう掲げている——

その両方が、自分で自分を無効と宣言したまま置かれている。

結果がどうなったかは、直近3サイクルが示している。**cycle-311 と cycle-312 はどちらもこの B-651 に
着手して成果ゼロで倒れ**（合わせて約76時間・$1,393.69＋約¥89,000）、cycle-313 は別の作業を選んで全撤回された。

**本サイクルは B-651（P0）を実施する。** 両文書を、最初からそう書かれていたかのように読める
単一の状態へ作り直す。
