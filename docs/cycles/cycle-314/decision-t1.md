**決定: 3つとも追認する。** 覆す根拠を持たないからではなく、**覆すに足る事実が存在しないことを確かめたうえで**追認する。

## 覆せるかを確かめた

ADR006 は覆す条件を自分で定めている。

> **覆す根拠は、来訪者の側からの新しい事実**（例: 来訪者が「よろず屋」を誤解していることが問い合わせ・行動から
> 分かる）であって、好みや飽きではない。

**その新しい事実を、本サイクルは持っていない。**

- 本実行環境に `GOOGLE_APPLICATION_CREDENTIALS` は無く、GA4/BigQuery も Search Console も参照できない（実測）。
- 仮に参照できたとしても、**名乗りの語だけを変えた対照を作れない**ため寄与を取り出せない——
  ADR006 が「観測を伴わない純粋な決定」とした理由そのものである。
- 問い合わせ経路からの誤解の報告も無い。

**したがって決定1〜3を覆す根拠は無い。** 好みや「3サイクル潰した語だから替えたい」は、ADR006 が明示的に排除した理由である。

## 追認したうえでの1点の是正——「読むサイト」ではなく「読む**だけ**のサイト」

決定1 が定める来訪者への一言と、現行 `docs/site-concept.md` の記述が食い違っている。

| 出どころ                           | 文言                                                                         |
| ---------------------------------- | ---------------------------------------------------------------------------- |
| ADR006 決定1                       | 「**読むだけの**サイトではなく、やってみるサイト——AI が営むよろず屋です」    |
| `docs/site-concept.md:17`          | 「**読む**サイトではなく、やってみるサイト——AI が営むよろず屋です」          |
| 実装（`src/app/page.tsx:193-195`） | 「**読むだけの**サイトではなく、やってみるサイト。AIが営む、よろず屋です。」 |

**ADR006 の文言を採る。** 理由は来訪者の側にある——このサイトにはブログ87記事と辞典があり、
**読むために来る人が実在する**。「読むサイトではなく」はその人たちに「あなたの用は無い」と言う文になる。
「読む**だけ**のサイトではなく」なら、読むことを否定せずに「その先がある」と言える。

**これは「実装を正として規範を書き換える」ではない。** 権威は ADR006（決定文書）にあり、
実装がたまたまそれに一致しているだけである。もし実装だけが「読むだけの」で ADR006 が「読む」だったなら、
規範の側を採って実装を直す対象にした。**根拠は ADR006 と来訪者の実在であって、`src/` の現状ではない。**

## T4・T5 への申し送り

- **T4**（`docs/site-concept.md` の書き直し）: 決定1 の文言をこの形で載せる。決定2 を、
  `site-concept.md:9` の禁止規定（店の signifier が自明に伝わると仮定しない／「やってみる」を売り込みにしない）と
  自己名乗りの食い違いを**解く形**で書く——禁止が向いているのは**派生した私的な符牒**であって、自己名乗りそのものではない。
- **T5**（`DESIGN.md` の再導出）: 決定2 が「内部の設計語彙（店構え・のれん・品書き・値札・包み）は有効なまま」と
  定めているので、**内部語彙は残してよい**。ただし**来訪者の画面に出る語**は「説明なしに意味へ届くか」で判定する。
  決定3 は `DESIGN.md` §4 の識別マーク規定の導出元になる（完了条件8 のカテゴリ1）。

cycle-312 の全取り消しで消えたこと**である（ADR 自身の記載）。本サイクルで決定が再び成果物に載るため、
**ADR009 として、本追認と上記の是正1点を含めて起票し直す**（T7）。ADR006 は経緯の記録として expired に残す。
