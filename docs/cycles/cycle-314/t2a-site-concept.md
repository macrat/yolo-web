## §1. L9（最大の塊）の分解——3つの規範と、捨てる経緯

L9 は単一段落に cycle-309/310 の判断経緯を丸ごと抱えている。**規範として残すのは3点だけ**で、残りは経緯なので落とす。

| L9 の内容                                                 | 処遇                                                                                                     |
| --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| サイト名の由来＝「YOLO×よろず」の二重の意味（不変の事実） | **残す。** 「このサイトは何か」の中に事実として書く。来訪者に「由来はよろず屋（店）だ」と偽らないこと    |
| (2) 店の独自 signifier が自明に伝わると仮定しない         | **ADR006 決定2 の形に置き換える**——線は語の出自ではなく「**説明なしにその場の意味へ届くか**」で引く      |
| (3)「実験/試作/やってみる」を identity の売り込みにしない | **限定して残す。** 下記の緊張を解く                                                                      |
| cycle-309 E3・cycle-310 E1 の判断履歴、マークの形の経緯   | **削除。** 経緯であり、識別マークの規範は ADR006 決定3 から `DESIGN.md` §4 が導く（完了条件8 カテゴリ1） |

**(3) と自己名乗りの緊張を解く。** L9(3) は「やってみる」を売り込むなと言い、L17 は「やってみるサイト」と名乗っている。
これは矛盾ではなく、**禁止の対象を取り違えた書き方**だった。

- 禁じるべきは「**実験サイトであること**を価値として売り込むこと」——試しているのは運営であって来訪者ではない。
  来訪者にとって「実験中です」は価値ではなく、むしろ品質への不安である。rule 3 の AI 明示は**正直の開示**に留める。
- 「やってみる」は**来訪者の行為**であって運営の実験ではない。「やってみるサイト」は来訪者が何をできるかを言っている。

**この区別を本文に書く。** そうすれば禁止と自己名乗りが両立する。

## §2. L19 の書き換え

L19 は3つの問題を同時に抱えている。

1. **「運営者の言葉で言い直すと」という構造**——来訪者向けの一言が足りなかったので後から運営者向けの言い直しを足した、
   という経緯そのもの。**削除して本文に溶かす。**
2. **「よろず屋の店主が AI であることは」**——「店主」は ADR006 決定2 が「来訪者に出さない語」とした側にある
   （cycle-309 が可視面から除去済み）。**「店主」を使わずに書く。**
3. **「このサイトの注意書きではなく個性である」**——後付けの強調。**削除。**
   ただし rule 3（AI 明示）を**負い目として書かない**という趣旨は残す価値がある。
   書くなら「AI が運営していることを隠さない」と事実として書き、価値づけも弁解もしない。

## §3. L57 のオーナー帰属

**「オーナーは積極的な実験を奨励する」は裏取りできない**（cycle-311 の棚卸し §5 が AP-P34 として指摘）。

**だけ**にする。rule 5 は「地」であり、帰属ラベルを足す必要が無い。
