## §1. サイト名の由来——**間違っていたのは公開記事ではなく、規範文書とわたし自身だった**

### 一次資料

`src/blog/content/2026-02-18-site-rename-yolos-net.md:36` が、オーナーの指示メモを逐語で引き、リンクまで張っている。

> オーナーからの指示メモには「名前の由来: YOLO (You Only Live Once) + よろず（万事・あらゆるもの）」と記されていました。

記事本文（`:29-35`）も一次資料どおりに書いている——**YOLO = "You Only Live Once"（人生一度きり）**、
**よろず = 「万事・あらゆるもの」**、合わせて「一度きりの人生で、あらゆるものを」。

### 実際の食い違い

| 面                                      | YOLO をどう説明しているか                          | 一次資料と         |
| --------------------------------------- | -------------------------------------------------- | ------------------ |
| 公開記事（`2026-02-18-site-rename…`）   | "You Only Live Once"（人生一度きり）               | **一致**           |
| `/about`（`src/app/about/page.tsx:88`） | 「運営のすべてを AI に任せた実験、という意味です」 | **食い違う**       |
| 旧 `docs/site-concept.md`               | 「運営を AI に丸投げした実験サイト」               | **食い違っていた** |

**B-680 の起票は前提が逆だった。** 公開記事は一次資料どおりで、由来を取り違えていたのは**規範文書と `/about`** である。
しかも**本サイクルの T4 初稿は、その取り違えをそのまま引き継いでいた**——
「運営を AI に丸投げした実験サイト」を YOLO の意味として書いていた。T7b の調査で気づいて是正した。

「運営を AI に丸投げしている」ことは事実であり、サイトの性格として書いてよい。
**それを名前の意味だと書くことが誤り**だった。現行の `docs/site-concept.md` は、由来（2語の literal な意味）と
その下でやっていること（AI 丸投げ・範囲を狭めない）を分けて書き、「両者を混ぜない」と明記している。

### 処遇

- **B-680**: **起票の前提が誤り。** 公開記事に欠陥は無い。ただし**取り下げではなく、対象を入れ替えて残す**——
  正しい欠陥は「`/about` の YOLO の説明が一次資料と食い違う」である。これは B-683 に統合する。
- **B-683**: 「`/about` が site-concept と食い違う」という形では **T4 で解消**（規範側が正された）。
  しかし**一次資料との食い違いは残る**——`/about:88` は依然として YOLO を「運営のすべてを AI に任せた実験」と説明している。
  **`src/` の修正が要るので本サイクルでは解けない。** 着手条件なしで Queued へ戻し、
  タイトルを「`/about` の YOLO の説明が一次資料（You Only Live Once）と食い違う」に改める。

**来訪者にとっての意味**: いま `/about` を読んだ人は、サイト名の由来を**事実と違う形で**受け取っている。
規模は小さいが、由来の説明は「このサイトは何か」を伝える中心の一つであり、しかも自分たちで一次資料を持っているのに違えている。
