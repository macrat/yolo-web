### WCAG 判定——**3層**で判定する

一次資料: WCAG 2.2 Understanding SC 1.4.11 Non-text Contrast
（https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html ・2026-09-15 確認）

**訂正。** 初稿は「理解に必要でないグラフィック（純粋な装飾・**区切り線**）は対象外と**明記されている**」と書いた。
**これは誤りである。** 本文を取得してタグを除去し機械検索した結果は次のとおり。

```
divider           : 0 hits
separator         : 0 hits
dividing          : 0 hits
purely decorative : 0 hits
```

**「区切り線（divider / separator）」は一次資料に一度も出てこない。** 装飾例外からの類推をわたしが
「明記」と書いたもので、外部権威を使って検証を止める形になっていた。
cycle-312 の `external-spec-check.md` も同じ検索を行い、「区切り線に特化した規定・例外は存在しない」と結論している。

さらに初稿は **SC のもう半分と Boundaries 節を丸ごと落としていた**。一次資料の逐語（上記 curl 取得分より）:

> **Boundaries**: This success criterion does not require that controls have a visual boundary indicating the hit area.
> If a control has visible content (such as text or a sufficiently contrasting icon), which helps users identify the
> presence of the control, then a border or other indication of the overall boundary of the hit area is not required…
> **Having a visual boundary indicating the hit area is only required when there is no other visual way to identify
> the presence of the control** – and in those cases, the boundary must have sufficient non-text contrast.

**したがって判定は次の3層で行う。** 初稿の「装飾の区切りか／構造の主役か」という二択は誤りで、
**「装飾だから違反ではない」と言い換えて実在しうる欠陥を無害化する出口**を用意していた。

1. **User Interface Components**——コンポーネントと状態の識別に必要な視覚情報か
2. **Boundaries の免除**——そのコンポーネントに可視のテキストや十分なコントラストのアイコンがあるか
3. **Graphical Objects**——そのグラフィックの理解に必要か
