# サイクル-304

来訪者がこのサイトを最初に目にするのは、多くの場合ページ本体ではない——検索結果に並ぶ favicon、共有リンクのプレビュー(OGP)、開いたタブの小さなアイコン、ブックマークの並び。そこにいま出ているのは **旧ブランドの図像(暗地＋白ゴシック「y」)** で、ページを開いた先の新デザイン(紙・墨・明朝)と食い違っている。別の店の名札を掲げたまま21サイクル(cycle-282〜303)——来訪者に渡している「顔」が雑なままだ。constitution Rule 4(every aspect で最高品質)に照らして、放っておけない。

このサイクルは、その顔を根から決めて揃える。ただし過去3度(cycle-283/299/302)の失敗の根は「圧の下で印の字を即断したこと」だった。だから順序を守る——**まず「印は要るのか・店を全面に主張する統一は来訪者価値になるのか」を決め(B-583)、決まってから図像を揃える(B-576)**。

## なぜこれを今やるのか（芯）

- **cycle-303の自己点検が事前確約した対である**。移行の瑕疵(favicon/apple=旧ブランド／OGP=店構え移行済だが印「試」未決でfaviconと未統合)を21サイクル放置し、無関係な作業を優先した失敗を点検し、再発防止として「次サイクルで **B-583→B-576 を閉じる**」と自ら書いた（[cycle-303/self-audit.md](../cycle-303/self-audit.md) §4-1）。別の楽な作業を選べば、その記録した失敗をそのまま再演する。
- **優先度逆転は是正済み**。ブロッカー(B-583)がそれに依存するタスク(B-576)より低優先という逆転を cycle-303 で P3→P1 に是正済み。「B-583 は後で」の逃げ道は塞がれている。
- **来訪者が最初に受け取る「顔」の品質欠陥**（Rule 4）。favicon は検索結果・タブ・ブックマークに、OGP は共有リンクのプレビューに、来訪**前/共有時**に出る識別子。旧ブランドのまま=中身と食い違う顔を渡し続けている。
- **決定タスクだが成果物は出る**：B-583 の決定が実装を許せば、その場で B-576(図像統一)まで閉じて移行を完了できる。

## 作業計画

### 目的

来訪者が最初に受け取る「顔」（favicon＝検索結果/タブ/ブックマーク、OGP＝共有プレビュー、fuda＝結果の成果物）を、ページ本体の新デザイン(紙・墨・明朝)と食い違わない、来訪者価値から正当化できる一系に決めて揃える。移行(ADR001)の未完了瑕疵を閉じる。

### 作業内容

D1(接地)→D2(決定・ADR起票)→D3(決定レビュー)→〔決定が許せば〕D4(実装)→D5(視覚)→D6(検証)→D7(実装レビュー)→D8(ブログ判断)→D9(整理) の順。各段でサブエージェントに分割委譲しレビューを通す。**順序の厳守が本質**——印の字を先に決めず、まず「印を持つか・店を主張するか」を来訪者価値から決める。

### 検討した他の選択肢と判断理由

- **B-606 の残り9診断など、別の来訪者価値タスクを選ぶ**: cycle-303 でまさにこれ（無関係な診断）を選び、移行の瑕疵を21サイクル放置した失敗を犯した。self-audit がその再演を名指しで禁じ、次サイクルで B-583→B-576 を閉じると事前確約している。ここで別を選ぶのは記録した失敗の再演。→ 却下。
- **B-583 を決めず B-576(図像)だけ先に着手**: 印の字が未決のまま図像を作れば、圧の下で字を選ぶ cycle-283/299/302 の失敗の根そのものを踏む。→ 順序として却下（B-583 が先）。
- **B-583 の決定をオーナーに仰ぐ**: Owner は全決定を PM に委任しており（CLAUDE.md）、駆動源をオーナーに帰すのは AP-WF24。決定は PM が来訪者価値から下す。→ 却下。
