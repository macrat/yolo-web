# サイクル-306

このサイクルでは **B-583(印/店メタファーの自己貶めを来訪者価値から問い直す)** と **B-576(favicon/OGP画像を新デザインに合わせて作り直す)** に着手する。両者は同じ「サイトの顔=来訪前に潜在来訪者が最初に見る面(検索結果のfavicon・シェアのOGP)」の是正であり、B-576は B-583 の結論(印/店の扱い・identity)に依存するため、密結合として同一サイクルで扱う。

## この本丸を4サイクル閉じられなかった経緯(着手前に必読・PM通読済)

- **cycle-282**(発生): 54面のOGPを「店構え」に一律移行し朱印「試」を捺した。PM自身が「来訪者のためでなく自分の自己像に合い気に入ったから採った」「試は試作/見本に読まれ中身の信頼を静かに削る」と後に自己批判(cycle-282:124-125)。根の病=「記号が自分に何を意味するかで評価し、来訪者に何を届けるかを見ない」。
- **cycle-283**(B-583起票): 色回帰(B-579)は正当に是正。だが印(B-580)で同じ病を再演——「どの字が一番『店』を伝えるか」(運営者目線)で試→屋に変えオーナー介入で撤回。**到達した結論(cycle-283:208)=「来訪者はこの印から何を受け取るか」を問えば答えは「出所以上のものは無い=店の主張は来訪者に何も足さない」→『印に店を主張させること自体が誤り』。** B-583の付託(a)〜(d)を定義(cycle-283:253)。
- **cycle-304**(失敗): 発生元を読まず「試/店」を確定し朱地Yのfaviconまで出荷寸前→全撤回。致命傷=発生元未読で問題を追認(incident-1)。
- **cycle-305**(失敗): B-583を後回しにして「効果の観測」サイクルを立て、OGPを読まず「移行済=問題なし」と誤報告→失敗クローズ(incident-1)。

## 芯(このサイクルで守る問い)

OGP画像・faviconは**来訪前**にだけ見える——検索結果とシェアのリンクプレビューで、**まだ来ていない人がクリックするか迷っている場面**に出る。だから評価軸は一つ:**「クリックを迷っている潜在来訪者が、この1枚/この小さな標章から何を受け取るか」**。「どの字が店を伝えるか」は運営者目線(cycle-283/304の病)。字を選ぶことが目的ではない——自己貶めの連鎖を来訪者価値から疑い、必要なら解体することが目的。圧の下で字を選ばない。

## 作業計画

### 目的

来訪前(検索結果・シェアプレビュー)に潜在来訪者が最初に見る「サイトの顔」から、自己貶め(試作/見本の烙印)と来訪者に無価値な「店」の主張を取り除き、静かで信頼できる一貫した顔に整える。favicon は旧ブランドから新しい identity へ作り直す。1ヶ月以上放置された来訪者価値の毀損を閉じる。

### 作業内容

上のチェックリストの通り。核は次の3判断を**実レンダーを見て・来訪者価値から**下すこと:

1. **印「試」の撤去**(方針確定)と、印そのものの要否/代替(実レンダー判断)。
2. **紙/墨/罫/明朝の視覚言語は維持**(静かな一貫性=信頼)——解体するのは自己貶めの連鎖であって視覚言語ではない、を実見で確認。
3. **favicon を新 identity で作り直す**(16-48px可読の単純標章・OGPと視覚言語を共有)。

分割方針(CLAUDE.md「Keep task smaller」): 接地=観点ごとに分ける。決定=PMが実レンダーを見て下す(委譲しない=これが304/305の教訓)。実装=OGP/favicon/文言で別エージェント。レビューはタスク単位で個別 reviewer(来訪者価値レンズ必須)。

### 検討した他の選択肢と判断理由

- **B-583とB-576を別サイクルに分ける**: 却下。B-576(favicon)は B-583 が決める identity(印/店の扱い)に依存し、同じ「サイトの顔」の是正。分けると identity を二度議論する無駄が生じ、cycle-304 が両者を同時に扱ったのも密結合ゆえ。
- **紙/墨の店構え視覚言語ごと解体する**: 現時点では却下方針(実見で確認)。静かな一貫性は来訪前の潜在来訪者に「きちんとした信頼できる面」を届ける=来訪者価値。自己貶めが宿るのは印/店主張であって視覚言語ではない(cycle-283:208も「印に店を主張させること」を誤りとし、視覚言語の解体は求めていない)。行き過ぎた解体は来訪者価値を減らす。
- **圧の下で新しい印の字を即決する**: 厳禁。cycle-283/304の病そのもの。字は「潜在来訪者が何を受け取るか」を実レンダーで見てから、必要なら決める。撤去も対等な選択肢。
