# cycle-306 決定(decision)

評価軸(芯): **来訪前(検索結果・シェアプレビュー)にクリックを迷う潜在来訪者が、この顔から何を受け取るか。** 「どの字が店を伝えるか」ではない(cycle-283/304の病)。すべて実レンダー(`tmp/cycle-306/`)を実見して下した判断。

## 連鎖の正しい読み(過剰解体も過少解体も避ける)

B-583の芯「よろず→よろず屋(店)→試の烙印」の解体とは、**店の比喩=個性を消すことではない**:

- **よろず**(=万事・あらゆるもの)= 誠実な名前の由来。identity。維持。
- **よろず屋(店)の比喩** = オーナー承認の個性(cycle-283:216・site-concept.md:15「注意書きではなく個性」)。維持。ただし**由来を「店」と偽る箇所は是正**(下記(c))。
- **試の烙印** = 自己貶め(試作/見本=来訪前に信頼を削る)。**撤去**。

解体対象は「自己貶め部(試)」と「偽装部(由来偽装)」であって、店の個性ではない。

## 決定1: OGP器面の印「試」を撤去する(確定)

- 実見(`ogp-A-current-shi.png`)で、朱の「試」が唯一の色として視線を集め副題「実験的」と重なり「試作/暫定」の気配を渡すことを確認。cycle-282:125のPM自身の指摘「試は試作/見本に読まれ中身の信頼を静かに削る」の実物確認。
- constitution Rule 3(AI実験の告知)はサイト上の注意書き(Footer・トップの名乗り注記)で果たしており、来訪前のプレビューに「試作」の烙印を焼く理由にならない。
- GA接地: シェア露出ほぼゼロ=これはcraft/誠実さの判断(測定トラフィックの判断ではない)。

## 決定2: 紙/墨/罫/明朝の視覚言語は維持する(確定)

- 実見(`ogp-B-noseal.png`)で、印を外しても紙/墨の器面は静かで清潔・信頼できる顔として成立することを確認。
- 静かな一貫性は来訪前の潜在来訪者に「きちんとした信頼できる面」を届ける=来訪者価値。解体すべきは自己貶め/偽装であって視覚言語ではない(cycle-283:208も視覚言語の解体は求めていない)。行き過ぎた解体は価値を減らす。

## 決定3: favicon/apple-icon を F2「朱の印・白抜きy」で作り直す(確定・B-576)

- 実見(`favicon-all-16-32-48.png`・`favicon-sheet-F2.png`)で4方向を比較:
  - F1(紙地・墨y)/F3(紙地・墨よ): 紙地が白背景に溶けて**16pxで境界が消え存在感が弱い**。最重要の検索結果16pxで埋没。
  - F4(朱地ベタ・白y): 存在感は強いが角四角の朱ベタが重く、cycle-304の朱地Y(撤回済)に近い。
  - **F2(朱の角丸印・白抜きy)**: 16pxで検索結果に映え(境界あり・朱=ブランドのアクセント色)、明朝のyが端正、180pxでも本物のアプリアイコンとして成立。**サイトの印/hanko の視覚言語を、店主張でも自己貶めでもなく「サイトの頭字y(=yolos)の印」として体現**。誠実(y=ドメイン頭字)・旧(y+点)からの橋渡し。
- **なぜyか(病の再演でない根拠)**: 「y」は運営者の自己像の投影(試=実験の洒落)でも店主張(屋)でもなく、**yolos.net の客観的な頭字=誠実なidentity**。字を選ぶ病(cycle-283/304)とは別物で、実レンダーを来訪者価値の軸で見て選んだ。
- 実装の申し送り: favicon(タブ/検索)=朱の角丸印を紙地に。**apple-touch-icon(180)=朱を全面ブリード**(iOSが全面角丸マスクをかけるため紙縁の二重角丸を避ける)。色はSSoT(PAPER/INK/ACCENT)厳守。白抜きyの朱地に対するコントラストはAA相当を確認すること。
