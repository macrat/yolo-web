### 1-D. 冒頭ブロックから本文へ移す有効な規律 — 3件

いずれも**注記ではなく規則として**書く。接地は過去サイクルの経緯ではなく **constitution** に取る（引用元の保持ログ2件は git に存在せず追跡できないため、経緯に依存しない接地へ置き換える）。

1. **来訪者に「サイト名の由来はよろず屋（店）だ」と言わない。** 由来は「よろず＝あらゆるもの」であり、事実でないことを来訪者に言わないのは rule 1（法令・基本的倫理）の直接の要求である。
2. **独自の語・記号が説明なしに伝わると仮定しない。** 判定の具体は `DESIGN.md` §6 の規則（[decision-yorozuya.md](./decision-yorozuya.md)）。
3. **「実験している」ことを価値として売り込まない。** 試しているのは運営であって来訪者ではない。rule 3 が求めるのは**開示**であって、宣伝ではない。
