## 2. 実装の実態（ファイルごと）

### 2.1 `public/icon.svg`（favicon・全 1 行の SVG）

- ファイル全体は `<rect>` 2 本 + `<path>` 1 本。ビューボックス `0 0 100 100`。
- **地**: `<rect width=100 height=100 fill="#f8f7f2">`＝紙（`PAPER`）の全面。
- **容器**: `<rect x=10 y=10 width=80 height=80 rx=17.6 ry=17.6 fill="#af3622">`＝朱（`ACCENT`）の**角丸正方形**。タイル比 **80%**、角丸半径 **17.6**（正方形辺の 22%）。
- **字**: `<path … fill="#f8f7f2">`＝紙色で白抜きした明朝小文字 `y` のアウトライン（`<text>` ではなくベクタ path 埋め込み）。
- **回転**: なし（**0°**）。
- **色数**: 3 値ではなく 2 値（`#f8f7f2` と `#af3622`）だが、**マーク自体は朱＋紙色の 2 色**。
- 本番配信物と同一（`https://yolos.net/icon.svg` を取得して `public/icon.svg` と `diff` → 一致）。

### 2.2 `scripts/generate-favicons.ts`（favicon 資産の生成器）

- 幾何定数: `TILE = 100` / `SEAL_RATIO = 0.8`（印はタイル比 80%）/ `SEAL_PAD = 10` / `SEAL_RADIUS = SEAL * 0.22 = 17.6` / `FAVICON_GLYPH_PX = 62`。
- 字: Google Fonts から **Noto Serif JP wght@900** の TTF を取得し、opentype.js で `y` のアウトラインを path 化。可視 bbox の中心を印の中心へ実測で合わせる。
- 色: `PAPER` / `ACCENT` を `src/lib/utsuwaHex.ts` から import（直書き禁止）。
- 生成物 3 種:
  - `public/icon.svg`（上記）
  - `public/favicon.ico`（**16/32/48px の 3 サブイメージ**を内包する PNG 埋め込み ICO。実物を検査して 3 件・それぞれ 358/660/984 バイトを確認）
  - `public/apple-touch-icon.png`（`APPLE_TILE = 180` / `APPLE_GLYPH_PX = 129`。**朱を全面ブリードし角丸なし**・紙色の白抜き y・回転なし）
- 冒頭コメントは本デザインを「**ブランド標章 F2「朱の印・白抜き y」**」「サイトの印/hanko」ではなく…とは書かず、単に F2 と呼ぶ。`B-576（cycle-306）で PM が実レンダーを見て確定した方向` と記す。

### 2.3 `scripts/recolor-icon-accent.ts`

- 識別マークの**形には一切関与しない**。cycle-302 の E0（favicon/apple-touch-icon から §8-1 が禁じる青を除去した作業）で使った色置換をスクリプト化したもの。

### 2.6 `src/components/In/index.tsx` + `In.module.css`（画面上の印）

- `MAX_ROTATE_DEG = 8`。`rotateDeg` 既定 **-4**、範囲外は `Math.max(-8, Math.min(8, …))` で**機械的にクランプ**。
- `char` は書記素 1 字に切り詰め（`[...char][0]`）。
- 形: `<svg viewBox="0 0 40 40"><circle cx=20 cy=20 r=18.5 vectorEffect="non-scaling-stroke"/></svg>` ＋ 中央に 1 字。
- CSS: `.ringLine { fill:none; stroke: var(--accent); stroke-width: 1.5px }`、`.char { color: var(--accent); font-family: var(--font-mincho); font-size: calc(var(--in-size,48px) * 0.55); font-weight:600; font-feature-settings:"palt" }`、`.in { inline-size/block-size: var(--in-size,48px); transform: rotate(var(--in-rotate,-4deg)) }`。
- 色はすべて `var(--accent)` 経由（インライン直書きなし）。`border-radius` は使わず円環は SVG circle。
- **使用箇所は `src/components/Tsutsumi/index.tsx` の 1 箇所のみ**（他はテスト）。`<In char={seal} size="100%" label={"印 " + seal[0]} />`。
- `Tsutsumi.module.css` の `.seal` は `position:absolute; top:var(--space-24); right:var(--space-24); inline-size:18%; max-inline-size:64px; z-index:1`。
- **実測の挙動（実ブラウザ）**: `size="100%"` を受けた `.in` は `inline-size:100%`／`block-size:100%` となり、親 `.seal`（絶対配置の `<span>`・高さは内容依存）に対して高さが解決できず、実測 **63.5 × 13.2px の扁平な箱**になる。SVG は `preserveAspectRatio` 既定で短辺に合わせるため、**円環は直径約 13px の小円**として描かれる。字の `font-size` は `calc(100% * 0.55)` が親フォントサイズ 16px に対して解決され **8.8px**。結果、画面上の印は「**約 13px の朱い小さな丸の中に 8.8px の字**」で判読できない（§5 のスクリーンショット参照）。同じ CSS は本番にも配信されている（本番 CSS `Tsutsumi-module__Qvq-Wq__seal{…inline-size:18%;max-inline-size:64px…}` と `--in-size,48px` の calc をライブ配信 CSS で確認・ローカルと同一ハッシュ）。
- コンポーネントの JSDoc/CSS コメントは cycle-278 版の厳密仕様（「文字 1 字（明朝）＋細い円環（2px 以内）・朱一色・±8°・包み幅の 1/5 以下」「店の印」）をそのまま保持している。現行 `DESIGN.md` §4 は「店の印」を否定し、共通仕様から円環を外しているので、**コメントの参照先と現行 §4 の本文は一致していない**。
