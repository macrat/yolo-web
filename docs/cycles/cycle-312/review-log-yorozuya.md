## MUST（対応しないと決定が誤り）

### MUST-1. 「当サイトは広告で成り立つ」は現時点で事実でない

決定文書は A の否定面（「営む」＝商取引の連想）をこう打ち消している。

> かつ当サイトは広告で成り立つため、「営む」は不正確ですらない。

実装を確認したところ、**サイトに広告は1つも出ていない**。`src/` 配下に `adsbygoogle` / `googlesyndication` / 広告コンポーネントは存在せず、本番 HTML を取得して grep しても 0 件だった。存在するのは `public/ads.txt`（`pub-3422033280057965`）とプライバシーポリシーの記述だけである。つまり現在のサイトは 1 円も稼いでおらず、「広告で成り立つ」は成立していない。

これは決定の根拠に置かれた**裏取り不能／実装と食い違う主張**であり、cycle-312 の完了条件4が両文書から排除しようとしているものそのものである（AP-WF06 / AP-WF12）。削るか、「広告の掲載を前提に運営している（現時点では未掲載）」のように実態どおりに書くこと。なお、この一文を削っても A は選べる（「営む」の否定面は "画面を一つ見れば消える" 側の論拠だけで足りる）。

### MUST-2. cycle-276 の「まだ道具箱」の引用が事実と違う。かつ cycle-276 は権威として使えない

決定文書は B の否定面にこう書く。

> cycle-276 で「まだ道具箱」は実体の狭さの指摘として使われた語である

`docs/` 全体で "まだ道具箱" が出るのは `cycle-276.md:176` の1箇所だけで、その文脈は次のとおり。

> 「自己定義の是正が資する」→ **偽**。サイトの実体（アーキ・デザイン）はまだ道具箱なのに metadata/JSON-LD/about だけ「診断の場」と名乗らせた＝**サイトが自分について嘘をつく状態**を作った。

これは「道具箱という概念が狭い」という指摘ではなく、**ラベルを実体より先に替えたことへの自己批判**である。しかも cycle-276 の来訪者向け変更は**全 revert** され（同 176〜184 行）、その概念判断自体も cycle-278 で白紙から書き直されている。引用は誤りであるうえ、引用元は「確定済みの判断」として使える文書ではない（AP-P34: 過去サイクルの決定を疑えないものとして権威づけない）。

さらに皮肉な点として、この一文が本当に言っているのは「**名乗りを実体より先に替えるな**」であり、それは B を退ける根拠ではなく **A を残す（＝今は替えない）根拠**になる。削除するか、正しい含意で書き直すこと。

### MUST-3. 「来訪者が実際に読んでいる文」という節の見出しが実測と食い違う／論点の所在が誤記

- 節見出しは「**来訪者が実際に読んでいる文（現状）**」だが、リポジトリ内の実測（`cycle-311/visitor-reality.md`）では **トップ `/` は28日で PV 50・検索結果からの直接クリックは 0**、organic セッションの 95.1% は1ページで離脱、クリックの 88.0% は `/play/character-personality` に着地している。トップの名乗りは「来訪者が実際に読んでいる文」ではなく、**ほとんど誰にも読まれていない文**である。見出しを実態に合わせること（決定の向きは変わらないが、**どれだけの重みの判断なのか**が読み手に伝わらないのは害になる。ここを正直に書けば「Aを残す＝来訪者への影響ほぼゼロ」という、この決定の本当の性格が見える）。
- 「論点は、この**3行目**の空欄に何を入れるかに尽きる」は誤り。引用された3行のうち「よろず屋」が入っているのは**2行目**（3行目は AI 明示）。

### MUST-4. 来訪者に見えている自己名乗りは4通りあり、最も広く配られている面は候補Cの言い方で出荷済み

4番目が重い。これは全ページ共通の既定 description であり、**SNS でサイトのトップが共有されたときに画像に焼かれて出る文**でもある。つまり「AI が営む実験室です」という**候補 C の名乗りが、いちばん広く配られる面で現に出荷されている**。決定文書は C を「来訪者を被験者の位置に置く」として退けながら、この面の存在に一度も触れていない。

### MUST-5. 「説明なしにその場の意味へ届くか」は、このままでは判定がぶれる（規則として使えない）

依頼のあった境界事例に、文書に書かれた形のまま当ててみた。

| 語                                                                     | 判定を試みた結果                                                                                                                                                                                   |
| ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **印**（`Tsutsumi`→`In` の `aria-label="印 診"`・SR で読み上げ）       | **落ちる**。音声で「しるし しん」と読まれても意味が立たない。ここは規則が機能する                                                                                                                  |
| **値札**                                                               | **判定不能**。「値札」の辞書的意味（＝値段の札）はそのまま届く。だが届いた意味は**この場では偽**（何も売っていない）。規則は「意味が届くか」しか問わないので、**届くが間違っている語**を素通しする |
| **札**（トップ本文「結果は**札**にして持ち帰れます」＝現に来訪者可視） | **判定不能**。「札」は fuda / さつ の両読みがあり、単独では立たない。しかし右隣に見本画像があるので**文脈では届く**。→ 文脈を数えてよいのか否かで判定が反転する                                    |
| **棚**                                                                 | **判定不能**。辞書的意味（棚）は届くが、指示対象（一覧の区画）は届かない。「その場の意味」がどちらを指すのか文書が定義していない                                                                   |
| **包み**                                                               | 同上。中身は「結果画像」で、包装ではない                                                                                                                                                           |

そして最大の問題は、**文書自身が同じ検査を非対称に使っている**ことである。「よろず屋」の商取引連想については「画面を一つ見れば消える」と**文脈による解決を認め**、「品書き」については「目次なのか値段表なのか判断できない」と**文脈による解決を認めない**。同じ規則を同じように当てれば、品書きも「罫で区切られたリンクの一覧の上に載っている」という文脈で解けてしまう。この非対称のままでは、規則は「PM が残したい語は通り、外したい語は落ちる」装置になる（AP-P02 の留保の選択的適用）。

規則として成立させるには、少なくとも次の3点を規則本文に入れる必要がある。

1. **二段の検査にする**: (a) 説明なしに意味が立つか、(b) 立った意味が**その場で真か**（「値札」は (a) を通り (b) で落ちる）。
2. **文脈を数えるかどうかを明記する**（「同じ画面内に意味を確定させる現物があるならよい」等）。数えるなら、品書きの判定もその基準でやり直すこと。
3. **適用範囲を定義する**。文書は「来訪者の**画面に出す**言葉」と書いているが、`aria-label`・`alt`・`title`・`meta description`・OGP 画像の文字は画面に出ないか、出ても目に見えない。ここを含めないと MUST-6 の実害が規則の外に落ちる。

### MUST-6. 線を引いただけで、現に来訪者へ届いている派生語の処置が決まっていない

決定文書は「**問題は語ではなく派生語を来訪者の画面に持ち込む癖だ**」と正しく言い当てたうえで、「品書きは内部に留める」と書いている。しかし**現状すでに内部に留まっていない**。

- `aria-label="◯◯の品書き"` が **11 箇所**（`page.tsx` 4・`about` 1・`dictionary` 2・`tools` 1・`play` 1・`RelatedArticles` 1・テスト1）。スクリーンリーダー利用者には毎回読み上げられる
- `aria-label="印 診"`（`Tsutsumi`→`In`）
- 画面本文の「**札**」（トップ2箇所・`FudaActions` の「この結果を札として持ち帰る」・OGP の `alt="診断結果の札"`）

`cycle-311/reference-map.md` は来訪者可視の店語彙を **26 箇所 / 10 ファイル**と数え、B-649 として起票済み・**Deferred**（着手条件＝B-651 完了）である。決定文書は B-649 に一言も触れていない。この決定の価値は「線を引いたこと」ではなく「線の向こうにある語を実際に外すこと」でしか来訪者に届かない。**決定文書の「文書へ落とす内容」に、B-649 の扱い（この線で判定し直す・着手条件を満たした）を明記すること。**

なお「判断材料にしなかったもの」に挙がっている**内部識別子（`Shinagaki` 等）と、`aria-label`・`alt`・`meta` は別物**である。前者は来訪者に届かないが後者は届く。今の書き方だと同じ籠に入って見えるので、明示的に切り分けること。

### MUST-7. 候補の並べ方が公平でない（有力候補の欠落・D のストローマン化・A の最大の否定面の欠落）

- **「なんでも屋」が無い**。辞書（ja.wikipedia・国語辞典）で「よろず屋」の第一の言い換えとして挙がる語であり、A の最も近い競合である。これを並べずに A を選ぶのは、比較のふりをした追認になる（AP-P17 は3案以上の列挙を求めるが、**質の伴わない4案**では条件を満たしたことにならない＝AP-WF09）。
- **D が弱い形で立てられている**。D の文を「AIが営む、やってみるサイト。」とすれば直前と重複するのは当然で、D は負けるように書かれている。比喩なしで広さを言う言い方（例: 「ジャンルを問わず、なんでもあります。」）なら重複しない。この形の D と A を比べて初めて「A だけが新しい情報を足す」が言える。
- **A の最大の否定面が書かれていない**。「よろず屋／なんでも屋」には辞書的に「**広く浅く対応するジェネラリスト**」の比喩義がある（ja.wikipedia）。constitution rule 4（量より質）を掲げるサイトが自ら「広く浅い」を含意する語を名乗る点は、A の否定面として最も重い。挙がっている3つ（営む・古風・派生語）より重要である。
- **「説明なしに届く」を否定する材料を探していない**。辞書系の記述では「万屋は現代の一般会話ではあまり使われず、店名・屋号に残る程度」とされ、コンビニに置き換わった語として扱われている。一方、実測上の典型的来訪者は「あなたに最も近いアニメキャラ診断」で来る層（SC クリックの 88%）で、この語が最も通じにくい層と重なる可能性が高い。A を選ぶこと自体は否定しないが、**「説明なしに届く」を無根拠に断定してはいけない**（AP-P32: 観測事実／検証済み結論／未検証の判断を区別する）。「若年層には語として馴染みが薄い可能性があるが、前段の『やってみるサイト』が主メッセージを担うため、届かなくても実害は小さい」といった正直な書き方なら成立する。

### MUST-8. GA4/SC の除外が広すぎ、かつ自分では測定由来の主張を使っている

- 文書は「GA4 の実測値は判断材料にしない」と宣言しながら、B の否定面で「**来訪者最多の面（診断）**を名乗りが取りこぼす」という**測定由来の主張**を使っている。留保の選択的適用（AP-P02）。
- 「コンセプトは測定から導かない」は妥当な規律だが、「**どの面に来訪者がいるか／その文はどれだけ読まれているか**」は概念の導出ではなく**接地**であり、cycle-309/grounding.md も接地には使ってよいとしている。実際、接地を外したせいで MUST-3（トップはほぼ読まれていない）と MUST-4（最も広く配られる面は別の名乗り）を取りこぼしている。除外の線を「概念の選択を測定から導かない」に限定し、「面の重み付けには使う」と書き分けること。

## NICE（改善提案）

- **NICE-1**: 現行 `DESIGN.md` §6 末尾には「凝った言い回しが説明の明瞭さと衝突したら、**明瞭さが勝つ**」という決着規則がある。決定文書は同文を「判定の手がかりを持たない」と評して丸ごと置換する方針だが、この一文は新しい線が判定不能に陥ったとき（MUST-5 の境界事例）の tiebreak として有効である。置換ではなく、新しい線＋この tiebreak の2段で書くことを勧める。
- **NICE-2**: A の肯定面「サイト名の『よろず』と一致し、名前と正体がずれない」は、**この文書自身の線に引っかかる**。来訪者は `yolos.net` を見て「よろず」を読み取らない（/about の「名前の由来」を読んで初めて繋がる）。＝説明なしには届かない。肯定面として使うなら「説明を読んだ人には筋が通る」と限定して書くこと。
- **NICE-3**: 実機で見ると、375px では名乗りが「読むだけのサイトではなく、／やってみるサイト。／AIが営む、よろず屋です。」の3行に割れ、直後に「運営しているのは人ではなくAIです。」が続く。**"AI" が2行連続で出る**（`AIが営む` → `運営しているのは人ではなくAI`）。「一呼吸で読めるか」を問うなら、この重複も検討対象になる（「よろず屋」を残しつつ "AI" を一度にする言い方の余地がある）。文書は折り返し後の見え方を見ていない。
- **NICE-4**: 「`Shinagaki` 109箇所・`Nefuda` 67箇所ほか78ファイル」は cycle-311 の未レビュー調査（`reference-map.md`）由来で、cycle-312 T1 の検証がまだ済んでいない（`Nefuda`=67 は再集計で一致したが、`Shinagaki` は集計条件によって 90〜120 と振れる）。判断材料にしなかった数字であっても、検証前の数値をそのまま載せない（AP-WF06）。件数を書く必要がないなら落とすのが早い。
- **NICE-5**: 決定文書の論拠は「cycle-276 で〜」「cycle-309 で確定済み」という過去サイクル参照に強く依存している。cycle-312 の完了条件2は両文書から「過去 cycle への参照」を1件も残さないことを求めているので、**ここに書いた理由がそのままでは本文へ移せない**。移す段で理由を自立した形（語そのものの性質として）に書き換える必要がある。今のうちに自立形で書いておくと T4/T5 が楽になる。

## 依頼された問いへの回答

**1. この言葉は来た人にどう見えるか／比較は来訪者目線か／抜けている候補はないか**
375px と 1280px の実画面で名乗りを確認した。「読むだけのサイトではなく、やってみるサイト。」で用件は済んでおり、「AIが営む、よろず屋です。」は**添えの一言**として働いている。害は見当たらない（売り物と誤読される心配は、値段も買い物かごも無い画面では実際に起きにくい）。ただし比較は来訪者目線で**十分には**行われていない——最近接の候補「なんでも屋」が無く、D が弱い形で立てられ、A の比喩義（広く浅い）と語の通用度への反証が検討されていない（MUST-7）。

**2. 一言になっているか**
なっている。2文・約30拍で、実機でも破綻なく読める（文節ごとの `inline-block` が効いて折り返しが文節境界で起きることを375pxで確認）。ただし "AI" が隣接2行で重複する点は改善余地（NICE-3）。

**3. そもそも変える必要があったのか**
**残す判断は妥当**と考える。(a) 替えても来訪者価値は動かない（トップは28日で50PV・SERP クリック0）、(b) B は実測で最大の面である診断を取りこぼす、(c) C は最も広く配られる面で既に使われているが「実験」を売りにしない規律（cycle-309 grounding §0.1(4)・一次確認済み）と衝突する、(d) 替えれば内部識別子78ファイルの改名まで連鎖する一方、来訪者側の得は無い。残すべきでない理由として見落とされているのは「広く浅い」の比喩義（MUST-7）だが、これは A を覆すほどではない。**ただし「残す」で決着したことにはならない**——同じ問いが掛かっている metadata / OGP の「実験的Webサイト」を放置したままだから（MUST-4）。

**4. 新しい線は実際に使えるか**
**使えない**。5つの境界事例に当てた結果、判定が下せたのは「印」1件のみで、「値札」「札」「棚」「包み」は判定不能だった。さらに文書自身が A と品書きで検査を非対称に使っている。二段検査化・文脈の扱いの明記・適用範囲（aria-label 等を含むか）の3点を足せば使える規則になる（MUST-5）。

**5. 判断材料から外したものの妥当性**
