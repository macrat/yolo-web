## この経過から確かめられたこと

**スポット修正は、同じ型の欠陥を書き換えた先に生む。** 14巡目の MUST 6件のうち3件、15巡目の MUST 14件のうち少なくとも3件が、**前の巡の修正が作ったもの**である。具体的には——

- `site-concept.md:103` の「この賭けは」は、前巡で長すぎる行を2つに割ったときに先行詞を失った。
- 同 `:52` の「2項を除いて」は、判断基準3 の項の切り方を変えたときに数も語も指し先も壊れた。**他節の箇条を数える形の例外**だったため、他節を触った瞬間に壊れる構造だった。
- 同 `:98` の「機械で判定できる題材を優先する」は、前巡で記述（「機械で決まる題材ほど差が小さい」）を規範（「優先する」）へ書き換えたときに、娯楽を後回しにする読みを許した。

**対策として効いたのは、節を通しで書き直すことである。** 15巡目で `DESIGN.md` §4 の看板の項（409字1行・例外の入れ子）と `site-concept.md` の実験枠（416字・三重の言い直し）を通しで書き直したところ、どちらも**文書の最長行ではなくなった**（324字・328字）。行単位の差し替えを続けていた12〜14巡では、この2行はどの巡でも触られていない。

**「指摘は入力であって指示ではない」は、実際に却下の形で行使した。** 15巡目、`site-concept.md:61` の外部事実の帰属（scaled content abuse）を「doorway abuse の誤り」とする指摘を受けたが、[external-spec-check.md](./external-spec-check.md) に記録した Google の一次資料（AI 最適化ガイド・Last updated 2026-07-10）が本文と同じ帰属を名指ししていたため却下した。レビュアーが引いたのは別ページの定義である。
