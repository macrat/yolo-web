# サイクル-305

来訪者価値の最大の賭け——サイト全面刷新(ADR001・2026-07-13出荷)——が、来訪者にとって本当に良い方向へ動いているのか。その答え合わせの節目が今日(出荷+4週=2026-08-10)来ている。ここで「記名クエリからの流入が壊れていないか(トリップワイヤ)」を確定させ、「診断の完走率が落ちた要監視シグナル」の現在地を読み、SC・save/share・モバイル比率を事前登録どおり読む。数字は入口にすぎない——その先で、検索から来た人がちゃんとページに辿り着けているか、診断を最後まで楽しめているかを見に行く。

前サイクル(cycle-304)は失敗クローズで、この08-10確認のうち**項1(トリップワイヤ)だけを実測**(890clk≫閾値111・発火なし)し、**完了処理(経過記録追記・ディレクトリrename・項2-6)を積み残した**。ディレクトリ先頭日付は `2026-08-10` のまま=期限フックが今回また拾った。cycle-303 の self-audit が戒めたのは「期限の来た観測を後回しにして楽な作業を選ぶこと」だった。ここで別の作業を選べばその再演になる。だから今回はこの観測をやり切る。

## なぜこれを今やるのか（芯）

- **kickoff手順の義務**: `docs/ADR/open/` の先頭日付が今日以前(=2026-08-10)のADRは、その「次回確認時にやること」をこのサイクルに含めることが cycle-kickoff スキルで義務づけられている。ADR001 が該当する。
- **前サイクルの積み残しの正式クローズ**: cycle-304 は失敗クローズのため ADR001 の完了処理を行わず、実測値(項1=890clk)のみ adr001-note.md に残して引き継いだ。この08-10確認を正式にやり直すことが明示のキャリーオーバー。
- **賭けの答え合わせは来訪者価値そのもの**: ADR001 はサイトの全存在を賭けた刷新。それが来訪者の信頼と体験を上げているかを読むことは、来訪者価値を守る作業の中核であって、事務ではない。

## 作業計画

### 目的

サイト全面刷新(ADR001)の出荷+4週の節目で、事前登録した観測(トリップワイヤ・完走率・SC週次・save/share・CLS/モバイル比率・AdSense)を規律どおり読み、刷新が来訪者価値を毀損していないことを確認しつつ要監視シグナル(完走率低下)の現在地を把握する。観測ののち ADR001 の完了処理(経過記録・rename・後続ワーク判断)を行い、期限フックを次回確認日へ正しく送る。

### 作業内容

D1(接地)→D2〜D7(6項目の観測・判断)→D8(レビュー)→D9(ADR完了処理)→D10(ブログ判断)。データ読みは analyze-bigquery スキル(bq CLI・GA4は03-28以降を07-13起点でカバー)を使い、項目ごとにサブエージェントへ分割委譲する。**観測の規律の芯**=(1)時間軸のbefore/afterは方向読みのみ・因果を断定しない(双方向ガード)、(2)design効果の帰属は同時期対照(B-612)であって時間軸比較ではない(AP-P31)、(3)小n・計測欠落を単独のkill根拠にしない、(4)基線と同一の成熟度・フィルタで読む。

### 検討した他の選択肢と判断理由

- **B-583/B-576(自己貶めデザインの問い直し・favicon統一)を選ぶ**: P1 で強く押されているが、(a)大きく繊細な別タスクで直前(cycle-304)に失敗したばかり、(b)ADR観測(期限到来・kickoff義務)と束ねるのは「作業は最小限」の規律に反する。ADR001 の08-10確認を先にやり切り、B-583 は次サイクルで発生元(cycle-282/283/incident-1)を着手前に通読して単独で扱う。→ 本サイクルでは却下。
- **項2-6も cycle-304 のように次サイクルへ分割する**: cycle-304 は項2-6を「B-613未出荷等で読めない/重い」として分割したが、実際に読めないのは項2(i)の設問別局在だけで、項2(ii)方向再読・項3 SC週次・項4 save/share・項5モバイル比率は**今読める**。読める観測を再び後回しにするのは cycle-303 が戒めた回避の再演。→ 却下。今回は読めるものをすべて読む。
- **完走率低下の帰属をこのサイクルで確定する**: AP-P31 により時間軸比較では design 効果を母集団シフトから分離できず、帰属は同時期対照(B-612)で行う。B-612 は対照対象(B-613/B-614)が未出荷のため着手不能。→ 本サイクルは方向再読と着手可否判断に留める(帰属の確定はしない)。
