## §1 タイプ定義の復元（結果本文からの帰納・発明なし）と弁別診断

8タイプの `description`/`traits`/`behaviors` を通読し、行動的定義を復元した（典拠は各 result 本文）:

| typeId           | 四字熟語 | 復元した行動的定義（本文根拠）                                                                                    |
| ---------------- | -------- | ----------------------------------------------------------------------------------------------------------------- |
| elegant-precise  | 一字千金 | 言葉を**削ぎ落とす**。少ない語で多くを届ける。「何を言わない**か**」を選び、一語で言い切る／要約する。            |
| warm-empathy     | 和顔愛語 | 相手の感情を読み、**安心できる言葉**を差し出す。共感を先に、語尾・絵文字の温度を調整。                            |
| creative-playful | 奇想天外 | 予想を裏切る**比喩・造語**。正確さより**面白さ/新しさ**。言葉で遊ぶ。                                             |
| logical-clear    | 理路整然 | 複雑を**整理**。結論→理由→具体例。曖昧を嫌う。※本文明記「短さではなく“迷子にさせない設計”」＝**簡潔さとは別物**。 |
| poetic-sensory   | 花鳥風月 | **五感描写**で景色を浮かべる。感情を感覚イメージへ変換。※本文明記「奇想天外と違い**実在の感覚に根ざす**」。       |
| bold-impact      | 疾風迅雷 | 短く**魂のこもった一言**で人を動かす。**断言・熱量**。                                                            |
| humor-wit        | 抱腹絶倒 | **笑い**を生む。ボケ・タイミング・緊張をほどく。                                                                  |
| gentle-indirect  | 柔和温順 | **角を立てない/間接**。クッション言葉、言い切らない、断らない。                                                   |

**弁別診断（重要な結論）**: 8タイプは本文上**相互に弁別可能**で、定義が重なって同点を必然化する対は**無い**。ただし意味的に**隣接**する3対がある: **creative↔humor**（新奇 vs 笑い）・**warm↔gentle**（直接的共感 vs 間接的軟化）・**elegant↔logical**（簡潔 vs 構造）。本文はいずれも明示的に線を引いている（例: 花鳥風月「奇想天外と違い実在の感覚」、理路整然「短さではない」）。**つまり同点27.79%はタイプ定義の欠陥ではなく、設問・配点が“隣接だが別物”を分離できていない欠陥**である。これが結果先行テーゼの裏づけ（タイプは健全・設問側が不全）。

## §2 なぜ27.79%も同点が出るか（悉皆で特定した構造的根）

現配点「主2点＋副1点」の**副点が固定的な“影(shadow)”結合**を作っている。悉皆で同点の型対を分解した実測:

- **crea↔humor = 全同点の21.7%**: crea主の選択肢は必ずhumor副、humor主は必ずcrea副（Q1,3,4,5,6,7,8,9,10 で相互）。**両者は常に連動し分離しない**。
- **warm↔gentle = 16.6%**: 同様に相互副点で連動。
- **eleg↔log = 10.0%**: **log主の5選択肢すべてがeleg副**。log(+2)は毎回eleg(+1)を相乗り→logはelegを構造上追い越せない（理論最大 log11 vs eleg15）。bold・poetも同型に eleg/warm を養う「影」。

副点供給の非対称（eleg=8…bold=2）は症状で、**病根は「固定した主→副の対結合」**。これが (a) 特定対の恒常同点と (b) 出現6.15倍（影に養われる eleg/warm が太り、影である log/bold/poet が痩せる）を同時に生む。

## §3 結果先行の再設計

### 判定機構（共有関数は不変）

各設問の4択を**各1タイプの純粋な声（single-signal）**にする。回答は1タイプへの投票。判定は既存の最高得点勝者（`determineResult`）。**副点（影結合）を廃止**することが病根の除去そのもの。

### 反同点配点（cycle-295 の手法を8フラット型へ適用）

問ごとに**相異なる重み W_q** を与える（回答者には不可視の解像度装置。意味は「どのタイプの声か」が担う）。悉皆探索で、各タイプの上限（=所属5問の重み和）が均衡し整数同点が稀になる重みを選ぶ。**重みは判別の代わりではなく、判別する設問の上に乗る解像度装置**（single-signal 化と incidence 改修が判別の本体）。

**測定した存在証明 V1**（incidence は現物のタイプ配置を保持、`W=[49,36,70,67,32,46,65,68,45,53]`, 各選択肢 `{その型: W_q}` のみ）:

| 指標                 | 現行    | V1（実測・悉皆）                        |
| -------------------- | ------- | --------------------------------------- |
| 同点依存(恣意決着率) | 27.79%  | **0.833%**（2択同点のみ・3択以上0.00%） |
| 出現 最大/最小       | 6.15倍  | **1.29倍**                              |
| dead型(G2)           | 0       | **0**                                   |
| G1 理想回答者 strict | 8/8     | **8/8**                                 |
| 先頭偏り(最大)       | +6.11pt | **+0.14pt**                             |

### 「既存設問固定で配点だけ振り直す壊れた枠」ではない根拠（cycle-295 準拠）

1. **結果先行で検証**: タイプを本文から定義→隣接3対を同定→**悉皆G1=8/8で「各タイプが正直回答者に strict 単独で届く＝設問が全8を判別する」ことを確認**した（cycle-295 が要求した結果先行の検算）。
2. **機構的除去であって微調整でない**: 病根（固定副点結合）を**廃止**する。数値を撫でるのではなく同点を生む構造を消す。
3. **word-sense の最高得点フラット機構は壊れていない**（軸構造・同型・dead が無い＝cycle-295 の character-personality と病巣が違う）。ゆえに正しい結果先行の是正は**まさに判別設計＝どの選択肢がどの型の声か／どれだけ強く効くか**にあり、それが変わる。

### incidence（同時出題）の精緻化＝結果先行の主眼

残余同点の実測は **warm|gentle 16.1%** が首位で、これは warm/gentle が**全10問で1問しか直接対決していない**（crea/humor も1問のみ）ことに対応。**隣接3対の直接対決を1→2問以上に増やす incidence 改修**を推奨（純粋な判別力向上であり数値合わせではない）。builder は §1 の定義に照らして各選択肢文が**単一タイプの声**になるよう監査・必要箇所を書き直し、incidence 確定後に重み探索を再実行して最終 W を凍結する。

### 凍結するゲート（数値を見てから物差しを動かさない）

- **G1 到達性(hard)**: 各タイプが各設問 T-argmax の正直回答ベストケースで strict 単独勝者。**8/8**。（既存 reachability.test の理想回答者ガードがそのまま担保）
- **G2 悉皆到達(hard)**: 4^10 悉皆で dead=0。（既存悉皆ガードが担保）
- **G-恣意(主指標・hard)**: 恣意決着率（回答由来の規準を尽くしてなお結果が一意に定まらない回答の割合）**≤5%** を凍結（cycle-295 G5 の踏襲）。**目標 ≤2%／実測 0.833%**。→ 悉皆の同点依存率アサーションを回帰テスト化することを推奨。
- **出現バランス(soft)**: 極端に痩せる/太る型が無いこと（**均一化は目的化しない**＝cycle-295 G4c 撤回に従う。一様フロアは課さない）。目安 最大/最小 ≤2.0／実測 1.29。

## §4 保持する制約（点検済み）

- **typeId・title 不変**（資産）→ 相性36エントリのキー・結果ページ・OGP・SEO は**すべて typeId 参照ゆえ無波及**。detailedContent/description/FAQ の typeId→本文対応も不変（磨きは B-606 後続）。
- **共有 `determineResult` 不変**（最高得点勝者のまま）。是正は `choice.points` と設問/選択肢文のみ。
- **QuizContainer.tsx の分岐は変えない＝word-sense は汎用経路のまま**。判断理由: 再設計後は恣意決着が0.83%まで落ち、残余の配列順フォールバックの先頭偏りは**+0.14pt**（現+6.11pt）と無害。専用判定を足す複雑化・共有関数改変を避け、「1診断ずつ(cycle-297)」「共有タイブレーク差し替えはやらない(壊れた枠)」を尊守。
- **決定性/再現性**: 同一回答→同一得点→同一勝者（残余同点も既存の決定的規則）。シェア/再受験で再現。
- 他9診断への波及なし（共有関数不変・word-sense のデータ局所変更）。

## §5 未解決の論点

- **incidence 改修の範囲**: 隣接3対の直接対決増加のため一部設問のタイプ配置を組み替えるか、現配置維持で選択肢文の純化に留めるか（前者の方が判別力は上がるが設問文の書き直し量が増える）。builder/PM 判断。
- **最終 W の凍結**: incidence 確定後に悉皆探索で再導出（探索は決定的シードで再現可能）。凍結するのは**ゲート**であって特定 W ではない。
- **副点を完全廃止するか、影を作らない範囲で軽い副点を残すか**: 純 single-signal は影ゼロを証明可能なので第一推奨。副点を残す場合は「固定対結合を作らない」ことを悉皆で反証する必要（本サイクルでは不要）。
