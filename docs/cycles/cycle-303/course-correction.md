# cycle-303 方向転換: 「タイブレーク」は壊れた枠だった（オーナー指摘・P1 差し戻し）

## 何が起きたか

P1 の設計（[design.md](./design.md) §4）は **案①＝公正タイブレーク**（配列順を判定から除き、主選択回数→対称ハッシュで同点を決着）を採用した。2名のレビュアーは実測を再現し方向を支持した。

その直後、オーナーが指摘した——**「タイブレークという言葉が出た時点ですでに破綻している」という教訓があったはず**。

## 教訓の原典（このプロジェクトが過去に自分で書いた記録）

`docs/cycles/cycle-294/incident-2.md`（cycle-295 が「教訓の原典」として引く）:

- §1「なぜ『タイブレーク』という語が出たのか」（逐語要点）: 「正しい性格診断は、先に性格タイプが在り、そこへ正しく判別するために設問を設計する。設問が判別できていれば同点（タイブレーク）はほとんど生じない。『タイブレーク』が要るのは、設問を先に作り、点数最大のタイプに当て、ぶつかったら適当に決めるという後付けの割り振りをした場合だけである。**36% も同点が出ること自体が設問設計の不全の証拠。**…B-589 の本当の問いは『タイブレークの是正』ではなく、**タイプの定義と、そこへ振り分ける設問設計が成立しているか**である。」
- §7 学び（逐語）: 「診断は『タイプが先、設問がそこへ判別する』設計。**『タイブレーク』という語が中心に来た時点で、後付け割り振りの壊れた枠に入っている。**」

## なぜ案①は誤りか

- タイブレークを「公正」にしても、**同点の 27.79% の来訪者の結果は依然として答えではなくハッシュ（または主選択回数）で決まる**。診断が診断していない状態は変わらない。「公正な決着」は、壊れた枠の内側での上澄みにすぎない。
- **27.79% という高い同点率は、それ自体が設問設計の不全の証拠**であって、決着ロジックで裁く対象ではない。裁くのではなく、生じないように設問を設計するのが本筋。

## わたしがした、より深い誤り（機械の問いへのすり替え）

design.md §3 は案③（結果先行の再設計）を「**word-sense に dead type が無いので案③の主動機（到達性回復）が欠落**」として退けた。これは cycle-294/incident-2 §0・§1 が名指しした**価値の問いを機械の問いにすり替える**行為そのもの:

- **価値の問い**（本来）: この診断は、来訪者の回答がその人の結果を決めているか。
- **機械の問い**（すり替え先）: 到達不能タイプ（dead）があるか。

「実害＝dead の有無」と狭く定義すれば「dead=0 だから案③不要」と結論でき、サイクルを安く閉じられる。これは AP-P02（作業を終わらせられる方向で検証を止める）を実害の定義そのものに適用した cycle-294 の再演。**dead が無くても、27.79% の来訪者の結果が答えで決まっていないなら、診断は診断していない**——これが是正すべき実害。

## アンチパターン点検（CLAUDE.md「Check anti-patterns on failure」）

- **既存の AP が覆っている**: AP-P09・AP-P12・AP-P25（価値の問いを機械の問いにすり替える／機械として受け入れ可能かで判断する）＝ `docs/anti-patterns/planning.md` の cycle-294 追記。加えて cycle-294/incident-2 §7 の「タイブレーク語が中心＝壊れた枠」。
- **なぜバイパスされたか**: PM（わたし）が planner への指示で、選択肢を「案①公正タイブレーク／案②開示UX／案③再設計」と並べ、**「比例した1案を選べ」という機械的な選択問題に枠づけた**。この枠が「タイブレークで安く閉じる」答えを許した。triage 自身が「本筋はタイブレーク差し替えでなく結果先行の再設計」と明記していたのに、それを「dead=0 だから」で上書きした。**新 AP は追加しない**（既存で覆われている）。守れなかったのはわたしであってルールではない。

## 差し替え後の芯

**word-sense-personality を、結果先行で再設計する。** タイプ（8種）が先に在り、10問の設問がそこへ判別する。**同点が設計上ほとんど生じない**よう、タイプ定義（結果本文から復元）と設問・配点を設計し直す。成功の指標は「タイブレークを公正にしたか」ではなく「来訪者の回答が結果を決めているか＝恣意決着率が設計で低く落ちるか」。

- 保持する資産: typeId・title（改名しない）。
- 参照する方法論: cycle-295 の結果先行再設計（G1 到達性・G2 悉皆到達・G5 恣意決着率・反同点配点）。ただし word-sense は8フラット型で character-personality の6アーキタイプ×同型構造を持たないため、ゲート集合は単純化される（同型フロア G4c の三すくみは無い）。機械的流用でなく方法論として。
- **design.md §4（案①採用）は破棄。** §1・§2 の実測（構造・同点27.79%・出現6.15倍・副点非対称）は、欠陥の実在を示す有効な証拠として残す。§3 の案②は将来候補として §6 の扱いを維持。

## 比例性について（先回りの自己点検）

「PV53 に結果先行の再設計は過大」という比例性の論法は、**それ自体が cycle-294 が退けた罠**（コスト・規模を理由に劣位UXを選ぶ＝CLAUDE.md 決定原則違反、かつ機械の問いへのすり替え）。constitution の唯一の基準は来訪者価値で、Rule 4 は every aspect の最高品質を求める。word-sense は実測で診断内トラフィック2位。**規模を理由に本筋を避けない。** ただし cycle-295 の「1診断ずつ・最小サイクル」に従い、対象は word-sense 1本に限る。

## 第2ラウンド（結果先行再設計 V1）のレビュー結果と PM 裁定（2026-08-09）

redesign.md の V1（純 single-signal ＋ 問ごと反同点重み W）を2名が独立検証し、**両者が同じ核心に到達した**（review-log.md「再設計・技術検証節」「再設計・判断/整合検証節」）。

### 判明した核心（V1 も破棄）

- **R1（高）**: 重み W は「判別する設問の上に乗る解像度」ではなく**同点を消している本体**。等重み（設問だけの判別）だと同点 **43.28%**＝現状27.79%より悪化。0.833% は設問内容と無関係な調律済み W が単独で達成。**「タイブレーク」の語を避けて、位置→設問重みへ決着規準を移した同型の壊れた枠**。cycle-295 は重みが二層目 score に効き一層目の整数 count が判別を担っていたが、word-sense には下層の整数判別が無く重み付き和が一次得点そのもの＝「cycle-295 準拠」の擁護は構造差を伏せている。
- **R2（中〜高）**: 「incidence 改修＝判別の主眼」と言いながら V1 は現 incidence 据え置きで、判別が本体であることを一度も実測していない。
- **R3（中）**: single-signal 化（副点全廃）はむしろ判別を捨てている（副点は正味で同点を15.5pt減らしていた）。病根は副点そのものでなく**固定した隣接対の主→副結合**に限定。非隣接副点には意味的 nuance が実在。
- R4/R5（低）: builder 申し送りの境界条件・字句の不正確（3択以上同点30件など）。

### PM 裁定 — 真の成功指標を置き直す

**成功指標は「同点率 ≤5%」ではない。「設問が内容から8タイプを判別しているか」である。** 調律重みで数字を作ることを禁じる。次の制約で再々設計する（P1c 差し戻し → P1c'）:

1. **内容に接地しない同点最小化の重み探索を使わない。** 配点は必ずタイプの意味（その選択肢がどのタイプの声か・どれだけ強いか）から導く。
2. **判別は設問の内容で上げる**: (a) 各選択肢文が明確に単一タイプの声になるよう純化、(b) 隣接3対（crea↔humor・warm↔gentle・eleg↔log）を直接対決させる incidence 改修。**改修後、意味に接地した配点での同点率を実測して正直に報告する**（目標値に向けて重みを撫でない）。
3. **副点は捨てず、意味で設計し直す**: 固定隣接対の影結合を廃し、各選択肢の副signalを**内容上の部分的類似から**与える（数合わせでなく nuance）。R3 の指摘どおり、これは判別を助ける。
4. **真に残る同点（本当に2タイプの間にいる人）は、恣意的に割らず正直に開示する**（「あなたは X 型寄り、Y 型の要素も強い」）。開示の重さ（結果面の改修範囲）は残余同点率を実測してから比例で決める。**同点を隠すために重みを調律しない。**

この裁定の含意: **10問4択で8フラット型を完全に無同点化できないなら、それは正直に受け入れる**（少数の真の同点は開示する）。壊れた枠は「同点が出ること」ではなく「同点を恣意的に・不可視に割ること」。前者は設計の誠実な限界、後者が病。
