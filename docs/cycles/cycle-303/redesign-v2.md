## A. 選択肢の意味監査と内容接地の配点再設計

### A-1. 現状監査の要点（redesign.md §1 の8タイプ定義に照らして）

現状の全40択は「主2＋副1」で、副が**固定影結合**（crea↔humor・warm↔gentle が相互に、log/bold/poet が eleg/warm に常時相乗り）。これが (a) 隣接対の恒常同点と (b) 出現6.15倍を同時に生む病根（redesign §2 を悉皆で再確認）。muddy な例: 現 Q1-a は eleg2+log1 だが「要点だけ短く整理」は log の声も強く eleg/log が割れて聞こえる。→ V2 では固定影結合を**全廃**し、副点は各選択肢が**内容上その副タイプの性質を実際に帯びるときだけ**、意味的近傍から与える。

### A-2. 配点原則（調律禁止・意味からのみ導出）

- **主signal**: その選択肢の明確なタイプに、**強度**で 2 または 3。
  - **3（pure）**= 純度が高く、他タイプの声を帯びない emphatic な単一voice（例: bold「好きです。付き合ってください」）。副点なし。
  - **2（blended）**= 主タイプが明確だが、内容上もう一つのタイプの性質を部分的に帯びる。→ その近傍タイプに**副1**。
- **副signal**は「意味的近傍」からのみ（下記）、かつ**固定対結合を作らない**（crea を常に humor に相乗りさせない等）。副点の宛先は、各型が等しく勝てるよう（balance＝soft目標）近傍集合の中で選ぶ。**副の無い選択肢（pure）が全40中17ある**（当初「18」は誤り・V-4）。
- 意味的近傍（redesign.md §1 定義から）: E↔{L,B} / W↔{G,P} / C↔{H,P} / L↔{E} / P↔{W,C} / B↔{E,W} / H↔{C} / G↔{W,P}

## B. incidence（同時出題）改修＝判別の主眼

### B-1. 新 incidence 構成（各型5回・隣接3対を各3問で直接対決）

型番号 E0 W1 C2 L3 P4 B5 H6 G7。各Qの4択が担う型:

```

Q2: E,L,C,H   (EL + CH 対決)
Q3: W,G,C,H   (WG + CH 対決)
```

隣接対の直接対決回数: **EL=3, WG=3, CH=3**（現状 EL=2, WG=1, CH=1）。各型出題回数=5。dead=0・G1=8/8を悉皆確認済み。

### B-2. incidence 改修の効果（実測・R1/R2 に正直に応答）

- **単一signal（主2のみ）の同点率は incidence を変えても動かない**: 現 incidence 43.28% → 新 incidence 42.83%。→ **「判別が本体・重みは解像度」という V1 の自己記述は誤り**だった。設問だけ（等重み）では約43%同点は構造的で、incidence 改修**単独では総同点率をほとんど下げない**。これを正直に開示する（review R1）。
- **incidence 改修の真の効果は "紛らわしい隣接対の同点を潰す" こと**（＝判別の質）: 単一signalでも、新 incidence では同点トップ対が隣接対（EL/WG/CH）から**非隣接の別物対**（EH, WB, PG, CL…）へ移る。V2 最終配点では crea\|humor が首位同点対から陥落する（**全同点比 21.73%→9.71%＝約2.2倍／全回答比 6.04%→2.08%＝約2.9倍**。当初「10倍」と書いたのは分母不一致の誇張で撤回・V-1）。**紛らわしい隣接対を人が選択で分離できるようにする**のが incidence 改修の本質で、これは数値合わせでなく判別力の向上。
- **総同点率の低下（27.79%→21.39%）は nuance 副点＋強度による granularity**の産物であり、重み調律ではない（すべて意味接地）。

> 正直な位置づけ: 「10問4択8型・整数投票では総同点は構造的に残る（下限 ~21%）。incidence 改修は総数でなく "どの型同士が同点になるか" を是正し、判別できない隣接対の同点を判別できる別物対の thin な同点へ置き換える。残余は C で開示。」

## C. 真の残余同点の正直な開示（案②の最小実装）

### C-1. 実測した残余（開示の重さを比例で決める根拠）

- 総同点率 **21.39%**（2型同点 16.40%・3型以上 4.99%）。約**5人に1人**が最大得点を2型以上で分け合う。
- ばらけ方: トップでも CH 2.08%・CP 1.99%・EB 1.56%…と**薄く分散**。特定対に偏らない＝「判別失敗の集中同点」ではなく「本当に2つの声を等しく持つ人」。

### C-2. 開示方針（比例＝"見える一ブロック"。dual-typeId アーキ改変はしない）

21% は無視できないが、**typeId を2つに増やす構造改変は過大**。最小かつ誠実な実装:

1. **主タイプは従来どおり決定的に1つ**（`determineResult` の配列順勝者＝再受験/シェア再現性を保つ）。**ただし同点時は "隠して配列順で割る" のをやめ、副タイプを併記**する。
2. 受検者本人の `ResultCard`（`/play/word-sense-personality` インライン）に、同点時のみ**開示ブロック**を表示。**真の同点は同格として提示する**（「主に X」と上下をつけない。X>Y を暗示しないコピーにする＝レビュー指摘の誠実性要件）。3型同点なら同格3つを列挙。
3. **単独勝者（78.6%）には一切出さない**（従来体験そのまま）。

### C-3. 波及点検と最小改修範囲（単一 typeId 前提の資産は不変）
