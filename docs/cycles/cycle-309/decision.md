## 判定レンズ（grounding.md §0・§0.1・constitution）

## E0（概念レベル・§0.1(2)）: 「よろず屋」を概念に置くか → **平明な言葉としての orientation は keep・店の signifier cosplay は remove**

**立証（visitor value から）**: yolos.net は実際に雑多（性格診断・辞典・道具・あそび）。初訪の検索者は「これは何のサイトか・なぜ散らばっているのか・信頼できるか」で迷う。

- **「よろず屋」は一般に通じる日本語**（＝あらゆるものを扱う店）。これを**平明な言葉として**「AIが営む、よろず屋です」と使うと、来訪者は private な符牒を解読せずに「AI が営む、いろいろある場所」と理解でき、**雑多さが『意図された品揃え』として腑に落ちる**——これは orientation の実価値（§0.1(3) を満たす＝一般語で伝わる）。→ **概念としての「よろず屋」は、平明な一般語 orientation としてのみ keep**。ただし語一つに載せきらず、具体（何があるか）と対で置く。
- **しかし店の signifier cosplay**（印を店の朱肉印として顔に・content を「品書き」・AI を「店主」・のれん/店構え/札の来訪者向け語）は、**来訪者が解読する前提**に立っており §0.1(3) に反する（伝わらない・価値を落とす）。→ **remove/reframe**。
- 結論: **orientation のアイデア（AI が営む・いろいろ・その場でためせる）を平明な言葉で keep、店 theming の signifier を remove**。以下 E1〜E3 はこの概念判断の各面への適用。

## E1（charter a・b）: OGP 看板の店の意匠 → **印を外す（remove）・構造は残す（keep）・全面主張の統一は不要（demote）**

**実物で見えたこと**:

- **V2（素）は匿名の未完成カードに見える**。枠も見出しの店号も無く、AI スロップサイトが吐く既定 OG カードに近い。→ 構造的な枠（2px 罫＋上部の店号＋一本罫）を全部剥ぐのは来訪者価値上マイナス（Rule4 の「手入れされた佇まい」を失う）。
- ただし**その枠は、来訪者の目には「和風商店ののれん」ではなく、ただの整ったマストヘッド／囲みとして映る**。つまり「店構え＝店の押し付け」ではなく、品質と識別を伝える普通の編集構造。内部名「のれん／店構え」は開発語彙で、来訪者が受け取るのは「良い見出し」。→ **構造は keep**（店の押し付けではなく Rule4 の品質・識別に効く）。
- **朱の hanko 印（V0）は、1200×630 のシェアでは「店の朱肉印」とはほぼ読めず「赤いロゴバッジ」として映る**。だがこのカードは既に「yolos.net」を**のれん帯と大見出しで二度名乗っており、印は識別として冗長**。V0/V1 を並べると **V1（印なし）の方が静かで整って見える**（DESIGN 自身の原則「信頼は引き算・器を派手にしない」＝constitution Rule2/4 由来と一致）。加えてこの印こそオーナーが一次ログで名指しした「OGP の店ブランディング／印」。→ **OGP の印は remove**（識別は店号が担い、印は冗長な装飾＝引き算する）。

**決定**:

- **(a) 店を全面主張する統一は不要**。静かな一貫性（マストヘッド＋正直な品名／説明）で足り、その方が来訪者に整って・信頼できるものとして届く。DESIGN.md の「店構え＝唯一の視覚規範／全面主張」の格を降ろす（脱正典化）。
- **(b) OGP 看板の朱印は remove**。共有レンダラ `createOgpImageResponse` から印を外す（約60ルート一括で静かになる）。品名・説明・店号（マストヘッド）は残す。
- 立証の担保: V1（印を外した実物）を実際にレンダーして V0 と並べ、V1 が来訪者価値上まさっていることを確認して決めた（撤去版を作らずに決めていない＝308 の失敗を犯していない）。

## E2（charter b）: favicon の印 → **マークは残す（keep）・「店の印」の物語は外す（reframe）**

**実物で見えたこと**（`fav-cur-{16,32,48}.png`）:

- **16px**: 赤い塊に薄い印。y も角丸(hanko)も判別不能——ただの小さな赤アイコン。
- **32/48px**: 赤い角丸バッジに白い明朝 y。**「朱肉の店の印」ではなく現代的な角丸アプリアイコンに読める**。「店の印/hanko」という意味は、**検索結果に出るこのサイズでは来訪者に一切届かない**。

**決定**:

- **favicon のマーク（赤い角丸＋白 y）は keep**。favicon は検索結果に出る面（実トラフィックの大半が通る）で、16px では店号を置けず**この赤いマークだけが唯一の識別**。明確な色面のマークは小サイズでの認識に効く（Google の favicon ガイダンス＝ブランドを視覚表現する認識可能なマークを推奨）。バラの細い明朝一字より認識性が高い。→ 認識という来訪者価値で keep。
  - 立証の限界（silent cap にしない）: 「容器を外した素の y」の実寸ラスタは、この環境の convert にフォント／librsvg 委譲が無く描けなかった（空 PNG になった）。ただし結論（赤い色面マークの方が 16px で認識しやすい）は現行レンダーの実見と Google ガイダンスで立つ。実寸の別版比較は未実施と明記する。
- **「店の印／hanko／店の顔」という物語（DESIGN.md §4・コード内コメント）は外す（reframe→「識別マーク／identity mark」）**。来訪者にはこのサイズで「店の印」が知覚されず、**押し付けも助けも起きていない**（空回りの内部語彙）。この物語こそが「どの字か（試/屋/y）・どの形か（円/角丸）」の6サイクルの churn と「試」の自己貶めを生んだ発生源。マークは「認識のための識別標章」として据え、店を体現させる役目は負わせない。
- **(b) の答え**: 「印（店の朱肉印）」としては不要（favicon で知覚されず・OGP で冗長）。「識別マーク」としては favicon で必要（認識）。＝**店の印を外し、識別マークとして最小限を残す。**

## E3（charter d）: 名乗り・about のコピー → **店の押し付けを外す（change）・自己定義は残す（keep）**

**両版の読み比べ**（実文面）:

- **トップ名乗り**:
  - 現行: 「AIが営む、よろず屋です。／**店主**は人ではなくAIです。実験として営んでいるので、内容に誤りがあるかもしれません。」
  - 素案: 「AIが営む、よろず屋です。／**運営しているのは**人ではなくAIです。実験なので、内容に誤りがあるかもしれません。」
  - 判断: 「AIが営む、よろず屋です」は **E0 の平明な一般語 orientation として keep**（「よろず屋」は一般に通じる語で、来訪者は解読せず「AI が営むいろいろある場所」と理解できる・§0.1(3)）。「**店主**」は「店」という枠を来訪者が受け入れる前提の literal な押し付け（§0.1(3) に反する）→ 「運営しているのは」に change（Rule3 の「運営は人でなく AI」という正直の開示はむしろ明確に保つ＝§0.1(4)・footer が詳細注記を常時持つ）。
- **about 見出し下**:
  - 現行: 「**店の品書き**は、大きく四つです。」
  - 素案: 「ここにあるものは、大きく四つです。」
  - 判断: 「店の品書き」は店の literal な押し付け＋site-concept ガード「凝った言い回しより明瞭さ」に反する→ 平明に change。about「名前の由来」節は既に「よろず＝万事・あらゆるもの」と正しく述べ由来を偽っていない（(c) 是正済）ので触らない。

**決定**: 上記2箇所を change（店主→運営者・店の品書き→平明）。**(d) の答え**: 「よろず屋」は平明な一般語 orientation として立証できる（E0）が、「店主／店の品書き」は「店」の枠を来訪者が受け入れる前提の literal な押し付けで、平明さより符牒が勝った表現＝§0.1(3) 違反・来訪者価値を落とす→外す。

## 射程外（follow-up として記録・本サイクルで無闇に広げない）

- **「品書き」aria-label（SR 可視・複数面）**: 「店の」を伴わない「品書き」は店の押し付けとしては弱く、site-concept／DESIGN §6 が「来訪者が誤解しない範囲の店の語彙は可」と許容する範囲。ただし SR 明瞭さの観点で見直す価値はある→ **follow-up 起票**（同じ立証レンズで別サイクル）。本サイクルは primary copy の明確な literal push 2箇所に絞る。
- **コンポーネント名・コードコメントの店語彙（Shinagaki/Tsutsumi/Nefuda/In・「棚/値札/包み」）**: 来訪者不可視＝射程外（churn になるだけ）。ただし DESIGN.md の視覚規範としての「店構え＝唯一の規範」格下げに合わせ、コメントが「店の印/店の顔」と**来訪者向けの主張**を騙る箇所のみ識別マーク表現へ是正（E1/E2 の実装で扱う）。
- **内容 fuda 印（fuda-image.tsx の 診/色 等の内容一字）**: identity の店の印とは別カテゴリ（結果札の「見せたくなる結果」の内容標章・DESIGN §4/§7）。本サイクルの identity 店メタファーの射程外。

## B-576 の扱い（P6）

E1/E2 の決定＝「favicon のマークは識別標章として keep（塗り替え不要・現行で認識価値を満たす）／OGP の印は remove（作り直しでなく除去）」。**B-576（favicon/OGP を新デザインに作り直す）は、作り直すべき新 identity が生じないため不要＝解消**。根拠は露出（308 の撤回済み理由）でなく、立証で「マークは現行のままブランド識別として機能し、店の印の物語だけを外す」と決めたこと。→ B-576 Done（decision 由来）。
