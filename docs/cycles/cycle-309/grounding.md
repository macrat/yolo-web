## §0.1 立証の基準（研ぎ澄まし・4点）

1. **由来は不変**: yolos.net の由来は「YOLO×よろず」の二重の意味。これは疑わない不変の事実。
2. **「よろず屋」の概念を置くか外すかは PM 判断。ただし keep も remove も『来訪者価値を最高にする』論理的立証の責務を負う。** 「オーナーが許容したから」「暖かいから」は justification にならない——**採否どちらも visitor value からの立証で決める**（§0 当初版が「オーナー許容だから keep」と書いたのは誤り・是正）。
3. **独自用語・signifier（店/屋/札/品書き/店構え/印）が来訪者に自明に伝わると仮定してはならない。** 「『店』と書けば来訪者は即座によろず屋概念を理解する」「『屋』一字で yolos.net を連想する」「『札/品書き/店構え』は説明不要で伝わる」とでも考えるかのようなサイトづくりは、**明白に来訪者価値を落とす判断**。keep するなら「来訪者が実際に平明に理解できる（＝一般に通じる言葉）／認識できる（＝反復露出で識別できるマーク）」ことで立証する。伝わらない signifier は外す。
4. **「試作サイトである／いろいろ試している」ことに来訪者が価値を見出す前提は禁**（constitution 違反）。試しているのは PM（運営）であって来訪者ではない——これは PM 都合の押し付け。**Rule3 の AI 明示は「正直の開示」であって価値の売り込みではない**。「実験/やってみる」を identity の売りにしない（来訪者の価値は、その場で得られる具体的な結果・成果物・体験そのもの）。

> なお本節の是正の義務の源は constitution と一次資料の記録であって、オーナーの発言ではない（AP-WF24）。オーナーは前提の取り違え・立証基準の緩さを指差したにすぎず、立証を visitor value から立て直すのはルールが求めるもの。

## §4. コンセプト/constitution からの導出（P2）

> **⚠ cycle-310 supersession 注記（識別マークの分類の上書き）**: 下記「顔の仕事」で「店の朱肉印・のれん等の**符牒**に識別を依存させない」「店 theming の signifier は remove/reframe」と書いた——ここで remove/reframe の対象に暗に含めていた**朱の y 角丸標章（favicon/OGP のマーク）は、cycle-310 の再立証で分類が上書きされた**。E2/E1（cycle-309 decision E2・cycle-310 decision E1）が実物レンダー比較で、このマークは「符牒（店の朱肉印として意味を解読させるもの）」としては来訪者に知覚されず、**§0.1(3) が識別手段として是認する『反復露出で認識できるマーク』**に該当する（favicon⇔OGP で同一標章＝面をまたいだ認識）ことを立証した。したがって本§4が退けるのは「符牒への識別依存」であって、この標章の keep ではない——**このマークは remove/reframe の対象ではなく keep（物語だけ reframe）**。§4 が「OGP の識別は店号・品名で果たす」と書いたのはロゴマーク（別チャネル）を排除する意味ではない（名とマークは併存しうる）。字義で「OGP マークは撤去」と読まないこと。詳細 `docs/cycles/cycle-310/decision.md`。

来訪前の顔・可視コピーが「クリックを迷う人／来訪直後の人」に果たすべき仕事を、地（由来＝YOLO×よろず・constitution）と §0.1 から導く:

- **顔（favicon/OGP）の仕事**: そのサイト/ページが何を差し出すかを、来訪者が**解読なしに**受け取れること＋信頼できる佇まい（Rule4）＋AI 運営の正直な開示（Rule3）。識別は「反復露出で認識できるマーク（favicon）」「平明に読める店号・品名（OGP）」で果たす。→ 店の朱肉印・のれん等の**符牒に識別を依存させない**（§0.1(3)）。
- **可視コピーの仕事**: 雑多な品揃えを「意図された広さ」として腑に落とす orientation を、**一般に通じる言葉**で渡す（「AI が営む・いろいろある・その場でためせる」）。「店主/品書き/店構え」等の独自語彙に理解を依存させない（§0.1(3)）。「実験/試作」を価値として売らない——Rule3 は正直の開示に留める（§0.1(4)）。
- この導出を各面へ適用した keep/remove/change は decision.md（E0〜E3）。P2 の結論＝「orientation のアイデアは平明な言葉で keep・店 theming の signifier は remove/reframe」。

（本サイクルは §0.1(4) の点検として、可視コピーに「実験/試作/やってみる」を**価値として売り込む**表現が無いことも確認した——「実験として営んでいるので誤りがありえる」は Rule3 の開示・「やってみるサイト」は来訪者が操作して結果を得る価値の記述であり、いずれも売り込みでない。）
