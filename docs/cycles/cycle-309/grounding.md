### 確定した線

|                          | 内容                                                                                                                 | 地位                       |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| 地（由来・オーナー由来） | サイト名 yolos.net の由来＝「**よろず**（八百万＝あらゆるもの）」                                                    | B-583 の射程外（疑わない） |
| 地（constitution）       | Goal＝来訪者価値の最大化・Rule2 助け/楽しさ・害の禁止・Rule3 AI 明示・Rule4 品質                                     | 判定の岩盤                 |
| PM 構築物（容疑者）      | 「**よろず屋（店）**」の自己定義／店メタファーの連鎖（店構え・印「試/屋」・OGP 店ブランディング・店主/品書きの語彙） | B-583 が立証にかける対象   |

オーナーが引いた線（＝立証の判定レンズ）:

1. 「よろず屋」と**自己定義すること自体は許容**（来訪者に「多くのものを扱う・AI が営む」と伝える暖かい言い方として）。
2. 来訪者に「**名前の由来はよろず屋（店）だ**」と**偽るのは禁**（由来は「よろず＝あらゆるもの」）。→ 現状 about の「名前の由来」節は正しく「よろず＝万事・あらゆるもの」と述べており **(c) は是正済**（cycle-306）。可視面で由来を「よろず屋」と偽る箇所は現存しない（本サイクル P1a で grep 確認）。
3. 「**店であることを来訪者に押し付ける**」のは禁（店構えデザイン・印・OGP 店ブランディング）。

**結論**: B-583 の立証対象は「視覚意匠だけ」ではなく、**店メタファーの来訪者への押し付けそのもの**。ただし反射的な全撤去はしない（AP-P05・「よろず屋の自己定義」はオーナー許容）。立証で要素ごとに「来訪者を偽る/押し付けるだけか、それとも Rule2 の助け/楽しさになるか」を実物で見て決める。

> なお本節の是正の義務の源は constitution と一次資料の記録であって、オーナーの発言ではない（AP-WF24）。オーナーは「前提の調査が足りない」と地（構築物と地の取り違え）を指差したにすぎず、線を引き直す一次資料調査はルールが求めるもの。

## §2. 各要素が出る顔（P1b・外部仕様の事実・scope 用/露出は判断根拠にしない）

- **favicon → 検索結果**: Google は検索結果に favicon を表示しうる（正方形・48px 以上推奨・ブランドを視覚表現すべき）。[Define a favicon](https://developers.google.com/search/docs/appearance/favicon-in-search)（2026-08-11 再点検）。
- **OGP → シェア unfurl**: SNS/チャットでリンクが展開される瞬間の1枚。
- **名乗り・about → 来訪後**: クリックして到達した来訪者が読む。
- 露出の多寡（GA）は本立証の判断根拠にしない——ブランディングは測定でなくコンセプト/constitution から決める（incident-1 §2(c)）。新規 GA 取得はしない。
