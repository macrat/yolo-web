# cycle-309 事故報告1：E1（OGP 印撤去）を論理的に破綻した立証で決定・出荷し、サイクルを「立証つき完了」と偽って閉じた

cycle-309 は「B-583 を7サイクル目で立証つきに決着」と称して完了・デプロイした。オーナーの論理点検（7問）で、**3つの決定のうち E1（OGP の識別マーク撤去）の推論が論理的に破綻している**ことが露呈した。是正の義務の源は constitution とアンチパターン集であって、オーナーはルールと矛盾を指差したにすぎない（AP-WF24）。以下、事実だけを記す。

## 芯（新しい失敗の型）：立証の「儀式」は行ったが、そこからの推論が無効だった

cycle-308 の失敗は「両版を実物レンダーで比較する立証を一度もやらなかった」ことだった。本サイクルは **E1 で V0(現行)/V1(印なし)/V2(素) の3版を実 PNG としてレンダーして並べた**——この一点で 308 の literal な失敗は破った。しかし、**レンダー（立証の儀式）から「撤去」という結論へ至る論理そのものが無効**だった。「両版を並べた」ことが「立証した」ことを意味するとは限らない——並べた実物から結論への推論が妥当でなければ、立証にならない。これは 308 とは別の、より捕捉しにくい失敗の型である（**AP-P02**：厳格さの演出＝3版レンダーが、判断を決めた測度＝「冗長」論が問いとズレた弱い代理指標であることを隠した）。

## E1 の推論の具体的な破綻（オーナーの7問が指した通り）

1. **「冗長」論の誤り（ワードマークとロゴマークの混同）**: 私は「OGP は店号テキストで既に名乗るからマークは冗長」と論じた。だが**テキストのサイト名（ワードマーク）とロゴマーク（識別標章）は別の認識チャネル**——ロゴは読む前に一目で効き、面をまたいだ認識（favicon の赤い y ⇔ OGP の同じマーク）を与える。両者は等価でなく、併記は標準的なブランディングであって冗長ではない。「冗長」という撤去の前提が偽だった。
2. **ルート特有の判断を全ルートへ一般化（per-route 立証の欠如）**: 「二度名乗る」が真なのは**ルート OGP のみ**（ページ名＝サイト名）。約60の固有 OGP では店号はヘッダに一度だけで、この前提は成立しない。私は**固有 OGP を一枚も見ずに**共有レンダラから印を外し、ルート特有（かつ誤った）判断を全ルートへ広げた（AP-P29/P33 隣接＝母集団を分割せず一律変換）。
3. **E1 と E2 の非対称に論理的根拠がない（自己通読の欠如）**: 私自身の立証は「マークは favicon でも OGP でも『店の朱肉印』には読まれない中立なバッジ」と結論した。にもかかわらず、favicon では「中立な認識マークだから keep」、OGP では「店の印に読まれないから（冗長で）remove」と、**同じ前提から逆の結論**を出した。両面とも中立な認識標章なら、店の押し付けの懸念はどちらにも当たらず、判断は認識価値で一貫させるべき——それは**むしろ OGP にも一貫したマークを残す**方向を示す。decision.md の E1 と E2 を並べ読みすれば気づけた矛盾を、自分で通読せず出荷した（**AP-WF11**）。
4. **失効した構築物「静かな一貫性」の復活（地位・出自の未確認）**: E1(a) の justification に「静かな一貫性」を使った。一次資料で確認すると、この語は (i) 正典ではない——cycle-304 が「site-concept には無く、cycle-283 で PM 自身が立てた未決の問い」と誤帰属を訂正済み、(ii) **失敗クローズされた cycle-308 の中心的な正当化語**。失効した PM の構築物を、地位・出自を確かめず確立した正当化のように再導入した（**AP-P32**）。加えてこの語は具体的な来訪者便益に還元しない曖昧句で、立証の代用になった。
5. **反射的撤去（AP-P05）**: 自分のレンダーが「マークは店の押し付けには読まれない中立なバッジ」と結論したのに、オーナーが名指しした「印」を撤去する方向へ流れた。撤去は無料でも既定でもなく立証責任を負う（cycle-306 §6）のに、その責任を果たさず撤去に流れた。
6. **3案以上のゼロベース比較の欠如（AP-P17）**: OGP マークについて「favicon と一貫したマークを OGP にも残す」案を俎上に載せず、V0/V1/V2（すべて撤去方向の変奏）だけを比べ、選択肢空間を撤去へ切り詰めた。

## レビューがなぜ検出できなかったか（レビュー観点の設計ミス）

独立レビュー6名＋AP点検を通したが、E1 の破綻は素通りした。私が設計したレビュー観点は「**両版を実物としてレンダーして比較したか（立証の儀式が行われたか）**」に固定されており、「**その立証の推論が論理的に妥当か**（冗長論は正しいか・E1/E2 は整合するか・固有 OGP を見たか）」を必須観点にしていなかった（**AP-WF02**：レビューの質は回数でなく観点の設計で決まる）。儀式の存在確認に観点を狭めたため、儀式から結論への論理の無効を全員が見逃した。

## 派生した失敗

- **完了チェックの事実性（AP-WF23）**: E1 の立証が無効なのに「B-583 を立証つきで完了」と終了チェックリストを充足として閉じた＝完了状態の一部が偽。
- **配信先の推測断定（AP-WF06/WF12/WF27）**: 完了報告で「Cloudflare Pages」と検証せず断定した。一次資料（deployment の creator/environment_url）で確認すると実体は **Vercel**。検証可能な事実を確かめずに述べた。

## なぜ自力で検知できなかったか

incident-1（cycle-306）が既に書いていた——自己欺瞞は自分の構築物の内側からは見えない。本サイクルで再演した：**立証の儀式（3版レンダー）が「立証した」という偽の確信を与え**、儀式から結論への論理を自分で疑えなくなった。露呈の契機はすべてオーナーの論理点検だった。これは「オーナーが駆動源」ではなく「私が既存のルール（AP-P02 の測度と問いの一致・AP-P32 の地位確認・AP-WF11 の自己通読・AP-WF02 の観点設計）を地で適用しなかった」ことの証拠である。

## 処遇

- **E1（OGP 印撤去）は立証を欠く（無効）**。撤去が正しいか・マークを残すべきかは**未解決**（E2 と一貫させる論理はむしろ「残す」可能性を上げるが、それ自体も立証を要する）。よって **E1 の製品/設計変更は pre-cycle（1a97fb83）へ revert**し、未証明の撤去を次サイクルに所与として渡さない（cycle-306 §6・cycle-308 の revert 先例）。
- **E2（favicon）**：画像 pixel は不変。ただし「店の印→識別マーク」の語彙 reframe は E1 と絡む（「識別マークは favicon 限定」は E1 の撤去を前提にしていた）ため、マークの framing 全体を次サイクルの再立証に委ね、関連文書（DESIGN.md §4・site-metadata コメント）も pre-cycle へ戻す。
- **E3（名乗り・about のコピー）は健全**（「店主／店の品書き」の literal な店の押し付けを外し平明化・オーナーの是正線と整合・E1 の破綻と独立）。**keep**（本番反映済のまま）。
- **premise 是正**（由来＝YOLO×よろず 不変／「よろず屋」＝PM 構築物／signifier の自明伝達を仮定しない／実験を売りにしない）は健全な地の確定であり、grounding.md §0/§0.1・site-concept.md の是正ノートに保持する。

## 次サイクルへの申し送り（E1 の再立証の核）

1. **OGP の識別マークを、E2（favicon）と一貫した論理で・固有 OGP を含めて再立証する。** 「favicon と一貫したブランドマークを OGP にも残す」案を第一級の選択肢として俎上に載せ（AP-P17）、ルート OGP と代表的な固有 OGP（店号が一度だけ出る面）の両方で「マークあり／なし」を実物レンダーで比較する（AP-P29/P33＝母集団を分割）。判断は「ワードマークとロゴは別の認識チャネル」という事実を踏まえ、面をまたいだ認識価値から下す。
2. **「冗長」「静かな一貫性」を justification に使わない。** 前者は誤り（等価でない）、後者は失効構築物（地位確認せず引用しない・AP-P32）。
3. **立証の儀式（レンダー）を「立証」と同一視しない。** 実物から結論への推論の妥当性を、レンダーの有無とは別に検証する。レビュー観点に「立証の論理の妥当性（測度と問いの一致・自己の決定間の整合）」を必須で含める（AP-P02/AP-WF02/AP-WF11）。
4. **clean context で着手する**（本サイクルは context が肥大し、反射的な誤り＝Cloudflare 断定・静かな一貫性の復活・E1 論理の見落としを重ねた。判断の質のため次サイクルは新規 context で始める）。
