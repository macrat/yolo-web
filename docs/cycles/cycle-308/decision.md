# cycle-308 判定（B-583 (a)(b)(d)）

前提: [grounding.md](./grounding.md)（P1 生の観測・P2 constitution 導出）。判定は PM 自身が実物の顔を見て下す（委譲しない＝304/305 の教訓）。各要素に keep/remove/change の立証責任を負わせ、来訪者価値からの justification を持つ。**「印の字・形・配色をどうするか」は一切扱わない**（それを始めた時点で B-583 に失敗＝5サイクルの型）。問うのは「この要素は来訪者価値に照らして要るか」だけ。

---

## (b) 印(hanko)の要否

分けて判定する（露出が桁違いのため・grounding P1a）。

### (b-1) favicon のマーク（実露出のある唯一の来訪前の顔）

- **判定: keep（ブランドマークとして維持）。根拠は「認識」であって「店の印」ではない。**
- **来訪者価値からの justification**: 検索結果に favicon は出る（Google は提供しなければ既定の地球儀を出す）。一覧の中で認識でき・信頼を削らないマークは、クリックを迷う検索者の選択と信頼を助ける（Rule2/4・grounding P2）。現行マーク（朱の角丸＋白抜き「y」）は 16px で「赤い y のマーク」として認識でき、自己貶め（試）は無い（実見・P1b）。マークの**存在**は来訪者価値（認識）から正当化される。
- **ただし framing を是正する**: このマークの正当化は「認識」であって「店が印を持つべきだから」ではない。検索者は「日本の店の印(hanko)」を復号しない（P1b）。⇒ DESIGN.md §4 が「印＝店の言語の延長」「看板/札に店の印を捺す」と**店の主張として正典化**しているのを是正し、「識別のためのブランドマーク」に位置づけ直す。**「印(hanko)」という店メタファーは来訪者に届かない内部の視覚処理ラベルであり、その存在を正当化する根拠にも・他面へ拡張する権威にもしない。**
- **やらないこと**: マークの字・形・配色・かすれ等の craft をここで比較・選定しない（B-583 の失敗判定法）。現行マークは「認識」の仕事を満たしており、より良い craft の探索は別問題（かつ実露出 16px・来訪者価値の本体はコンテンツ側）。

### (b-2) OGP 看板の印／結果札(fuda)の内容印

- **判定: 現状維持（触らない）。ただし「成果」扱いも「店の主張」扱いもしない。**
- **justification**: OGP/シェア面の実露出は 5 セッション≒0（P1a）。ここの印は**来訪者にほぼ届かない**。keep も remove も来訪者にはほぼ不可視で、来訪者価値の差はゼロ。⇒ **どちらにも来訪者価値の根拠が立たない以上、労力を注ぐ価値が無い**。撤去は追加の churn と工数を生むだけ（AP-P05 の反射的撤去を避ける）。**現状のまま触らず、以後「見えない顔の印を塗り替える」作業に価値を認めない**（cycle-306 の ship-revert ループを閉じる）。
- 露出≒0 ゆえ「店の主張」として来訪者に届いてもいない（cycle-283:204 の「OGP は来訪前にしか出ない」の実証）。

**(b) の答え**: 来訪者価値から必要なのは「検索結果で認識されるブランドマーク（favicon）」の**存在**だけ。「店の印(hanko)」という店メタファーは来訪者に届かず、存在の根拠にも他面への権威にもならない。OGP/札の印は露出≒0 で塗り替えに価値なし＝触らない。

## (a) 店を全面主張する統一は来訪者価値上必要か（静かな一貫性で足りないか）

- **判定: 「店の全面主張」の統一は不要（remove/de-canonize）。来訪者価値があるのは「静かな一貫性」であって「店の主張」ではない。**
- **justification**: 来訪者が受け取るのは「落ち着いた・一貫した・信頼できる、よく作られたサイト」という佇まい（紙/墨/罫/明朝の視覚言語）＝これは Rule4（あらゆる面で最高品質）・Rule2（信頼）の来訪者価値。だが**その価値は「静かな一貫性」から出ており、「これは店だ」と主張することからは出ていない**。「店構え」という**ラベル**は来訪者に届かない内部語（P1c）。⇒ 統一の来訪者価値は「静かな一貫性」に還元され、「店を全面主張する統一」は来訪者価値上**不要**。
- **これは cycle-283:208 の到達点（「印に店を主張させること自体が誤り」）と一致するが、過去結論の引き写しではなく本サイクルで constitution から独立に導出した**（grounding P2）。
- **remove の対象は「店構え＝正典/権威」という地位**であって、視覚言語（紙/墨/罫/明朝）そのものではない。視覚言語は静かな一貫性という来訪者価値を担うので keep。**反射的に視覚言語ごと解体することはしない**（撤去も立証責任・AP-P05。視覚言語を壊すと静かな一貫性という来訪者価値が減る）。

**(a) の答え**: NO。必要なのは静かな一貫性（Rule4）だけ。「店構え」を唯一の視覚規範＝正典とする地位を降格し、来訪者価値の根拠を「店の主張」から「静かな一貫性」へ置き直す。

## (d) 店の押し付けの有無

来訪者に届く店フレーム（grounding P1c）ごとに判定。

### (d-1) トップの名乗り「AIが営む、よろず屋です。」＋「店主は人ではなくAIです。実験として営んでいるので…」＋ meta description

- **判定: keep（来訪者価値から正当化される・押し付けではない）。**
- **justification**: 「よろず屋」は「あらゆるものが揃う店」＝サイトが実際に持つ**多様な品揃え（診断・占い・あそび・漢字/四字/色の辞典・道具・読みもの）を正直に伝える**。この1フレームが同時に3つの来訪者価値を担う——(1) この場が何を差し出すか（広さ）を伝える、(2) 温かく親しみやすい（Rule2）、(3) 「AIが営む実験・誤りがありうる」という **Rule3 の告知**を運ぶ。⇒ これは「店の押し付け」ではなく helpful かつ honest な枠組み。商取引の誤認リスクは「その場でためして持ち帰れる（無料でためせる）」が打ち消す。**keep の根拠は DESIGN.md でなく来訪者価値（Rule2+3・広さの伝達）。**

### (d-2) aria-label「〜の品書き」（SR 来訪者に届く）

- **判定: change を推奨（ただし B-583 の核でなく follow-up として backlog へ）。**
- **justification**: DESIGN.md §11 自身が「品書き等が初訪者に意図どおり伝わるか」を**未検証**とし、§6 が「凝った言い回しが明瞭さと衝突したら明瞭さが勝つ」と定める。SR 利用者には「品書き」より「一覧」の方が即座に構造を把握できる（craft でなく明瞭さの問題）。⇒ 可視コピーの親しみ枠は保ちつつ、**aria-label（機能ラベル）は「一覧」等の平明語へ**寄せる余地がある。ただしこれは a11y の明瞭さ改善で、B-583 の「メタファーの是非」の核ではなく、B-599（a11y 軽微群）と同性質。**核の判定を薄めないよう follow-up として backlog に回す**（本サイクルで断定的に全置換はしない＝低リスクだが検証を要する craft 判断）。

**(d) の答え**: トップの店フレームは押し付けでなく来訪者価値（広さの伝達＋Rule3 告知）＝keep。SR の「品書き」ラベルのみ明瞭さの follow-up（backlog）。それ以外の店の押し付けは可視面に無い。

## 判定が指示する変更（P4 のスコープ）

5サイクルの失敗の根は「出荷物」そのものより、**(i) DESIGN.md §4/§1 の店構え/印を正典・権威として扱ったこと**と **(ii) 実露出≒0 の OGP/favicon を繰り返し塗り替えたこと**（cycle-306/incident-1.md §3・§4）。判定が指示する変更はこの根を断つもの:

1. **DESIGN.md の店メタファーの脱・正典化（de-canonize）**（実装の主対象）:
   - §5 ヘッダの「唯一の視覚規範・正典」と §11 の「導出済み仮説・店の語彙は未検証」の矛盾を解消し、**視覚言語の来訪者価値は「静かな一貫性（Rule4）」であって「店の主張」ではない**ことを明記。
   - §4「印」＝店の印/店の言語の延長という正典的位置づけを、「**識別のためのブランドマーク（favicon の認識）**」に是正。印の**存在**を「店が印を持つべきだから」で正当化せず・他面へ拡張する権威にしない。
   - 「店/店構え/のれん/品書き/札/印」は**来訪者に届かない内部ニックネーム**であって、来訪者に店を主張する mandate でも要素存在の権威でもない、と明記。
   - **実露出の事実（favicon=検索の顔／OGP≒0）を接地として記録し、「見えない顔の塗り替えに価値なし＝以後やらない」を明文化**（ship-revert ループの遮断）。
2. **コード内コメントの脱・正典化**: `src/lib/ogp-image.tsx`・`fuda-image.tsx` 等が印/看板を「店の主張」「店の顔」として正典参照している箇所を、上記の位置づけに整合させる（来訪者可視の挙動は変えない＝コメントのみ）。
3. **可視の出荷物は原則 keep**（favicon マーク・トップの店フレーム＝いずれも来訪者価値から justified）。**可視面の店コピーを反射的に撤去しない**（AP-P05）。
4. **follow-up を backlog へ**: (d-2) SR aria-label の明瞭さ（B-599 隣接）。

## B-576 の扱い（P6・favicon/OGP を作り直すか）

- **判定: B-576 は「作り直し（re-paint）」としては不要＝解消。**
- **justification**: 現行 favicon マークは「検索結果での認識」という来訪者価値の仕事を満たしている（b-1）。OGP は露出≒0 で塗り替えに価値なし（b-2）。⇒ B-576 の前提「新デザインに合わせて作り直す」は、**現行マークが認識の仕事を満たしている以上、更なる作り直しは churn であって来訪者価値を生まない**（cycle-306 が塗装代を捨てた失敗の反復になる）。B-576 は本判定をもって解消（backlog に理由を記録）。craft の微改善が将来必要になれば、その時に来訪者価値から個別起票する（印ありき・作り直しありきで起票しない）。

## ADR 判断

- 本判定は来訪前の顔の Rule4 品質を来訪者価値から問い直した是正で、コンセプト/アーキテクチャ/戦略の転換ではない（サイトが「AIが営むよろず屋」であること自体は keep＝転換なし）。DESIGN.md の脱・正典化は「仮説の地位の是正」であって新戦略の採用ではない。かつ来訪前の顔（特に OGP）は実露出≒0 で観測可能な賭けの窓を持てない（cycle-305 の教訓＝計測不能なものに観測 ADR を作らない）。⇒ **新規 ADR 不要・既存 ADR 更新なし**。ADR001 は先頭日付が未来で本サイクルは観測対象外。
