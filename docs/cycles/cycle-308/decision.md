# cycle-308 判定（B-583 (a)(b)(d)）

前提: [grounding.md](./grounding.md)（P1 生の観測・P2 constitution 導出）。判定は PM 自身が実物の顔を見て下す（委譲しない＝304/305 の教訓）。各要素に keep/remove/change の立証責任を負わせ、来訪者価値からの justification を持つ。**「印の字・形・配色をどうするか」は一切扱わない**（それを始めた時点で B-583 に失敗＝5サイクルの型）。問うのは「この要素は来訪者価値に照らして要るか」だけ。

## (b) 印(hanko)の要否

分けて判定する（露出が桁違いのため・grounding P1a）。

### (b-1) favicon のマーク（実露出のある唯一の来訪前の顔）

- **判定: keep（ブランドマークとして維持）。根拠は「認識」であって「店の印」ではない。**
- **来訪者価値からの justification**: 検索結果に favicon は出る（Google は提供しなければ既定の地球儀を出す）。一覧の中で認識でき・信頼を削らないマークは、クリックを迷う検索者の選択と信頼を助ける（Rule2/4・grounding P2）。現行マーク（朱の角丸＋白抜き「y」）は 16px で「赤い y のマーク」として認識でき、自己貶め（試）は無い（実見・P1b）。マークの**存在**は来訪者価値（認識）から正当化される。
- **ただし framing を是正する**: このマークの正当化は「認識」であって「店が印を持つべきだから」ではない。検索者は「日本の店の印(hanko)」を復号しない（P1b）。⇒ DESIGN.md §4 が「印＝店の言語の延長」「看板/札に店の印を捺す」と**店の主張として正典化**しているのを是正し、「識別のためのブランドマーク」に位置づけ直す。**「印(hanko)」という店メタファーは来訪者に届かない内部の視覚処理ラベルであり、その存在を正当化する根拠にも・他面へ拡張する権威にもしない。**
- **やらないこと**: マークの字・形・配色・かすれ等の craft をここで比較・選定しない（B-583 の失敗判定法）。現行マークは「認識」の仕事を満たしており、より良い craft の探索は別問題（かつ実露出 16px・来訪者価値の本体はコンテンツ側）。

### (b-2) OGP 看板の印／結果札(fuda)の内容印

- **判定: 現状維持（触らない）。ただし「成果」扱いも「店の主張」扱いもしない。**
- **justification**: OGP/シェア面の実露出は 5 セッション≒0（P1a）。ここの印は**来訪者にほぼ届かない**。keep も remove も来訪者にはほぼ不可視で、来訪者価値の差はゼロ。⇒ **どちらにも来訪者価値の根拠が立たない以上、労力を注ぐ価値が無い**。撤去は追加の churn と工数を生むだけ（AP-P05 の反射的撤去を避ける）。**現状のまま触らず、以後「見えない顔の印を塗り替える」作業に価値を認めない**（cycle-306 の ship-revert ループを閉じる）。
- 露出≒0 ゆえ「店の主張」として来訪者に届いてもいない（cycle-283:204 の「OGP は来訪前にしか出ない」の実証）。

**(b) の答え**: 来訪者価値から必要なのは「検索結果で認識されるブランドマーク（favicon）」の**存在**だけ。「店の印(hanko)」という店メタファーは来訪者に届かず、存在の根拠にも他面への権威にもならない。OGP/札の印は露出≒0 で塗り替えに価値なし＝触らない。

## (a) 店を全面主張する統一は来訪者価値上必要か（静かな一貫性で足りないか）

- **判定: 「店の全面主張」の統一は不要（remove/de-canonize）。来訪者価値があるのは「静かな一貫性」であって「店の主張」ではない。**
- **justification**: 来訪者が受け取るのは「落ち着いた・一貫した・信頼できる、よく作られたサイト」という佇まい（紙/墨/罫/明朝の視覚言語）＝これは Rule4（あらゆる面で最高品質）・Rule2（信頼）の来訪者価値。だが**その価値は「静かな一貫性」から出ており、「これは店だ」と主張することからは出ていない**。「店構え」という**ラベル**は来訪者に届かない内部語（P1c）。⇒ 統一の来訪者価値は「静かな一貫性」に還元され、「店を全面主張する統一」は来訪者価値上**不要**。
- 本判定は本サイクルで constitution（Rule4／grounding P2）から独立に導出したものであり、過去結論を根拠にしない（cycle-283:208 が同趣旨に達しているが、それは**権威・根拠補強として引かない**＝AP-P34。導出の地はあくまで constitution と生の観測）。
- **remove の対象は「店構え＝正典/権威」という地位**であって、視覚言語（紙/墨/罫/明朝）そのものではない。視覚言語は静かな一貫性という来訪者価値を担うので keep。**反射的に視覚言語ごと解体することはしない**（撤去も立証責任・AP-P05。視覚言語を壊すと静かな一貫性という来訪者価値が減る）。

**(a) の答え**: NO。必要なのは静かな一貫性（Rule4）だけ。「店構え」を唯一の視覚規範＝正典とする地位を降格し、来訪者価値の根拠を「店の主張」から「静かな一貫性」へ置き直す。

## (d) 店の押し付けの有無

来訪者に届く店フレーム（grounding P1c）ごとに判定。

### (d-1) 「AIが営むよろず屋」名乗り（トップ `:194/:198/:38`・about `:82/:88`）

**isolation 検証（レビュー1 B1 の指摘で追加）**: 「広さを伝える」だけなら平明表現（例「AIがつくる、いろいろためせるサイト」）でも果たせる。ゆえに「広さ」は店メタファー**そのもの**の必要性を立証しない。平明表現に対して「よろず屋」名乗りが**上乗せする固有の来訪者価値**を切り分けて test する:

- **(i) 名前との一致（identity coherence）**: サイト名 `yolos` は「YOLO × **よろず**（万事）」に由来し、about `:88` がそれを来訪者に明示する。「よろず屋」名乗りは、来訪者が URL/ロゴで見る名前の由来と一致し、名前を意味づける——平明表現は名前との結び目を失う。これは操作側の自己像でなく、**来訪者に「この名前は何を意味するか」を届ける**来訪者価値。
- **(ii) Rule3 告知の自然な担い手**: 「店主は人ではなくAIです。実験として営んでいるので、内容に誤りがあるかもしれません」は、店フレームがあるからこそ一つの自然な文で Rule3 を運ぶ（別途フッターにも明示ありだが、ここは重複でなく親しみのある入口）。
- **(iii) 温かさ／親しみ**: これは cycle-282 が病と名指した「自己像・美意識の軸」に近く、**単独では keep の根拠にしない**（isolation で落とす）。

⇒ **判定: keep**。ただし根拠は「広さ」や「温かさ」の bundle でなく、**isolation を生き延びた (i) 名前との一致＋(ii) Rule3 の自然な担い手**。これは操作側の一貫性でなく来訪者に届く価値であり、cycle-306 申し送り§3（よろず屋の自己定義も容疑者・settled 扱いせず test）に対し、実際に平明表現と対比して test した上での keep。商取引の誤認リスクは「その場でためして持ち帰れる（無料）」と about `:88`（由来＝万事）が打ち消す。**keep の根拠は DESIGN.md でなく来訪者価値。**

### (d-1b) about `:97`「店の品書きは、大きく四つです。」（全 src で唯一の字義的「店」）

- **判定: change（isolation で来訪者価値を持たない・平明表現へ）。**
- **isolation**: 平明表現「ここにあるものは、大きく四つです」と比べ、「**店の**品書き」の「店」が上乗せするのは**操作側のメタファー一貫性のみ**で、来訪者の理解は同等（むしろ about `:88` が「よろず＝万事であって店ではない」と説明する直後に字義的「店」を置くのは軽い不整合）。⇒ 「店」を落とすのは来訪者価値からの是正であって反射的撤去（AP-P05）ではない（isolation の結果として change・(d-1) は同じ test を生き延びて keep＝一律撤去でない証拠）。低リスク・1行の具体的変更。

### (d-2) aria-label「〜の品書き」（SR 来訪者に届く・全サイトの Shinagaki）

- **判定: change 推奨（機能ラベルは「一覧」等の平明語へ）。ただし実行は follow-up backlog（分離＝Keep task smaller・先送りの口実にしない）。**
- **justification**: DESIGN.md §11 自身が「品書き等が初訪者に意図どおり伝わるか」を**未検証**とし、§6 が「凝った言い回しが明瞭さと衝突したら明瞭さが勝つ」と定める。SR 利用者には「品書き」より「一覧」の方が即座に構造を把握できる（craft でなく明瞭さの問題）＝**change すべき**という判断は本サイクルで下している。
- **なぜ本サイクルで全置換しないか（先送りでないことの明示）**: 対象は**全サイトの Shinagaki の aria-label**（`dictionary`/`tools`/`play`/`RelatedArticles` 等・多数ファイル＋テストの aria 期待）に及ぶ機械的 a11y craft で、B-583 の核（メタファーの**要否**の判定）とは別種の作業。判定（change 推奨）は下した上で、実行を B-599 隣接の follow-up として分離する（CLAUDE.md「Keep task smaller」）。核の可視是正（about `:97`）は本サイクルで実施するので、「core を薄める先送り」には当たらない。

**(d) の答え**: 「AIが営むよろず屋」名乗り（トップ・about）は isolation を生き延びる来訪者価値（名前との一致＋Rule3 の担い手）＝keep。about `:97` の字義的「店の品書き」は isolation で価値を持たず平明表現へ change。SR の「品書き」aria-label（全サイト）は change 推奨だが a11y craft のため backlog 化。**可視の店主張はこの4系統（grounding P1c）で網羅し、各々に判定を下した**（初版の「可視面に無い」断定は about の取りこぼしで誤りだったため撤回・訂正済み）。

## 判定が指示する変更（P4 のスコープ）

5サイクルの失敗の根は「出荷物」そのものより、**(i) DESIGN.md §4/§1 の店構え/印を正典・権威として扱ったこと**と **(ii) 実露出≒0 の OGP/favicon を繰り返し塗り替えたこと**（cycle-306/incident-1.md §3・§4）。判定が指示する変更はこの根を断つもの:

1. **DESIGN.md の店メタファーの脱・正典化（de-canonize）**（実装の主対象）:
   - 冒頭ヘッダ（行5）の「唯一の視覚規範・値の正典」と §11 の「導出済み仮説・店の語彙は未検証」の矛盾を解消し、**視覚言語の来訪者価値は「静かな一貫性（Rule4）」であって「店の主張」ではない**ことを明記。
   - §4（行72）「印」＝店の印/店の言語の延長という正典的位置づけを、「**識別のためのブランドマーク（favicon の認識）**」に是正。印の**存在**を「店が印を持つべきだから」で正当化せず・他面へ拡張する権威にしない。
   - 「店/店構え/のれん/品書き/札/印」は**来訪者に届かない内部ニックネーム**であって、来訪者に店を主張する mandate でも要素存在の権威でもない、と明記。
   - **実露出の事実（favicon=検索の顔／OGP≒0）を接地として記録し、「見えない顔の塗り替えに価値なし＝以後やらない」を明文化**（ship-revert ループの遮断）。
2. **コード内コメントの脱・正典化**: `src/lib/ogp-image.tsx`・`fuda-image.tsx` 等が印/看板を「店の主張」「店の顔」として正典参照している箇所を、上記の位置づけに整合させる（来訪者可視の挙動は変えない＝コメントのみ）。
3. **可視の是正（isolation が指示するもののみ）**: about `:97`「**店の**品書きは、大きく四つです。」の字義的「店」を平明表現へ change（(d-1b)・isolation で来訪者価値なし）。それ以外の可視出荷物（favicon マーク・「AIが営むよろず屋」名乗り）は isolation を生き延びた来訪者価値ゆえ keep＝**反射的撤去はしない**（AP-P05）。
4. **follow-up を backlog へ**: (d-2) 全サイトの Shinagaki aria-label「品書き」→平明語（B-599 隣接・機械的 a11y craft・範囲は全サイト）。

## AP-P02 自己監査（検証の非対称の stress-test・レビュー1 B2 の指摘で追加）

B-583 の病は「PM 自身に見抜けない自己欺瞞」であり、AP-P02（工数が増える結論には検証を掛け、終わらせやすい結論には掛けない非対称）が最大の残り火。都合の良い形＝「可視ゼロ変更で終わる」を明示的に stress-test する:

- **全体形は「可視ゼロ変更」ではない**: 判定は約束どおり about `:97` の可視 change を生み、aria-label 全サイト change を推奨判断した（実行のみ分離）。「何も変えず内部 doc だけ直す」楽な帰結には倒れていない。
- **keep が多いのは工数回避でなく isolation の結果**: favicon・「よろず屋」名乗りの keep は、平明表現/撤去との対比（(b-1)・(d-1) の isolation）を生き延びた来訪者価値による。同じ isolation を about `:97` は生き延びず change に振れている＝keep は一律追認でなく test の産物。
- **最も工数の要る結論を回避していない**: 本判定の主対象（DESIGN.md 脱正典化）は「何もしない」より工数が多い方の結論であり、終わらせやすい方（＝店構え正典を温存して据え置く）へ倒していない。むしろ5サイクルが避け続けた根（正典化）に工数を割いている。
- **残る非対称リスクの明示**: favicon の craft 微改善（より良いマークの探索）は「工数が増える結論」だが、本サイクルは意図的に扱わない——理由は工数回避でなく、(1) B-583 の失敗判定法（字/形選定に入らない）、(2) 実露出16pxで来訪者価値の本体はコンテンツ側。この不作為は AP-P02 でなく付託の scope 判断であることを記録する。

## B-576 の扱い（P6・favicon/OGP を作り直すか）

- **判定: B-576 は「作り直し（re-paint）」としては不要＝解消。**
- **justification**: 現行 favicon マークは「検索結果での認識」という来訪者価値の仕事を満たしている（b-1）。OGP は露出≒0 で塗り替えに価値なし（b-2）。⇒ B-576 の前提「新デザインに合わせて作り直す」は、**現行マークが認識の仕事を満たしている以上、更なる作り直しは churn であって来訪者価値を生まない**（cycle-306 が塗装代を捨てた失敗の反復になる）。B-576 は本判定をもって解消（backlog に理由を記録）。craft の微改善が将来必要になれば、その時に来訪者価値から個別起票する（印ありき・作り直しありきで起票しない）。

## ADR 判断

- 本判定は来訪前の顔の Rule4 品質を来訪者価値から問い直した是正で、コンセプト/アーキテクチャ/戦略の転換ではない（サイトが「AIが営むよろず屋」であること自体は keep＝転換なし）。DESIGN.md の脱・正典化は「仮説の地位の是正」であって新戦略の採用ではない。かつ来訪前の顔（特に OGP）は実露出≒0 で観測可能な賭けの窓を持てない（cycle-305 の教訓＝計測不能なものに観測 ADR を作らない）。⇒ **新規 ADR 不要・既存 ADR 更新なし**。ADR001 は先頭日付が未来で本サイクルは観測対象外。
