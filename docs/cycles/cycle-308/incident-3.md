# cycle-308 事故報告3：アンチパターンに個別具体の実例を書き込んだ（作成ルール違反・PM 全責任）

失敗クローズの途中、AP-P34 に禁止語「本丸」を追加する編集で、**アンチパターンの本体に個別具体の実例を書き込んだ**。オーナーの指摘で露呈。

## 違反した内容とルール

- **やったこと**: AP-P34（`docs/anti-patterns/planning.md`）に「本丸」を追加する際、(1) 本体の説明に「『5サイクル失敗した本丸』等と大書きしながら…cycle-308 が実演した」という cycle-308 固有の実例を書き、(2) 発生欄に「308＝『本丸』を連発して…オーナー指摘で禁止語に追加」という冗長な個別注記を書いた。
- **違反したルール**: `.claude/rules/anti-patterns-directory.md`——「Do: 一般化した説明として広く捉えられるように記録する」（10行）、「Do: 再発時は `（cycle-XXX, XXXで実際に発生）` に**サイクル番号のみ**を追記する」（14行）、「Don't: 特定の状況に特化した具体的な事例を記録する。具体的な事例はサイクルドキュメントに記録し、**サイクル番号だけを書くのが正しい**」（23-24行）。

## 根

これは本サイクルで繰り返してきた病と同型——**中身の一般則よりも、自分の失敗を劇的に語る具体の物語を盛りたがる**（「本丸」で大書きしたのと同じ衝動）。一般化すべきアンチパターンに、劇的な個別実例を持ち込んだ。加えて、禁止語「本丸」を追加する編集の中で、その追加を説明する具体例を書くという形で、直そうとしている当のもの（大仰な物語化）を再演した。

## 是正

- AP-P34 本体の cycle-308 固有の実例を削除し、「本丸」の一般化した特徴づけ（＝課題を大決戦に仕立てて具体の立証・作業から目を逸らす警戒語）だけを残した。
- 発生欄の冗長な「308＝…」注記を削除し、**サイクル番号「308」のみ**にした。詳細は本サイクルドキュメント（incident-2.md）に在る。
- 「本丸」を禁止語に追加したこと自体（AP-P34 の一般則としての本文）は維持。

## 残る同種の先行違反（本インシデントで拡張しない）

同じ AP-P34 の発生欄に先行して在る「305＝不正書き換えの…」という個別注記も同種のルール違反だが、これは cycle-305 以前からの既存で、**B-540（アンチパターン集の規約準拠クリーンアップ）**の射程。本インシデントは自分が今作った違反の是正に留め、B-540 の全面清掃に混ぜない（スコープ膨張を避ける）。B-540 で発生欄の個別注記を番号のみへ揃える対象として扱う。
