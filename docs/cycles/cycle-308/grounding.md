## P2. constitution からの導出（来訪前の顔は来訪者に何をすべきか）

**地**: constitution（Goal・Rule1-5）＋ P1 の生の観測。**容疑者として排除**: DESIGN.md（冒頭ヘッダ〔行5〕は「唯一の視覚規範・値の正典」と書くが、§11 自身が「cycle-278 の**導出済み仮説**」「店の語彙の来訪者到達性は**実測で確かめる項目**」と自己申告＝正典ではなく検証対象。B-583 が正す対象そのもの）。

- **Goal（来訪者価値＝PV の最大化）**: 来訪前の顔＝検索結果の favicon は、クリックを迷う検索者が「この結果を選び・正しい期待で来る」のを助けるべき。
- **Rule2（helpful/enjoyable・悲しませない）**: 検索結果の一覧の中で、認識でき・信頼できるマークは選択と信頼を助ける。自己貶め（試＝試作）や意味不明な記号は逆に信頼を削る。
- **Rule3（AI 実験の告知）**: favicon は 16-48px で告知を担えない＝**告知は favicon の仕事ではない**（サイト内のコピー／フッターが担う）。
- **Rule4（あらゆる面で最高品質）**: マークは 16-48px で可読・オンブランド・誠実であること。

⇒ **導出される favicon の仕事＝「検索結果で認識でき・信頼できる、16-48px で可読なブランドマーク」。** ここに「店」「印(hanko)」は一切要求されない——それらは内部メタファー。Google も「favicon はブランドを視覚表現すべき」とし、提供しなければ既定の地球儀が出る（[Google Search Central](https://developers.google.com/search/docs/appearance/favicon-in-search)・2026-08-11 確認）＝**ブランドマークの存在自体は来訪者価値（認識）から正当化される**が、それが「店の印」である必然性は無い。

導出した「顔の仕事」に照らして各要素の要否を判定する基準:

- 要素が **検索者の認識・信頼・正しい期待**に資するか（Rule2/4）。
- 資さない「店の自己表現」なら、その存在は PM 文書の許可でなく**来訪者価値でのみ**正当化されねばならない（cycle-306/incident-1.md §3）。
- keep/remove/change のどれも立証責任を負う。撤去も無料の既定でない（AP-P05）。

→ 各要素の判定は [decision.md](./decision.md)。
