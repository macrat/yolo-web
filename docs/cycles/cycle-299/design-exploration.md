# favicon 図案のゼロベース探索（cycle-299・第2回=incident-1 D1 の実施記録）

第1回の真因は「『y.』1案への固執・拡大表示でのレビュー」（AP-P17/AP-I01・[incident-1.md](./incident-1.md)）。是正として、図案を**ゼロベースで複数案起こし、タブ実寸 16px（拡大でなく自然サイズ）で比較**した。以下はその比較と選定根拠（プレビュー画像は `tmp/`＝gitignore のため、各案の 16px での見えを言葉で残す）。

## 起こした案と 16px 実寸での評価

## 選定根拠（採用＝G）

- **16px で読める**（本タスクの至上要件）: 真の 900 ウェイトで、小文字 y でも 16px タブで solid に立つ。A の失敗（細さで潰れる）を、案そのものを変えずに**その案固有の欠陥＝ウェイト不足**として正した。
- **identity 忠実**: のれん（`src/components/Header`＝店号「yolos.net」を明朝・墨・ドットのみ朱）の頭文字縮約に最も近い。C（大文字）は読めるが小文字ワードマークから外れる。
- **デザインシステム内**: E/F（地色反転タイル）は 16px 可読では最強だが DESIGN §2「地は常に紙／朱は印だけ」を破り、favicon だけ店構えの地を変える前例を作る（AP-I08＝未定義表現は先に DESIGN 更新＋レビュー）。G は紙地を保ち系統内に収まる。**可読の要件を、システムを壊さずに満たせる案があるなら、それを選ぶ**。
- **B-583 非先取り**: 印「試」を使わずワードマークに拠る（E/F/G いずれも印なし）。
- ウェイトは 900、ドットはベースライン右（ピリオド）＝いずれも「G という案」の中の小サイズ craft の詰め（[incident-1.md](./incident-1.md) の中黒・下重心の是正を含む）。

## 判定の観点（第1回との違い）

第1回は 15倍拡大で「拡大すれば y と分かる」を合格にした（AP-I01/AP-P02）。第2回は**すべてタブ実寸 16px（自然サイズ）の描画を来訪者目線で見て**判定した。光学中央（下重心の是正）も、目視だけでなく 512 マスター上の content bbox 上下余白を実測して均衡させた（favicon top73/bottom79・apple top118/bottom124）。
