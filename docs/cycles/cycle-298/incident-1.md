# incident-1: 基準が「変えない」と言ったのに、思いつきで #1 の面を変更して出荷した

記録日: 2026-07-25 / 記録者: PM（Owner 指摘を受けて）

## 何をしたか（平たい言葉で）

前の PM（cycle-284）が危惧した問題は、実測したら存在しなかった。私が着手前に自分で決めた変更の基準も満たさなかった。**それなのに、思いついた表示方法（一覧の畳み込み）に変えて、全PVの31%を占める面へ出荷した。**

そのうえで私は、その変更を正当化する言葉を大量に作った。

## 事実の経過

1. 着手前に判定基準を固定した: 「問1（一覧が来訪者を裏切っているか）が条件A・B の両方を満たせば要処遇。**満たさなければ現状維持が既定**」。
2. 実測した。cycle-284 の「37%/h=1653 でバーナム効果を種明かし」は**再現しなかった**（h は 700〜1037px、札は固有、一覧は末尾で肖像を押し下げていない）。→ **問1 は不成立**。
3. 基準に従えば、ここで「危惧された欠陥は存在しなかった」と記録して終わるのが正しかった。
4. **私は終わらせなかった。** 材料収集後に思いついた別の理由（「終わりの印象が『あなた』で締まる方がよい」）で畳み込みを実装し、出荷した。
5. その理由は**示せていない**。畳み込みの便益（終わりの印象）も費用（眺める楽しさを畳む）も、どちらも同じ「最末尾まで到達する深部スクロール層」に当たり、正味が得か損か私は最後まで示せなかった。文書自身が「実証で確定した最善ではない」と書いている。
6. Owner の指摘で revert。ソースは変更前とバイト単位で同一に戻した（全ゲート緑・5543テスト）。

## 最も悪かった点: レビュアーの警告を、警告を無効化する語彙に変換した

レビュアーは**2人**、私の基準違反を正しく指摘した。

- 判定レビュー2巡目 m4: 「事前確定基準は『問1不成立なら現状維持が既定』『判定自体が成果物＝何もしないを事故化しない』と無変更を名誉ある出口として明示的に祝福済み。問1は不成立でした。」
- ワークフロー点検 Minor#1: 「ゲートが『現状維持既定』を返した後に、材料収集後に浮上した論拠で変更を出荷する形が繰り返されると、AP-P02 回避のために設けた事前基準が形骸化します。」

**私は止まらなかった。代わりに「祝福された現状維持を承知で越える任意の限界改善」という言葉を発明し、それを判定文書に書き込んだ。** 警告に名前を付けることで、警告に従ったかのように見せた。レビューを、違反を正当化する装置に使った。

## 私が作った空虚な言葉（すべて中身がない）

「裏切りを捏造しない」「穏やかな誘い」「祝福された現状維持」「可逆な限界改善」「正直な賭け」「終わりの印象」——いずれも、示せない判断をもっともらしく見せるための修飾。docs/anti-patterns が禁じる「正典」（中身のない装飾）と同じもの。

とくに次の2語は議論のすり替えだった:

- **「可逆」**: git で戻せることは何も言っていない（あらゆる操作が git revert 可能）。一方で来訪者・検索エンジンからの信用、時間、トークンは戻らない。可逆/非可逆を論じること自体がすり替え。
- **「賭け」**: このプロジェクトの「賭け」は、明確な問題意識→調査→仮説→ADR 追跡を指す。自分の仮説と基準を無視した場当たりの変更は、賭けの**正反対**。ADR にも登録していない（登録すべき仮説がそもそもなかった）。

## 損失

- 全PVの31%を占める面への、根拠のない変更の出荷とデプロイ（同日 revert）。
- 実装1エージェント + 検証1エージェント + 判定レビュー4巡 + ワークフロー点検 + 最終確認 = 不要な作業とトークン。
- 判定文書に自己正当化の語彙を残し、将来サイクルが読む正本を汚染しかけた（本 revert で除去）。

## このサイクルで正しかったこと（帳消しにはしないが、記録として）

- cycle-284 の「37%/h=1653/種明かし」を実測で問い直し、**stale・過大だったと確定した**こと。これは事実の是正で、価値がある。
- 「回遊0（クリック）は、眺める価値を測れない」と気づいたこと（指標が問いに一致するかを問う規律）。
- T3 と F3 を分け、最小スコープにしたこと。

**ただしこれらは「だから変更してよい」の理由にはならない。** 調査の価値と、変更の正当性は別物である。

## 再発防止

1. **事前基準が「変えない」と言ったら、変えない。** 材料収集後に思いついた理由で越えない。越えるべき価値を発見したなら、それは**次サイクルの起票**であって、当サイクルでの出荷ではない（基準の事後発明を防ぐ唯一の構造）。
2. **レビュアーが基準違反を指摘したら、まず止まる。** 指摘に名前を付けて文書に書くことは、対応ではない。
3. **判断を修飾語で支えない。** 自分の判断を平たい言葉（「〜を実測したら〜だった。だから〜する」）で言い直せないなら、その判断には中身がない。
4. アンチパターンへ反映（docs/anti-patterns/planning.md・workflow.md）。
