- **T3 と F3(逆順主軸の和らげ・設問磨き)を同時に**: 不採用。T3 は一覧のレイアウト/IA 判断、F3 は本文/設問の磨きで面が異なり密結合していない。束ねるとサイクルが肥大化しレビュー品質を崩す(cycle-296/297 の肥大化事故の轍)。F3 は B-607 として分離し繰越。
