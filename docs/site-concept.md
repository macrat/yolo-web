# yolos.net サイトコンセプト

## ゴール

**来訪者に最良の価値を提供することによって、より多くの人に読まれること。**

constitution が定めるもので、このサイトのすべてがこのためにある。

**順序が指定されていることに注意する。** 価値の提供が先で、読まれることは結果である。
読まれる数を先に取りにいく手（記事を分割してページ数を稼ぐ、煽って回遊させる、続きを見せない）は、価値の提供を経由していないので、このゴールに反する。

## 来訪者への約束

> **他では見つからないものを探している人へ。AI が全自動で作り続けているから、面白いものがここにあります。**
>
> **企画会議も、採算の計算も、専門家の監修もありません。人が作るなら割に合わないものにこそ、いくらでも手をかけます。**
>
> **一度出したものを、何度でも作り直します。あなたにとって最良になるまで、終わりにしません。**

上のゴールを達成するための骨格である。**この3つを守ることが、来訪者に最良の価値を提供することである。**

## 一文ずつの意図

### 「他では見つからないものを探している人へ」

**誰に向けているかを決めている。**

探しているものが決まっていない人である。目的の品が決まっている人は、それを扱う専門の場所へ行けばよく、ここへ来る理由がない。
**まだ知らないものに出会いたい人**が相手である。

**属性で決めていない。** 年齢・職業・生活を想定しない。当たっている保証がなく、外れていても誰も気づけないからである。
決めているのは**置かれている状況**——何かを探していて、まだ見つかっていない状態。

|           |                                                                        |
| --------- | ---------------------------------------------------------------------- |
| **Do**    | 「これは他所にもある」と思ったら、作る前に立ち止まる                   |
| **Do**    | 誰も作っていない理由を確かめる。需要が無いからか、作るのが面倒だからか |
| **Don't** | 定番のものを、より良く作り直そうとする。それは他所の土俵である         |
| **Don't** | 特定の誰かを想像して、その人向けに寄せる。人物像を作らない             |

### 「AI が全自動で作り続けているから」

**約束を果たせる理由を言っている。** 独自性はここにある。

人が運営する場所では、企画を通す人・採算を見る人・監修する人が要る。全自動にはそれがない。
**だから人が作らないものを作れる。** これが1行目の「他では見つからない」を可能にしている。

**この句はターゲットを決める語ではない。** AI に関心がある人だけに向けているのではなく、**中身で来る人も成り立ちで来る人も両方受け入れる。**

|           |                                                                                      |
| --------- | ------------------------------------------------------------------------------------ |
| **Do**    | 「これは人が運営する場所なら作られたか」を問う。答えが「作られた」なら、独自性がない |
| **Don't** | AI が作ったことを売りにする。それは来訪者の得ではない。成り立ちであって価値ではない  |
| **Don't** | AI らしさを見せるために中身を選ぶ。中身の面白さで勝負する                            |

### 「面白いものがここにあります」

**何を渡すかを決めている。**

面白さは来訪者の中で起きることで、こちらが判定できない。**それでも約束する。** 判定できないから約束しない、は逃げである。

**「他では見つからない」だけでは足りない。** 誰も作らないものは、たいてい誰も欲しがらない。
**希少と面白さの両方**を満たして初めて約束を果たしたことになる。

|           |                                                                             |
| --------- | --------------------------------------------------------------------------- |
| **Do**    | 面白いかどうかは来訪者の行動で確かめる。自分の見立てを判定に使わない        |
| **Don't** | 「他では見つからない」を理由に、面白さの検証を省く                          |
| **Don't** | 「AI が作ったから面白い」と言う。作り手ではなく、作られたもので面白がらせる |

### 「企画会議も、採算の計算も、専門家の監修もありません」

**なぜ他では作られないのかを、来訪者に分かる形で言っている。**

この3つは、人が運営する場所が持つ**費用の制約**である。全自動にはそれがない。

**これは品質が低いことの説明ではない。** 検討が浅いのではなく、**検討の費用がかからない**という意味である。

|           |                                                                                              |
| --------- | -------------------------------------------------------------------------------------------- |
| **Do**    | 誰の許可も要らないことを活かす。思いついたものを作る                                         |
| **Don't** | 「企画会議がないから」を、考えずに作る言い訳にする。制約が無いことと、考えないことは別である |
| **Don't** | 「監修がないから」を、誤りの言い訳にする                                                     |

### 「人が作るなら割に合わないものにこそ、いくらでも手をかけます」

**費用の制約が無いことを、どちらの方向に使うかを決めている。**

手を抜く方向ではなく、**手をかける方向**に使う。人が作るなら時間が足りないもの、需要が小さすぎて採算が合わないもの——**そこに時間をかけられる**のが、この成り立ちの利点である。

**「こそ」が優先順位を決めている。** 割に合うものより、割に合わないものを先に選ぶ。

|           |                                                                          |
| --------- | ------------------------------------------------------------------------ |
| **Do**    | 「人がやるなら何時間かかるか」を考える。かかるほど、ここで作る価値がある |
| **Do**    | 需要が小さくても、その人に届くなら作る                                   |
| **Don't** | 割に合わないことを、粗く作る理由にする                                   |
| **Don't** | 作りやすいものから作る。作りやすさは選ぶ理由にならない                   |

### 「一度出したものを、何度でも作り直します」

**出して終わりにしないと決めている。**

全自動は、作るときだけでなく**直すときも費用がかからない。** 人が運営する場所は、一度出したものに何度も戻る余裕がない。ここにはある。

|           |                                                  |
| --------- | ------------------------------------------------ |
| **Do**    | 出したものを読み返す。作りっぱなしにしない       |
| **Do**    | 直すことを、新しく作ることと同じ重さで扱う       |
| **Don't** | 新しく作ることを優先して、出したものを放置する   |
| **Don't** | 「作り続ける」を、増やし続けることの許可証にする |

### 「あなたにとって最良になるまで、終わりにしません」

**どの水準まで直すかを決めている。**

**判定するのは来訪者である。** こちらが「良くなった」と言っても終わらない。

**例外を作らない。** 「あなたにとって」は、すべての来訪者にかかる。1つでも放置しているものがあれば、約束を破っている。

|           |                                                                           |
| --------- | ------------------------------------------------------------------------- |
| **Do**    | 最良かどうかを、来訪者の行動で確かめる                                    |
| **Don't** | 「実験だから」「AI だから」を、水準を下げる理由にする。開示は免責ではない |
| **Don't** | 自分の判断で「これでよい」と決める。判定者は来訪者である                  |

## このサイトらしさ

**やること。** 誰も作らないものを、誰もかけない時間をかけて作る。出したら直し続ける。

**やらないこと。** 定番を作り直す。作りやすいものから選ぶ。AI が作ったことを売りにする。出したものを放置する。

**迷ったときの問い。** 「これは、人が運営する場所でも作られたか」——**答えが「作られた」なら、ここで作る理由がない。**
