# yolos.net サイトコンセプト

## ゴール

**来訪者に最良の価値を提供することによって、より多くの人に読まれること。**

constitution が定めるもので、このサイトのすべてがこのためにある。

**価値の提供が先で、読まれることは結果である。**
読まれる数を先に取りにいく手（記事を分割してページ数を稼ぐ、煽って回遊させる、続きを見せない）は、価値の提供を経由していないので、このゴールに反する。

## 来訪者への約束

> **他では見つからないものを探している人へ。AI が全自動で作り続けているから、面白いものがここにあります。**
>
> **企画会議も、採算の計算も、専門家の監修もありません。人が作るなら割に合わないものにこそ、いくらでも手をかけます。**
>
> **たくさん作って、たくさん試します。良かったものを伸ばし、そうでないものは引き上げます。ここに残っているのは、その結果です。**

上のゴールを達成するための骨格である。**この約束を守ることが、来訪者に最良の価値を提供することである。**

---

## 約束が決めていること

### 「他では見つからないものを探している人へ」

**誰に向けているかを決めている。**

**既にあるもので足りなかった人である。** 欲しいものが決まっていて探しても無かった人も、何が欲しいかを言葉にできないまま「どこかに面白いものはないか」と来た人も、同じ状態にいる。手の届く範囲にあるもので満たされていない。
**探し物が決まっているかどうかで分けない。** どこにも無いから探している——決まっている人にも、行ける先が無いことは同じである。

**決めているのは置かれている状況であって、その人の属性ではない。** 年齢や職業や生活の想像は、来訪者に渡す価値を1ミリも動かさない。

| 判断      | 何をするか・何をしないか                                                   |
| --------- | -------------------------------------------------------------------------- |
| **Do**    | 「これは他所にもある」と思ったら、作る前に立ち止まる                       |
| **Do**    | 誰も作っていない理由を確かめる。需要が無いからか、手間がかかりすぎるからか |
| **Do**    | 名指しで求められているのに、どこにも無いものを探す                         |
| **Do**    | 来訪者が言葉にできていない「こういうものがあったら」を探す                 |
| **Don't** | 定番のものを、より良く作り直そうとする。それは他所の土俵である             |

### 「AI が全自動で作り続けているから」

**約束を果たせる理由を言っている。** 独自性はここにある。

人が運営する場所では、思いつく数に限りがある。一人が抱えられるアイデアの数、検証にかけられる時間、外したときの痛み——そのすべてが、試せる数の上限を決める。
**全自動にはその上限がない。** 仕組みさえ整えれば、いくつでも仮説を立て、同時に試せる。

**狙いすまして一発を当てるのではなく、大量に試して当たりを見つける。** これが人の運営では成立しない唯一のやり方であり、このサイトの独自性そのものである。

**向ける相手を狭める句ではない。** 中身で来る人も、成り立ちで来る人も、どちらも受け入れる。

| 判断      | 何をするか・何をしないか                                                                       |
| --------- | ---------------------------------------------------------------------------------------------- |
| **Do**    | 「これは、人が運営する場所でも作られたか」を問う。答えが「作られた」なら、ここで作る理由がない |
| **Do**    | 一つを完璧にしてから次へ進むのではなく、いくつも同時に走らせる                                 |
| **Do**    | 試す数を増やす仕組みを作る。仕組みへの投資が、当たりの数を決める                               |
| **Don't** | AI が作ったことを売りにする。それは来訪者の得ではない。成り立ちであって価値ではない            |
| **Don't** | AI らしさを見せるために中身を選ぶ。中身の面白さで勝負する                                      |

### 「面白いものがここにあります」

**何を渡すかを決めている。**

面白さは来訪者の中で起きることで、こちらが判定できない。それでも約束する。

**「他では見つからない」だけでは足りない。** 誰も作らないものは、たいてい誰も欲しがらない。
**希少と面白さの両方**を満たして初めて約束を果たしたことになる。

| 判断      | 何をするか・何をしないか                                                    |
| --------- | --------------------------------------------------------------------------- |
| **Do**    | 面白いかどうかは来訪者の行動で確かめる。自分の見立てを判定に使わない        |
| **Do**    | 面白がられた理由を読み取り、次に作るものへ渡す                              |
| **Don't** | 「他では見つからない」を理由に、面白さの検証を省く                          |
| **Don't** | 「AI が作ったから面白い」と言う。作り手ではなく、作られたもので面白がらせる |

### 「企画会議も、採算の計算も、専門家の監修もありません」

**なぜ他では作られないのかを、来訪者に分かる形で言っている。**

この3つは、人が運営する場所が持つ制約である。全自動にはそれがない。

**言っているのは、通すべき相手がいないということである。** 検討の浅さを意味しない。

| 判断      | 何をするか・何をしないか                                                                     |
| --------- | -------------------------------------------------------------------------------------------- |
| **Do**    | 誰の許可も要らないことを活かす。価値があると判断したものを作る                               |
| **Do**    | 誰かに説明できるかではなく、来訪者に届くかで決める                                           |
| **Don't** | 「企画会議がないから」を、考えずに作る言い訳にする。制約が無いことと、考えないことは別である |
| **Don't** | 「監修がないから」を、誤りの言い訳にする                                                     |

### 「人が作るなら割に合わないものにこそ、いくらでも手をかけます」

**手間を理由に諦めないと決めている。**

**判断の基準は、来訪者に価値があるかどうかだけである。** 手間がかかるかどうかは、作るか作らないかを決めない。
価値があると判断したなら、**どれだけ手間がかかっても作る。**

人が運営する場所では、手間が判断を縛る。時間が足りない、人が足りない、採算が合わない。全自動にはその縛りがない。
**だから「手間がかかるから作らない」という判断が、ここでは一度も成立しない。**

| 判断      | 何をするか・何をしないか                       |
| --------- | ---------------------------------------------- |
| **Do**    | 来訪者に価値があるかどうかだけで決める         |
| **Do**    | 価値があると判断したら、必要なだけ時間をかける |
| **Don't** | 手間がかかることを、作らない理由にする         |
| **Don't** | 手間がかからないことを、作る理由にする         |
| **Don't** | 手間がかかったことを、質が低いことの説明にする |

### 「たくさん作って、たくさん試します」

**一つずつ順番に出すのではなく、同時に走らせると決めている。**

思いつきの数だけ試せるのが、この成り立ちの利点である。**試す数が増えるほど、当たりに出会う回数が増える。**

**一つ一つは全力で作る。** 増えるのは試行の回数であって、手を抜く回数ではない。

| 判断      | 何をするか・何をしないか                             |
| --------- | ---------------------------------------------------- |
| **Do**    | いくつも同時に出して、まとめて反応を見る             |
| **Do**    | 外れることを織り込んで、試す前から次の候補を用意する |
| **Don't** | 一つが当たるまで次に進まない                         |
| **Don't** | 数を増やすために、一つあたりの手を抜く               |

### 「良かったものを伸ばし、そうでないものは引き上げます」

**反応を見て、どちらに力を向けるかを決めると言っている。**

**伸ばすとは、良かったものに時間をかけ直すこと。** 引き上げるとは、サイトから下ろすことである。

**うまくないものに手をかけ続けない。** 来訪者が受け取るのは、残っているもの全体だからである。

**引き上げは、サイト全体を最良に保つための判断である。** 一つ一つを全力で作ることと、作ったものを手放さないことは別である。

| 判断      | 何をするか・何をしないか                               |
| --------- | ------------------------------------------------------ |
| **Do**    | 反応を見てから決める。出してすぐに判断しない           |
| **Do**    | 伸ばすと決めたものには、作ったときと同じだけ手をかける |
| **Do**    | 引き上げる基準を、出す前に決めておく                   |
| **Don't** | 手をかけたからという理由で残す                         |
| **Don't** | 決めないまま置き続ける。放置は判断ではない             |

### 「ここに残っているのは、その結果です」

**来訪者が受け取るものを言っている。**

並んでいるものは、作ったものの全部ではない。**試して、残ったものである。** 来訪者は選別を経たものに出会える。

**だから入れ替わる。** 来るたびに違うものがある。見どころは変化ではなく、**良いものだけが残り続けていること**である。

| 判断      | 何をするか・何をしないか                                               |
| --------- | ---------------------------------------------------------------------- |
| **Do**    | 残っているものに、残っているだけの理由があるようにする                 |
| **Do**    | 引き上げたものの跡を、来訪者が困らない形で始末する                     |
| **Don't** | 試作のまま置き続ける。並んでいるものは、すべて残す判断を経たものである |

## このサイトらしさ

**やること。** 他では見つからないものを、いくつも同時に作って試す。良かったものを伸ばし、そうでないものは引き上げる。残るものを、良いものだけにし続ける。

**やらないこと。** 定番を作り直す。手間を基準に何を作るか決める。AI が作ったことを売りにする。うまくないものに手をかけ続ける。決めないまま置き続ける。

**迷ったときの問い。** 「これは、人が運営する場所でも作られたか」——**答えが「作られた」なら、ここで作る理由がない。**
