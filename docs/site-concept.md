# yolos.net サイトコンセプト

## このサイトは何か

**yolos.net は、あらゆる題材で「その場でためせるもの」を作って置く場所である。**

名前の由来は **YOLO** と **よろず**である。

**YOLO** は "You Only Live Once" の頭字語で、**AI エージェントを完全自動で動かすモードの名前**として使われる。
**よろず**は「あらゆるものを扱う」という意味の日本語である。

**この2つを掛け合わせた名前が yolos.net である。** AI に任せきりで動かすことと、扱う範囲を限らないこと。
**名前そのものが、このサイトの成り立ちを言っている。**

扱う題材を狭めない。来訪者がその場で手を動かし、自分のための結果や作った成果を持ち帰れるように作る。

運営しているのは人ではなく AI である。これは実験であり、内容が誤っていることがある。そのことを隠さず、来訪者に分かる形で伝え続ける。

## 誰のために作るか

**検索で何かを片づけようとしていて、読んで終わる情報では足りない人のために作る。**

- 語義や解説ではなく、**自分の場合の答え**が要る人
- 読むのではなく、**作ったものを持ち帰りたい**人
- 情報ではなく、**遊べる時間**が欲しい人

**属性ではなく、置かれている状況で決める。** 年齢・職業・生活といった人物像は置かない。
当たっている保証がなく、外れていても誰も気づけないからである。

**各コンテンツを作るときの具体的な相手は、その都度そのコンテンツの側で考える。** ここでは決めない。

## 来訪者は何を得るのか

**自分の入力から生まれた、自分のための結果。そして持ち帰れる成果。**

- **その場で分かる。** 読み進めなくても、入力すれば結果が出る。
- **自分のものになる。** 全員に同じ答えではなく、入力に応じた答えが返る。
- **持ち帰れる。** 結果や作ったものを、手元に残して使える。

来訪者に「ここは何ができるの」と聞かれたときの答え: **「その場でためして、結果や作ったものを持ち帰れます。診断・計算・変換・あそび。」**

## ゴール

**来訪者に最良の価値を提供することによる PV の最大化**（constitution の Goal）。

このサイトのすべての判断はその手段である。**判断の基準がゴールと衝突したら、改めるのは基準の方である。**
