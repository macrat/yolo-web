# ADR007: 掲載数のしきい値を撤廃し全タグにページを用意する

- 状態: 確定（adopted）
- 起票日 / 確定日: 2026-09-14 ／ 2026-09-14
- 決定: タグページの存在を掲載記事数で絞るのをやめ、記事に書かれたすべてのタグにページを用意する。
  同時に、検索エンジンへの申告は絞ったままにする——掲載5本未満のタグページは `noindex, follow` とし、
  `sitemap.xml` にも載せない。

  **この決定の芯は「読者への到達性」と「検索エンジンへの申告」を別の問題として扱うことである。**
  従来は1つのしきい値が両方を決めていた。ページを作るかどうか（＝読者が辿り着けるか）と、
  索引を許すかどうか（＝薄いページを検索結果に出すか）は、答えが違ってよい。

- 根拠:
  - 撤廃前は掲載3本未満のタグにページが無く、9記事で著者の書いたタグがリンクにならず読者から見えなかった
    （[cycle-313/measurements.md §14](../../../cycles/cycle-313/measurements.md#14-タグページを持たないタグが読者から隠れていた)）。
    届かないタグは、書かれていないのと同じである。
  - タグページは29から37へ増えた。新規8ページはすべて `noindex, follow`。
    `sitemap.xml` のタグURLは23で変化なし（実測）。**読者向けの面だけが増え、申告は増えていない。**
  - 実装は `MIN_POSTS_FOR_TAG_PAGE` の撤廃と `MIN_POSTS_FOR_TAG_INDEX = 5`（索引可否）の維持で、
    `TagList` の `linkableTags` は廃した（`f9526235`・`9b6b9aaf`・`0b538a3e`）。

- 観測は行わない。
  **この決定の来訪者価値の仮説（著者の付けた分類は読者にとっても入口になる）を測る計器が無い。**
  新設ページは `noindex` なので Search Console の検索流入は構造的にほぼ0になり、
  残る内部クリックは GA4 でしか見えないが n が小さく単独の根拠にならない。
  「タグページ以外の表示回数が落ちていないか」なら SC で測れるが、それは害が出ていないかの検査であって、
  入口として意味があるかという問いを測っていない。**測れない仮説に観測窓と撤退基準を付けない。**

- この決定を覆すとき:
  掲載の少ないタグページが読者の役に立っていないと判断する材料が出た場合、
  **しきい値を戻すのではなく `/blog/tags` の索引ページを作って薄いページを集約する**方向を先に検討する。
  しきい値を戻すと、9記事で読者からタグが消える状態に戻るためである。
  この面の情報設計は [B-710](../../../backlog.md)（掲載の少ないタグページに横へ広がる道が無い）と
  [B-711](../../../backlog.md)（押せるタグと押せない値札が見分けられない）が扱う。

- 付記: この変更は cycle-313 が選んだ作業（B-685＝パーサが frontmatter を読めず値が空配列に落ちるバグ）の
  範囲外である。バグ修正の途中で設計判断を挟んだこと自体が逸脱であり、その経緯は
  [cycle-313/incident-3.md](../../../cycles/cycle-313/incident-3.md) にある。
