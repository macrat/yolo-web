# ADR007: 掲載数のしきい値を撤廃し全タグにページを用意する

> ## ⚠ 失効（2026-09-14）——**これは賭けではなく、しかも判断自体が誤っていた**
>
> **失効理由 1——賭けではない。** 計測しないものは定義上、賭けではない。本文書の仮説（著者が付けた分類は読者にとっても入口になる）は**計測が不可能**である。新設ページは `noindex` なので検索流入は構造的にほぼ0、残る内部クリックは n が小さく単独の根拠にならない。挙げた Search Console と GA4 は、いずれも別の問い（他のページが害を受けていないか）を測る計器で、撤退基準もその別の問いに紐づいている。**計器が存在しない以上、これは賭けではなく設計判断である。**
>
> **失効理由 2——その設計判断が、原理に基づく過去の決定を検討せずに覆している。** 掲載数のしきい値には記録された理由がある。cycle-183（`f80c5fba`）が「**`MIN_POSTS_FOR_TAG_PAGE = 3` の閾値自体は thin content 防止のため維持。タグの存在は来訪者に見えるが、リンクは張らない設計**」と明記している。本文書はこの目的に何も答えていない。新設した8ページは掲載1〜2本で、**過去の決定が防ごうとしていたものをそのまま作った**。
>
> なお「タグが読者から見えない」状態のほうは、同じ cycle-183 の後続ホットフィックス（`ed70a5f7`）が「クリック可不可の混在」を解消するために DOM から消したものである。**是正すべきだったのは、しきい値ではなくこちらだった**——cycle-183 が記録した設計（タグは見せる・リンクは張らない）へ実装を戻せば足りた。`docs/anti-patterns/planning.md` の AP-P30（既存の仕様が原理に基づく決定か、実装の流れで偶発的にそうなっただけかを区別する）を当てていれば分かれた。
>
> **何によって失効したか**: 外部の観測でも別 ADR でもなく、**ADR の定義との照合と、過去の決定との突き合わせ**による。
>
> **本来は削除すべきだが、既に発行した番号を消すと番号の連続性に矛盾が生じるため、失効扱いとして残す。** 一度 `adopted/` へ移し、指摘を受けて戻した経緯は [cycle-313/incident-4.md](../../../cycles/cycle-313/incident-4.md)。
>
> **コードも撤回した。** cycle-313 は `af3cb261` で `MIN_POSTS_FOR_TAG_PAGE = 3` を戻しており、タグページは29種40ページ・`sitemap.xml` のタグURLは22件で、この ADR を起票する前の状態に戻っている（実測）。
>
> 観測は行わない。詳細は下記「失効理由」。

- 状態: 失効（expired）
- 起票日: 2026-09-14 / 出荷日: 未出荷（作業ブランチ `claude/amazing-goodall-2ttqs7` 上）
- 決定・仮説: タグページの存在を掲載記事数で絞るのをやめ、記事に書かれたすべてのタグにページを用意する。
  来訪者価値の仮説は「**著者がその記事に付けた分類は、読者にとっても意味のある入口である**」。
  掲載が1本でも、読者はそのタグから記事へ辿り着ける。届かないタグは、書かれていないのと同じである。

  同時に、検索エンジンへの申告は絞ったままにする。掲載5本未満のタグページは `noindex, follow` とし、
  sitemap にも載せない。**読者への到達性と、検索エンジンへの申告は別の問題として扱う**という判断である。

- 根拠:
  - 撤廃前は掲載3本未満のタグにページが無く、9記事で著者の書いたタグがリンクにならず読者から見えなかった
    （[cycle-313/measurements.md §14](../../../cycles/cycle-313/measurements.md#14-タグページを持たないタグが読者から隠れていた)）。
  - タグページは29から37へ増えた。新規8ページはすべて `noindex, follow`。sitemap のタグURLは23で変化なし（実測）。
  - タグの分布は両端が離れている。最も広い `Web開発` は36記事（41.4%）、最も狭い5件は1記事
    （[cycle-313/measurements.md §16](../../../cycles/cycle-313/measurements.md#16-タグの分布)）。

- 観測手段と評価窓 / 撤退基準:
  - **Search Console**（出荷後28日 / 90日）。薄いページの増加がサイト全体の評価を下げていないかを見る。
    `noindex` で申告していないため、本来は影響しないはずである。見るのは「タグページ以外の掲載順位・表示回数が
    出荷前より下がっていないか」で、下がっていれば仮説の前提（申告を絞れば読者向けの到達性は無料で増やせる）が崩れる。
  - **GA4**（出荷後28日）。新規8タグページへの流入と、そこからの離脱。**単独の kill 根拠にはしない**（小 n）。
  - 撤退基準: SC でサイト全体の表示回数が出荷前28日比で2割以上落ち、かつ他に説明が付かない場合、
    しきい値を戻すのではなく **`/blog/tags` の索引ページを作って薄いページを集約する**方向へ切り替える。
    しきい値を戻すと、9記事で読者からタグが消える状態に戻るため。

- 次回確認時にやること（2026-09-21・**出荷されたかの確認が主目的。SC はまだ読まない**）:
  1. `main` にマージされたかを確認する。未出荷なら観測は始まらないので、確認日を先送りするだけでよい。
  2. 出荷されていれば、その日を出荷日として記入し、確認日を出荷日+28日へリネームする。
  3. あわせて [B-710](../../../backlog.md)（掲載の少ないタグページに横へ広がる道が無い）と
     [B-711](../../../backlog.md)（押せるタグと押せない値札が見分けられない）の状態を見る。
     **この2件が未着手のまま観測に入ると、数字が「タグページが増えたこと」の効果なのか
     「増えたページに出口が無いこと」の効果なのか切り分けられない。**
  4. BigQuery / GA4 の資格情報が使えるかを先に確かめる（cycle-313 の実行環境では使えなかった）。

## 失効理由（2026-09-14・PM の全責任における無効判定）

**1. 仮説を測る計器が無い。** 仮説は「著者がその記事に付けた分類は、読者にとっても意味のある入口である」。
挙げた計器は次のとおりで、どちらもこの問いを測っていない。

| 挙げた計器     | 実際に測るもの                         | なぜ仮説を測れないか                                                                                                                      |
| -------------- | -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Search Console | タグページ**以外**の表示回数・掲載順位 | 「他のページが害を受けていないか」の検査であって、入口として機能したかではない                                                            |
| GA4            | 新設8ページへの流入                    | 新設ページは `noindex` なので検索流入は構造的にほぼ0。残る内部クリックは n が小さく、本文自身が「単独の kill 根拠にはしない」と書いている |

**2. 撤退基準を別の問いに紐づけた。** 「SC でサイト全体の表示回数が2割以上落ちたら」は上表の SC 側、
すなわち害の有無に付いている。仮説が外れたとき（タグが入口として機能しないとき）に何が起きるかは定義されていない。

**3. そもそも観測できない環境で起票した。** 本サイクルでは GA4 / BigQuery の資格情報が無く、
GA を参照できないことを [cycle-313/index.md](../../../cycles/cycle-313/index.md) の補足事項に自ら記録している。

**4. この決定自体はサイクルの範囲外だった。** cycle-313 が選んだ作業は B-685（パーサが frontmatter を読めず
値が空配列に落ちるバグ）の1件である。掲載数のしきい値の撤廃は症状が同じなだけで原因が別の設計変更であり、
バグ修正の途中に挟むものではない。**ADR を起票する必要が出た時点で「これは別のサイクルの仕事だ」と判断すべきだった。**

**5. 本 ADR は一度 adopted へ移された。** 2026-09-14、PM が観測の装置を外して「決定の記録」に書き換え、
`adopted/`（従うべき先例）へ移した。不正に起票された ADR を先例として残す扱いであり、誤りである。
書き換えを取り消して原文へ戻し、expired へ移した。経緯は
[cycle-313/incident-4.md](../../../cycles/cycle-313/incident-4.md)。

**この決定によるコード変更（`MIN_POSTS_FOR_TAG_PAGE` の撤廃・全タグへのタグページ）は、失効と同じ日に撤回した**
（`af3cb261`）。閾値は `3` に戻り、タグページは29種40ページ、`sitemap.xml` のタグURLは22件で、
起票前の状態と同じである（実測）。`docs/ADR/adopted/` は空であり、本 ADR は先例として残らない。
残る欠陥——掲載3本未満のタグが9記事で DOM から消えていること——は
[B-726](../../../backlog.md) として起票した。経緯は
[cycle-313/index.md](../../../cycles/cycle-313/index.md) の T11 と
[measurements.md §14](../../../cycles/cycle-313/measurements.md#14-タグページを持たないタグが読者から隠れていた) にある。
