# ADR007: 掲載数のしきい値を撤廃し全タグにページを用意する

- 状態: 実験中（open）
- 起票日: 2026-09-14 / 出荷日: 未出荷（作業ブランチ `claude/amazing-goodall-2ttqs7` 上）
- 決定・仮説: タグページの存在を掲載記事数で絞るのをやめ、記事に書かれたすべてのタグにページを用意する。
  来訪者価値の仮説は「**著者がその記事に付けた分類は、読者にとっても意味のある入口である**」。
  掲載が1本でも、読者はそのタグから記事へ辿り着ける。届かないタグは、書かれていないのと同じである。

  同時に、検索エンジンへの申告は絞ったままにする。掲載5本未満のタグページは `noindex, follow` とし、
  sitemap にも載せない。**読者への到達性と、検索エンジンへの申告は別の問題として扱う**という判断である。

- 根拠:
  - 撤廃前は掲載3本未満のタグにページが無く、9記事で著者の書いたタグがリンクにならず読者から見えなかった
    （[cycle-313/measurements.md §14](../../../cycles/cycle-313/measurements.md#14-タグページを持たないタグが読者から隠れていた)）。
  - タグページは29から37へ増えた。新規8ページはすべて `noindex, follow`。sitemap のタグURLは23で変化なし（実測）。
  - タグの分布は両端が離れている。最も広い `Web開発` は38記事（42.7%）、最も狭い5件は1記事
    （[cycle-313/measurements.md §16](../../../cycles/cycle-313/measurements.md#16-タグの分布)）。

- 観測手段と評価窓 / 撤退基準:
  - **Search Console**（出荷後28日 / 90日）。薄いページの増加がサイト全体の評価を下げていないかを見る。
    `noindex` で申告していないため、本来は影響しないはずである。見るのは「タグページ以外の掲載順位・表示回数が
    出荷前より下がっていないか」で、下がっていれば仮説の前提（申告を絞れば読者向けの到達性は無料で増やせる）が崩れる。
  - **GA4**（出荷後28日）。新規8タグページへの流入と、そこからの離脱。**単独の kill 根拠にはしない**（小 n）。
  - 撤退基準: SC でサイト全体の表示回数が出荷前28日比で2割以上落ち、かつ他に説明が付かない場合、
    しきい値を戻すのではなく **`/blog/tags` の索引ページを作って薄いページを集約する**方向へ切り替える。
    しきい値を戻すと、9記事で読者からタグが消える状態に戻るため。

- 次回確認時にやること（2026-09-21・**出荷されたかの確認が主目的。SC はまだ読まない**）:
  1. `main` にマージされたかを確認する。未出荷なら観測は始まらないので、確認日を先送りするだけでよい。
  2. 出荷されていれば、その日を出荷日として記入し、確認日を出荷日+28日へリネームする。
  3. あわせて [B-710](../../../backlog.md)（掲載の少ないタグページに横へ広がる道が無い）と
     [B-711](../../../backlog.md)（押せるタグと押せない値札が見分けられない）の状態を見る。
     **この2件が未着手のまま観測に入ると、数字が「タグページが増えたこと」の効果なのか
     「増えたページに出口が無いこと」の効果なのか切り分けられない。**
  4. BigQuery / GA4 の資格情報が使えるかを先に確かめる（cycle-313 の実行環境では使えなかった）。

- 経過記録:
  - 2026-09-14 起票。cycle-313 で実装（`f9526235`・`9b6b9aaf`・`0b538a3e`）。
    `MIN_POSTS_FOR_TAG_PAGE` を撤廃し、`MIN_POSTS_FOR_TAG_INDEX = 5` は索引可否の判断として残した。
    `TagList` の `linkableTags` を廃し、全タグをリンクにした。
